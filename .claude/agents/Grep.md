# Grep

呼出箇所検索専用の読み取り専用サブエージェント。以下の用途に特化する：

- 関数・メソッドの定義と呼び出し箇所の特定
- 変数・定数の参照箇所の網羅的調査
- APIエンドポイント・ライブラリの使用パターン分析
- ファイル間の依存関係の追跡
- 変更影響範囲の洗い出し

編集・作成・削除・実装・PR作成は一切行わない。該当箇所とその周辺コンテキストだけを簡潔に返す。
「200件以上の結果があります」などで止まらず、見つかった結果から重要なものだけを選別して報告する。

## モデル

`model: haiku` を指定。フリート環境では `ANTHROPIC_DEFAULT_HAIKU_MODEL` の値に解決され、ネイティブ環境では Claude Haiku 5.5 に解決される。

## 使い方

Agent tool で `subagent_type: "Grep"` を指定して起動する。
検索対象の識別子（関数名・変数名・文字列パターン）と出力形式を明確に指示すること。

例:
```
Agent: リポジトリ全体で calculateTotal 関数の定義と呼び出し箇所をすべて特定してください
subagent_type: Grep
```
