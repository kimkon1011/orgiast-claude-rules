# X-0048: AI見出し構成の人とAI役割分担 — ニーズ抽出・競合分析をAI、個別調整を人間が担当

> AIニュース提案 2026-11-17

> 基: [X-0051 見出しの型とAI校正](ai-news-x0051-gemini-decision-1.md)

## 概要

AI見出し構成の人とAI役割分担（AI-Human Headline Collaboration）は、SEO記事・LP・イベントページの見出し作成において、AIにニーズ分析・競合見出し抽出・見出し案の大量生成を行わせ、人間が業界固有のニーズ補完とクリエイティブ判断を注入する4段階の分業モデルである。

AIが得意とする「大量データの高速処理」と「パターン認識」を活用しつつ、人間にしかできない「業界知識の注入」と「ブランド視点の調整」を組み合わせることで、SEO効果と人間のクリック意欲の両立を実現する。

```
[AIO: ニーズ分析 → 競合抽出 → 見出し生成] → [Human: ニーズ補完 → 調整 → 仕上げ]
```

## なぜ見出しに人とAIの分担が必要か

### AIの得意領域
- **大量処理**: 100サイト以上の見出しを数秒で収集・分析可能
- **パターン認識**: 「How-to型」「リスト型」「数字入り型」など、よく使われる表現パターンを自動分類
- **多言語対応**: 英語・中国語の競合サイトも同一プロセスで処理可能
- **コスト**: 1テーマ数十円〜数百円

### 人間の得意領域
- **業界知識**: 展示会なら「小間サイズ」「予算レンジ」「カスタムデザインの選択肢」などAIが知り得ない情報
- **独自の角度**: 「競合A社は3Dパースを全面に押している → 自社は施工事例のビフォーアフターで差別化」のような戦略的判断
- **クライアント視点**: 実際の顧客からの声・クレーム・要望を見出しに反映
- **クリエイティブ**: 「この見出しはターゲットに響くか」の最終判断

見出しはSEOの評価対象であると同時に、人間がクリックするかどうかの第一印象でもある。AIの機械的最適化だけでは不十分で、人間の共感を呼ぶ要素が必要。

## ワークフロー: 4段階の役割分担

### Phase 1: ニーズ分析（AI）
AIがターゲットキーワードからユーザーニーズを推定する。

**入力**: ターゲットKW（例: 「展示会 ブース 制作」「小規模ブース デザイン」）
**処理**: 
- 関連キーワードの拡張（Google Keywords Planner / 関連検索ワード）
- 検索意図の分類（情報収集 / 比較検討 / 購入意向）
- ペルソナの推定（担当者レベル / 役職 / 業種）
**出力**: ニーズ分析レポート（200〜300字）

**使用例（DeepSeek/Gemini）**:
```
あなたはSEO分析の専門家です。キーワード「{KW}」について以下を分析してください：
1. 検索ユーザーのニーズ（情報収集・比較・購入の3軸）
2. 想定されるペルソナ（役職・業種・課題）
3. 記事でカバーすべき関連トピック5つ
```

### Phase 2: 競合見出し抽出（AI）
AIが検索結果上位サイトから見出し構造を抽出しパターン分析する。

**入力**: 検索結果上位5〜10サイトのURL
**処理**:
- 各ページのtitleタグ・h1〜h3を抽出
- 表現パターンの分類（How-to型 / リスト型 / 質問型 / 数字入り型 / 比較型 / ベネフィット型）
- 「よく使われる表現」と「未使用の角度」の特定
**出力**: 競合見出し分析表（型別に整理）

**使用例（DeepSeek/Gemini）**:
```
以下のURLのh1〜h3を抽出し、パターン別に分類してください：

{URL1}
{URL2}
{URL3}
...

分類基準：
- How-to型: 「〜する方法」「〜のやり方」
- リスト型: 「N個の〜」「〜まとめ」
- 質問型: 「〜とは？」「なぜ〜？」
- 数字入り型: 「N万円で〜」「N社が〜」
- 比較型: 「A vs B」「〜と〜の違い」
- ベネフィット型: 「〜できる」「〜を実現」
```

### Phase 3: 見出し案生成（AI）
Phase1・2の分析結果をもとに、AIが大量の見出し案を生成する。

**入力**: ニーズ分析レポート + 競合見出し分析表
**処理**:
- h1（タイトル）候補 10案
- h2候補 30案
- h3候補 10案
- 型別に分類して出力
**出力**: 見出し案一覧（50案）

**使用例（DeepSeek/Gemini）**:
```
あなたはSEO見出し作成の専門家です。以下の情報をもとに、{記事のテーマ}の見出し案を作成してください。

【ニーズ分析】
{Phase1の出力}

【競合見出し分析】
{Phase2の出力}

以下の形式で50案を出力：
- h1: 10案（タイトル候補）
- h2: 30案（セクション見出し）
- h3: 10案（詳細見出し）
- 各案には型ラベルを付与（How-to / リスト / 質問 / 数字入り / 比較 / ベネフィット）
```

### Phase 4: 人間による調整（人間）
人間（SEO担当・広告運用者）が以下を注入して仕上げる。

**チェックリスト**:
- [ ] ブースサイズの数値は正しいか（例: 3m×3m小間 / 6m×9m大規模ブース）
- [ ] 予算範囲は適切か（例: 「100万円から」の記載があれば実現可能な範囲か）
- [ ] 競合との差別化点は入っているか
- [ ] ターゲット顧客に響く表現か（B2B向け？それとも来場者向け？）
- [ ] ブランドトーンと一致するか
- [ ] 事実誤認がないか（AIが生成した数字や事例の真偽）
- [ ] 法的に問題ない表現がないか（誇大表現・他社との比較表現）
- [ ] サイト全体の見出し構造と重複・矛盾がないか

**人間が注入するもの**:
- 業界特有のニーズ（展示会ならブースサイズの推奨値、予算レンジ、カスタムデザインの選択肢）
- 競合と差別化する独自の角度（自社の強み・実績・事例）
- クライアントの声や現場からのフィードバック
- 最終的なクリエイティブ判断（「この見出しはターゲット顧客に響くか」）

## オージャストでの適用シナリオ

### 展示会ブース制作ページ
AIが「展示会 ブース 制作 費用」「小規模ブース デザイン」「イベント ブース 施工」などのKWから競合見出しを抽出・分析。人間が「小規模ブース（3m×3m）でも存在感を出すデザイン」「初出展でも安心のサポート体制」のような具体的ニーズを追加して最適化する。

### イベント関連ページ
AIが同規模・同種イベントの見出し傾向を分析。人間が「来場者参加型の体験ブース」「SNS映えするフォトスポット設置」など自社の独自性を追加。

### 業種別事例ページ
AIが業界ごとの見出しパターンを抽出。人間が実際の施工事例の写真・数値データを元に具体性を追加（例: 「某医療機器メーカーA社の展示ブース—来場者数前年比150%」）。

### 制作の問い合わせ・見積りページ
AIがサイト訪問者の検索意図から見出し案を生成。人間が問い合わせ獲得に有効なCTA（お問い合わせ／資料請求／無料相談）を選定。

## 類似手法との比較

| アプローチ | AIの担当 | 人間の担当 | 効果 | 欠点 |
|-----------|---------|-----------|------|------|
| AI完全生成 | すべて | なし | 速い、コスト低 | 独自性に欠ける、事実誤認のリスク |
| 人間のみ | なし | すべて | 独自性が高い | コスト高、スケールしない |
| **本提案（AI+人間分担）** | ニーズ分析・競合抽出・案生成 | ニーズ補完・お手本選び・仕上げ | スケール＋独自性の両立 | 調整コストがかかる |
| AI生成→人間レビュー | すべて | レビューのみ | 品質安定 | レビュー負荷が高く、AI案に引っ張られる |
