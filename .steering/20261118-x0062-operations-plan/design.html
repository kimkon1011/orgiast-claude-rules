X-0062 ⑤ 運用案（GAS定期実行化の検討含む） — 設計

作成: 2026-11-18 | ステータス: 初版

1. 採用案の概要

ハイブリッド運用を採用する：

要素方式理由
Phase 1（KW収集）CI cron（GitHub Actions）CLIスクリプト完結、GAS経由のオーバーヘッド不要
Phase 2（ChatGPT評価）人間操作（入力フォーマットは自動生成）ChatGPTはAPI自動化対象外、ブラウザ操作が必要
Phase 3（提案生成）CI cron + GAS併用提案ファイル生成はCI、一覧管理と通知はGAS
Phase 4（記事化判断）人間判断判断は人間にしかできない
Phase 5（効果検証）CI cron + GASデータ収集はCI、可視化とレポートはGAS

3. GASアーキテクチャ（提案管理）

3.1 GASプロジェクト構成

新規GASプロジェクト gas/news-theme-proposals/ を作成：

ファイル役割
appsscript.jsonGAS設定（spreadsheets/drive/external_request OAuth）
Setup.gs初回セットアップ（シート自動作成・トリガー設定）
ProposalSheet.gs提案一覧シート操作（追加・更新・状態変更）
DiscordNotify.gsDiscord Webhook通知
CommandQueue.gsコマンドキュー（既存パターン流用）

3.2 Google Sheets構造

    シート名: AIニュース提案管理
    スプレッドシートID: 新規作成（初回セットアップ時）

    | 列 | 説明 |
    |---|---|
    | A: 提案ID | x0062-yyyymmdd-nn 形式 |
    | B: キーワード | 提案の元となったKW |
    | C: 検索意図 | ChatGPT評価結果 |
    | D: 判定 | 新規記事/追記/対象外 |
    | E: 優先度 | 高/中/低 |
    | F: 推奨タイトル | 新規記事向きの場合 |
    | G: 状態 | 未着手/進行中/完了/スキップ |
    | H: 作成日 | 提案生成日 |
    | I: 記事化日 | 実際に記事化した日 |
    | J: 備考 | 自由メモ |

3.3 GAS定期実行トリガー

スケジュール処理方式
每月1日 09:00提案ファイルの存在確認→Discord通知GAS time-driven trigger
每月5日 09:00未着手提案のリマインダー通知GAS time-driven trigger
月末 23:00当月の運用状態サマリ生成GAS time-driven trigger

4. CI cron構成

GitHub Actions workflow .github/workflows/ai-news-pipeline.yml を新規作成：

項目設定
スケジュール0 0 1 * *（每月1日 00:00 UTC = 09:00 JST）
ジョブ1: kw-collectnode seo/x0057-ai-news-pipeline.mjs --mode full
ジョブ2: proposal-commit出力をコミット・プッシュ
ジョブ3: chatgpt-format-genChatGPT入力フォーマットを生成
ジョブ4: notifyDiscord/GAS通知

5. データフロー

7. 通知設計

Phase 3完了Discord #ai-news提案一覧・優先度高件数
遅延警告Discord @kim遅延内容・想定影響

8. セキュリティ

  • GASスクリプトプロパティでAPIキー・Webhook URLを管理
  • コード内に秘匿値を直接記述しない
  • CIのGitHub Secretsに必要なトークンを保存
  • GASの実行権限はMYSELF（デプロイ者のみ）に制限

9. UI影響

UI変更なし。 本設計はバックエンドの運用自動化と通知設計のみを対象とし、ユーザー向け画面の変更を一切含まない。
