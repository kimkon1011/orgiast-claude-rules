要求定義: 車両運行管理アプリ

作成: 2026-11-27 | 更新: 2026-11-27

1. 概要

既存の Google Sheets ベース車検台帳（vehicleSheetId: 1mo8-hSCA-qDgblGBND-mjPEAF5fZ73etoz_mPeMZMLA）と期限台帳の車両データを、Web UI で一元管理するアプリケーション。

現在は tools/vehicle-inspection-watch.mjs が CLI で車検期限を監視し kim-inbox へ通知するのみ。管理担当者が Web 画面で直感的に確認・操作できるようにする。

2. ターゲットユーザー

  • 管理担当者（社用車の運行管理を行うメンバー）
  • 管理者（kim）：全車両の状態を俯瞰し、期限切れ・未手配を把握

3. ユーザーストーリー

#ストーリー優先度
1管理担当者はダッシュボードで全車両の一覧と状態を一目で確認したい高
2管理担当者は車検期限が近い車両をフィルタして確認したい高
3管理担当者は新しい車両を台帳に追加したい高
4管理担当者は既存車両の情報（保管場所・状態等）を編集したい高
5管理担当者は車検の進捗状態を更新したい高
6管理者は過去の車検履歴を参照したい中
7管理担当者は車検依頼先に自動で連絡したい低

4. 機能要件

  1. ダッシュボード画面: 全車両数／期限切れ／今月期限／未手配のサマリ表示
  2. 車両一覧画面: 表形式で全車両表示（ソート・フィルタ可能）
  3. 車両詳細画面: 個別車両の全項目表示・編集フォーム
  4. 車両登録: 新規車両の追加フォーム（バリデーション付き）
  5. 状態管理: 車検の状態遷移（未手配→見積依頼中→予約済→入庫中→完了→次回）
  6. 期限カレンダー: カレンダー表示で期限を視覚化

5. 非機能要件

  • Google Sheets をバックエンドデータストアとして使用（既存台帳とリアルタイム同期）
  • 認証は Google OAuth 2.0（既存の Google Workspace アカウントでログイン）
  • レスポンシブ対応（PC / スマホ）
  • 画面遷移は最小限、直感的な操作

6. 制約事項

  • 既存の車検台帳シートの構造を変更しない（互換性維持）
  • 既存の vehicle-inspection-watch.mjs の CLI 動作に影響を与えない
  • Google Apps Script（GAS）をバックエンドに使用可能

7. 受け入れ条件

  • 既存の車検台帳の全レコードが Web UI で参照できる
  • 車検期限30日以内の車両がダッシュボードで強調表示される
  • 新規車両の追加・編集が Web 画面上から可能である
  • 状態変更がリアルタイムで Google Sheets に反映される
