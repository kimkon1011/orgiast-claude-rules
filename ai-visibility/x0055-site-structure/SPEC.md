# X-0055: AI引用を増やすサイト構造最適化 仕様書

> AIニュース提案 [X-0055] の実装仕様。サービス別・ロケーションページ、FAQ、構造化データ、著者資格を追加し、orgiast.jp の AI からの引用率を向上させる。

**関連**: X-0007 (FAQ構造化データ), X-0056 (前倒しコンテンツ構造), phase2-schema-spec.md (基本スキーマ)

---

## 1. 背景と根拠

### 1.1 問題

X-0007 PHASE1 スコアリング (2026-11-08) で判明:
- **会社名なし汎用クエリの引用率 0%** — 「大阪で展示会ブース制作を依頼できる会社は？」でオージャスト未検出
- **平均正確性 2.6/5.0** — 所在地・設立年・代表者名の幻覚が頻発
- **引用URLの不在** — 25件中実際のURLが含まれたのは3件のみ

### 1.2 対策の方針

| 問題 | 対策 | 期待効果 |
|------|------|---------|
| 汎用クエリで未検出 | ロケーションページ + Service schema で地域特化シグナル強化 | 地域＋サービス名クエリでの検出率向上 |
| 情報幻覚 | 構造化データ（JSON-LD）で事実情報を機械可読に | 所在地・設立年・代表者の正確な引用 |
| 引用URL不在 | 各ページに固有のcanonical URL + schema.org URL 明示 | AIが正しいURLを応答に含める |
| 信頼性不足 | 著者資格（Person + knowsAbout）マークアップ | EEATシグナル強化、引用率1.8倍 (Yext) |

### 1.3 Yext 根拠データ

- **全エンジン一致時の引用率**: 91% — 複数検索エンジンが同一ソースを参照すると引用率が極めて高い
- **著者情報エンリッチメント**: 著者情報を含むサイトの引用率は含まないサイトの約1.8倍
- **構造化データのあるサイト**: リッチスニペット獲得率が約2.5倍

### 2.3 必須構造化データ

各ロケーションページには以下のJSON-LDを実装:

```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "株式会社オージャスト",
  "description": "大阪・東京を拠点に展示会ブース制作・社内イベントプロデュースを一貫提供",
  "areaServed": [
    {
      "@type": "City",
      "name": "大阪市",
      "sameAs": "https://www.wikidata.org/wiki/Q35765"
    },
    {
      "@type": "State",
      "name": "大阪府",
      "sameAs": "https://www.wikidata.org/wiki/Q121210"
    }
  ],
  "hasOfferCatalog": {
    "@type": "OfferCatalog",
    "name": "展示会ブース制作サービス",
    "itemListElement": [
      {
        "@type": "Offer",
        "itemOffered": {
          "@type": "Service",
          "name": "展示会ブース設計・施工"
        }
      }
    ]
  },
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "大阪市",
    "addressRegion": "大阪府",
    "addressCountry": "JP"
  }
}
```

### 2.4 AI引用最適化ルール

1. ページ先頭2文で「誰が・どこで・何を」を明示（前倒し構造）
2. H2見出しは質問形式（「大阪の展示会ブース制作の費用相場は？」）
3. 固有名詞（拠点名・会場名・サービス名）を冒頭50語に含める
4. 断定的な表現（「可能です」「対応しています」）を使用

## 4. 著者資格（Author Credential）マークアップ

### 4.1 理由

Yext調査: **著者情報エンリッチメントで引用率1.8倍**。Google EEAT評価の重要なシグナル。

### 4.2 実装対象

- ブログ記事の著者プロフィール
- 事例ページ（/case/）の担当デザイナー・ディレクター
- 会社概要ページの代表者プロフィール

### 4.3 Person schema

```json
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "金 功勇",
  "givenName": "功勇",
  "familyName": "金",
  "jobTitle": "代表取締役",
  "worksFor": {
    "@type": "Organization",
    "name": "株式会社オージャスト"
  },
  "knowsAbout": ["展示会ブース制作", "社内イベントプロデュース", "イベント運営管理"],
  "description": "年間100件以上の展示会ブース制作・社内イベントを手がけるイベント制作のプロフェッショナル"
}
```

### 4.4 Article + author 紐付け

```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "展示会ブース制作の費用相場と抑え方【2027年版】",
  "author": {
    "@type": "Person",
    "name": "山田 太郎",
    "jobTitle": "展示会ブース デザインディレクター",
    "knowsAbout": ["ブースデザイン", "空間設計", "照明デザイン"],
    "description": "展示会ブースデザイン歴15年。大手企業から中小企業まで100件以上のブースデザインを担当。"
  }
}
```
