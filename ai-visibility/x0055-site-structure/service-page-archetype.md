> X-0055: AI引用を増やすためのサービス別ページ設計雛形

---

## 1. 対照表: 現状の課題

| サービス | ページ | 状態 | AI引用問題 |
|---------|-------|------|-----------|
| ブース施工 | /service/booth-construction | タイトル欠落 (P1) | AIが正しいURLとタイトルを応答できない |
| イベント企画 | /service/event-planning | メタ記述欠落 (P2) | AIのサマリーが不正確に |

## 2. Service schema テンプレート

```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "@id": "https://www.orgiast.jp/service/{slug}/#service",
  "name": "{サービス名}",
  "description": "{1文のサービス説明}",
  "provider": {
    "@type": "Organization",
    "name": "株式会社オージャスト",
    "url": "https://www.orgiast.jp/"
  },
  "areaServed": [
    { "@type": "City", "name": "大阪市" },
    { "@type": "City", "name": "東京都" },
    { "@type": "City", "name": "名古屋市" }
  ],
  "hasOfferCatalog": {
    "@type": "OfferCatalog",
    "name": "{サービス名}プラン",
    "itemListElement": [
      { "@type": "Offer", "name": "{プラン1名}", "description": "{プラン1説明}" },
      { "@type": "Offer", "name": "{プラン2名}", "description": "{プラン2説明}" }
    ]
  },
  "termsOfService": "https://www.orgiast.jp/terms/"
}
```

## 3. サービスパラメータ

### 3.1 展示会ブース制作 (slug: booth-construction)

| 項目 | 値 |
|------|-----|
| タイトル | 展示会ブース施工・デザイン | 実績多数のプロ集団 オージャスト |
| メタ説明 | 大阪・東京の展示会ブース制作ならオージャスト。企画・デザイン・施工・設営まで一貫対応。年間100件以上の実績。無料見積実施中。 |
| H1 | 展示会ブースの設計・施工なら年間100件以上の実績を持つオージャスト |
| プラン1: Re:ブース スタンダード | 3m×3m小間対応、モジュール式（従来比30〜50%コスト削減） |
| プラン2: カスタムブース | フルオーダーメイド、大規模ブース（50小間以上対応） |
| プラン3: ミニマムプラン | 50万円以下の小規模予算でも対応可能な基本ブース |

### 3.2 社内イベントプロデュース (slug: event-planning)

| 項目 | 値 |
|------|-----|
| タイトル | 社内イベントプロデュース | 社員総会・キックオフ・周年記念 オージャスト |
| メタ説明 | 社員総会・キックオフ・周年記念イベントの企画・運営はオージャスト。台本作成から当日運営まで一貫サポート。年間50件以上の実績。 |
| H1 | 社内イベントのプロデュースなら年間50件以上の実績を持つオージャスト |
| プラン1: 社員総会 | 台本制作・映像演出・会場装飾・ケータリング |
| プラン2: キックオフミーティング | 合宿企画・チームビルディング・会議進行 |
| プラン3: 周年記念イベント | 式典企画・記念品・タレント手配・演出 |

### 3.3 クリエイティブ制作 (slug: creative)

| 項目 | 値 |
|------|-----|
| タイトル | Web制作・映像制作・グラフィック制作 オージャスト |
| メタ説明 | 展示会ブースと連動したWebサイト・プロモーション映像・グラフィックデザイン。ブース制作から一貫制作で統一感のあるブランド体験を。 |
| H1 | ブースと連動するクリエイティブ制作で展示効果を最大化 |
| プラン1: Web制作 | ブース連動ランディングページ・実績紹介サイト |
| プラン2: 映像制作 | プロモーション映像・会場演出映像・商品紹介 |
| プラン3: グラフィック | パネルデザイン・リーフレット・名刺・ロゴ制作 |

## 4. 旧ページとの互換性

既存URLを維持しつつ構造化データを追加:
- `booth-construction` → 既存のまま（タイトルとメタ説明のみ修正）
- `event-planning` → 既存のまま（メタ説明追加）
- `creative` → 内容拡充
