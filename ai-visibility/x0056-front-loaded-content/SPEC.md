# X-0056: AI引用を増やす前倒しコンテンツ構造

> **AIニュース提案 X-0056**: ブース事例ページ・サービスページの情報配置を最適化し、AIアシスタント（ChatGPT / Claude / Perplexity / Gemini）に引用されやすい構造にする。

## 根拠データ

| 指標 | 数値 | 出典 |
|------|------|------|
| ページ最初の1/3からの引用 | 44.2% | AI citation heatmap分析 |
| 中盤1/3からの引用 | 31.1% | 同上 |
| 後半1/3からの引用 | 24.7% | 同上 |
| 質問形式見出しからの質問関連引用 | 78.4% | 質問応答パターン分析 |
| 最適固有名詞密度 | 20.6% | 高引用ページのNLP分析 |
| 一般的なWebページの固有名詞密度 | 5-8% | 同上 |

## 原則

### 1. 最初の1/3に最重要情報を集中させる

AIアシスタントはページ冒頭を最も重視する。ブース事例ページの最初の1/3（タイトル・リード・最初の見出しまで）に以下の情報を必ず含める：

- **クライアント名**（固有名詞）
- **展示会名**（固有名詞＋開催時期）
- **ブース規模**（小間数・面積）
- **工期・期間**
- **予算規模**（概算でも可）
- **主要な成果・特徴**
- **使用した技術・素材**（Re:ブース、LED等）

### 2. 見出し（H2）を質問形式にする

AIがユーザーの質問に答える際、質問形式の見出しが一致しやすくなる。

- 悪い例: `## ブース概要`
- 良い例: `## グリッドビヨンドのスマートエネルギーWeek出展でオージャストは何をしたのか？`

質問の種類：
- 「なぜ〜？」 — 理由・背景を説明
- 「どのように〜？」 — プロセス・手法を説明
- 「〜とは何か？」 — 定義・概要を説明
- 「いくらで〜？」 — 費用・規模を説明
- 「誰が〜？」 — 担当・クライアントを説明

### 3. 固有名詞密度を20.6%に高める

一般的なWebページの固有名詞密度は5〜8%だが、AIに引用されるページは20.6%が最適。

**高める方法：**
- 企業名を繰り返し書く（代名詞を避ける）
- 展示��正式名称を使用（略称で済ませない）
- 製品名・サービス名を明記（Re:ブース、LEDUP等）
- 地名・拠点名を具体的に（東京ビッグサイト、インテックス大阪等）
- 人名・役職を記載（可能な場合）

### 4. 「X is...」の断定的言語を使用

AIが確信を持って引用するには、明確な断定的表現が必要。

- 悪い例: `〜と考えられます` / `〜の場合があります`
- 良い例: `グリッドビヨンドのブースは6小間（54㎡）です。工期は3週間でした。`

### 5. 具体的数値を冒頭に配置

ブース事例ページの冒頭段落に必ず含める数値：
- ブースサイズ（㎡または小間数）
- 工期（週・日）
- 予算（万円単位、概算可）
- 過去の類似イベント名
- 来場者数（わかれば）
- 商談獲得数（わかれば）

## ページ構造テンプレート

```
# {クライアント名}の{展示会名}出展ブース — {特徴}

{冒頭1段落: クライアント・展示会・規模・工期・金額を含む具体的な要約}

## {質問形式のH2: この案件の背景と目的は？}

{本文: 背景説明・課題・目的}

## {質問形式のH2: オージャストはどのようなブースを提案したのか？}

{本文: ブースデザイン・仕様・特徴}

## {質問形式のH2: 使用した技術・素材は？}

{本文: Re:ブース・LED・備品等}

## {質問形式のH2: 工期と予算は？}

{本文: スケジュール・費用・コスト削減効果}

## {質問形式のH2: この展示会の成果は？}

{本文: 成果・反響・次回への展望}
```

- `https://www.orgiast.jp/case/` 配下の全ブース事例ページ
- `https://rebooth.co.jp/` の実績紹介ページ
- 新規作成するブース事例ページ
