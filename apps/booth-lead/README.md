# ブースAIリードアプリ

展示会ブースでリード獲得を効率化するウェブアプリ。

## 機能一覧

- **QRスキャン**: 名刺・バッジのQRコードを読み取り、即座にリード登録
- **会話録音**: ブース来場者との会話を録音・文字起こし（Web Speech API）
- **AIスコアリング**: 会話内容からリードスコアを自動算出（0-100点）
- **文字起こし**: 録音データをリアルタイム文字起こし
- **CRM連携**: CSV/JSONエクスポート・インポート
- **メールキャンペーン**: テンプレートからフォローアップメールを生成

## 使い方

### スキャンタブ
1. カメラが起動したら、来場者のQRコードをかざす
2. 自動的にフォームに入力されるので、不足情報を追記
3. 「登録」ボタンでリード保存
4. カメラがない環境では手動入力も可能

### ダッシュボード
1. 登録済みリードの統計を確認（総数・HOT/WARM/COLD）
2. 一覧からリードをクリックして詳細表示
3. 検索ボックスで名前・会社名でフィルター

### 会話タブ
1. リードを選択し、録音開始
2. リアルタイムで文字起こしを確認
3. 録音停止後にAIスコアが自動算出
4. スコアとサマリーを確認し、メモを追記

### キャンペーンタブ
1. エクスポート：CSV・JSON形式でリードデータ出力
2. インポート：JSONファイルからリードデータ取込
3. メールテンプレート：お礼・資料送付・デモ案内・見積確認から選択
4. テンプレート編集後、クリップボードにコピー

## 技術スタック

- **フロントエンド**: Pure HTML / CSS / JavaScript
- **QRコード読み取り**: html5-qrcode（CDN）
- **音声認識**: Web Speech API（SpeechRecognition）
- **録音**: MediaRecorder API
- **データ保存**: localStorage
- **外部依存**: html5-qrcode CDN のみ
