## ブース設計5原則

1. **「見せる」より「話せる」空間を先に決める**: 商談スペースの位置と席数を先に決定 → 残りで展示設計
2. **再利用可能な部材を選ぶ**: 3回以上の出展計画ならシステム部材でトータルコスト抑制（2回目以降30-40%）
3. **商談ゾーンは「座れる」だけでなく「書ける」環境**: 4席以上のテーブル、ホワイトボード、十分な天板面積
4. **通路から中が見える「半開放」を基本**: 全面壁の箱型は避け、開放度を目的に応じて選択
5. **デジタルと実物のハイブリッド展示**: 実物サンプル+映像で効率的な情報伝達

## スキーマ（booth-spec.schema.json）
- case_id: 案件ID文字列
- title: ブース名
- booth: { w_mm, d_mm, height_limit_mm, open_sides[], walls[] }
- items[]: { asset_id|param, w_mm, d_mm, h_mm, t_mm, pos_mm[x,y,z], rot_deg?, pitch_deg?, count? }
- views[]: カメラアングル（persp_front_left, persp_front_right, top, front, side_left, side_right, back）
- 座標系: 左前角が原点、X=幅、Y=奥行、Z=上、pos_mm は底面中心
