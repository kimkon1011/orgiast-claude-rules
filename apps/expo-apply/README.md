# 海外企業向け 日本展示会出展受付サイト

海外の企業が日本国内で開催される展示会・見本市へ出展する際の受付（リード取得・相談）を行うWebアプリケーションです。英語を既定言語とし、画面右上のボタンで日本語表示へ切り替えられます。スマホのブラウザでも利用可能です。依存パッケージはありません。

## 起動方法

リポジトリのルートで実行します。

```sh
python3 -m http.server 8000
```

[出展受付サイトを開く](http://localhost:8000/apps/expo-apply/)。ES Moduleを使用するため、HTMLファイルを直接開かずHTTPサーバーを使用してください。Windowsでpython3がない場合はpythonでも起動できます。スマホではその端末からアクセスできるHTTPS環境で配信してください（保存先は端末ごとに独立します）。

## 使い方

1. 言語切替（英語 ⇔ 日本語）で希望の言語を選択します。フォームのラベル・バリデーション・ステータス名が切り替わります。
2. フォームに会社名・国/地域・担当者名・メールアドレス・希望の展示会名・ブース規模・出展時期・必要サービス等を入力して送信します。
3. バリデーションエラーがある場合は該当項目の直下にエラー理由を表示します。送信成功時は受付番号（ID先頭8桁）を表示します。
4. 下部の「受付済み申込一覧・管理」で件数集計・ステータス変更（新規/連絡済み/受諾済み/キャンセル）・詳細確認・削除を行えます。
5. 「CSVコピー」「CSVダウンロード」「Markdownコピー」で登録データを外部出力できます。

## 保存とプライバシー

保存先はlocalStorageのキー`expo-apply-data`（version 1）のみです。外部API・CDN・Webフォントを使わず、外部送信を行いません。共有・同期・同時編集は非対応です。同じブラウザでもホストやポートが変われば別の保存先になります。ブラウザデータの削除で記録は消えるため、定期的に書き出し機能でバックアップしてください。

保存失敗時は画面にエラーを表示し、変更を適用しません。壊れたJSONや不正な基本構造は注意を表示して空で開始し、次の保存で置き換えます。読み込めるデータ内の型違い・未知キー・重複IDなどは補正します。

コア（`expo-apply-core.mjs`）はDOMやストレージに触れず、引数を変更しません。仕様上、新規IDの生成には`crypto.randomUUID()`（またはタイムスタンプフォールバック）を使用します。

## 検証コマンド

Node.js 20以上の標準モジュールのみを使用します。

```sh
node --check apps/expo-apply/expo-apply-core.mjs
node --test apps/expo-apply/test/expo-apply.test.mjs
```
