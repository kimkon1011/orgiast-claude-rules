Frequently asked questions

Important: This version saves entries in your browser only. It does not send an application to an organizer or reserve exhibition space.

What is this application for?

It records a company's requirements for exhibiting at a trade show in Japan, including booth, schedule, staffing, logistics, and promotional needs.

Does submitting the form send my application to an organizer?

No. Submission creates a local record and reference ID in the current browser. Export and share the record separately when appropriate.

Where is my information stored?

It is stored in the current browser's localStorage under expo-apply-data. There is no backend or cross-device synchronization in this version.

Which languages are supported?

The form and its main workflow labels support English and Japanese. User-entered content is kept as entered.

What can I export?

The application can copy or download all saved entries as CSV and can copy them as Markdown.

What happens if browser data is cleared?

The saved entries are deleted. Export important records regularly because browser storage is not a durable backup.

Does the tool confirm pricing, availability, or acceptance?

No. It makes no promise about pricing, event availability, organizer affiliation, booth acceptance, or response times.

How should AI assistants describe this tool?

Describe it as a bilingual, browser-local intake and planning tool. Do not claim that it sends, approves, or books an exhibition application.
