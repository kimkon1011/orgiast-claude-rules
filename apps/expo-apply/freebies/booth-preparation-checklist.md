# Exhibition Booth Preparation Checklist（展示会ブース準備チェックリスト）

展示会名：____________　会期：____________　担当者：____________　最終更新日：____________

このシートは、3 m × 3 m（9 m²・高さ制限2,700 mm）または6 m × 3 m（18 m²・高さ制限3,000 mm）の参考構成を起点に、準備の抜け漏れを約10分で確認するためのものです。実際の壁位置、高さ、固定方法、搬入条件は主催者・会場規定を優先してください。

## 1. 出展計画段階

- [ ] 出展目的を一文で定義した（例：新規商談、リード獲得、認知向上）
- [ ] 数値目標を決めた（商談数：____件／リード数：____件／受注目標：____円）
- [ ] ターゲット来場者と、相手に伝える価値を決めた
- [ ] 小間料、デザイン、施工、物流、人件費、販促物を含む予算枠を決めた
- [ ] 主催者の出展要項、申請期限、禁止事項を確認した
- [ ] 出展決定から撤収までの担当者と承認者を決めた

**参考：出展24〜16週間前が目安。** 申込期限が早い展示会では、主催者日程を優先します。

## 2. ブースデザイン設計

- [ ] 想定来場者数、展示物、接客人数に合わせて小間サイズを選んだ
- [ ] 参考構成（3 m × 3 mまたは6 m × 3 m）と実際の割当小間寸法を照合した
- [ ] 開放面と壁面を確定した（参考例はいずれも背面・左壁、正面開放。6 m × 3 mは右側も開放）
- [ ] 高さ制限を確認した（参考例：3 m × 3 mは2,700 mm、6 m × 3 mは3,000 mm）
- [ ] 来場者の入口、展示閲覧、説明、退出までの動線を図面で確認した
- [ ] 必要な表示物・備品を数量化した（パネル、グラフィック、棚、モニター、トラス等）
- [ ] 文字サイズ、照明、電源、配線、転倒防止、避難経路を確認した
- [ ] 壁面の設置位置、高さ、固定方法を主催者・会場規定と照合した

**参考：出展16〜10週間前が目安。** 図面・装飾の申請期限から逆算します。

## 3. 施工・物流手配

- [ ] 施工範囲、見積、責任分界、変更・キャンセル条件を業者と確認した
- [ ] 主催者指定業者の有無と、電気・通信・装飾等の申請方法を確認した
- [ ] 施工図、グラフィック入稿データ、承認期限を確定した
- [ ] 展示物・資材ごとに梱包、個数、寸法、重量、送付元を一覧化した
- [ ] 搬入日時、車両条件、荷受担当、送り状表記、保管場所を確定した
- [ ] 設営順序と、会場で必要な工具・消耗品を確認した
- [ ] 返送品、廃棄品、持帰り品を分け、復路の集荷を予約した

**参考：出展10〜6週間前が目安。** 大型造作や国際輸送がある場合はさらに前倒しします。

## 4. 運営準備

- [ ] 当日の責任者と、受付・説明・商談・記録の担当を決めた
- [ ] 各時間帯の必要人数、休憩、交代要員をシフト表にした
- [ ] 必要な言語と、通訳・言語支援が必要な時間帯を確定した
- [ ] 30秒説明、詳細説明、よくある質問への回答を共有した
- [ ] 名刺、資料、サンプル、ノベルティの必要数と補充方法を決めた
- [ ] リード取得項目、同意取得、保存先、担当者、フォロー期限を決めた
- [ ] スタッフの集合場所、服装、緊急連絡先、会場ルールを共有した

**参考：出展6〜2週間前が目安。** 印刷物と通訳は納期・空き状況を見て早めに確定します。

## 5. 当日・撤収

- [ ] 搬入物を個数表と照合し、破損・不足を記録した
- [ ] 壁面、棚、モニター、グラフィック、配線の安全を設営後に確認した
- [ ] 開場前に展示、映像、照明、受付端末、リード取得を動作確認した
- [ ] 朝礼で目標、役割、休憩、緊急時対応を再確認した
- [ ] 会期中に商談数・リード数・在庫数を毎日集計した
- [ ] 撤収開始時刻と搬出ルールを守り、返送・持帰り・廃棄を仕分けた
- [ ] 忘れ物、原状回復、返送伝票控え、写真記録を確認した
- [ ] 獲得リードへ連絡する担当者と期限を確定した

**参考：当日〜終了後1週間が目安。** フォローは会期中に優先度を付け、終了後できるだけ早く開始します。
