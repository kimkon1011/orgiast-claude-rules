# 02_ブース設計企画書 — 三共精機株式会社「2027 関西ものづくりワールド」

## 1. 設計コンセプト

### 1.1 テーマ

**「精密の極みを、この一瞬で。」**
高精度・高品質を象徴するクリーンでシャープなデザイン。来場者が足を止め、触れ、対話したくなるブース。

### 1.2 デザインキーワード
- **精密** — 直線基調、シャープなライン、幾何学模様
- **信頼** — ブルー×ホワイトのクリーンカラー、安定感のある構図
- **技術力** — 実機展示と情報パネルのハイブリッド
- **開放感** — 6m間口を活かしたオープンレイアウト

### 1.3 カラースキーム

| 要素 | カラー | 使用箇所 |
|------|--------|----------|
| ベースカラー | ホワイト (#FFFFFF) | 壁面、バックパネル |
| メインカラー | ディープブルー (#003366) | 高所サイン、アクセント壁 |
| アクセントカラー | シルバー (#C0C0C0) | 展示什器、フレーム |
| 強調色 | オレンジ (#FF6600) | CTA、キャッチコピー一部 |

## 3. 導線設計

### 3.1 来場者の理想的な動線

```
通路 ──→ ①視認（遠方から高所サインと実機が目に入る）
          │
          ├──→ ②接近（パンフレット台で資料を手に取る）
          │     │
          │     ├──→ ③展示見学（パネル→実機の順で技術力を理解）
          │     │     │
          │     │     ├──→ ④スタッフ接触（「お困りごとは？」と自然な声かけ）
          │     │     │     │
          │     │     │     ├──→ ⑤商談（奥の商談ゾーンで深掘り）
          │     │     │     │
          │     │     │     └──→ ⑥名刺交換＋アンケート回答
          │     │     │
          │     │     └──→ ⑦退出（パンフレットを持ち帰る）
          │
          └──→ ⑧リピート来場（後日改めて商談セッティング）
```

### 3.2 導線設計のポイント

| ポイント | 施策 |
|----------|------|
| 遠方からの視認性 | 6m幅の高所サインに企業名とキャッチコピーを大判印刷。LEDバックライトで輝度確保 |
| 自然な引き込み | 通路側に実機サンプルを一部見せ、視覚的興味を誘発 |
| 滞留防止 | エントランス付近に立ち話スペースを設けず、奥の商談ゾーンへ誘導 |
| スムーズな誘導 | スタッフ1名は常にエントランス付近で来場者対応。商談は奥の席へ |
| 回遊性 | パネル展示は左→右の順で読み進めるレイアウト（日本語の視線動線に合わせる） |

### 3.3 混雑時の対応

| 状況 | 対応 |
|------|------|
| 商談席が満席 | 名刺交換のみ行い「後日改めて詳細をご説明します」とフォローアップを約束 |
| 展示ゾーンに滞留 | スタッフが積極的に声かけし、関心レベルに応じて商談席へ誘導 |
| 通路側が混雑 | パンフレットは自由にお取りいただき、詳細はブース奥でご説明と案内 |

## 4. 視認性確保策

### 4.1 遠方視認（通路から10m以上）

| 施策 | 詳細 |
|------|------|
| 高所サイン | バックパネル上部に6m幅のサイン。文字高30cm以上、太字 |
| LED照明 | サイン内蔵LED（昼白色）でバックライト照射。消費電力50W以下 |
| コントラスト | 白地に濃紺文字＋オレンジのアクセントで視認性最大化 |
| キャッチコピー | 「精密機械部品のプロフェッショナル 三共精機」と大表記 |

### 4.2 中間視認（通路から3〜5m）

| 施策 | 詳細 |
|------|------|
| 実機展示の一部可視 | 通路側から実機サンプルが一部見える展示配置 |
| パネルタイトル | A1パネル上部に48pt以上の見出し |
| 映像モニター | 可能であれば40インチ以上のモニターで加工工程映像を再生（予算次第） |

### 4.3 近接視認（ブース内）

| 施策 | 詳細 |
|------|------|
| サンプル拡大写真 | 微細な部品は拡大写真と実物を併置 |
| タッチ＆トライ | 加工サンプルはアクリルケース越しでも手に取れる感覚を演出 |
| QRコード | 各パネルにQRコードを配置（詳細技術資料への導線） |

## 5. 精密機械部品の展示方法

### 5.1 ハイブリッド展示構成

**実機展示（50%）＋ パネル展示（40%）＋ デジタル展示（10%）**

| 展示種別 | 比率 | 内容 |
|----------|------|------|
| 実機展示 | 50% | 代表的な精密部品の実物サンプル（ガラスケース内） |
| パネル展示 | 40% | 加工事例、精度データ、取引実績、会社概要 |
| デジタル展示 | 10% | タブレットでの技術ギャラリー、加工動画（予算次第） |

### 5.2 実機展示詳細

**メイン展示ケース（ガラスケース内）**

| 展示品 | 展示方法 | アピールポイント |
|--------|----------|------------------|
| 代表的な精密旋盤加工品（3点） | 白ベースの展示台に個別配置 | 表面粗さRa0.4以下の鏡面仕上げ |
| 複雑形状部品（2点） | 加工前素材と加工後の対比展示 | 5軸加工による複雑形状対応力 |
| 微細加工部品（3点） | 拡大鏡＋実物併置 | φ0.5mm以下の微細穴加工技術 |

**サブ展示台（オープン展示）**

| 展示品 | 展示方法 | アピールポイント |
|--------|----------|------------------|
| 加工工程サンプル（3段階） | 加工前・途中・完成品を並置 | 一貫生産体制のアピール |
| 材質見本（5種） | アルミ・ステンレス・チタン・樹脂・銅 | 多材質対応力 |
| タッチサンプル（1点） | アクリルカバー越しに触診可能 | 表面品質の体感 |

### 5.3 パネル展示詳細（A1サイズ × 4枚）

| パネル番号 | タイトル | 内容 |
|-----------|----------|------|
| パネル1 | 会社概要・沿革 | 創業からの歩み、設備一覧、主要取引先 |
| パネル2 | 加工実例集 | 業種別加工事例（産業機械／半導体／自動車／医療） |
| パネル3 | 品質管理体制 | 測定機器一覧、品質認証（ISO取得有無）、不良率データ |
| パネル4 | 取引実績・導入フロー | 主要取引先ロゴ、見積〜納品までの流れ |

### 5.4 デジタル展示（予算許容時）

- タブレット端末2台（商談席に各1台）
- 技術ギャラリー（加工実績写真スライドショー）
- 加工動画（旋盤・フライス加工の工程映像、3分程度）
- デジタルパンフレット（PDF閲覧可能）

### 6.2 運営スタッフ体制

| 役割 | 人数 | 担当 |
|------|------|------|
| リーダー（全体統括） | 1名 | 営業部長 or マーケ担当 |
| 技術説明担当 | 2名 | 技術営業 or 現場技術者 |
| 名刺交換・受付担当 | 1名 | 営業アシスタント |
| 合計 | **4名**（最低3名ローテ） | — |

### 6.3 スタッフ行動マニュアル（要点）

| 状況 | アクション | セリフ例 |
|------|-----------|----------|
| 来場者が立ち止まる | アイコンタクト＋軽い会釈 | 「こんにちは！精密部品の加工でお困りごとはありませんか？」 |
| 実機展示を見ている | 展示品の説明���簡潔に | 「こちらは表面粗さRa0.4の鏡面仕上げのサンプルです。実際に触ってみますか？」 |
| パネルを見ている | パンフレットを手渡す | 「詳しい技術資料もご用意しています。お時間よろしければ奥でご説明します」 |
| 商談中 | 名刺交換＋ニーズヒアリング | 「御社の部品形状やご予算を教えていただければ、最適な加工方法をご提案します」 |
| 帰り際 | アンケート依頼＋次回アクション設定 | 「本日はありがとうございました。改めて資料をお送りしますので、名刺をいただけますか？」 |
