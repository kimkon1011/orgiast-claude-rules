# 03_スケジュール — 三共精機株式会社「2027 関西ものづくりワールド」

## 1. 全体タイムライン

**出展決定（2026年11月）→ 展示会本番（2027年5月想定）→ 効果検証完了（2027年11月）**

## 4. クリティカルパス

```
出展申込 (2026/12) 
  → 企画確定 (2027/1) 
    → デザイン確定 (2027/2) 
      → 制作発注 (2027/3中旬) 
        → 設営 (2027/5前日) 
          → 展示会本番 (2027/5)
```

**注意点**
- デザイン確定の遅れは制作期間を圧迫する。2027年2月末をデッドラインとし、それ以降のデザイン変更は認めない。
- パネル印刷には校了から納品まで2〜3週間必要。余裕をもったスケジュールを組む。
- 設営日の作業時間は限られている（通常1日8時間程度）。事前にレイアウト図面を施工会社と共有し、当日の手戻りを防ぐ。

## 5. リスク対応スケジュール

| リスク | 影響フェーズ | バッファ | 代替策 |
|--------|-------------|----------|--------|
| 制作会社の納期遅延 | フェーズ2 | 2週間 | 別会社への分割発注を検討 |
| 展示会自体の延期・中止 | フェーズ3 | なし | オンライン展示会への振替を事前検討 |
| スタッフの急な欠員 | フェーズ3 | 1名 | 予備スタッフ1名を事前登録 |
| 予算超過 | フェーズ1〜2 | 予備費10% | ノベルティ・映像制作を削減 |
