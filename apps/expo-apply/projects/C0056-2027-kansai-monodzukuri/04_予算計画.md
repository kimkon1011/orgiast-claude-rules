## 4. 費用対効果試算

### 4.1 ブレークダウン分析

| 指標 | 値 |
|------|-----|
| 総投資額（推奨） | 175万円 |
| 目標リード数 | 50件 |
| リード単価（CPL） | **35,000円/件** |
| 目標商談数 | 20件 |
| 商談単価 | **87,500円/件** |
| 目標成約数 | 3件 |
| 成約単価（CPA） | **583,333円/件** |
| 1件あたり平均受注額（想定） | 150万円 |
| 投資回収に必要な成約数 | **2件**（総投資175万円 ÷ 平均受注額150万円 = 1.17→2件） |

### 4.2 予算シナリオ別比較

| シナリオ | 予算 | 削減・拡充内容 | リスク |
|----------|------|----------------|--------|
| 最小投資 | 150万円 | デジタル展示省略、ノベルティ簡素化 | 視認性・訴求力低下の可能性 |
| **推奨** | **175万円** | 上記計画通り | バランス重視、予備費確保 |
| 積極投資 | 200万円 | 映像制作追加、モニター設置、ノベルティ拡充 | 予算超過のリスクは低いが投資回収ラインが上昇 |

### 4.3 予算削減オプション（必要な場合）

| 削減項目 | 削減額 | 影響 |
|----------|--------|------|
| パネル4枚→3枚 | -3万円 | 情報量減少（パネル4はデジタル資料で代替可） |
| 実機展示ケース→簡易ケース | -5万円 | 高級感低下 |
| 高所サイン簡素化 | -5万円 | 遠方視認性低下 |
| ノベルティ削減（300個→150個） | -2万円 | 配布数減少 |
| 事前プロモーション削減 | -3万円 | 来場促進効果低下 |
| **最大削減合計** | **-18万円** | 157万円まで圧縮可能 |
