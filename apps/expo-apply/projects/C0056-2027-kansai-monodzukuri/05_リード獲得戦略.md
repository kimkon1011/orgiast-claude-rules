# 05_リード獲得戦略 — 三共精機株式会社「2027 関西ものづくりワールド」

## 1. 基本方針

**展示会を「単なる名刺交換の場」から「投資対効果を測定できるリード獲得チャネル」へ転換する。**

展示会当日のブース接客だけでなく、事前集客から事後フォローアップまでの一貫したリード獲得プロセスを設計する。

## 2. 目標リード50件の分解

| 獲得チャネル | 目標件数 | 比率 | 備考 |
|-------------|----------|------|------|
| ブース来場（フリー来場） | 30件 | 60% | ブースに立ち寄った来場者との名刺交換 |
| 事前アポイント | 10件 | 20% | 展示会前にアポを取得した企業との商談 |
| 既存顧客紹介 | 5件 | 10% | 取引��からの紹介で来場した見込み客 |
| SNS・メルマガ経由 | 5件 | 10% | 事前告知を見て来場した見込み客 |
| **合計** | **50件** | **100%** | |

## 3. ブース接客フロー

### 3.1 来場者属性別アプローチ

| 属性 | 見分け方 | アプローチ方法 | ゴール |
|------|----------|----------------|--------|
| A: 明確なニーズあり | 名刺を見て役職・業種を確認／「部品加工のことで」と自ら話しかける | すぐに商談席へ誘導、技術担当と同席で詳細ヒアリング | 商談化（後日見積提出まで約束） |
| B: 漠然とした関心あり | 展示をじっくり見ている／パンフレットを手に取る | 展示案内→軽いヒアリング→「よろしければ奥で詳しい資料をご説明します」と商談席へ誘導 | 名刺交換＋後日フォロー約束 |
| C: 通りすがり | 立ち止まるが積極的な関心は見せない | 「精密部品のサンプルをご覧になりますか？」と軽い声かけ→パンフレット手渡し | 名刺交換（できれば）＋パンフレット持ち帰り |
| D: 競合調査・学生等 | 質問が抽象的／名刺に製造業以外の記載 | 丁寧に対応しつつ、パンフレットと会社案内を手渡す | 無理な名刺交換は求めない |

### 3.2 接客ステップ（標準フロー）

```
Step 1: アイキャッチ（来場者の注意を引く）
  └→ 高所サイン・実機展示の視覚的訴求
  └→ スタッフの笑顔＋アイコンタクト
  │
Step 2: ファーストコンタクト（立ち止まりをアクションに変える）
  └→ 「精密機械部品のサンプルを実際にご覧いただけます」
  └→ 展示品の前で自然に声かけ
  │
Step 3: ニーズ発見（2〜3問の質問で属性判別）
  └→ 「御社ではどのような部品をお使いですか？」
  └→ 「現在、加工先は決まっていますか？」
  └→ 「試作から量産まで、どのフェーズでお困りですか？」
  │
Step 4: 展示説明（属性に応じた展示案内）
  └→ A：技術詳細を深掘り
  └→ B：サンプルを見せながら3分で三共精機の強みを説明
  └→ C：代表的な加工実例1つをピックアップ
  │
Step 5: 商談誘導（奥の商談席へ）
  └→ 「もう少し詳しい資料もございます。お時間よろしければ…」
  └→ 商談席で名刺交換＋ヒアリングシート記入
  │
Step 6: クロージング（次回アクションの明確化）
  └→ 名刺交換
  └→ アンケート記入依頼（タブレット or 紙）
  └→ 「後日、改めて技術資料をお送りしてもよろしいですか？」
  └→ フォローアップ手段の確認（電話／メール／訪問）
```

## 4. 名刺交換からフォローアップまでの導線

### 4.1 当日のデータ管理

```
名刺交換
  ↓
ヒアリング���ート（紙）に簡単なメモを記入
  ↓
展示会終了後、その日のうちに以下を実施：
  ① 名刺をスマホアプリ or スキャナーでデータ化
  ② ヒアリングシートの内容を名刺データと紐付け
  ③ リードの優先度をA／B／Cでランク付け
```

### 4.2 リード優先度定義

| ランク | 定義 | フォローアップ期限 | 方法 |
|--------|------|-------------------|------|
| **A** | 明確なニーズあり、具体的な案件あり、予算あり | 3営業日以内 | 電話＋メール、訪問調整 |
| **B** | 関心あり、案件はあるが時期未定 | 5営業日以内 | メール＋技術資料送付、1週間後に電話 |
| **C** | 情報収集段階、担当分野が合致しない | 7営業日以内 | メール＋会社案内送付、3ヶ月後に再コンタクト |

### 4.3 フォローアッププロセス（3段階）

#### 第1次: 感謝メール（展示会後3営業日以内に全リードへ）

**件名**: 【三共精機】関西ものづくりワールド2027 ご来場ありがとうございました

**本文構成**:
1. 展示会へのご来場のお礼
2. 当日の会話内容への言及（ヒアリングシートを参照）
3. 三共精機の技術力の再アピール（1行）
4. 「詳細資料をご希望の方はお知らせください」
5. 担当者署名（氏名・直通電話・メール）

#### 第2次: 技術資料送付（第1次から3〜5営業日後、Aランクのみ）

- Aランクリードには、ヒアリングで得たニーズに合わせたカスタム技術資料を送付
  - 例: 「御社のご要望に合わせた加工事例集」
  - 例: 「三共精機の品質管理体制について」
- 資料とともに、サンプル送付の提案を行う
- B・Cランクには汎用的な技術資料（会社案内＋加工実例集）を送付

#### 第3次: 商談アポ取得（第2次から5営業日後）

- Aランク: 電話で直接アポ取得を試みる（目標1週間以内の訪問orオンライン面談）
- Bランク: メールでアポ提案、「ご都合の良い時期がございましたら…」
- Cランク: メールマガジン登録の案内、定期的な情報配信

### 4.4 フォローアップスケジュール（リード獲得後）

| タイミング | アクション | 対象 | 担当 |
|-----------|-----------|------|------|
| 当日夜 | 名刺データ化、ヒアリングシート整理、優先度付け | 全リード | 営業部 |
| 3営業日以内 | 第1次フォローアップ（感謝メール） | 全リード | 営業部 |
| 5営業日以内 | 第2次フォローアップ（技術資料送付） | A・Bランク | 技術営業 |
| 10営業日以内 | 第3次フォローアップ（アポ取得） | Aランク優先 | 営業部長 |
| 2週間以内 | サンプル送付（必要に応じて） | Aランク | 技術営業 |
| 1ヶ月以内 | 進捗確認（未アポのA・Bランクに再連絡） | A・Bランク残 | 営業部 |
| 3ヶ月以内 | 再活性化メール（展示会から3ヶ月経過） | B・Cランク | マーケ担当 |
| 6ヶ月以内 | 最終確認（成約に至らなかったリードに） | 全未成約 | 営業部 |

## 8. スタッフ向けリード獲得Q&A

| 質問 | 回答 |
|------|------|
| 名刺交換のタイミングは？ | 来場者が興味を示したら早めに。ただし、最初から名刺を求めるのではなく、会話の流れで自然に |
| アンケートは必須か？ | 可能な限り記入を依頼。ただし強制はしない。名刺＋ヒアリングシートが最低限 |
| 競合他社の来場者には？ | 丁寧に対応し、パンフレットを渡す。無理な商談誘導はしない |
| 学生・研究者には？ | 技術の PR チャンス。名刺がなくても会社案内を渡し、将来の採用PRにつなげる |
| アポイントのない来場者に時間をかけすぎない方法は？ | 5分を目安に、それ以上は「後日改めて詳細をご説明します」と商談アポを設定 |
