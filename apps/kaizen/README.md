# 改善アプリ

イベント後の①改善項目の登録、②改善会での対策・担当・期限の決定、③実施計画書への反映記録をブラウザで管理する小さなアプリです。計画書自体の編集は行わず、編集済みの記録と任意の反映先URLを保存します。解決策の提案は任意です。

## 起動

リポジトリのルートで次を実行します。依存パッケージの追加は不要です。

```sh
python3 -m http.server 8000
```

[改善アプリを開く](http://localhost:8000/apps/kaizen/)。ES Moduleを使用するためHTMLの直接起動ではなく、このHTTPサーバーを使用してください。

1. 記入日（既定は端末の今日）、記入担当者名、クライアント+案件名、事象を入力し登録します。
2. 一覧の「対策を決める」を開き、対策・担当・任意の期限を保存します。
3. 実施計画書を編集した後、任意の反映先URLを記入し「計画書に反映」を押します。対応終了時に「完了」を押します。
4. 状態で一覧を絞り込み、全件の件数集計とMarkdownを確認・コピーできます。担当別集計は担当設定済みの項目だけが対象です。

状態変更の順番は強制しません。対策を再決定すると「改善会で決定」に戻ります。

データはlocalStorageのキー`kaizen-items`に`{items:[...]}`形式で保存します。外部API・CDN・フォントを使わず、外部サービスやGoogleスプレッドシートには一切送信しません。複数人・複数端末間での共有や同時編集には対応しません。同じブラウザでもアクセス先のホスト・ポートが異なると保存先が異なります。ブラウザデータの削除で記録が消えるため、必要な報告はMarkdownとして手元に保存してください。

保存JSONやデータ形式が壊れている場合は注意を表示して空の一覧で開始し、次の保存時に置き換えます。保存に失敗した場合は画面にエラーを表示し、変更を適用しません。コピーが許可されない環境では、選択済みの本文をCtrl+C（MacはCommand+C）でコピーできます。

## 検証

Node標準モジュールのみを使います。

```sh
node --check apps/kaizen/kaizen-core.mjs
node --test apps/kaizen/test/kaizen.test.mjs
```
