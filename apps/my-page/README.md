# 社員マイページアプリ

プロフィール／目標／自分のタスク／休暇予定／経費申請の状況／1on1メモを1画面で管理する、自分専用のハブです。スマホのブラウザでも使用できます。依存パッケージはありません。他アプリとの自動連携はなく、情報は手入力します。

## 起動方法

リポジトリのルートで実行します。

```sh
python3 -m http.server 8000
```

[社員マイページを開く](http://localhost:8000/apps/my-page/)。ES Moduleを使用するため、HTMLファイルを直接開かずHTTPサーバーを使用してください。Windowsでpython3がない場合はpythonでも起動できます。スマホではその端末からアクセスできるHTTPS環境で配信してください（保存先は端末ごとに独立します）。

## 使い方

1. 「プロフィール」に入力して保存します。スキル・資格はカンマ区切りです。入力済み項目数と割合を表示します。
2. 各タブで記録を追加します。「編集」で状態・進捗などを更新でき、「削除」は確認後に実行します。
3. タスクの未完了・期限超過・7日以内の件数を確認します。期限超過の未完了タスクは赤く表示します。
4. 休暇の集計年と付与日数を入力します。この2つは集計用の一時入力で保存しません。使用日数は指定年のother以外の全件（未来も含む）、予定日数は同年の今日以降の全種類です。残りは付与日数−使用日数で、マイナスも表示します。実際の勤怠・有給残高を確定する機能ではありません。
5. 「書き出し」でMarkdownをコピーして共有、またはJSONをダウンロードしてバックアップします。コピーできない環境では本文が選択されるので、端末のコピー操作を使用します。
6. JSON読み込みは内容を確認後、現在の全データを置き換えます。

## 保存とプライバシー

保存先はlocalStorageのキー`my-page-data`（version 1）のみです。外部API・CDN・Webフォントを使わず、外部送信しません。共有・同期・同時編集は非対応です。同じブラウザでもホストやポートが変われば別の保存先になります。ブラウザデータの削除で記録は消えるため、JSONで定期的にバックアップしてください。共有するMarkdownにはプロフィールや1on1の内容も含まれます。

保存失敗時は画面にエラーを表示し、変更を適用しません。壊れたJSONや不正な基本構造は注意を表示して空で開始し、次の保存で置き換えます。読み込めるデータ内の型違い・未知キー・重複IDなどは補正します。日付は実在するYYYY-MM-DD形式を使います。

コアはDOMやストレージに触れず、引数を変更しません。仕様上、新規IDの生成にはcrypto.randomUUID()、休暇集計の既定基準日には端末時計を使用します。leaveStatsの第4引数にYYYY-MM-DDを渡すと基準日を固定できます。その他の集計は渡された値だけで決まります。

## 検証コマンド

Node.js 20以上の標準モジュールのみを使用します。

```sh
node --check apps/my-page/my-page-core.mjs
node --test apps/my-page/test/my-page.test.mjs
```
