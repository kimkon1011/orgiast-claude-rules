制作プロセス

  1. Phase 1: 企画・見積 — ヒアリング → デザイン企画 → パース提案 → 見積提示 → 実施計画策定（目安: 1〜2週間）
  2. Phase 2: 設計・制作準備 — レイアウト設計 → 施工会社アサイン → アイテムリスト作成 → 申請書類作成（目安: 2〜4週間）
  3. Phase 3: 入稿・印刷 — パネル・グラフィック印刷発注 → 入稿データチェック（目安: 1〜2週間）
  4. Phase 4: 最終確認 — 最終仕様確認 → 当日スケジュール策定 → 関係者への案内（目安: 1週間前）
  5. Phase 5: 本番当日 — 設営 → 動作確認 → 当日運営サポート → 撤去
  6. Phase 6: アフターフォロー — 報告書作成 → 改善提案 → 次回出展相談
