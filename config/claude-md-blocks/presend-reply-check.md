**▶ 送信前の相手発言照合（全送信の必須ステップ）（kim 2026-11-28）**

（送信前の整合性チェック 項目7の強化）送る前に相手の直近の発言を、送信先スレッドと同じ相手がいる別チャット（直近24h）まで、画像・添付・本文空の投稿も実物を開いて全部読む。本文の各指示（置き場所・日時・部数・宛先・手順）を相手の発言と1文ずつ照合し、食い違う文は相手の発言に合わせるか削る。相手がすでに済ませたことは書かない。使い捨てスクリプトから送らず、必ず共通の送信前チェック（`node tools/pre-send-reply-check.mjs`。beeper-api の sendMessage は合格マーカー無しでは送らない）を通す。
   - 再発事例: 2026-11-28 東邦ハイツ301 で、相手が別チャットに「控えここ入れてます」＋写真、送信先に「乙第12号証」記入済みの写真（本文空）と「投函しておきます」を送っていたのに、使い捨てスクリプトから「乙第12号証と書く」「控えは持ち帰って」と送った。検査が無言で効かなかった故障なので、1回目で仕組みを直した。
