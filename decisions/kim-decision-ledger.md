# 金さんの決定台帳

金さんに質問・確認・申込可否を出す前に、必ずこの台帳を照合する。同じ質問への回答が載っていれば、**聞かずにその決定に従う**。見回りの報告で「金さんにしか決められない質問」を作る前も同様。新しい回答は、この Markdown と `config/kim-decision-ledger.json` の両方に追記する（機械照合の正本は JSON）。

照合: `node tools/kim-decision-ledger.mjs --check "質問文"`。当たれば聞かず、外れた応募者メールなどは対象外と出る。

## 使い方

1. 質問を書く前に JSON を読む（または `--check`）。
2. `doNotAsk: true` で `match` に当たる決定があれば、その `answer` に従い、金さんにも社員にも聞かない。
3. `except` に当たる文（例: doda経由の応募者）は台帳の対象外。通常どおり対応する。
4. 金さんから新しい回答を得たそのターンで、この台帳へ追記する。共通ルールは全PCに同期される。
