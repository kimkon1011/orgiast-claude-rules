**ヘッドライン**
「優秀な人材と、自社の課題を解くアイデアが出会う。」

**イベント概要**
年間12回・毎回テーマを変えるピッチコンテストシリーズの第1回。
株式会社エイト（エイトスペース）のインキュベーション事業の一環。

**企業の参加条件**
| 条件 | 内容 |
|---|---|
| 参加費 | 無料 |
| 課題 | 自社の課題を1つ提示 |
| 当日 | 審査にご参加（オンライン可） |
| 賞 | 称号の授与のみ（金銭負担なし） |
