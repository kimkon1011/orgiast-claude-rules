# 監督側の助言ルール（C2）

## 発動条件

Opus 助言は次の3条件に固定し、それ以外で呼ばない。

1. 大きな計画確定前。
2. 同一エラー再発時（2回目）。
3. 完了宣言前。

## 禁止事項

- 従量課金・APIキー利用は禁止。Claude API や SDK を使わず、契約内の CLI 操作で行う。
- Fable のサブエージェント指定は禁止。
- 実装は Codex へ委譲する。本ルールは監督側のモデル構成だけを対象とする。
- 秘密や実セッションの transcript を助言用の資料や比較 fixture に転記しない。

## Opus へ渡す文脈の最小形

次の形に絞り、決めたいことは1つにする。

```text
目的: （1行）
現状: （3行以内）
決めたいこと: （1つ）
制約: （守る条件）
```

助言を受けたら監督側を Sonnet に戻し、実装の依頼は Codex に渡す。
