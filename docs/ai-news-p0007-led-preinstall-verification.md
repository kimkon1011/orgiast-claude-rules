# AIニュース提案 [P-0007]: LED事前設置の効果検証

## 課題

展示会ブース設営において、LEDパネル（LED UP・LEDビジョン等）の配線・ケーブリングが**当日の作業時間を圧迫**している実態がある：

- **当日の配線作業に30〜60分以上を要する**: LEDパネルは重量がある上、ケーブルが多く、パネル枚数に比例して作業時間が増加
- **配線ミスの発生**: 時間制約の中で慌てて配線すると、ケーブルの抜け・極性間違い・延長不足が発生
- **開場直前のトラブル対応**: 配線不良が開場直前で発覚すると、修正に追加時間がかかり開場遅延リスク

## 目的

事前にLED配線（パネル間のケーブリング・電源接続・制御信号線の敷設）をオフサイトで行い、**当日の設営作業時間が30分以上短縮できるか**を実測で検証する。

## 現状分析

### LED設営の典型的な作業フロー（現状・事前配線なし）

```
当日:
  1. LEDパネルを運搬・開梱（5分）
  2. パネルをフレーム/トラスに取り付け（15分）
  3. パネル間の電源ケーブル接続（10分）
  4. 制御信号ケーブルの敷設・接続（10分）
  5. 電源ユニットの配置と主電源接続（5分）
  6. 通電テスト・表示確認（10分）
  7. 不具合箇所の修正（5〜15分）
  ─────────────────────────────────
  合計: 60〜70分（配線関連: 3+4+5 = 25分 + 修正15分 = 最大40分）
```

### 目標フロー（事前配線あり）

```
事前（オフサイト）:
  1. LEDパネルを床面に配置（10分）
  2. パネル間の全ケーブルを事前接続（15分）
  3. 事前通電テスト（10分）
  4. ケーブルを結束・マーキングし、折りたたんで保管（5分）
  ─────────────────────────────────
  事前作業合計: 40分（オフサイトで実施可能）

当日:
  1. 事前配線済みユニットを運搬・展開（5分）
  2. ユニットをフレームに取り付け（15分）
  3. 主電源接続のみ（2分）
  4. 簡易通電テスト（5分）
  ─────────────────────────────────
  当日作業合計: 27分
  削減時間: 60分 → 27分 = **33分削減（想定）**
```

## 検証計画

### 検証対象

| 項目 | 内容 |
|------|------|
| **対象機材** | LED UPパネル（LED UP 1000×500 等）、LEDビジョン、電源ユニット、信号ケーブル |
| **検証設営規模** | 3×3小間 〜 6×3小間（LEDパネル 4〜12枚程度） |
| **検証場所** | 倉庫または事務所（オフサイト事前準備）→ 実際の会場（当日設営） |
| **検証回数** | 最低3回（異なるレイアウトまたは担当者） |
| **計測方法** | ストップウォッチ計測 + 動画記録（後日分析用） |

### 検証手順

#### Step 1: 事前準備（オフサイト）

1. LEDパネル・ケーブル類をすべて床面に並べる
2. パネル間の電源ケーブルを接続（写真撮影して記録）
3. 制御信号ケーブル（Ethernet/DMX）を接続
4. 仮電源に接続し通電テストを実施（表示確認）
5. ケーブルを結束バンドで束ね、パネルごとにマーキング
6. パネルを安全に折りたたみ・積載可能な状態に保管
7. **計測**: 事前準備の所要時間を記録

#### Step 2: 当日設営（会場）

1. 事前配線済みユニットを会場へ運搬
2. フレーム/トラスに取り付け（配線は接続済みのため不要）
3. 主電源ケーブルを電源ユニットに接続
4. 通電テストを実施
5. **計測**: 当日設営の所要時間を記録（配線関連作業のみ）

#### Step 3: 比較

- 事前配線なしの場合の基準時間（過去の設営記録から取得）
- 事前配線ありの場合の実測時間
- 削減時間 = 基準時間 − 実測時間

### 成功基準

| 指標 | 目標値 | 測定方法 |
|------|--------|----------|
| 当日配線作業時間の削減 | **30分以上** | 事前配線あり/なしの差 |
| 配線ミスの発生率 | **0件** | 通電テスト時の不具合件数 |
| 作業者の負担感 | 「楽になった」 | 作業後のヒアリング |
| 追加コスト | **1.5万円以内** | 事前準備の人件費換算 |

## リスクと対策

| リスク | 確度 | 影響 | 対策 |
|--------|------|------|------|
| 事前配線したケーブルが輸送中に外れる | 中 | 中 | 結束バンド＋マーキングで固定、予備ケーブルを携行 |
