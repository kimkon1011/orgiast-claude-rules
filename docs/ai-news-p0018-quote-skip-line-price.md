# AIニュース提案 [P-0018]: 見積書作成不要化 — LINEで金額だけ伝える方式

観測日: 2026-11-18 | ステータス: 設計中

## 課題

展示会ブース・イベント制作において、「受注済み案件の少額追加・変更」ごとに**正式な見積書（Googleスプレッドシート、Growiマニュアル p0890/p2608 準拠）を作成している**現状がある。この方式には以下の問題がある：

- **見積書作成の手間に対して金額が小さすぎる**: 税込5,000円の追加備品1点のために、解説シートの記入・セル参照・共有設定・ファイル名決定という一連のプロセスを踏むのは過剰
- **返答スピードの低下**: 見積書を作ってから送るまでに最低30分〜1時間かかり、お客様からの「ちょっと追加したい」に即答できない
- **受注後なのに「見積もり待ち」が発生**: 本契約は確定しているのに、追加事項の見積書を待つタイムラグがお客様・双方の手間になる
- **小口の見積書作成が案件全体のコストを押し上げる**: 見積書1件あたりの人件費（アシスタント20〜40分・進行確認10分）が追加金額を上回るケースがある

## 目的

**受注済み案件における少額追加・変更に限り、見積書を作成せずLINE（またはメール）で金額だけ伝える方式を導入する。** これにより以下を実現する：

1. 返答スピードの向上（即日〜数時間 → 数分）
2. アシスタント・進行の見積書作成工数の削減
3. お客様の手間削減（「見積もり確認→承認」という工程を省略）
4. 少額追加のハードルを下げ、受注金額の増加につなげる

## 現状分析

### 見積書作成の工数実態

| 工程 | 標準所要時間 | 備考 |
|------|------------|------|
| お客様からの追加依頼受信 | — | LINE・メール |
| 追加内容の確認・単価調査 | 5〜10分 | 既存単価表・過去相場 |
| 見積書ファイル作成（コピー＋編集） | 10〜15分 | 解説シート記入・セル参照含む |
| 共有設定・ファイル名調整 | 5分 | オーナー seisaku-team @、common.users @ 編集権限 |
| 進行確認・送信 | 5〜10分 | kim 承認＋送信 |
| **合計** | **25〜40分** | |

**課題**: 税込5,000円の追加に対し、25〜40分の工数（人件費換算約1,250〜2,000円）が発生している。

### 追加依頼の金額分布（想定）

| 金額帯 | 割合（推定） | 備考 |
|--------|------------|------|
| 〜5,000円 | 30% | 備品1点追加・軽微な修正 |
| 5,001〜30,000円 | 40% | 備品数点・小規模オプション |
| 30,001〜50,000円 | 20% | 中規模オプション・レイアウト変更 |
| 50,001円〜 | 10% | 設備追加・大幅変更 |

**ターゲット**: 上2区分（〜5万円）が見積書省略の主な候補となる。

## 提案: 少額追加は金額のみ提示方式

### 新方式のフロー

```
[お客様から追加依頼]
　　　↓
① 追加内容の確認・単価算出（5分）
　　　↓
② kim に全文を見せ承認を得る（社外送信ルール）
　　　↓
③ LINE（またはメール）で金額だけ伝える
　「承知しました。こちらの追加で〇〇円（税込）となります。よろしいでしょうか？」
　　　↓
④ お客様了承 → 同日中に案件の見積シート「追加・変更」行に記録
　（または実施計画書の該当項目を更新）
```

### 対象範囲

| 対象 | 判定 | 理由 |
|------|------|------|
| **新規案件** | ❌ 従来どおり見積書を作成 | 契約前の正式見積もりは省略不可 |
| **展示会ブース本体・イベント本体** | ❌ 従来どおり見積書を作成 | 案件一覧マスター登録必須、Growiマニュアル p0890/p2608 準拠 |
| **受注済み案件の少額追加（〜5万円）** | ⚠️ 省略候補 | 閾値は提案値。最終決定は kim |
| **受注済み案件の5万円超追加** | ❌ 従来どおり見積書を作成 | 金額が大きく、お客様の稟議が要る可能性 |
| **既存単価表どおりのリピート小口** | ⚠️ 省略候補 | 単価が確定済みのため、金額提示のみで契約成立可能 |
| **お客様から正式な見積書を求められた場合** | ❌ 従来どおり見積書を作成 | お客様の社内ルールを優先 |

#### 閾値の考え方（提案）

- **基準**: 税込5万円未満
- **根拠**: お客様の社内稟議不要ラインとして一般的な金額帯。過去の追加依頼の約90%がこの範囲に収まる
- **補足**: 閾値はあくまで提案。kim の判断で上下することを許容する

### 省略してよい具体例

| カテゴリ | 例 | 金額目安 |
|---------|-----|---------|
| 追加備品 | パンフレットスタンド1台追加、モニター台数変更 | 3,000〜30,000円 |
| 軽微な修正 | パネル文言修正（印刷範囲内）、配色変更 | 5,000〜20,000円 |
| オプション追加 | 簡易クローク設置、展示台追加 | 10,000〜50,000円 |
| リピート小口 | 前回と同じ装飾オプションをもう1セット | 単価表どおり |

### 省略しない具体例

| カテゴリ | 理由 |
|---------|------|
| ブースレイアウトの変更 | 設営工数・資材が変わるため正式見積もりが必要 |
| 電源増設・特殊配線 | 会場指定業者による別途費用が発生 |
| 期間延長（出展期間の追加日） | 会場使用料・人件費が大きく変動 |
| お客様の社内稟議が必要な追加 | 稟議書類として見積書が不可欠 |

### 必須ルール

| ルール | 内容 |
|--------|------|
| **送信前承認** | 金額だけ伝える場合も、送信前に本文全文を kim に見せ、承認を得てから送る |
| **発注先秘匿** | お客様に発注先・原価・仲介サイト名を書かない（既存ルール） |
| **日付照合** | 社外文面の曜日・日付は計算で照合する（既存ルール） |
| **同日記録** | 伝えた金額は同日中に案件の見積シート「追加・変更」行（または実施計画書）に記録し、請求漏れを防ぐ |
| **書面要求対応** | お客様の経理・稟議で書面が必要な場合は、従来の見積書を速やかに作成する |

## 期待される効果

### 工数削減

| 項目 | 現行 | 新方式 | 削減率 |
|------|------|--------|--------|
| 少額追加1件あたりの作成時間 | 25〜40分 | 5〜10分 | 60〜80% |
| 月間の見積書作成時間（少額追加分） | 300〜500分（仮に10件/月） | 50〜100分 | 80〜90% |
| お客様の承認までのリードタイム | 半日〜1日 | 数分〜数時間 | 80〜95% |

### 返答スピード向上

- 追加依頼への即答が可能に（「承知しました。〇〇円です。」）
- お客様の「見積もり待ち」ストレスを解消
- 少額追加の心理的ハードル低下により、追加受注の増加を見込む

## リスクと対策

| リスク | 発生確率 | 影響 | 対策 |
|--------|---------|------|------|
| 金額を伝えたが「言った言わない」になる | 低 | 中 | LINE/メールのメッセージを保存。記録は必ず同日中に案件シートへ |
| 伝えた金額を請求し忘れる（請求漏れ） | 中 | 中 | 同日記録ルールを徹底。見積シートの「追加・変更」行に必ず記入 |
| お客様の社内稟議で書面が必要になる | 低 | 小 | その場合は従来の見積書を作成。書面要求があれば即対応 |
| 対象範囲を超えて見積書を省略してしまう | 中 | 大 | 対象範囲を明確に文書化し、kim 承認時に都度確認する |
| LINEのみで伝えた場合、お客様が見落とす | 中 | 小 | 了承の返信を確認。未読の場合は電話など別ルートでフォロー |
| 少額追加を重ねて合計が閾値を超える | 中 | 中 | 累積額を見積シートで管理。閾値超過時はkim判断で従来方式へ戻す |

## 実装ステップ

### Phase 1: 方針決定（今週）
- [ ] 本ドキュメントの内容を社内でレビュー
- [ ] 閾値（5万円）の最終確定
- [ ] 省略対象チャネルの確定（LINEのみ or メールも含む）

### Phase 2: 運用準備（1週間）
- [ ] 見積シートへの「追加・変更」記入ルールの策定（書式・行位置）
- [ ] 社内共有用の標準メッセージテンプレートの作成
- [ ] 既存ルールとの整理（社外送信ルール・発注先秘匿ルールとの整合性確認）

### Phase 3: 試験運用（1か月）
- [ ] 受注済み案件の少額追加・変更を対象に、1か月試験適用
- [ ] 対象件数、1件あたりの見積書作成・回答時間、お客様の反応を記録
- [ ] 請求漏れ0件を必須目標とし、同日記録の実施率を確認
- [ ] 課題の洗い出しとルール改訂

### Phase 4: 本格運用
- [ ] 全案件の少額追加に適用拡大
- [ ] 月次での件数・時間削減効果の測定
- [ ] 閾値の定期的な見直し（3か月ごと）
