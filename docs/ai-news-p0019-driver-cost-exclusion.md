# AIニュース提案 [P-0019]: ドライバー費用除外による総コスト削減

観測日: 2026-11-18 | ステータス: 設計中

## 課題

展示会ブースの設営・運搬において、**ドライバー費用（運送費に含まれる人件費）を作業費と一緒に見積もりに計上**している現状がある。この方式には以下の問題がある：

- **見積もり金額が割高に見える**: 運送費（車両代＋ドライバー人件費）を作業費に上乗せすると、競合他社の「運送費別途」の見積もりと比較された際に不利になる
- **ドライバーの待機時間がコストに反映されない**: 設営現場でドライバーが待機する時間（荷降ろし後の空き時間・設営完了までの待機）がコストとして可視化されず、非効率が放置される
- **繁忙期と閑散期でドライバー単価が変動**: 展示会シーズンによって運送会社のドライバー単価が変動し、見積もりの安定性を損ねる
- **小規模案件でドライバー費用の割合が過大になる**: 1〜2小間の小規模ブースでも最低限のドライバー1名分の費用が発生し、作業費に対して割高に見える

## 目的

**作業費のみで見積もりを提示し、ドライバー費用を計上しない方針を文書化する。** これにより以下を実現する：

1. 見積もりの競争力向上（表面的な金額を下げるのではなく、コスト構造を適正化）
2. ドライバーリソースの効率的な配置（複数案件の配送を統合し、ドライバー1人で複数現場を回る）
3. 繁忙期・閑散期にかかわらず安定した見積もり提示
4. 顧客にとって透明性の高いコスト内訳

## 現状分析

### ブース設営におけるドライバー費用の実態

| 案件規模 | 想定ドライバー費用（往復） | 作業費に対する割合 | 備考 |
|---------|--------------------------|-------------------|------|
| 1小間（簡易ブース） | 2〜3万円 | 15〜25% | 車両1台＋ドライバー1名、半日 |
| 2〜3小間（標準） | 3〜5万円 | 10〜15% | 車両1台＋ドライバー1名、1日 |
| 4〜6小間（中規模） | 5〜8万円 | 8〜12% | 車両1〜2台＋ドライバー1〜2名 |
| 6小間以上（大規模） | 8〜15万円 | 5〜10% | 車両2台以上＋ドライバー2名以上 |

**課題**: 小規模案件ほどドライバー費用の割合が高く、見積もりの競争力を損ねている。

### 業界比較

| 要素 | オージャスト（現行） | 競合A社 | 競合B社 |
|------|-------------------|---------|---------|
| 見積もり表示 | 作業費＋運送費（ドライバー込み） | 作業費のみ（運送費別途） | 作業費のみ（運送費別途） |
| ドライバー費用の扱い | 見積もりに含める | 別途計上（顧客手配の場合あり） | 別途計上 |
| 顧客の印象 | 総額が高く見える | 作業費が安く見える | 作業費が安く見える |

## 提案: ドライバー費用除外方式

### 新方式のコスト構造

```
見積もり金額 = 作業費（デザイン・制作・設営・解体）のみ
　　　　　　　← ドライバー費用は含まない

ドライバー費用 = 社内でプール管理
　　　　　　　← 複数案件を統合し、効率的な配送ルートを組む
　　　　　　　← 繁忙期は外部運送会社とスポット契約
```

### 具体的な運用ルール

#### 1. 見積もり記載ルール

| 項目 | 記載方法 |
|------|---------|
| 作業費（デザイン・制作・設営・解体） | ✅ 見積もりに明記 |
| 資材費（パネル・印刷・照明等） | ✅ 見積もりに明記 |
| 運送費（車両代） | ✅ 別途実費（見積もり備考欄に記載） |
| **ドライバー人件費** | **❌ 計上しない（社内コストとして吸収）** |
| 現場での追加配送 | ✅ 実費（事前見積もり範囲外は別途協議） |

#### 2. ドライバーリソースの統合管理

```
[従来] 案件A ── ドライバーA（専属）
       案件B ── ドライバーB（専属）
       案件C ── ドライバーC（専属）
       → 3案件でドライバー3名必要

[新方式] 案件A ──┐
         案件B ──┼── ドライバー1名で統合配送
         案件C ──┘
         → 3案件でドライバー1名に最適化
```

#### 3. 対象範囲

| 対象 | 判定 |
|------|------|
| 大阪市内のブース設営 | ✅ 除外（自社ドライバーで対応可能） |
| 大阪近郊（50km圏内） | ✅ 除外（統合配送の対象） |
| 遠方（50km超・他都道府県） | ⚠️ 状況により別途計上を検討 |
| 特殊搬入（エレベーターなし・階段等） | ❌ 別途協議（運送会社の特殊車両が必要） |
| 大型案件（6小間超・重量物あり） | ⚠️ 状況により別途計上を検討 |

#### 4. 社内コスト管理

- **月次のドライバー稼働実績を集計**: 全案件の配送先・時間帯・距離を記録
- **統合配送率をKPI化**: 1配送トリップあたりの案件カバー率を測定
- **繁忙期の外部委託基準**: 自社ドライバーの稼働率が80%を超えたら外部運送会社を活用
- **コスト上限の設定**: 月間のドライバー関連コストを予算枠で管理

## 期待される効果

### コスト削減効果

| 項目 | 現行 | 新方式（試算） | 削減率 |
|------|------|--------------|--------|
| 1案件あたりのドライバー費用 | 3〜5万円 | 1〜2万円（統合配送後） | 40〜60% |
| 見積もり金額（2小間の場合） | 約60万円（ドライバー込み） | 約55万円（ドライバー除外） | 約8% |
| ドライバー稼働率 | 40〜50% | 60〜80% | 20〜30pt向上 |

### 競争力向上

- **見積もり金額が5〜15%低減**: 同条件の競合比較で優位に
- **価格交渉の余地が拡大**: ドライバー費用を値引き枠として活用可能
- **小規模案件の受注率向上**: 1〜2小間の案件でも価格競争力が改善

### 業務効率化

- 配送ルートの最適化による燃料費・時間の削減
- ドライバーの待機時間削減（次の現場への移動をスムーズに）
- 繁忙期の外部委託判断基準の明確化

## リスクと対策

| リスク | 発生確率 | 影響 | 対策 |
|--------|---------|------|------|
| 遠方案件でドライバー費用が想定外に膨らむ | 中 | 中 | 50km超は別途協議の対象とする |
| 繁忙期に自社ドライバーが不足する | 高 | 大 | 外部運送会社とのスポット契約を事前に締結 |
| 顧客が「運送費は含まれていますか」と問い合わせる | 高 | 小 | 見積もり備考欄に明記し、FAQを用意 |
| 統合配送の調整工数が増加する | 中 | 中 | 配送管理ツール（スプレッドシート）で一元管理 |
| 大型案件でドライバー1名では対応できない | 低 | 大 | 案件規模に応じて別途計上の判断基準を設定 |
