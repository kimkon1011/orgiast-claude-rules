# P-0025 賃金台帳訂正と補助金リスクの検証

> **作成**: 2026-11-19
> **状態**: 提案
> **担当**: 総務・労務管理

---

## 課題

7月分賃金台帳に修正（訂正）が入った。この修正後の賃金台帳を元に補助金申請を行う場合、既に提出済みの申請書類との整合性や、審査基準への適合性をどう担保するかが課題。

特に、労働局の助成金審査では **「提出後の書類差し替え・訂正は原則認められない」** という厳格なルールがあり、事後的な修正が不正受給とみなされるリスクがある。

---

## 調査結果

### 1. 賃金台帳の訂正と補助金審査のルール

#### 差し替え・訂正は原則不可

厚生労働省および各労働局の公式見解：

| 根拠 | 内容 |
|------|------|
| 厚生労働省「業務改善助成金」申請マニュアル | 「申請に対する審査で賃金台帳にかかる不備を指摘された後、賃金台帳の記載が誤っていた等を主張されても**差替えは認められません**」 |
| 北海道労働局 | 「不正受給防止のため、申請用に賃金台帳を作り直すことは行わないでください」 |
| 岐阜労働局 | 「事業主都合による書類の差し替えや訂正は原則、認められず、**不支給決定となります**」 |
| 東京労働局 | 「不正受給防止の観点から、一度提出された書類について、事業主の都合などによる差替えや訂正を行うことはできません」 |

#### 例外：客観的資料で真実の状況が確認できる場合

審査で不備を指摘された後に「誤りだった」と主張しても、**客観的資料**で真実の状況が支給要件を満たすことが確認できる場合に限り救済される可能性がある。

### 2. 違反時のペナルティ

| ペナルティ | 詳細 |
|-----------|------|
| **返還請求** | 支給された助成金全額の返還 |
| **違約金** | 返還額の約20％相当 |
| **延滞金** | 年3％ |
| **5年間の雇用関係助成金受給停止** | 全労働局所管の助成金が対象 |
| **企業名公表** | 悪質な場合は労働局が公表 |
| **刑事告発** | 刑法第246条詐欺罪に問われる可能性 |

### 3. 審査・調査で確認されるポイント

#### 帳簿間の突合チェック
- 出勤簿（タイムカード） ↔ 賃金台帳 ↔ 給与明細書 ↔ 源泉徴収簿 ↔ 総勘定元帳
- 労働条件通知書（雇用契約書）と実際の支払いの一致

#### 法定記載事項の網羅性（労働基準法第108条）
- 氏名・性別
- 賃金計算期間
- 労働日数・労働時間数
- 時間外労働時間数・休日労働時間数・深夜労働時間数
- 基本給・手当等の金額
- 控除額（社会保険料・所得税等）

#### 実態調査
- 従業員ヒアリング（支払実績の確認）
- 施錠記録・入退室記録と勤怠の整合性
- 事前連絡なしの立入検査

### 4. 外部監査による検証方法

外部の社会保険労務士等による労務監査では以下の手順が推奨されている：

1. **勤怠記録の統一**
   - タイムカード・出勤簿・入退館記録の時系列一致確認
2. **賃金台帳と雇用契約の突合**
   - 契約上の賃金と実際の支払いが一致するか
3. **就業規則と実態の一致**
   - 時間外労働のルール、休日規定が実運用と合致するか
4. **法定記載事項の網羅性確認**
   - 法第108条の必要項目が全て記載されているか
5. **時系列の整合性確認**
   - 修正箇所の前後で不自然な改ざん痕跡がないか

## 提案：外部監査による適合性検証の実施手順

### Phase 1: 現状分析（内部）

| ステップ | 内容 | 所要目安 |
|---------|------|---------|
| 1-1 | 7月分賃金台帳の修正箇所を特定（Before/After比較表） | 1日 |
| 1-2 | 修正理由を記録（誤記の種類・発覚経緯・修正日時） | 0.5日 |
| 1-3 | 修正後の賃金台帳と出勤簿・給与明細の整合性を自己点検 | 1日 |
| 1-4 | 該当補助金の要綱・申請時提出書類と現在の状態を対比 | 1日 |

### Phase 2: 外部社労士による監査

| ステップ | 内容 | 所要目安 |
|---------|------|---------|
| 2-1 | 顧問社労士または外部労務監査専門事務所へ監査依頼 | ー |
| 2-2 | 修正前後の全書類を提供し、監査人による検証 | 3〜5日 |
| 2-3 | 監査結果報告書の受領（適合/要注意/不適合の判定） | ー |

### Phase 3: リスク評価と対応方針決定

| リスクレベル | 状態 | 対応方針 |
|------------|------|---------|
| **低** | 軽微な計算誤記（例：端数処理の違い）で実支給額に影響なし | 修正経緯を記録し、次回申請時の添付資料として説明できる状態を整備 |
| **中** | 記載漏れ（例：一部の手当の内訳が未記載）だが実支給額は正しい | 補正説明資料を作成し、労働局の指摘に備える |
| **高** | 実支給額と台帳が異なる / 労働時間の記載が実態と乖離 | 専門家に相談の上、自主点検・自主申告の要否を判断 |

### Phase 4: 再発防止策

| 施策 | 概要 | 効果 |
|------|------|------|
| 勤怠管理システム導入 | タイムカードの自動集計・賃金台帳との連動 | 転記ミス・入力漏れを防止 |
| 月次内部チェック | 毎月15日までに前月分の賃金台帳と出勤簿を照合 | 早期発見・早期修正（申請前） |
| 法定記載事項テンプレート | 賃金台帳の法定項目が漏れなく埋まる様式を使用 | 記載漏れリスクの低減 |
| 四半期ごとの社労士レビュー | 年4回の定期労務監査 | 申請時の突発的修正リスクを回避 |

## 推奨アクション

1. **至急**: 7月分賃金台帳の修正箇所を洗い出し、修正前後の状態を記録する
2. **推奨**: 顧問社労士に現状を開示し、助成金審査への影響を確認する（外部監査Phase 2）
3. **重要**: 修正の理由・経緯・日時を明確に文書化し、客観的証拠を揃える
4. **中期的**: 勤怠管理システムの導入を検討し、転記ミスの根本原因を断つ
5. **継続的**: 月次の自己点検ルーチンを確立し、申請前に不整合を発見できる体制を整える
