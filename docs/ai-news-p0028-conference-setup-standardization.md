# P-0028: 学会設営・撤去フローの標準化による搬入搬出時間20%短縮の検証

## 概要

展示会・学会ブースの設営と撤去は案件ごとに作業者が異なり、手順が属人化しやすい。
チェックリストと共有スプレッドシートを導入し、搬入搬出時間を20%短縮できるかを
実案件で検証する。

## 現状分析

### 課題

1. **属人化**: 設営・撤去の手順が担当者ごとの暗黙知に依存し、引き継ぎが非効率
2. **二度手順**: 同じ会場でも毎回ゼロから段取りを考え直している
3. **忘却漏れ**: 写真記録忘れ・備品返却漏れで後日対応が発生
4. **役割不明確**: 誰が何をいつやるかが口頭伝達のみで、抜け・重複が発生
5. **データ不在**: 「前回の設営に何分かかったか」の計測データが残っていない

### 実測したい指標

- **搬入時間（設営開始〜設営完了）**: 現状のベースラインを計測
- **搬出時間（撤去開始〜原状回復完了）**: 同上
- **手戻り件数（忘れ物・再作業）**: チェックリスト導入前後で比較
- **質問回数（「これどこ？」「次なに？」の発生）**: 属人化の度合いを数値化

### 2. 共有スプレッドシートの構成

Google スプレッドシート（案件Driveに作成）で以下のシート構成とする:

| シート名 | 内容 |
|---------|------|
| 設営チェックリスト | 上記18タスク＋作業者・実績時間カラム |
| 撤去チェックリスト | 上記14タスク＋作業者・実績時間カラム |
| 役割分担 | 班分け・リーダー・連絡先 |
| 機材一覧 | 持込機材リスト（メーカー・型番・数量・写真URL） |
| 時間計測 | 搬入搬出の実績時間蓄積（案件ID・会場名・搬入時間・撤去時間・特記事項） |
| 写真台帳 | 搬入前／搬出後の会場写真URL（Before/After比較用） |
| 改善ログ | 各案件の反省点・改善案（次回へのフィードバック） |

### 3. 運用フロー

```
案件着手
  │
  ├─ 案件の規模（小/中/大）に応じてチェックリスト範囲を選択
  ├─ 共有スプレッドシートを案件Driveに複製
  ├─ 役割分担シートを事前に記入しスタッフへ共有
  │
  ▼
設営当日
  │
  ├─ ①搬入前の会場写真：シートの写真台帳に記録
  ├─ ②役割分担に従い並行作業開始
  ├─ ③各タスク完了時に☑と実績時間を記入
  ├─ ④設営完了時：全体写真＋最終確認
  │
  ▼
撤去当日
  │
  ├─ ①撤去開始時刻を逆算して明示
  ├─ ②撤去タスクを並行実行（雰囲気を残しながら）
  ├─ ③搬出後の会場写真：Before/After対比
  ├─ ④忘れ物チェック＋清掃確認
  │
  ▼
案件終了後
  │
  ├─ 時間計測シートに実績を転記
  ├─ 改善ログに気づきを記入
  ├─ 次回同会場案件があれば参照
```

## コスト試算・期待効果

### 導入コスト
- チェックリスト作成: 1回（約2時間・初期コスト）
- 共有スプレッドシートテンプレート: 1回（約1時間・初期コスト）
- 案件ごとの複製・調整: 各案件10〜15分
- スタッフ教育: 初回案件で30分のオンサイト説明

### 期待効果

| 指標 | 現状（推定） | 目標 | 根拠 |
|------|------------|------|------|
| 搬入時間 | 3〜5時間 | 2.4〜4時間（▲20%） | 並行作業の明示化・抜けの削除 |
| 撤去時間 | 2〜3時間 | 1.6〜2.4時間（▲20%） | 逆算思考＋役割明確化 |
| 手戻り件数 | 案件あたり1〜3件 | 0〜1件（▲67%） | チェックリストで忘れ防止 |
| 引き継ぎ時間 | 30〜60分/回 | 10〜15分/回（▲70%） | スプレッドシートで情報共有済み |

### 20%短縮の根拠
1. **並行作業の促進**: 役割分担表で並行作業が可能なタスクを明示し、直列→並列に転換
2. **判断時間の削減**: 「次に何をやるか」の判断が不要（チェックリストで一目瞭然）
3. **手戻りの削減**: 忘れ物確認・再作業の時間ゼロ
4. **職能別動線**: 道具・機材の位置が事前共有され「取りに行く」ロスタイム削減

## 検証計画

### フェーズ1（初回案件での検証）
- 次回の学会/展示会案件でチェックリストとスプレッドシートを試用
- 各タスクの実績時間を計測・記録
- スタッフへのヒアリングで改善点を収集

### フェーズ2（3案件後の評価）
- 3案件のデータを蓄積し、搬入搬出時間の推移をグラフ化
- 20%削減達成度を評価
- チ���クリストの改善（不要タスクの削除・追加タスクの組み込み）

### フェーズ3（標準化・定着）
- テンプレートの確定と案件Driveへの常設
- 案件マスターファイルでチェックリスト使用をルール化
- 新人が初めて設営を担当しても迷わない状態を目標
