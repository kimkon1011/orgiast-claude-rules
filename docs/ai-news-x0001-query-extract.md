# X-0001: 正規表現でAIクエリ抽出 — 疑問文系・依頼文系の抽出

観測日: 2026-11-09。出典: AIニュース digest X-0001「正規表現でAIクエリ抽出」。
本稿は「株式会社オージャストで試す手順」＝展示会ブース制作・イベント関連サイトで、訪問者の検索クエリやLINE投稿から**疑問文系（質問）と依頼文系（依頼・要望）を正規表現で抽出**し、LLMO（LLM最適化）分析に活用するためのツールと手順を文書化したもの。

## 従来の課題

| 問題 | 説明 | 結果 |
|------|------|------|
| 訪問者がサイトで何を知りたいのか、漠然とした検索クエリから意図が読み取れない | 検索クエリが短く「展示会 ブース」「イベント 制作」のような名詞連打 | ユーザーが質問しているのか、見積もり依頼なのか区別できず、コンテンツ戦略が曖昧になる |
| LINEからの問い合わせが一文で複��の意図を含む | 「3m小間の見積もりと搬入日程を教えてください」に質問と依頼が混在 | 定型返信では片方しか答えず、再問い合わせが発生する |
| AIによるクエリ分類をLLMに丸投げするとコストがかかる | 全クエリを毎回LLMに投げるのは検索クエリ数が多いと高額 | 正規表現で軽量に一次分類し、不明分だけLLMに回したい |

## ツール: `tools/ai-query-extract.mjs`

### 機能

- 入力テキストを文単位に分割
- 各文を**疑問文系**（❓）と**依頼文系**（📋）に正規表現で分類
- 両方に該当する文は `both` と判定
- JSON出力（`--json`）・集計表示（`--summary`）・標準表示の3モード

### 正規表現パターン一覧

#### 疑問文系（question）

| パターン名 | 正規表現の狙い | マッチ例 |
|-----------|--------------|---------|
| 疑問符 | 文末の `？` `?` | 「いつまでですか？」 |
| 疑問詞 | `なぜ/どう/どの/どこ/いつ` + 文末疑問形 | 「なぜこのデザインが選ばれたのですか」 |
| 文末疑問 | `か/でしょうか/ですか/ますか/だろうか` | 「予算内で収まるものでしょうか」 |
| 丁寧疑問 | `可能でしょうか/いただけますか/よろしいでしょうか` | 「3m小間での施工は可能ですか」 |
| 条件疑問 | `場合/とき/際` + 疑問形 | 「急ぎの場合、納期はどのくらいですか」 |

#### 依頼文系（request）

| パターン名 | マッチ例 |
|-----------|---------|
| 〜てください | 「見積書を送ってください」 |
| 〜してほしい/もらいたい | 「デザイン案を出してほしい」 |
| 〜お願い | 「資料の送付をお願いします」 |
| 〜教えて | 「出展手順を教えてください」 |
| 〜知りたい | 「事例について知りたい」 |
| 〜調べて | 「価格を調べてください」 |
| 〜たい希望 | 「見積もりたい/相談したい/提案してほしい」 |
| 〜依頼 | 「デザインの依頼」 |
| 〜見積もり | 「3m小間の見積もり」 |

### 使用方法

```bash
# ファイルから抽出
node tools/ai-query-extract.mjs sample.txt

# パイプ入力
echo "3m小間の見積もりをお願いします。納期はいつですか？" | node tools/ai-query-extract.mjs

# JSON出力（他のツールとの連携用）
node tools/ai-query-extract.mjs queries.txt --json

# 集計表示
node tools/ai-query-extract.mjs queries.txt --summary
```

### 出力例

```
R [request] (〜お願い): 3m小間の見積もりをお願いします。
? [question] (疑問符, 文末疑問): 納期はいつですか？
--- 合計: 2件（疑問:1 / 依頼:1 / 両方:0）
```

`--summary` モード:
```
--- 抽出結果 ---
総文: 2
疑問文系: 1
依頼文系: 1
両方: 0

--- 上位パターン ---
  request:〜お願い: 1件
  question:疑問符: 1件
  question:文末疑問: 1件

--- 抽出クエリ ---
R [request] 3m小間の見積もりをお願いします。
? [question] 納期はいつですか？
```

## オージャストで試す手順

### Step 1: サイト検索クエリの収集

Google Search Console から「展示会ブース制作」「イベント制作」関連の検索クエリをエクスポートする。

```bash
# GSCデータ（query.csv）をツールにかける
node tools/ai-query-extract.mjs gsc-queries.csv --summary
```

→ どのクエリが「質問型」で、どのクエリが「見積もり依頼型」かが分かる。

### Step 2: LINE投稿の分析

LINE公式アカウントのトーク履歴（エクスポートJSONL）を分析する。

```bash
# LINEのトーク履歴からクエリ抽出
cat ~/.claude/line-openchat/2026-11.jsonl | node tools/ai-query-extract.mjs --summary
```

→ 「質問」「依頼」「両方」の比率が分かり、自動応答の振り分け設計に使える。

### Step 3: LLMO分析への活用

抽出結果をLLMO（LLM最適化）の指標として使う:

1. **質問型クエリの多いページ** → FAQ・解説コンテンツを充実させる（AIが引用しやすい構造化マークアップ）
2. **依頼型クエリの多いページ** → 問い合わせフォーム・見積もり導線を最適化する
3. **両方のクエリ** → AI回答テンプレートで質問＋見積もりの両方に一度で応答する設計

### Step 4: 自動化（cron定期実行）

毎週のクエリ傾向を自動計測する場合:

```bash
# 週次で集計
node tools/ai-query-extract.mjs --json < weekly-queries.txt > query-classification-weekly.json
```

→ トレンド変化（質問から依頼へのシフト等）を追跡できる。
