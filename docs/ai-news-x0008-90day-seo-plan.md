# X-0008: 展示会関連新トピックの90日AI SEO計画

策定日: 2026-11-10 | 出典: AIニュース提案 [X-0008] 新トピックの90日AI SEO計画
自社目標: 月間クリック328 → 12ヶ月後22,443（既存X-0008 Ahrefs分析を基軸に展示会ブース制作SEOを拡大）

本計画は「X/Trendsで発見した展示会新トレンド → Claudeでトピックマップ化 → 質問ページ公開 → Search Consoleで追跡」のサイクルを90日で実行する実践計画。既存のX-0008 Ahrefs競合分析・展示会出展者ワークフローと連動し、展示会ブース制作におけるオージャストのSEO可視性を飛躍的に高める。

### 3.2 Search Console 5-20位ページの改善ループ

**対象**: 掲載順位5-20位のページ（クリックポテンシャルが高い）

**改善手順**:

1. Search Consoleから「掲載順位5-20位・impressions 100以上」のクエリをエクスポート
2. 各クエリに対して:
   - タイトルタグにクエリを含める
   - H2/H3見出しに自然な形でクエリを追加
   - 関連FAQセクションの拡充
   - 内部リンクの追加（該当ページへの導線強化）
3. 改善から2週間後の順位変動を確認
4. 改善効果があったパターンをテンプレート化
