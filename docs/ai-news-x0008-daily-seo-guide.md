# X-0008: コーディングエージェントと毎日1本のSEOガイド

**AIニュース提案 X-0008**: GSCデータから高IMP低CTRキーワードを毎朝発見し、そのキーワードで高品質SEOガイドを1本生成するワークフロー。生成したガイドは内部リンクとCTAを含む構造化マークダウンとして出力し、サイトへ追加することを前提とする。

## コンセプト

gum（AIコーディングエージェント）がGoogle Search ConsoleとKeyword Plannerに接続し、サイトが表示されるがクリックがないキーワード（例: 16,000インプレッションで50位）を見つけ、そのキーワードで高品質ガイドを1本書くフロー。Googleは3-4日で新しいコンテンツをピックアップし、CTA経由で約10%の訪問者がコンバージョンする。

株式会社オージャストでは**展示会ブース制作関連キーワード**で同様の毎日1ガイド生成を行い、サービスページへ内部リンクするワークフローを試す。

## アーキテクチャ

```
GSC CSV/JSON (キーワードデータ)
       │
       ▼
daily-seo-guide.mjs ───┬──→ ① キーワード選択（未カバー・高優先度）
       │                ├──→ ② SEOガイド生成（llm-ask.mjs 経由 安価AI）
       │                ├──→ ③ 内部リンク・CTA埋め込み
       │                └──→ ④ マークダウン出力 + レジャー記録
       │
       ▼
outputs/X-0008/guides/{date}-{slug}.md  (生成されたガイド)
outputs/X-0008/ledger.json              (生成履歴管理)
```

## 既存ツールとの関係

| ツール | 役割 | 連携 |
|--------|------|------|
| `tools/gsc-keyword-finder.mjs` | GSCから高IMP低CTRキーワード抽出 | そのJSON出力を本ツールの入力に使う |
| `tools/seo-content-complement.mjs` | 既存ページのSEO補完 | 別用途（X-0013）。本ツールは新規ガイド生成 |
| `tools/llm-ask.mjs` | 安価AIへの質問 | ガイド本文の生成に使う |

## 測定と改善サイクル

1. **毎朝実行**: 前日のGSCデータを読み込み、未カバーで優先度の高いキーワードを選択
2. **ガイド生成**: 安価AIでSEOガイドを1本生成
3. **公開**: 生成されたガイドをサイトに追加（手動またはCI連携）
4. **測定**: 7-14日後にGSCで掲載順位・CTRの変化を確認
5. **改善**: ガイドの構成・キーワード選択ロジックを反復改善

## 制約

- Claude APIは使わない。`tools/llm-ask.mjs` 経由の安価AI（gemini/deepseek/groq）のみ
- GSC APIのOAuthが未設定の場合はCSVエクスポートからの読み取りに対応
- 外部npmパッケージの追加インストールは行わない（Node.js組み込みのみ）
