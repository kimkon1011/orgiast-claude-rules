# X-0009: AI引用ソースのブランド言及分析ツール

> 設計書 v1 — 2026-11-10

## 概要

商業的質問を複数の安価AI（Gemini/DeepSeek/Groq）に同時に送信し、各AIの回答中にどの企業ブランドが言及されているかを抽出・比較する。
自社ブランド（オージャスト）が言及されているか、競合が言及されているかを一覧化し、不足している言及を埋めるコンテンツ戦略の判断材料を提供する。

## 元記事との対応

Surfer分析の手法（289,105引用URL、73%が1つのAIのみに出現、全4AI出現は2.2%）をオージャスト向けにスコープダウン：
- 自社ツールの LLM (`tools/llm-ask.mjs`) で代用（Claude/Perplexity 等の実API呼び出しは行わない）
- 複数プロバイダ（gemini / deepseek / groq）に同質問を投げ、回答中のブランド出現を抽出
- 「自社（オージャスト）が出ているか」「競合（rebooth等）が出ているか」を判定

## CLI仕様

```bash
# 単一質問のブランド言及分析
node tools/brand-mention-analyzer.mjs \
  --question "展示会ブース制作 おすすめの会社は？" \
  --brand "オージャスト" \
  --output markdown

# 複数質問の一括分析（CSV入力）
node tools/brand-mention-analyzer.mjs \
  --questions-file data/commercial-questions.csv \
  --brand "オージャスト" \
  --output json

# 競合ブランドを指定して比較
node tools/brand-mention-analyzer.mjs \
  --question "展示会ブース デザイン 会社" \
  --brand "オージャスト" \
  --competitors "リブース,クラフト,ブーステック" \
  --output markdown
```

### オプション

| フラグ | 必須 | デフォルト | 説明 |
|--------|------|-----------|------|
| `--question` | 条件付き | - | 分析する商業的質問（questions-file と排他） |
| `--questions-file` | 条件付き | - | 質問CSVファイル（question と排他） |
| `--brand` | いいえ | "オージャスト" | 自社ブランド名（言及検出対象） |
| `--competitors` | いいえ | - | カンマ区切りの競合ブランド一覧 |
| `--providers` | いいえ | "gemini,deepseek,groq" | 問い合わせ先AIプロバイダ |
| `--output` | いいえ | "markdown" | 出力形式 (markdown / json) |

## 処理フロー

```
[入力] --question "展示会ブース制作 おすすめの会社は？"
    │
    ├──→ llm-ask.mjs (gemini)  → 回答テキスト + 引用抽出
    ├──→ llm-ask.mjs (deepseek) → 回答テキスト + 引用抽出  
    └──→ llm-ask.mjs (groq)     → 回答テキスト + 引用抽出
    │
    ├──→ ブランド名抽出（キーワードマッチ + 簡易NER）
    ├──→ 引用URL抽出（URLパターン）
    ├──→ クロス集計（ブランド × AIプロバイダ）
    └──→ レポート生成（markdown / json）
```

## LLMプロンプト設計

各AIに送るシステムプロンプト:

```
あなたは有益な情報を提供するアシスタントです。
以下の質問に対して、具体的な企業名やサービス名を含めて回答してください。
回答の末尾には、参考にした情報源のURLがあれば列挙してください。
```

各AIに送るユーザープロンプト: `--question` の値をそのまま使用。

## ブランド検出ロジック

1. **完全一致**: 回答テキストにブランド名が文字列として含まれているか
2. **部分一致**: ブランド名の一部（「オージャスト」が「オージャスト株式会社」として出現など）
3. **URLドメイン一致**: 回答に含まれるURLのドメインがブランドのWebサイトと一致するか
4. **競合ブランド**: `--competitors` で指定されたブランドも同様に検出

ブランド情報は設定不要で動作する組み込みセット（オージャスト／リブース）に加え、`--competitors` で拡張可能。

## 依存

- `tools/llm-ask.mjs` — 各AIへの質問・回答取得
- Node.js 20+ (ES Modules)

## 制約

- 実際のClaude/ChatGPT/Perplexity APIは使わず、`tools/llm-ask.mjs` 経由の安価AIのみ
- AIの回答品質は各プロバイダの知識カットオフとトレーニングデータに依存
- 「引用」はAIが回答中に明示的に言及した企業名・URLであり、実際の学習データ中の割合とは異なる
- 回答の再現性は保証されない（同じプロバイダでも温度パラメータ等で変動）
