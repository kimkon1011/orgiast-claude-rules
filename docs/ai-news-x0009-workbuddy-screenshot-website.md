# X-0009: スクショからAIでウェブサイト再現 — WorkBuddy + Hy4 統合設計書

> 2026-11-10 設計。自動セッションによる初回実装。

## 概要

WorkBuddy（Tencent 提供の AI Agent for Everyday Office Work）の **Code タブ** で Website テンプレートを選択し、Frontend Developer と UI Designer の AI エージェントを追加。Hy4（高思考モード）を選択し、スクリーンショットとデザイン資産をアップロードすることで、スクショを元にしたフルスクラッチの Web サイトを生成する。

本設計書は、株式会社オージャストの展示会ブース提案・イベントサイト構築フローに本手法を組み込むためのスキル定義とワークフローを提供する。

## WorkBuddy + Hy4 の screenshot-to-website 能力

2026年11月に公開された Tencent Hy4 は、Tencent 史上初の vision / computer use 対応モデル。WorkBuddy 上で無料枠（2026-11-15 まで）で利用可能。スクショ1枚から数分で動作する Web ページを生成できる。

| 機能 | 説明 |
|------|------|
| **Vision 対応** | 画像を読み取り、レイアウト・カラー・構造を正確に再現 |
| **Code タブ** | Website テンプレート + Frontend Developer/UI Designer エージェントの協調生成 |
| **Hy4 高思考** | 複雑なレイアウト・UI インタラクションも正確に再現する高思考モード |
| **マルチテンプレート** | Website / App / Dashboard / Portfolio などのテンプレートから選択 |
| **生成物** | HTML/CSS/JS、Vue2、React などに対応。ファイル構成・プレビュー・最適化テーブルを表示 |
| **価格 (API)** | $0.834/1M token input, $2.501/1M token output（OpenRouter / Tencent Cloud TokenHub） |

## ワークフロー

```
[準備] 再現したい Web サイトのスクショを用意（全面 or 主要セクション）
   ↓
[WorkBuddy Code タブ]
   ├─ Website テンプレート選択
   ├─ Frontend Developer + UI Designer エージェント追加
   ├─ Hy4 (高思考) モード選択
   └─ スクショ + ブランド資産（ロゴ/フォント/カラーコード）をアップロード
   ↓
[プロンプト投入]
   ├─ 構造: ヘッダー/メイン/フッター/セクション配置
   ├─ ブランド: カラー（#rrggbb）/フォント/トーン
   ├─ レイアウト: デスクトップ/タブレット/モバイル
   ├─ インタラクティブ: ホバー/アニメーション/フォーム
   └─ 技術スタック: HTML5+Tailwind/React/Vue/素のCSS
   ↓
[レビュー]
   ├─ 最適化テーブル: 各指標のスコア確認
   ├─ デザイン比較: スクショと生成結果の比較
   ├─ ファイル構成: 生成されたファイル一覧
   ├─ プレビュー: 実ブラウザプレビュー
   └─ レスポンシブ: モバイル/タブレット表示確認
```

## プロンプトテンプレート

本リポジトリの `tools/screenshot-website-builder.mjs`（X-0014）を WorkBuddy 投入用プロンプト生成に使用する。下記は標準テンプレートの構造：

| セクション | 内容 | 必須 |
|---|---|---|
| Screenshot Reference | アップロードしたスクショの説明 | ✓ |
| Structural Guide | ページ構造（header, main, footer, grid） | ✓ |
| Brand Spec | ブランドカラー・フォント・トーンマナー | ✓ |
| Layout Rules | デスクトップ/タブレット/モバイルの振る舞い | ✓ |
| Interactive Spec | ホバー・クリック・フォームの動作定義 | optional |
| Component Checklist | 生成すべきUIコンポーネント一覧 | ✓ |
| Tech Stack | フレームワーク・CSS・JS制約 | ✓ |

`skills/workbuddy-screenshot/SKILL.md` は AI エージェントが本ワークフローを再現するための手順書。

## 期待効果

- **高速プロトタイピング**: スクショ1枚から数分で Web ページが生成される
- **デザイン意図の正確な伝達**: 「言葉で説明しにくい」レイアウトや雰囲気をそのまま再現
- **マルチエージェント品質**: Frontend Developer と UI Designer が協調して品質を高める
- **Hy4 の高思考**: 複雑な UI インタラクション・レスポンシブ対応も正確
- **オージャスト固有最適化**: 展示会ブース案件ごとに統一感のある Web ページを効率生成
- **コスト効率**: 従来の人工作業と比較して約 1/10 の時間で同等以上の品質

## 制約・注意点

- WorkBuddy は mac/Windows アプリ（別途インストール・契約が必要）
- Hy4 無料枠は 2026-11-15 まで。以降は API 課金（$0.834/1M input tokens）
- スクショはデザイン参照用であり、そのままの複製ではなく「同様のUI」を生成する
- 生成後は必ず人間のレビュー（アクセシビリティ・コントラスト・実テキスト置換・リンク修正）を行う
- オージャスト ブランドガイドライン（CLAUDE.md 配布）と整合させること
- 機密情報（顧客名・金額等）がスクショに写っていないことを確認すること
