# X-0014: スクショからAIウェブサイト生成

- **ステータス**: PHASE1 設計完了（2026-11-09）
- **AIニュース提案**: WorkBuddy Codeタブ + Hy4高思考 + スクショアップロード → スキャフォールド・コンポーネント生成
- **オージャスト適用**: 展示会ブース・イベントサイトのデザインスクショから同様のUI生成

---

## 1. 概要

WorkBuddy の Code タブで Website テンプレートを選び、Frontend Developer と UI Designer エージェントを追加。Hy4 (high-thinking) モードを選択し、オリジナルのスクリーンショットとデザイン資産をアップロード。構造・ブランド・レイアウト・インタラクティブ要素を指定したプロンプトを与えて Run Now し、スキャフォールドとコンポーネント生成を実行する。生成後は最適化テーブル、デザイン比較、ファイル構成、プレビュー、レスポンシブ表示をレビューする。

## 2. ワークフロー

```
[スクショ・資産準備]
       ↓
[WorkBuddy Code タブ]
  ├─ Website テンプレート選択
  ├─ Frontend Developer + UI Designer 追加
  ├─ Hy4 (高思考) モード選択
  └─ オリジナルスクショ + 資産アップロード
       ↓
[プロンプト設計]
  ├─ 構造: ヘッダー/フッター/グリッド/セクション配置
  ├─ ブランド: カラー/フォント/トーン
  ├─ レイアウト: デスクトップ/タブレット/モバイル
  └─ インタラクティブ要素: ホバー/アニメーション/フォーム
       ↓
[生成・レビュー]
  ├─ スキャフォールド生成
  ├─ コンポーネント生成
  ├─ 最適化テーブル確認
  ├─ デザイン比較確認
  ├─ ファイル構成確認
  ├─ プレビュー確認
  └─ レスポンシブ確認
```

## 3. プロンプトテンプレート

本リポジトリの `tools/screenshot-website-builder.mjs` は WorkBuddy 投入用の構造化プロンプトを生成する。

### テンプレート構造

| セクション | 内容 | 必須 |
|---|---|---|
| Screenshot Reference | アップロードしたスクショの説明 | ✓ |
| Structural Guide | ページ構造（header, main, footer, grid） | ✓ |
| Brand Spec | ブランドカラー・フォント・トンマナー | ✓ |
| Layout Rules | デスクトップ/タブレット/モバイルの振る舞い | ✓ |
| Interactive Spec | ホバー・クリック・フォームの動作定義 | optional |
| Component Checklist | 生成すべきUIコンポーネント一覧 | ✓ |
| Tech Stack | フレームワーク・CSS・JS制約 | ✓ |

## 4. Orgiast ユースケース

株式会社オージャストの展示会ブース・イベントサイトに特化した下記の適用例を `outputs/X-0014/orgiast-use-case-analysis.md` に詳述:

| # | ユースケース | 入力スクショ | 生成ターゲット |
|---|---|---|---|
| 1 | 標準ブース提案LP | 既存ブース写真・レイアウト図 | 提案先用ランディングページ |
| 2 | イベント詳細ページ | 過去イベント名刺・フライヤー | 出展情報・タイムテーブル |
| 3 | 会社概要・実績紹介 | パンフレットスキャン | 施工実績ギャラリー |
| 4 | お問い合わせフォーム | 既存Webのフォームスクショ | レスポンシブ問合せフォーム |
| 5 | 複数ブース比較表 | Excel/PDFの比較表 | ソート・フィルター付き比較表 |

## 5. この方法の利点

- **デザイン意図の保持**: スクショをそのままアップロードするため「言葉で説明しにくい」デザイン意図が正確に伝わる
- **反復生成の効率**: Hy4 高思考モードで複雑なレイアウトを正確に再現
- **マルチエージェント**: Frontend Developer と UI Designer が協調して品質を高める
- **レスポンシブ**: デスクトップ/モバイルの両方を意識した生成
- **オージャスト固有**: 展示会ブース案件ごとに統一感のあるWebページを効率生成

## 6. 制約・注意点

- WorkBuddy Code タブは別途契約・セットアップが必要
- スクショはデザインの参照用であり、そのままの複製ではなく「同様のUI」を生成する意図
- 生成後は必ず人間のレビュー（アクセシビリティ・コントラスト・実テキスト置換）を行う
- 既存の Orgiast ブランドガイドライン（CLAUDE.md 配布）と整合させること
