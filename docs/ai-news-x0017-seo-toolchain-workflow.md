# X-0017: SEOサイト制作のAIツール連鎖ワークフロー

**AIニュース提案 X-0017**: リサーチ→ドラフト→最適化→作成→公開の5段階を、異なる専門AIツールの連鎖で実行するSEOサイト制作ワークフロー。調査にChatGPT / Gemini / Claude / NotebookLM / Perplexity、SEO最適化にWritesonic / Surfer SEO / Ahrefs Webmaster Tools / Semrush Free Toolsを使用する。

観測日: 2026-11-10

---

## 1. 概要

単一のAIツールでSEO記事を完結させるのは困難である。リサーチ能力・文章生成品質・SEOスコアリング・技術的最適化はそれぞれ異なるツールが得意としており、**専門ツールを連鎖させることで初めて高品質なSEOサイト制作が実現する**。

本提案では、以下の5段階ワークフローを定義し、各段階に最適なAIツールを割り当てる。

```
[1. リサーチ] → [2. ドラフト] → [3. SEO最適化] → [4. 作成] → [5. 公開・監視]
    │                │               │               │              │
    ├ Perplexity     ├ Claude        ├ Surfer SEO    ├ Writesonic   ├ Ahrefs
    ├ ChatGPT        ├ ChatGPT       ├ Semrush       ├ Claude        ├ GSC
    ├ Gemini         ├ Writesonic    ├ Ahrefs WMT    └ Surfer SEO   └ Semrush
    ├ NotebookLM     └ Gemini
    └ Claude
```

---

## 2. 各段階の詳細

### Stage 1: リサーチ（Research）

**目的**: キーワード発掘、検索意図の把握、競合分析、トピッククラスターの設計

| ツール | 役割 | 特長 |
|--------|------|------|
| **Perplexity** | 最新情報・ソース発見 | リアルタイムWeb検索＋引用付き回答。トップ10記事のカバレッジ分析 |
| **NotebookLM** | 知識ベース構築 | 競合記事・業界PDF・GSCデータを1ノートブックに集約。トピックカバレッジマトリックス作成 |
| **ChatGPT / Gemini** | 検索意図分析 | キーワードクラスタリング、検索意図（Informational / Commercial / Transactional）分類 |
| **Claude** | 構造化分析 | 長文の競合分析レポート、ギャップ分析、アウトライン生成 |

**出力**: キーワードリスト（優先度順）＋ 競合カバレッジマトリックス ＋ アウトライン

### Stage 2: ドラフト（Draft）

**目的**: リサーチ結果に基づき、セクションごとに記事を生成する

| ツール | 役割 | 特長 |
|--------|------|------|
| **Claude** | セクション単位の生成 | 長文コンテキスト（200K tokens）で全文を保持しつつ、セクションごとに高品質なドラフトを生成 |
| **ChatGPT** | トーン調整・リライト | ブランドボイスへの適合、ターゲット読者に合わせたトーン調整 |
| **Gemini** | 多様なバリエーション生成 | 複数の見出し案・リード文案を短時間で生成 |

**出力**: セクションごとのドラフト ＋ トーン調整済み本文

### Stage 3: SEO最適化（Optimize）

**目的**: ドラフトを検索エンジンとAI検索の両方に最適化する

| ツール | 役割 | 特長 |
|--------|------|------|
| **Surfer SEO** | コンテンツスコアリング | トップランキングページとの一致度を0-100でスコアリング。Auto-Optimizeで不足エンティティ・ファクトを1クリック挿入。Content AuditでQuick Win特定 |
| **Semrush Free Tools** | キーワード分析 | Keyword Overview / Keyword Magic Tool で検索ボリューム・難易度・トレンド確認 |
| **Ahrefs Webmaster Tools** | 自社サイト分析 | 被リンク状況・インデックス状況・トップページ確認 |

**出力**: SEOスコア70+の最適化済み記事 ＋ 内部リンク提案

### Stage 4: 作成（Create）

**目的**: 最適化されたコンテンツを実際のWebページとして組み立てる

| ツール | 役割 | 特長 |
|--------|------|------|
| **Writesonic** | エンドツーエンド生成 | AI Article Writer 6.0（100+ステップ・11フレームワーク）でGoogle/AI検索両方に最適化された記事を生成 |
| **Surfer SEO** | 最終スコア確認 | 最終版のContent Scoreを確認。不足エンティティの補完 |

**出力**: 公開可能な最終稿 ＋ メタデータ（タイトルタグ・メタディスクリプション・FAQスキーマ）

### Stage 5: 公開・監視（Publish & Monitor）

**目的**: 公開後のパフォーマンスを測定し、次のサイクルにフィードバックする

| ツール | 役割 | 特長 |
|--------|------|------|
| **Ahrefs Webmaster Tools** | ランキング追跡 | 掲載順位・被リンク・インデックス状況の継続監視 |
| **Semrush** | 競合トラッキング | 競合の動き・シェア・オブ・ボイスの変化を追跡 |
| **Google Search Console** | パフォーマンス測定 | 表示回数・CTR・平均掲載順位の実測 |

**出力**: 週次/月次パフォーマンスレポート ＋ 改善提案

## 4. 株式会社オージャストへの適用

### ユースケース: 展示会ブース制作サイト（orgiast.jp）のイベント紹介ページ

| 段階 | オージャスト固有の適用 |
|------|----------------------|
| **リサーチ** | 「展示会ブース制作」「イベントプロデュース」「企業周年行事」のキーワードをPerplexityで調査。NotebookLMに過去の施工事例PDF・競合サイト（乃村工藝社・丹青社等）の公開情報を投入し、トピックカバレッジを分析 |
| **ドラフト** | Claudeで「大阪・展示会ブース制作2026」のようなイベント紹介ページをセクションごとにドラフト。施工実績・対応エリア・業種別提案を構造化 |
| **最適化** | Surfer SEOでコンテンツスコアを70+に調整。不足エンティティ（「内装工事」「デザイン設計」「プロジェクト管理」等）を補完 |
| **作成** | WritesonicのAI Article Writerで最終稿を生成し、FAQスキーマ・内部リンクを自動付与 |
| **公開** | orgiast.jpに公開後、Ahrefs Webmaster Tools + GSCで掲載順位・CTRを週次監視。30日後に効果を測定し、改善サイクルへ |

### 期待効果

| 指標 | 手動（従来） | 本ワークフロー |
|------|-----------|--------------|
| 1記事あたりの制作時間 | 12〜20時間 | 4〜6時間 |
| 初回SEOスコア（Surfer） | 40〜55 | 65〜80 |
| 公開から1位到達までの日数 | 30〜90日 | 14〜45日（推定） |
| 複数キーワードの並行調査 | 困難 | NotebookLMで同時分析可能 |

### 制約・注意点

- **各ツールの個別契約が必要**: Perplexity $20/月、Surfer SEO $49〜99/月、Writesonic $39〜49/月、Semrush $140/月（無料枠あり）
- **人間のレビューは不可欠**: 特に事実確認・引用検証・ブランドボイス適合はAI任せにできない
- **NotebookLMはライブWebアクセス不可**: 事前にソースをアップロードする手間が必要
- **Surfer SEOスコアと実際のランキングは完全には相関しない**: あくまで指標の1つとして活用
- **GSC API / Ahrefs API へのアクセス権限が必要**: 自動化には別途OAuth設定
