# X-0018 AIを執筆アシスタントにしたSEOコンテンツ7ステップ

## 概要
人間（編集者）とAI（執筆アシスタント）が協調するSEOコンテンツ制作の再現可能なワークフロー。AIが下書きし、人間が検証・肉付けし、継続的に改善するサイクルを回す。

**適用ニッチ**: 展示会ブース制作・イベント（株式会社オージャスト / Re:ブース）

## 7ステップ全体像

```
Step 1: キーワード調査 ──→ Step 2: AI下書き ──→ Step 3: 公開 ──→ Step 4: インデックス
                                                                              │
                                                                              ▼
                Step 7: 再インデックス ←── Step 6: 未カバー特定書き換え ←── Step 5: GSC確認
```

---

## Step 1: 低KDキーワード選定と意図確認

### ツール
- **Ahrefs キーワードエクスプローラー** / **Semrush Keyword Magic**（有料）
- **Google キーワードプランナー**（無料）
- **ラッコキーワード**（無料・サジェスト収集）

### フィルター条件
| 条件 | 値 |
|------|-----|
| 検索ボリューム | 50〜500/月 |
| KD（難易度） | 0〜20 |
| 語数 | 4語以上（ロングテール） |
| DR（ドメインレーティング） | 上位5位にDR30以下のサイトがいる |

### オージャスト適用例
展示会ブース制作ニッチの低KDキーワード候補（推定）:

- `[地域名] 展示会 ブース 制作 会社`（東京・大阪・名古屋等）
- `[地域名] 小間 施工 業者 おすすめ`
- `展示会 初めて ブース 制作 費用`
- `小規模 ブース おしゃれ デザイン 格安`
- `展示会 予算 少ない ブース 設営 コツ`
- `リユース 展示会 ブース 費用 相場`
- `Re:ブース 口コミ 評判`
- `展示会 ブース 装飾 のみ 依頼`

### プロンプトテンプレート（キーワード分析用）

以下のシードキーワードを分析し、(1)関連キーワードグループ (2)検索意図 (3)トップ10のページタイプ を出力してください。

- 競合がカバーしていない角度:

## Step 2: AI下書き生成（[SCREENSHOT][MY TAKE]プレースホルダ）

### コンテンツ構造テンプレート

```markdown
---
title: {SEOタイトル（キーワード先頭・約束＋年）}
description: {メタディスクリプション（120字以内・キーワード含む）}
keyword: {ターゲットKW}
category: {カテゴリ}
date: {公開日}
---

## {H1: ターゲットKWを含む見出し}

### はじめに
{読者の課題・悩みから入る導入文}

### {H2: 具体的情報}
{本文}

[SCREENSHOT: 実際のブース写真/図解をここに配置]
*キャプション: 写真の説明文*

### {H2: 実践的ノウハウ}

[MY TAKE: 編集者の実体験・補足コメント]
ここに人間が実際の経験に基づく意見や事例を追加します。

### まとめ
{CTA: 問い合わせや次の行動への誘導}

### よくある質問（FAQ）
{Q&A形式で3〜5件}
```

### プロンプトテンプレート（下書き生成用）

````
あなたは展示会ブース制作の専門知識を持つSEOライターです。
以下の条件でSEOコンテンツの下書きを生成してください。

ターゲットキーワード: {KW}
検索意図: {INTENT}
参照事例: {CASE_STUDY_URL}
文字数: 2,000〜3,000字

要件:
1. タイトルにキーワードを含め、末尾に「【2025年最新】」を付ける
2. H2・H3でキーワードのバリエーションを自然に含める
3. 主語は「株式会社オージャスト」ではなく「展示会ブース制作会社」などの一般形
4. [SCREENSHOT: ...] プレースホルダを実際のブース写真・図を入れる位置に配置
5. [MY TAKE: ...] プレースホルダを編集者の実体験・補足コメントを入れる位置に配置
6. 最後に「よくある質問（FAQ）」セクションを追加（構造化データ対応）
7. 客観的事実（相場・法律・統計）には出典を明記
8. 競合他社の否定・自社の過度なPRは禁止
````

## Step 3: 公開

### チェックリスト
- [ ] タイトルが60字以内（Google検索結果表示制限）
- [ ] メタディスクリプションが120字以内
- [ ] 見出しにキーワードが自然に含まれている
- [ ] 内部リンク（関連記事3〜5本）を設定
- [ ] [SCREENSHOT]を実際の画像に差し替え
- [ ] [MY TAKE]に人間のコメントを追記
- [ ] 画像のalt属性を設定
- [ ] 公開前にプレビューで最終確認
- [ ] URL（スラッグ）にキーワードを含める

## Step 5: 7/14/30日後GSC確認

### 確認項目
| 項目 | 7日後 | 14日後 | 30日後 |
|------|-------|--------|--------|
| 表示回数 | ≥100 | ≥300 | ≥500 |
| クリック数 | ≥3 | ≥10 | ≥20 |
| CTR | ≥1% | ≥2% | ≥3% |
| 平均掲載順位 | ≤30 | ≤20 | ≤15 |
| インデックス状況 | ✅ | ✅ | ✅ |

## Step 6: GSC未カバークエリ特定＋該当箇所のみ書き換え

### 手順
1. GSCで該当URLのクエリ一覧を取得
2. ユーザーが検索して見つからなかったクエリを特定
3. 該当クエリに関連する見出し・本文を特定
4. 以下のプロンプトで該当箇所のみ修正:

### 書き換えプロンプトテンプレート

````
以下の記事本文のうち、{ユーザーが検索して見つからなかったクエリ} に関連する箇所を特定し、
その部分だけを書き換えてください。全体を書き直さないでください。

## ターゲットクエリ
{QUERY}

## 現在の該当箇所
{EXISTING_SECTION}

## 改善ポイント
{IMPROVEMENT_POINTS}

## 出力
書き換えた該当箇所のみ（見出しレベルの変更があれば含める）
````

## オージャスト適用：ブース事例コンテンツ

このリポジトリの `seo/x0018-seo-content-pipeline.mjs` は上記ワークフローを自動化するツール。

### 使い方

```bash
# キーワード調査モック
node seo/x0018-seo-content-pipeline.mjs --research --kw "展示会 ブース 制作 費用" --output outputs/X-0018/keyword-analysis.md

# コンテンツ下書き生成（モック）
node seo/x0018-seo-content-pipeline.mjs --draft --kw "展示会 ブース 制作 費用" --intent "費用相場を知りたい" --output outputs/X-0018/content-draft.md

# 全文書生成（research + draft + output）
node seo/x0018-seo-content-pipeline.mjs --full --kw "展示会 ブース 制作 費用" --output outputs/X-0018/full-output.md
```
