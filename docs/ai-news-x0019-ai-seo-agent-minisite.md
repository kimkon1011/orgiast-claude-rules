# X-0019: AI SEOエージェントによるミニサイト展開と自動化ワークフロー

> AIニュース提案 2026-11-12
> 対象: 展示会ブース制作サイト（orgiast.jp）のSEO自動改善パイプライン

## 概要

AIエージェント（Hermes / OpenClaw / Claude Code / ChatGPT）をSEO専門エージェントとしてデプロイし、**ミニサイトの自動展開・SEO分析・推奨生成・実装・再帰的テスト・レポート生成**をcronで自動化するワークフローを構築する。月10ドルのVPS上で動作し、1st/3rdパーティSEOツールをMCP経由で統合する。

```
[AI SEO Agent Workflow]
  GSC/GA4 データ取得 → AI分析(キーワード/コンテンツギャップ)
    → SEO推奨生成 → 実装(ミニサイト/コンテンツ)
      → 効果測定 → レポート生成 → [ループ]
```

**実績**: あるサイトで過去3ヶ月YOYクリック140%増、別サイトで前3ヶ月比45%増、複数キーワードでGoogle#1。

## 1. アーキテクチャ概要

### 1.1 構成要素

| コンポーネント | 役割 | 候補 | 月額費用 |
|--------------|------|------|---------|
| **AIエージェント基盤** | SEO判断・分析・コンテンツ生成の頭脳 | Hermes / OpenClaw / Claude Code / ChatGPT | $0〜20（従量/定額） |
| **VPS** | エージェントの常時稼働環境 | Hetzner CX22 / Linode Nanode 1GB | **$10〜12/月** |
| **SEOツールMCP** | キーワード・競合・被リンク・ランキングデータ | Google Search Console API / GA4 Data API / Ahrefs API / Screaming Frog | 無料〜$100/月 |
| **CMS/デプロイ先** | ミニサイトの公開 | Cloudflare Pages / Vercel / Netlify（無料枠） | $0/月 |
| **cron/scheduler** | 定期実行・ワークフロー制御 | systemd timer / GitHub Actions schedule / node-cron | $0 |

### 1.2 データフロー

```
[定時トリガー]
  ↓
① GSC/GA4 データ取得（MCP経由）
  └→ キーワードランキング変動、CTR/インプレッション、ユーザー行動
  ↓
② AI分析エンジン
  ├→ キーワード機会スコアリング（検索ボリューム×自社ランキング×競合強度）
  ├→ コンテンツギャップ分析（競合がカバーしているが自社にないトピック）
  └→ 技術的SEO監査（Core Web Vitals / 構造化データ / インデックス状態）
  ↓
③ SEO推奨生成
  ├→ ミニサイト新規企画（特定キーワード群に最適化したランディングページ）
  ├→ 既存ページ改善（タイトル/メタ/見出し/内部リンク）
  └→ スキーマ追加提案（FAQ / Product / HowTo / BreadcrumbList）
  ↓
④ 自動実装
  ├→ ミニサイトHTML生成（SEO構造化 + 高速読み込み）
  ├→ コンテンツ差し替え（既存ページの該当セクションを更新）
  └→ 構造化データ注入
  ↓
⑤ 再帰的SEOテスト
  ├→ ランキング変動トラッキング（導入前後7日間比較）
  └→ A/Bテスト（タイトル/メタ記述のCTR比較）
  ↓
⑥ レポート生成
  └→ 週次/月次レポート（改善率・残課題・次週計画）
```

## 2. 3つの実装パス

実現方法として3つの選択肢がある。オージャストの技術スタックと運用体制に合わせて選択する。

### パスA: Claude Code + GAS（推奨 / 即日開始）

既存のClaude Code/GAS基盤をそのままSEOエージェントとして活用する。

| 項目 | 内容 |
|------|------|
| **エージェント基盤** | Claude Code（既存）+ GAS（定期実行） |
| **追加コスト** | $0（既存環境を流用） |
| **VPS** | 不要（GASがcron代わり） |
| **SEOデータ** | GSC API + GA4 API を GAS で取得、Claude Code に渡す |
| **ミニサイト公開** | Cloudflare Pages（無料枠） |
| **導入期間** | 1〜2日 |
| **制約** | GASの実行時間制限（6分/回）、同時実行不可 |

**適用例**: まずこのパスで PoC を実施。GSCデータをGASで定期取得→Claude Codeが分析・推奨→手動確認後実装。

### パスB: Hermes/OpenClaw（本格運用 / 中規模）

専用AIエージェントフレームワークをVPS上で稼働させる。

| 項目 | 内容 |
|------|------|
| **エージェント基盤** | Hermes（OSS, MIT）または OpenClaw |
| **追加コスト** | $10/月（VPS）+ API従量 |
| **VPS** | Hetzner CX22（2 vCPU / 4GB RAM / $10.89/月） |
| **SEOデータ** | MCPサーバー経由で各種API統合 |
| **ミニサイト公開** | 自動デプロイ（Vercel/Cloudflare Pages） |
| **導入期間** | 1〜2週間 |
| **強み** | 24時間自律稼働、複数エージェントの協調動作、状態管理 |

### パスC: カスタムNode.jsエージェント（軽量 / 制御容易）

既存のNode.jsツール群（orgiast-claude-rules）に組み込む。

| 項目 | 内容 |
|------|------|
| **エージェント基盤** | Node.js + LLM API（Gemini/DeepSeek/Groq/Claude） |
| **追加コスト** | API従量のみ（VPS不要・GitHub Actionsの無料枠使用） |
| **SEOデータ** | GSC/GA4 API 直接呼び出し |
| **ミニサイト公開** | gh-pages / Cloudflare Pages |
| **導入期間** | 3〜5日 |
| **強み** | 全コード管理下、コスト最小、テスト容易 |

## 3. ミニサイト戦略

### 3.1 ミニサイトとは

特定のキーワードクラスターに特化した**軽量ランディングページ群**。大規模サイト改修ではなく、狙ったクエリに最適化した独立ページを量産する。

### 3.2 オージャスト適用例（展示会ブース制作）

| ミニサイトテーマ | 狙うキーワード | コンテンツ構成 |
|----------------|--------------|--------------|
| **「展示会ブース 費用 相場」** | ブース費用/相場/予算/坪単価 | 費用テーブル + 規模別事例 + 見積依頼CTA |
| **「小規模ブース デザイン」** | 小規模/3坪/6坪/島ブース | 実績ギャラリー + レイアウト例 + 費用目安 |
| **「展示会 集客 施策」** | 集客/ノベルティ/ブース誘導 | 施策リスト + 事例 + チェックリストDL |
| **「イベント企画 代行」** | イベント企画/運営代行/丸投げ | サービス一覧 + フローチャート + 実績 |
| **「ブース製作 会社 比較」** | ブース製作会社/選び方/比較 | 選定基準 + 自社の強み + 比較表 |

各ミニサイトは:
- 単一テーマに集中（情報拡散を防ぐ）
- SEO構造化データ完備（FAQ / Product / BreadcrumbList）
- 内部リンクで相互接続（サイロ構造）
- CTAから本サイトの問い合わせへ誘導

### 3.3 自動生成ワークフロー

```
[週次cron]
  1. GSCからパフォーマンスデータ取得（直近28日）
  2. AIがキーワード機会をスコアリング
  3. 上位5件のミニサイト企画を自動生成
  4. 企画案をレビュー用に保存（自動公開はしない）
  5. 週次レポートを生成 → kim確認
```

## 4. SEO分析・推奨エンジン

### 4.1 分析項目

| 分析 | データソース | 頻度 | 出力 |
|------|------------|------|------|
| キーワードランキング変動 | GSC API | 毎日 | 上昇/下降トップ20 |
| コンテンツギャップ | GSC + 競合クロール | 週次 | 未カバートピック一覧 |
| 技術的SEO | PageSpeed Insights API | 週次 | CWVスコア + 改善点 |
| 内部リンク構造 | サイトクロール | 月次 | 孤立ページ/サイロ改善案 |
| 被リンクプロファイル | Ahrefs API（オプション） | 月次 | 新規/喪失リンク |

### 4.2 推奨生成ロジック

AIは以下のルールセットに従って推奨を生成する:

```
優先度 = インパクト × 実装容易性 ÷ リスク

インパクト:
  - 検索ボリューム × CTR改善余地 × コンバージョン率
実装容易性:
  - コンテンツ作成: 高（既存リソース流用） / 中（新規作成） / 低（専門知識必要）
  - 技術的変更: 高（テキスト修正） / 中（構造変更） / 低（インフラ変更）
リスク:
  - ランキング下落リスク、ブランド毀損リスク、ペナルティリスク
```

## 5. ツール: AI SEO Agent Workflow CLI

本提案に付属する `tools/ai-seo-agent-workflow.mjs` は、上記ワークフローの**オーケストレーションとコスト試算**を行うCLIツール。

### 機能

| コマンド | 説明 |
|---------|------|
| `--scenario plan` | 選択した実装パスの週次運用コスト試算 |
| `--scenario keywords` | キーワード機会スコアリングシミュレーション |
| `--scenario minisite` | ミニサイト企画の自動生成テンプレート |
| `--json` | JSON形式で出力 |
| `--list` | 利用可能シナリオ一覧 |

### コスト試算サマリー

| パス | 月額運用コスト | 導入期間 | 推奨 |
|------|--------------|---------|------|
| A: Claude Code + GAS | 約$0〜5 | 1〜2日 | ⭐ PoC最適 |
| B: Hermes/OpenClaw on VPS | 約$10〜30 | 1〜2週間 | 本格運用 |
| C: カスタムNode.js | 約$1〜10 | 3〜5日 | 制御重視 |
