## 1. データモデルと索引
履歴は「プレフィックス（安定）」＋「セグメント列（古い→新しい）」。
- プレフィックス: システム指示・案件の固定仕様。**不変**。ハッシュ（sha256）を記録。
- セグメント: 連番 `seg-0001…` の履歴断片。状態は `live`（全文を入れる）か `folded`（スタブに置換）。

索引（JSON、キー順固定）の各エントリ:
| 項目 | 内容 |
| --- | --- |
| id | セグメントID（`seg-NNNN`、連番ゼロ埋め4桁） |
| summary | 決定的に作る短い要約（先頭N文字＋見出し語。LLM生成は索引の正本にしない） |
| sha256 | 元本バイト列のハッシュ |
| tokens | 元本のトークン概算（定義: ceil(UTF-8バイト数 / 3)。日本語混在の保守的概算。モデル別トークナイザではない旨を出力に明記） |
| bytes | 元本のバイト数 |
| state | live / folded |

元本は別ストア（`store/<id>.txt`、または索引と同ディレクトリ）に**全文そのまま**保存する。

## 2. 操作の入出力
- **fold(session, {keepRecent, targetIds?})** → 新しい session。先頭プレフィックスは触らない。最新 `keepRecent` 個を除く古い live セグメントを folded にし、本文を決定的スタブ `[[folded:seg-0007 sha256=<先頭12桁> tokens=<n>]] <summary>` に置換。元本は store に保存済みであることを確認してから置換する。
- **unfold(session, ids)** → 指定IDを store から読み戻し、sha256 を検証して元本のバイト列を復元。ハッシュ不一致・存在しないID・壊れた索引は**例外で明示失敗**（握りつぶさない）。
- **search(session, query, {k})** → folded セグメントの summary と元本の語（store 側の転置語彙）に対するスコア（決定的なBM25風 or トークン重なり）で上位k件の `{id, score}` を返す。同点は id 昇順。
- **stats(session)** → 全体／プレフィックス／live／folded のトークン数、fold 率、索引整合性。

## 3. キャッシュ前綴を壊さない規約
1. プレフィックスのバイト列・sha256 は、何回 fold/unfold しても**不変**。
2. fold の対象は「プレフィックスの後ろの古いセグメント」のみ。プレフィックスと最新 keepRecent 個は対象外。
3. 置換は**決定的でバイト安定**: 同一入力→同一出力。時刻・乱数・LLM出力を前綴側に混ぜない。スタブ書式は固定。
4. 折りたたみは追記方向（古い側が縮む）だけが起きる。前綴の直後に並ぶ領域が変わると以降のキャッシュは再書込になるため、fold は「まとめて・まれに」行い、ターンごとに揺らさない（C4 の計算モデルは fold 時に再書込係数を課金する）。
5. unfold は応答用の一時挿入（末尾側）として扱い、前綴・既存スタブ列を書き換えない。

## 4. 非ロスレス要約の禁止
- 要約は検索のための**索引**であり、元本の代替ではない。元本はいつでも sha256 検証つきで完全復元できる。
- 「要約に置換して元本を捨てる」実装は不採用。テストで元本バイト一致（ラウンドトリップ）を必須とする。

## 5. 検証設計（基準との対応）
- C2: fold→unfold ラウンドトリップ／前綴ハッシュ不変／決定性／不正ID・壊れた索引の明示エラー。較正のため「前綴を書き換える fold」「索引を壊す fold」「何もしない fold」の不合格実装例もテストに含める（何もしない fold は削減率0で C4 不合格）。
- C4: 「全履歴常時投入」対「fold運用」の入力トークン・入力コスト。ターン数 50/200/1000 × 検索解凍率 5/20/50% の感度表。単価表は出典・取得日つき。キャッシュ読込/書込係数を明示。
- C5: ホールドアウト質問20問以上で recall@k。取りこぼし率10%超は採用不可と明記。
- recall を上げるために fold 対象を減らして削減率を犠牲にしないよう C4 と C5 を対で見る。

## 6. コーパスの扱い
- 実測コーパスはローカル既存ファイルのみ。パス一覧・件数・合計文字数/トークン概算を state に記録。原文は**リポジトリにコミットしない**。
- コミットするのは匿名化・合成フィクスチャと集計値のみ。
