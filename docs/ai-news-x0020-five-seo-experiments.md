# X-0020: 5つのSEO実験でサイト最適化 — Google上位獲得の実証手順

**AIニュース提案 X-0020**: Google Page-1 listicle (pos #7): 45 visitors -> 25 paying customers -> $478.25。商業ページリタイトル+8 DR50+バックリンクでposition 11.5から7.1へ(+24% impressions, $3,008 30d search rev)。株式会社オージャストのブース制作listicle作成でGoogle上位を狙い、サービスページタイトル最適化とバックリンク追加を試す。

観測日: 2026-11-10

---

## 1. 概要

SEO施策の効果測定は「何を・どの順で・どれだけ」やれば結果が出るのか、実証データが不足しがちである。本稿は外部SEO事例で実証済みの5つの実験を、株式会社オージャストの展示会ブース制作サイト（orgiast.jp）に適用するための実装手順を定義する。

各実験は以下の基準で設計した:
- **測定可能**: 開始前の順位・表示回数・クリック数を記録し、30日後の変化を比較する
- **再現可能**: 他サイトでも同じ手順を踏めるよう、ツール・パラメータまで明記する
- **低リスク**: 既存トラフィックを損なわず、追加投資を最小限に抑える

```
実験1: カウント型リスト記事の作成（listicle）
実験2: 既存サービスページのタイトル最適化
実験3: DR50+ 被リンクの獲得（8本以上）
実験4: FAQスキーマの実装とAI検索対策
実験5: 内部リンク構造の整理とハブページ化
```

---

## 2. 実験1: カウント型リスト記事（listicle）作成

### 背景

データ分析（Search Engine Land, 3,000+ listicle調査）によれば:
- カウント型リスト（"17 Best X"）は編集者ラウンドアップより平均1ポジション上位（3.77位 vs 4.59位）
- 数値の大きいタイトル（51–100）は小さいもの（2–5）より上位表示される
- 新鮮性が最強のランキングシグナル（トップ3の66.6%は過去2年以内の日付）
- 見出し数が多いほどトップ3入り確率が低下（1標準偏差増加で29%低下）

### オージャスト向け実装

**対象URL**: `/event/`（イベントプロデュース実績ページ）または新規ページ `/booth-listicle/`

**タイトル案**: 「2026年版 展示会ブース制作会社選び7つのチェックポイント｜失敗しない選定基準」

**構造**:
```
H1: 2026年版 展示会ブース制作会社選び7つのチェックポイント
→ 読者の問題意識に共感するリード文（50-80字）
→ 7つのチェックポイント（各200-300字、実績データ付き）
  1. ブースの再利用可能性（Re:ブースのCO2-77%・コスト-40%）
  2. デザインの自由度（木工＋ハイブリッド方式）
  3. 全国対応エリア（東京・大阪・福岡）
  4. ワンストップ対応力（企画→撤去）
  5. 実績の業界幅（通信・医薬・万博出展）
  6. 見積もりの透明性
  7. アフターサポート・保管
→ 比較表（従来型 vs リユース型 vs ハイブリッド）
→ CTA: 無料相談・事例集ダウンロード
→ FAQセクション（構造化データ対応）
```

**更新頻度**: 四半期ごとに数値・事例を更新し、公開日を最新に保つ

**測定指標**: 
- Google Search Console 掲載順位（目標: トップ5）
- オーガニッククリック数（目標: 月間200+）
- 問い合わせコンバージョン数（目標: 月間5+）

## 3. 実験2: 既存サービスページのタイトル最適化

### 背景

外部事例（Push Group × BRITA）では、商業ページのタイトル書き換え＋内部リンク再構築で平均ポジションが13.9→6.4に改善。単純なタイトル変更だけでなく、検索意図との一致が重要。

### オージャスト向け実装

**現状の課題**: orgiast.jpのサービスページタイトルは「展示会ブースのSDGs対応｜廃棄ゼロとCO2削減のリユース」「展示会ブース装飾の費用と種類」など、情報ニーズに強い反面、購買意図（「依頼する」「見積もる」）への対応が弱い。

**リタイトル方針**:

| 現行タイトル | 改善案 | 意図 |
|-------------|--------|------|
| 展示会ブースのSDGs対応｜廃棄ゼロとCO2削減のリユース | 展示会ブース制作【オージャスト】SDGs対応リユースブース 見積・実績 | ブランド＋サービス＋CTAを1行に |
| 展示会ブース装飾の費用と種類｜集客できるデザインの考え方 | 展示会ブース装飾の費用と種類2026｜集客デザイン＋施工事例10選 | 年号追加＋事例数で具体性向上 |
| 地球環境に配慮した捨てない展示ブース「Re:ブース」 | Re:ブース（リユース展示ブース）｜コスト40%削減・CO2-77% | 数字を前面に |

**手順**:
1. Google Search Consoleで現行ページの掲載クエリをエクスポート
2. クエリを「情報系」「商業系」に分類
3. 商業系クエリに不足している場合はタイトルを修正
4. メタディスクリプションも併せて最適化（120-160字、行動喚起を含む）
5. 変更30日後にSearch Consoleで表示回数・CTRの変化を確認

**測定指標**:
- 各ページの平均掲載順位（目標: 3ポジション以上改善）
- クリック率（CTR）の変化（目標: +20%）
- 問い合わせフォーム送信数

## 4. 実験3: DR50+ 被リンク獲得（8本以上）

### 背景

複数のケーススタディで実証済み:
- **KeySERP事例**: 12本のDR50+リンクでカテゴリページが28位→11位、organic sessions +340%、$3,180 revenue増
- **Push Group事例**: 6本のDR50+リンクでDR 1→19、平均ポジション13.9→6.4
- **Linkull事例**: 14本の関連性重視リンクでSaaSページが27位→8位、organic clicks 735→2,500+

### オージャスト向け実装

**ターゲット被リンク元（DR50+ かつ展示会・マーケティング関連）**:

| カテゴリ | 候補サイト | DR目安 | 獲得方法 |
|---------|-----------|--------|---------|
| 展示会業界メディア | 日経クロストレンド, MarkeZine, イベント業界専門メディア | 60-80 | Re:ブース事例の寄稿・プレスリリース転載 |
| B2B比較サイト | ツクル、アイミツ、発注ナビ | 50-65 | サービス登録＋口コミ獲得 |
| 自治体・公社サイト | 大阪ビジネスパーク、JETRO、中小機構 | 70-90 | 万博出展実績のケーススタディ掲載 |
| パートナー企業サイト | 会場運営会社、制作協力会社 | 40-55 | 相互リンク・協業実績ページ |
| 業界ブログ・まとめサイト | 展示会マーケティング戦略まとめサイト | 50-70 | 専門家コメント・ゲスト寄稿 |

**リンク獲得スクリプトの優先順位**:
1. **既存実績からのDE（デジタルPR）**: 万博出展実績をプレスリリース→業界メディア転載
2. **ゲスト寄稿**: 展示会マーケティング系メディアに「SDGsと展示会ブース」の記事を寄稿
3. **未リンクブランド言及の発見**: Ahrefs/Semrushで「オージャスト」の言及を検索・リンク化依頼
4. **パートナーからの相互リンク**: 取引先・協力会社とのリンク交換

**測定指標**:
- 獲得したDR50+リンク数（目標: 8本/30日）
- 対象ページの掲載順位変化（目標: 4ポジション以上改善）
- リファラルトラフィック（目標: 月間+50%）

## 5. 実験4: FAQスキーマ実装とAI検索（AEO）対策

### 背景

ChatGPT・Perplexity・GeminiなどのAI検索エンジンが普及し、**AI Overviews**での引用が新しいトラフィック源となっている。AI検索はFAQ・定義・比較形式のコンテンツを好む傾向がある。Scroll Launch社の調査では、FAQスキーマを実装したページはAI検索の引用率が約2倍になる。

### オージャスト向け実装

**step 1: FAQ記事の作成**

各サービスページの下部にFAQセクションを追加。AI検索が拾いやすいQA形式:

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "展示会ブース制作の費用相場はいくらですか？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "小規模ブース（小間1〜2区画）で50〜150万円、中規模（3〜6区画）で150〜500万円、大規模（ブース面積50㎡以上）で500万円〜が目安です。オージャストのRe:ブースは2回目以降50%以上のコスト削減が可能です。"
      }
    },
    {
      "@type": "Question",
      "name": "リユース可能な展示ブースのメリットは？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "廃棄物ゼロ、CO2排出量77%削減、コスト40%削減が主なメリットです。同じデザインを複数回の展示会で使い回せるため、長期的なランニングコストを大幅に低減できます。"
      }
    },
    {
      "@type": "Question",
      "name": "展示会ブース制作の依頼から納品までの期間は？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "標準的なスケジュールは企画設計2〜4週間、制作3〜6週間、設営1〜3日前です。Re:ブースの場合は過去デザインの流用が可能なため、最短2週間での対応も可能です。"
      }
    }
  ]
}
```

**step 2: 「〇〇な会社5社教えて」対策**

ChatGPT/Perplexityで「展示会ブース制作でおすすめの会社を5社教えて」というクエリで自社が引用されることを目標とする。必要な要素:
- 明確なサービスの定義（「リユース型展示ブース専門会社」）
- 具体的な実績数値（施工実績数、削減率などの数字）
- 第三者の評価（口コミ、受賞歴、メディア掲載）
- 他の競合との差別化ポイントの明示

**測定指標**:
- ChatGPT/Perplexity/Geminiで自社名を含む検索クエリの出現数（月次）
- FAQスキーマ実装ページのSearch Console表示回数
- AI Overviewsでの自社引用の有無（月1回手動確認）

## 6. 実験5: 内部リンク構造の整理とハブページ化

### 背景

内部リンク構造の最適化はSEOで最もコストパフォーマンスの高い施策の一つ。Search Engine Landの調査によれば、適切な内部リンク整理だけでトラフィックが20-40%増加するケースがある。

### オージャスト向け実装

**現状のページ構造（推定）**:
```
トップページ
├─ イベントプロデュース（実績一覧）
├─ 展示会ブースのSDGs対応（サービス詳細）
├─ 展示会ブース装飾の費用と種類（ガイド記事）
├─ Re:ブースについて（サービス詳細）
├─ 会社概要
└─ お問い合わせ
```

**改善後**:
```
トップページ（ハブ）
├─ [ハブ] 展示会ブース制作サービス
│   ├─ Re:ブース（リユース型）
│   ├─ 木工造作ブース
│   ├─ システムパネルブース
│   └─ ハイブリッドブース
├─ [ハブ] 実績・事例
│   ├─ 万博出展実績
│   ├─ 通信業界事例
│   ├─ 医薬品業界事例
│   └─ スタートアップ事例
├─ [ハブ] お役立ちコンテンツ
│   ├─ ブース制作費用ガイド（listicle）← 実験1
│   ├─ 展示会選びのチェックリスト
│   └─ SDGs対応ガイド
├─ 会社概要
└─ お問い合わせ
```

**内部リンク付与ルール**:
1. 各サービスページからハブページへのリンクをフッターに設置
2. 記事コンテンツ内で関連サービスへの自然な内部リンク（文脈リンク）を必ず1つ以上含める
3. Pillar（柱）ページからCluster（クラスター）ページへのリンク、ClusterからPillarへの相互リンク
4. サイトマップを動的生成し、全ページを3クリック以内で到達可能に

**測定指標**:
- クロール効率（Google Search Consoleのインデックス率）
- 内部リンク経由のページビュー割合（Google Analytics）
- 重要ページの掲載順位変化
