# X-0024: Ahrefsで質の高い被リンクを3分抽出 — リンクビルディング実践手順

**AIニュース提案 X-0024**: Ahrefs Site Explorerで自社・競合サイトの被リンクを一括抽出し、ドメインレーティング（DR）30以上・月間流入500以上の「質の高い被リンク元」だけを3分でリスト化する。株式会社オージャストの展示会ブース制作サイト（orgiast.jp）で試し、同業他社サイトの被リンク元と比較して獲得候補を洗い出す。

観測日: 2026-11-18 | カテゴリ: SEO / リンクビルディング / Ahrefs活用

---

## 1. 概要

Ahrefs Site Explorerの「ベストリンク」フィルタは、**数百〜数千の被リンクから「質の高いリンク」だけを自動選別**する。このフィルタと手動閾値（DR≥30・月間流入≥500）を組み合わせれば、1サイトあたり3分で獲得候補をリスト化できる。

本記事では以下の4ステップを実践する:

1. **Site ExplorerにURLを入力**
2. **「被リンク」タブを選択**
3. **「ベストリンクのみ」フィルタを適用**
4. **CSVエクスポート → ドメインリスト化**

## 2. ベストリンクの基準と設定

Ahrefsの「ベストリンク」は以下の特性を持つリンクを自動選別する:

| 特性 | 内容 |
|------|------|
| ドメインレーティング（DR） | **30以上** — 被リンク元サイトの被リンクプロファイル全体の強さ |
| 月間検索流入 | **500以上** — 被リンク元サイトが検索から得ている月間トラフィック |
| フォローリンク | nofollowではなくフォローリンク（SEO評価を渡す） |
| 被リンク元の多様性 | 同一ドメインからの大量リンクは1件に集約 |

※「ベスト」の厳密な閾値はAhrefsの非公開アルゴリズムだが、実用上は**DR≥30・流入≥500が経験的な目安**となる。

## 3. 実践手順

### Step 1: Site ExplorerにURLを入力

```
https://ahrefs.com/site-explorer/
```

検索バーに対象URLを入力する。orgiast.jpの場合は:

```
https://www.orgiast.jp
```

### Step 2: 被リンクタブ → ベストリンクフィルタ

左サイドバーから「被リンク（Backlinks）」を選択。上部フィルタで「ベストリンクのみ（Best links only）」を有効にする。

### Step 3: ドメインリスト表示に切り替え

画面右上の表示切替で「ドメイン（Referring domains）」を選択。これで個別URLではなく**リンク元ドメイン**の一覧になる。

### Step 4: CSVエクスポート

右上の「エクスポート（Export）」→「CSV」でダウンロード。以下の列を含む:

- `Referring domain` — リンク元ドメイン
- `DR` — Domain Rating
- `Traffic` — 月間検索流入
- `Links` — 被リンク数
- `First seen` — 初回検出日
- `Anchor` — アンカーテキスト

## 4. 実データで試す

### 4.1 株式会社オージャスト（orgiast.jp）

| 指標 | 値 |
|------|-----|
| ドメイン年齢 | 約15年（2006年2月〜） |
| 業種 | 展示会ブース制作・イベントプロデュース |
| 月間訪問者 | 約6,400（推定） |
| 主な被リンク元 | 制作実績紹介ページ、業界メディア、SNS |

orgiast.jpの被リンク獲得状況をAhrefs Site Explorerでチェックし、「ベストリンク」フィルタ後のドメイン一覧をエクスポート。**DR≥30かつ流入≥500のドメイン**だけを抽出する。

### 4.2 競合サイトの被リンク抽出

展示会ブース制作の競合サイトでも同様に抽出する:

| 競合 | URL | 特徴 |
|------|-----|------|
| 株式会社博展 | haku-ten.co.jp | 体験型マーケティング、パケテン |
| 株式会社フジヤ | fujiya-av.co.jp | 全国15拠点、総合ディスプレイ |
| 株式会社ボックス・ワン | box1.jp | 自社倉庫・低価格帯 |
| 株式会社ストラーツ | straats.co.jp | 企画設計からのトータル支援 |
| 株式会社TRAアート | tra-art.co.jp | 意匠性重視・木工 |
| 株式会社東京展飾 | ten-shoku.co.jp | 1〜2小間に特化・低価格 |

各競合サイトの被リンクプロファイルを比較し、**自社に無いリンク元ドメイン**を獲得候補としてリストアップする。

## 5. 期待される成果

| 項目 | 予想件数 |
|------|---------|
| orgiast.jp ベスト被リンク元（DR≥30） | 10〜30ドメイン |
| 競合サイト合計 ベスト被リンク元 | 50〜150ドメイン |
| 自社に無い獲得候補 | 30〜80ドメイン |
| 優先アプローチ候補（流入≥1,000） | 10〜20ドメイン |

## 6. リンク獲得アプローチ

抽出したドメインリストを以下の優先順でアプローチする:

| 優先度 | ドメイン種別 | アプローチ方法 |
|--------|-------------|---------------|
| P0 | 業界メディア・ニュースサイト | 展示会実績・新サービスのプレスリリース配信 |
| P1 | 取引先・協業先 | 相互リンク・協業事例の共同作成 |
| P2 | 業界ブログ・まとめサイト | インタビュー・ゲスト記事の提案 |
| P3 | ポータル・ディレクトリ | プロフィール更新・実績追加 |

## 7. 自動化の拡張（次のフェーズ）

現状は手動エクスポートだが、Ahrefs API（`https://api.ahrefs.com/v3/site-explorer/backlinks`）と組み合わせると全自動化が可能:

```bash
# Ahrefs APIで被リンク取得（構想）
node seo/ahrefs-backlink-extract.mjs \
  --target orgiast.jp \
  --min-dr 30 \
  --min-traffic 500 \
  --output seo/reports/backlinks-YYYYMMDD.csv
```

Ahrefs APIは有料契約が必要（Lite $129/月〜、標準APIアクセスはStandard $249/月〜）。

## 8. 制約と注意点

- **Ahrefsの「ベストリンク」閾値は非公開**: 目安としてDR≥30・流入≥500だが、実際のフィルタ条件は変動する
- **被リンクデータは常に過去のスナップショット**: 最新の被リンク獲得状況を反映するには定期的な再取得が必要
- **競合分析は週次が目安**: 被リンクプロファイルは急激に変わらないため、週1回の取得で十分
- **獲得候補は量より質**: 100件リスト化しても実際にアプローチすべきは上位20%程度
