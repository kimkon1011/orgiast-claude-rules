# X-0026: モデルルーターで品質あたりコスト8.82倍 — ブースデザイン生成ベンチマーク

**AIニュース提案 X-0026**: 452モデル・25ベンチマークの大規模比較で、モデルルーティングにより品質あたりコストを平均8.82倍改善。コーディングタスクでは25.5倍の効率向上、品質損失はわずか0.44点（5点満点）。株式会社オージャストではブースデザイン生成タスクの再現可能なベンチマーク（25プロンプト）を作成し、既存の `model-router.mjs` 分類体系に基づいてコスト効率の良いモデルへ振り分けて試す。

観測日: 2026-11-12（元投稿: 2026-11-10、@rohanpaul_ai）

---

## 1. 概要

モデルルーターは同一入力を複数の候補モデルで実行し、品質が同等なら安価なモデルにルーティングする手法。既存の `model-router.mjs` は simple/medium/complex の3段階分類に基づく静的ルーティングテーブル（simple→deepseek、medium→kimi、complex→gpt-4o）を提供している。本提案はこれを拡張し、**ブースデザイン生成タスクに特化した25件のベンチマークセットで品質/コスト比を実測し、ルーティング精度を検証する**。

**元論文の知見**（@rohanpaul_ai 2026-11-10）:
- 452モデル・25ベンチマーク: 平均8.82Xの品質/コスト向上
- コーディングタスク: 25.5倍効率、品質損失0.44点
- 静的ルーティング（手動ルール）でも大幅改善、動的ルーティング（モデル判断）はさらに高性能

## 3. ブースデザイン生成ベンチマーク設計

### 3.1 評価セット構成（25プロンプト）

| カテゴリ | 件数 | 期待ルート | 例 |
|----------|------|-----------|-----|
| タイトル生成 | 5 | simple | 「イベント名から展示会ブースタイトルを3案」 |
| キャッチコピー | 4 | simple | 「ブースの特徴を30字のキャッチに」 |
| 企画概要 | 5 | medium | 「来場者ターゲットに合わせたブース企画の要約」 |
| 仕様プロンプト | 6 | complex | 「10m×10mのブース設計仕様書」 |
| セクション記述 | 5 | medium | 「ブース内ゾーンごとの説明文」 |

各プロンプトは実際の展示会ブース制作業務で発生するタスクを基に設計。`model-router.mjs` の `RULES`（simple/medium/complex 分類）と照合して期待ルートと一致するかを検証できる。

### 3.2 品質評価基準（1-5点）

| スコア | 基準 |
|--------|------|
| 5 | プロンプトの指示を完全に満たし、追加修正不要で実務投入可能 |
| 4 | 要件を満たすが細部の調整が必要 |
| 3 | 概ね要件を満たすが、複数箇所の修正が必要 |
| 2 | 方向性は合っているが内容が不十分 |
| 1 | 指示と大きく異なる、または内容が破綻している |

### 3.3 実行手順

```sh
# 模擬モード（API呼び出しなし）
node tools/booth-bench.mjs --mock

# 特定providerでの実測（OpenRouter経由、dry-run無効）
# node tools/booth-bench.mjs --provider openrouter --model openai/gpt-4o
```

模擬モードでは `model-router.mjs` の価格テーブルを使用したコスト計算と、固定品質スコア（期待ルートのモデルは高め、他は低め）を表示する。

## 4. 実装計画

### PHASE1（本セッション）
- ✅ `outputs/X-0026/booth-design-benchmark.jsonl` — 評価セット
- ✅ `tools/booth-bench.mjs` — ベンチマークランナー（--mock）

- ✅ `outputs/X-0026/cost-estimate.md` — コスト見積

- `booth-bench.mjs` で実際の OpenRouter API を叩いて品質スコアを収集
- 品質/コスト比に基づき、model-router.mjs のルーティングテーブルをチューニング
- ブース案件ごとにルーティング方針を適用

## 5. 期待効果

| 指標 | 現状 | 改善後 | 根拠 |
|------|------|--------|------|
| ブースデザイン生成あたりコスト | 全タスクgpt-4o: $0.05〜0.15 | ルーティング後: $0.01〜0.10 | 約60-80%削減 |
| 品質スコア | 全タスクgpt-4o: 4.0〜4.5 | ルーティング後: 3.6〜4.5 | 損失0.4点以内 |
| 品質あたりコスト | 基準値 | 8.82倍改善（@rohanpaul_ai比） | 静的ルーティング適用時 |

**オージャスト実績ベース**: ブース企画生成を月20タスクと仮定した場合、gpt-4o 一辺倒から model-router 振り分けに切り替えることで、月額約 $20→$5〜$8（約60-75%削減）。年間で約 $150〜$180（約2.2万円）の節約。

## 6. 禁止事項

- Anthropic / Claude モデルはベンチマークの候補に含めない（組織ルール §2.8）
- --mock 無しの実API呼び出しは PHASE2 以降。本セッションでは実行しない
- `booth-bench.mjs` は `model-router.mjs` の内部 `validateModel` を呼び出し、Anthropic系モデルを拒否する
