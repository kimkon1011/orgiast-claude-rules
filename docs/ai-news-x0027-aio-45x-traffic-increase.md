# X-0027: AI OverviewsでAI経由流入4.5倍 — 実例に学ぶLLMO対策のROI

> AIニュース提案 2026-11-21
> 対象: AI Overviews / LLMO / GEO / SEO / オージャスト自社サイト流入改善

## 概要

Google AI Overviews（AIO）やChatGPT・Perplexityなどの生成AI検索の普及により、従来のSEOとは異なる「AIに選ばれるための最適化（LLMO / GEO）」が急務になっている。2026年に入り、複数の実測事例で**AI Overviews対応によってAI経由の流入が4.5倍以上に増加**したことが確認された。一方で、AI Overviewsが表示されるクエリでは**上位ページのCTRが34.5%低下**するというAhrefsの大規模分析もあり、対策の有無で明暗が分かれつつある。

株式会社オージャストでは、自社サイト（orgiast.jp / rebooth.co.jp）の流入変化を監視し、展示会ブース関連でAIに選ばれるサイト改善とブランド露出強化を試す段階にある。

```
従来SEO: 検索結果の上位表示がすべて
   ↓
2026年現在: Google検索 + AI Overviews + ChatGPT + Perplexity + Claude + Gemini
   ↓
求められる戦略: あらゆるAIに「引用される」ことを前提にした情報設計
```

## 3. なぜ4.5倍もの差が出るのか

### 3.1 AI検索の情報選択メカニズム

ChatGPT、Perplexity、Google AI Overviews、Claude、Geminiの各AIは、回答を生成する際に以下の優先順位で情報源を選択する:

1. **構造化データ（JSON-LD）** — 料金・所在地・在庫・評価などの定量情報
2. **冒頭の要約** — 最初の100〜200トークンが回答の根拠になりやすい
3. **引用のしやすさ** — 箇条書き・表・見出しが明確なページが選ばれる
4. **ブランドの信頼性** — SameAs / 公式サイト / 実績のあるドメイン

AIO未対応のサイトはこれらの条件を満たさず、AIに「存在しない」と判断されるリスクがある。

### 3.2 CTR減少との関係

Ahrefsの分析（30万KW対象）では、AI Overviewsが表示されると**上位1位のCTRが34.5%減少**する。これは「AI Overviewsがユーザーの質問に回答してしまい、リンクをクリックする必要が減る」ため。つまり:

- **AIO未対策**: CTR減少の**打撃だけを受ける**
- **AIO対策済み**: CTR減少を**AI経由の新規流入で補い、むしろ増加**

4.5倍の差は、この「失うだけの立場」と「得をする立場」の違いといえる。

## 5. 制約・注意点

| 制約 | 影響と対策 |
|------|-----------|
| AI Overviewsはクエリの一部にしか表示されない | 全クエリ対策ではなく、自社の強みが問われるクエリに集中 |
| CTR減少とAI流入増加はトレードオフ | 両方を測定し、ネットの効果を検証する仕組みが必要 |
| AIの回答アルゴリズムは非公開で変化する | 定点観測（月次）で変化を追い、対策をアップデート |
| 構造化データの誤りは逆効果 | 実際のページ内容と一致させる。TODOを残して公開しない |
| ブラックボックスなAI引用を完全制御は不可能 | 「引用されやすくする」が限界。SEOの土台が最重要 |

## 7. まとめ

AI Overviewsをはじめとする生成AI検索の普及は、SEOに構造的変化をもたらしている。複数の実例が示すように、**AIO対策の有無でAI経由流入に4.5倍以上の差が生じる**。一方でAhrefsの分析が示すCTR減少は、対策を怠ったサイトが「失うだけ」になるリスクを示唆する。

オージャストではX-0086の監査結果を踏まえ、まずは**Reブース（rebooth.co.jp）の構造化データ整備**を最優先に進める。費用は実質0円で始められ、効果測定の基盤も同時に構築する。6ヶ月後を目標に、AI経由の問い合わせを新規チャネルとして確立する。
