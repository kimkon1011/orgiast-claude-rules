# X-0027: Codex MCPでIllustrator作業5分自動化 — 手動15分→AI5分の実測比較

> AIニュース提案 2026-11-13
> 対象: Codex MCP + Adobe Illustrator の連携によるグラフィック制作自動化

## 概要

`codex-do` に Illustrator 作業を1つのプロンプトで指示すると、Codex が Adobe ExtendScript / Illustrator MCP を経由して**編集可能な .ai 形式のグラフィックを5分以内に生成**できる。従来、手動で行うと15〜30分かかるアピアランス効果（変形・ラフ・角丸・分割）を伴う見出しグラフィックを、最初の許可以外の操作なしで完了できる。オージャストの展示会ブースパネル・ロゴ・見出しグラフィック制作に適用し、手動時間と比較する。

```
[プロンプト例]
Illustrator 2027ドキュメント中央にネオクロ150Q「イラレ自動化！」文字作成、
1文字ずつウエイト変更、塗りM20+Y20%線K100%1pt、線上塗り下、
線に変形-2mm、-2mm、ラフ0.5mm繰り返し50角丸追加、
下方向複製しアピアランス分割・アウトライン化、アートボード余白調整
```

## 1. 現状の問題

| 問題 | 影響 |
|------|------|
| 展示会用ブースパネル・見出しグラフィックをデザイナーが手動制作 | 1枚あたり15〜30分、修正のたびに再作業 |
| アピアランス効果（変形・ラフ・角丸）の調整が試行錯誤 | 効果をかける順序・数値の調整に時間がかかる |
| 1文字ずつのウェイト変更が手作業 | 文字数が多いほど工数が線形に増加 |
| 同種のグラフィックを複数（ブース番号・セッション名・スポンサー表示）で作る必要 | バラエティがあるほど反復作業になる |
| 外注時の修正指示が手間 | 「変形-2mmの後にラフ0.5mmを重ねて」という指示の伝達ロス |

## 2. Codex MCP × Illustrator の連携方式

Codex MCP は Adobe Illustrator の以下の操作を、人間がGUIで操作する代わりにスクリプトで実行する:

| 分類 | 対応操作 | スクリプト実現方式 |
|------|---------|-----------------|
| ドキュメント操作 | 新規作成・アートボード設定・保存（.ai / .svg / .pdf） | app.documents.add() |
| テキスト | フォント指定・ウェイト変更・文字間隔・行送り | textRange.characterAttributes |
| 塗り・線 | CMYK/RGB色指定・線幅・線の位置（上/中/下） | filled/stroked プロパティ |
| アピアランス効果 | 変形・ラフ・角丸・パターニング・ドロップシャドウ | applyEffect() / 各種Effectオブジェクト |
| オブジェクト変換 | アピアランス分割・アウトライン化・複製・移動 | expand() / duplicate() / translate() |
| レイヤー管理 | レイヤー作成・名前変更・ロック・表示切替 | layers.add() |

**MCP連携の実装方式**:
1. Codex がプロンプトから Adobe ExtendScript（.jsx）コードを生成
2. `codex-do --kind implement` が生成したスクリプトを呼び出し
3. Illustrator の MCP サーバー（または `-r` フラグによるスクリプト実行）がオブジェクトを操作
4. 結果を .ai ファイルとして出力

## 3. 実測比較: 手動 vs Codex MCP

### 比較対象のグラフィック

「イラレ自動化！」の見出し文字に以下のアピアランス効果を適用したグラフィック:

1. ネオクロ150Qフォントで文字入力
2. 1文字ずつウェイト変更（文字ごとに異なる太さ）
3. 塗り: M20 + Y20%、線: K100% 1pt、線上塗り下
4. 線に変形効果: それぞれ-2mm、-2mm
5. ラフ効果: 0.5mm、繰り返し50、角丸追加
6. 下方向に複製
7. アピアランス分割・アウトライン化
8. アートボード余白調整

| 5. ラフ効果 + 角丸 | 2〜3分（数値調整含む） | 0.5分 | ▲75〜83% |

- **月間2.4〜6.3時間のデザイン工数削減**（外注費換算で数万円〜十数万円/月）

## 5. 制約・注意点

| 制約 | 影響と対策 |
|------|-----------|
| Illustrator の起動が必要 | 手元のPCにIllustratorがインストールされ、バックグラウンド実行可能な環境が必要 |
| 複雑なレイアウト（複数の画像・テキスト・図形の組み合わせ）は難易度が高い | 単一オブジェクト＋アピアランス効果の範囲で始め、徐々に範囲拡大 |
| ExtendScript の知識が若干必要 | プロンプト例をテンプレート化することで知識不要にできる |
| フォントの有無に依存 | フォントがインストールされていないと代替フォントになる。システムフォントを指定する |
| 商用利用時のライセンス確認 | Adobe のライセンス条項に従うこと（個人/商用/SSR） |

## 6. 推奨する初期実装

最小限の検証として、以下の手順で実現可能性を確認する:

1. `codex-do` に以下のプロンプトで指示:
   ```
   Illustratorで利用可能なExtendScriptコードを作成し、
   新規ドキュメントに「イラレ自動化！」テキストオブジェクトを作成、
   アピアランス効果（変形-2mm×2 + ラフ0.5mm+角丸）を適用し、
   .aiファイルとして保存するコードを生成して実行
   ```
2. 出力された .ai ファイルの見た目をIllustratorで開いて確認
3. この結果をプロンプトテンプレートとして `data/illustrator-templates/` に保存
4. 展示会用のパラメータ化（テキスト内容・色・フォントを引数化）
