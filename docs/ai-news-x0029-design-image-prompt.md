# X-0029: 参考画像と詳細プロンプトでAIデザイン生成の時間を短縮 — 実践的なプロンプトエンジニアリング

**AIニュース提案 X-0029**: AI画像生成で思うようなデザインが得られないとき、最も効果的な対策は「自分が持っている写真を参考画像として与える」こと。次に「各部の寸法・形状・位置を詳細に指定する」プロンプトの工夫。本稿では展示会ブース什器を例に、全長69cm・面の幅25cm・逆さのたまご型・Y字フレームといった具体的な数値と形状をプロンプトに組み込む方法を提示する。

観測日: 2026-11-13 | 出典: AIニュース提案 [X-0029]

---

## 1. 概要

**問題**: AI画像生成ツール（Midjourney・DALL-E・Stable Diffusion・Gemini等）に「スタイリッシュな展示台を作って」とプロンプトを送ると、見た目はきれいだが**実寸・構造・取付条件を満たさない**デザインが返ってくる。その後の修正プロンプトで調整を繰り返すうちに、トークン消費・時間・課金が膨らむ。

**解決策**: 以下の2つの手法を組み合わせるだけで、デザインの収束速度が格段に向上する。

| 手法 | 効果 | コスト |
|------|------|--------|
| **①参考画像の提供** | 構図・スタイル・色味が一発で決まる。最も効果的 | ゼロ（手持ち写真をアップロード） |
| **②詳細数値プロンプト** | 寸法・形状・位置を指定するとハルシネーション激減 | プロンプト文字数が増えるのみ |

### 適用対象（株式会社オージャスト）

展示会ブースの什器デザイン（パネル・台座・サイン・照明器具等）のAI生成において、デザイン案の収束までに要する**プロンプト往復数を従来の10〜20往復から3〜5往復に削減**できる。実際の2026年製作案件を例に、プロンプト実例を掲載する。

---

## 2. 手法①: 参考画像が最強の理由

### 2.1 「言葉」と「画像認識」のギャップ

AI画像生成モデルは、人間が「ラウンドフォルム」と表現する形状を正確に理解できない。なぜなら:

- 「ラウンド」の度合い（R50mmなのかR200mmなのか）を文章で伝えるのは困難
- 色味「オフホワイト」はモデルによってベージュ・クリーム・グレーがか·にばらつく
- 「高級感」のような抽象形容詞は学習データの平均値にしかならない

**解決**: 実際に撮影した参考写真（スマホで十分）を入力画像として与えると、構図・素材感・色味・光源を**ゼロ調整で再現できる**。人間のデザイナーに「こんな感じで」と見せるのと同等の効果。

### 2.2 参考画像の選び方

| 要素 | 推奨 | 避けるべき |
|------|------|----------|
| 構図 | 正面・斜め45度の両方 | 極端なアップ・俯瞰 |
| 背景 | 白背景または無地 | 複雑な背景（AIが模倣する） |
| 写り込み | マットな質感がわかるもの | 強い反射・逆光・影 |
| 比率 | 実寸比率がわかる（定規・人の横） | 被写体だけのトリミング |

## 3. 手法②: 詳細プロンプトの書き方

### 3.1 基本構造

```
[形状]の[部品・什器]で、[素材]。主要寸法は[数値]×[数値]×[数値]。特徴は[形状の詳細]。
[位置関係]は[条件]。ロゴや文字は入れない。背景は透過または[色]。
```

### 3.2 実例: 展示会什器（プレス加工品）

**悪い例**:
```
展示会用のスタイリッシュな台
```
→ 結果: 寸法不明・取付不可能・過度に装飾的

**良い例**（実際の2026年案件を基にしたプロンプト）:

```
展示会ブース用の自立式什器。
逆さのたまご型フォルムで、素材はマットホワイトの塗装鋼板とY字フレーム（ブラック粉体塗装）。
全長69cm（高さ）、面の幅25cm（最大幅）、奥行き18cm。
Y字フレームは台座から立ち上がり、上部で左右に分かれてたまご型の面を支える。
面の表面には凹凸・テクスチャなし、平滑仕上げ。
ロゴや文字は一切入れない。背景は白一色、ドロップシャドウのみ。
--image: [参考写真のURL]
```

**ポイント**:
- 「全長69cm」➡ 基準寸法（面の高さを特定）
- 「面の幅25cm」➡ 横方向の最大値
- 「逆さのたまご型」➡ 形状の基本輪郭
- 「Y字フレーム」➡ 支持構造の種類と形状
- 「ロゴや文字は入れない」➡ 不要な装飾を禁止（省略するとAIがでたらめな文字を生成する）

### 3.3 数値指定のコツ

| 指定方法 | 例 | 効果 |
|---------|-----|------|
| 絶対寸法 | 全長69cm | 縮尺が決まる |
| 相対比 | 面の幅は全長の約36% | 比率の維持 |
| 厚み指定 | 鋼板t1.6mm | 素材感がリアルに |
| 角度指定 | Y字の開き角45度 | 構造が具体的に |
| 位置関係 | フレームは後面に配置 | 前後関係の明確化 |

## 4. よくある失敗と対策

| 失敗パターン | 原因 | 対策 |
|------------|------|------|
| 寸法が無視される | プロンプト内の単位が認識されない | 整数（69cm）で書く。「約70cm」は曖昧 |
| 文字が入る | 「ロゴなし」を書かない | 明示的に「ロゴや文字は一切入れない」 |
| 背景が複雑すぎる | 背景指定なし | 「白背景」「ドロップシャドウのみ」を指定 |
| 素材が違う | 素材名だけでは足りない | 「マットホワイト塗装鋼板」と表面処理まで |
| フレーム形状が変形 | Y字の形状説明不足 | 「台座から立ち上がり、上部で左右に分かれる」と動詞で説明 |

## 5. オージャストでの適用方法

### 5.1 ワークフロー

```
機密デザイン（実物写真）
  → AI画像生成（参考画像＋詳細プロンプト）
  → 3Dデータ作成（Fusion 360 / Blender）
  → 制作図面
```

| 工程 | 従来の方法 | 本提案 | 時間削減 |
|------|----------|-------|---------|
| デザイン案作成 | キーワードのみで10回以上試行 | 参考画像＋詳細寸法で3〜5回 | **50〜70%減** |
| 寸法調整 | 「もう少し大きく」の繰り返し | 初回から数値指定 | **80%減** |
| 素材感の確認 | 別途マテリアルサンプル | 参考画像の質感がベースに | **調整ゼロに近い** |
| 構造検討 | デザイン後に別途エンジニアリング | フレーム形状まで同時提案 | **並行化** |

## 6. まとめ

AI画像生成の「うまくいかない」の多くは、**AIの能力不足ではなく、人間の伝え方の問題**。特に近年のマルチモーダルモデル（画像を入力として認識できる）の登場により、「参考画像＋詳細数値」の組み合わせが最も効果的な入力方法として確立した。

株式会社オージャストの展示会ブース制作においても、実物の参考写真（過去案件の写真撮影）と実寸をセットにしたプロンプトテンプレートを用意することで、デザイン生成の往復数を劇的に削減できる。本稿のプロンプトテンプレートを `prompts/booth-design/` 配下に蓄積し、案件ごとに再利用する仕組みが次のステップとなる。
