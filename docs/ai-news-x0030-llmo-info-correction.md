# X-0030: AI質問調査によるLLMO情報修正 — 展示会ブース制作のAI検索表示率を33%→73%へ

**AIニュース提案 X-0030**: 顧客がAIにどんな質問をするかを調べ、自社のサービスや専門性が伝わるようにサイト情報を修正する。株式会社オージャストでは展示会ブース・イベント関連のAI質問を調査し、サイト情報をLLMO（Large Language Model Optimization）対応に修正する。海外事例ではAI検索表示率33%→73%、AI経由サイト訪問16,462件、フォーム送信290件の効果が報告されている。

観測日: 2026-11-12

---

## 1. 概要

**LLMO（Large Language Model Optimization）** は、ChatGPT / Perplexity / Google AI Overviews / Claude 等の大規模言語モデルがユーザーの質問に回答する際に、自社の情報が正しく引用・表示されるようサイト情報を最適化する手法。従来のSEOとは異なり、**AIが「質問」に対して「回答」を生成するプロセスに最適化**する点が特徴である。

海外では「33%→73% のAI検索表示率向上」「AI経由サイト訪問16,462件」「フォーム送信290件」などの実証数値が報告されており、日本でも2026年に入りLLMO対策の重要性が急速に認知されつつある。

本提案では、展示会ブース制作業界におけるAI質問の実態調査と、株式会社オージャストのサイト情報修正を2週間で実施する計画を提示する。

### 参考: 海外事例と数値

| 指標 | 改善前 | 改善後 | 出典 |
|---|---|---|---|
| AI検索での自社表示率 | 33% | 73% | Brand UP「LLMO対策ガイド」 |
| AI経由のサイト訪問 | — | 16,462件 | 海外SEO事例 |
| AI経由のフォーム送信 | — | 290件 | 海外SEO事例 |
| クリック増加率 | — | 140%増（YOY） | SEOエージェント実績 |

## 2. 展示会ブース制作におけるAI質問の実態調査

### 2.1 顧客がAIに聞く質問カテゴリ

展示会ブース制作の見込み顧客がAI検索に投げる典型的な質問を、既存の `tools/ai-query-extract.mjs`（X-0005）のドメインパターンと業界調査から整理した。

| カテゴリ | 典型的な質問例 | 優先度 | AI回答に必要な情報 |
|---|---|---|---|
| **費用・見積もり** | 「展示会ブースの制作費用はいくら？」「3m×3mの小間の最低料金は？」「予算50万で可能？」 | ★★★ | 価格帯・内訳・最小構成 |
| **初めての出展** | 「初めての展示会、何から始めればいい？」「出展手順を教えて」「必要なもの一覧」 | ★★★ | 手順・チェックリスト・流れ |
| **期間・納期** | 「ブース制作の納期は？」「いつまでに頼めば間に合う？」「直前でも依頼できる？」 | ★★★ | スケジュール・リードタイム |
| **デザイン・カスタマイズ** | 「デザインはどこまで自由？」「自社ロゴの配置は？」「他社と差別化したい」 | ★★ | 実績・自由度・制約 |
| **規模・対応** | 「1小間だけでも依頼できる？」「大規模ブースの実績は？」「全国対応可能？」 | ★★ | 小規模〜大規模実績 |
| **SDGs・環境配慮** | 「環境に配慮したブースはある？」「廃棄物を減らしたい」「再利用可能なブース」 | ★★ | Re:ブース・SDGs対応 |
| **運営・設営** | 「設営・撤去は誰がやる？」「搬入搬出の手順は？」「会場への申請は代行可能？」 | ★★ | 施工体制・代行範囲 |
| **オンライン・ハイブリッド** | 「オンライン展示会にも対応？」「ハイブリッドイベントのブース構成」 | ★ | オンライン対応可否 |

### 2.2 既存ツールの活用

X-0005 で構築された `tools/ai-query-extract.mjs` には、展示会ドメインに特化した以下のパターンが既に実装されている：

| パターンID | 説明 | 抽出対象 |
|---|---|---|
| `domain_booth_size` | ブースサイズ・小間 | 小間数・面積 |
| `domain_booth_design` | デザイン関連 | デザイン・図面・レイアウト |
| `domain_event` | イベント・展示会 | 展示会・見本市・催事 |
| `domain_logistics` | 運営・設営 | 設営・搬入出・施工 |
| `domain_al_media` | デジタルメディア | デジタルサイネージ・VR・AR |
| `domain_ecofriendly` | サステナブル | SDGs・エコ素材・再利用 |
| `domain_overseas` | 海外出展 | 国際展示場・海外輸送 |
| `domain_online` | オンライン展示会 | ハイブリッド・バーチャル |

→ これらのパターンを使って実際の問い合わせや検索クエリからAI質問を抽出し、不足している情報をサイトに追加する。

## 3. オージャストサイトのLLMO診断結果

### 3.1 現状の問題点

2026-11-12 時点の実測調査に基づく：

| # | 問題 | 詳細 | 影響するAI質問カテゴリ |
|---|---|---|---|
| 1 | **FAQ・Q&Aが存在しない** | サイトにFAQセクションがなく、AIが回答生成時に引用できる情報がない | 全カテゴリ（最重要） |
| 2 | **料金情報が非公開** | どのページにも価格帯・費用相場の記載がない。問い合わせ必須 | 費用・見積もり |
| 3 | **情報が複数サイトに分散** | 展示会ブース情報が orgiast.jp（トップページ）・rebooth.co.jp・event-shop.jp に分散 | 全カテゴリ |
| 4 | **構造化データ不足** | FAQPage / Article / Organization 構造化データ未導入 | 全カテゴリ（AIの引用判断に影響） |
| 5 | **本文が結論より先に来ない** | トップページの説明文が導入文から始まり、結論ファーストになっていない | 全カテゴリ（AIの回答抽出に影響） |
| 6 | **公開日・更新日が不明瞭** | 各ページの最終更新日が表示されていない。AIは新鮮な情報を優先 | 期間・納期・料金 |
| 7 | **Re:ブースと展示会ブース制作の関係が不明瞭** | オージャストの展示会ブース制作とRe:ブースの関係（どちらも同じ会社が運営）がページから読み取れない | 全カテゴリ |
| 8 | **よく聞かれる質問への回答がない** | 「1小間から依頼できる？」「初めての出展はどうすれば？」などよくある質問への答えがサイトに存在しない | 規模・初めて |

### 3.2 LLMO表示率推定

現状の課題を踏まえ、主要AI質問に対する「自社情報が正回答に含まれるか」を推定した：

| AI質問 | 現在の表示可否 | 理由 |
|---|---|---|
| 「展示会ブース制作会社 おすすめ」 | △ 部分表示 | 社名は出るが強みが伝わらない |
| 「展示会ブース 費用 相場」 | ✗ 非表示 | 料金情報なし |
| 「SDGs対応 展示ブース ある？」 | ○ 表示可 | Re:ブースページあり |
| 「初めての展示会 何から始める」 | ✗ 非表示 | FAQなし |
| 「ブース制作 納期 いつまで」 | ✗ 非表示 | 納期情報なし |
| 「小間 1つから 依頼」 | ✗ 非表示 | 情報なし |
| 「大阪 展示会ブース制作 会社」 | △ 部分表示 | 所在地情報があいまい |

→ **表示率推定: 約29%（7問中2問のみ十分な回答が可能）** → 改善後目標: **70%以上**

## 4. 情報修正計画（2週間）

### Phase 1: 質問調査と情報ギャップ分析（Day 1-3）

1. **AI質問の収集**: GSCクエリ・問い合わせ実績・競合サイトから展示会ブース制作に関する質問を30〜50件収集
2. **情報ギャップ特定**: 各質問に対応するサイト情報の有無をマッピング（上記 3.2 の拡張版）
3. **優先順位付け**: AI表示率・検索流入・コンバージョンへの影響で優先度を決定

**ツール**: `tools/ai-query-extract.mjs --gsc <GSC_CSV> --llmo --opportunity`

### Phase 2: サイト情報の修正・追加（Day 4-10）

**優先度順に実施**：

| 優先度 | 修正内容 | 対応サイト | 対応するAI質問 |
|---|---|---|---|
| **P0** | FAQページの新設（10〜15問）- 結論ファースト・構造化データ付き | orgiast.jp | 全カテゴリ |
| **P1** | 展示会ブース制作の料金帯・内訳を具体的に記載（例: 壁だけプラン¥18万〜¥30万等） | orgiast.jp | 費用 |
| **P1** | 初めての出展者向けガイド（チェックリスト＋スケジュール）を新設 | orgiast.jp | 初めての出展 |
| **P2** | 各ページに公開日・更新日を表示 | orgiast.jp | 全般（AIの鮮度判断） |
| **P2** | 結論ファーストへの書き換え（導入文→結論に修正） | orgiast.jp トップ | 全般 |
| **P2** | 各サービスページに具体的な実績・事例を追加 | orgiast.jp | 全般 |
| **P3** | FAQPage / Article / Organization 構造化データを導入 | orgiast.jp | 全般（AIの引用判断） |
| **P3** | Re:ブースページとorgiast.jpの相互リンク・関係性の明示 | 両サイト | 全般 |

### Phase 3: 効果測定（Day 11-14）

1. **LLMO定点観測**: 主要AIプラットフォーム（ChatGPT / Perplexity / Google AI Overviews / Claude）で同一質問を複数回実行し、表示率・引用率・正確性を記録
2. **比較**: 改善前後の表示率変化を集計（目標: 29%→70%以上）
3. **レポート**: 結果をドキュメント化し、定期的なLLMO観測サイクルを確立

**測定ツール**:
- `tools/ai-query-extract.mjs --gsc <GSC_CSV> --llmo --opportunity`（定量的分析）
- 各AIプラットフォームでの手動クエリ実行（定性的評価）

## 6. 注意点・リスク

- **LLMOは継続的な取り組み**: 1回の修正で終わらず、AIモデルの更新（GPT-5等）に合わせて定期観測・更新が必要
- **過剰最適化のリスク**: AI向けに書きすぎると人間のユーザーに読みにくくなる。バランスが重要
- **新情報の追加タイミング**: 展示会ブースの料金は変動するため、定期的な見直しが必要
- **AIごとの回答特性差**: ChatGPT、Perplexity、Google AI Overviewsで引用基準が異なる。1つのAIだけ最適化しない
- **構造化データは必須ではない**: Google公式がFAQPage構造化データをAI Overviewsの必須条件としていないことを確認。基本は「人に役立つコンテンツ」が最優先（Tayori Blog 2026年10月）

展示会ブース制作の見込み顧客は、まずAIに「展示会ブース制作 費用」「初めての出展 何から」といった質問を投げる。**AIが正確に回答できる情報をサイトに用意することで、問い合わせ前の顧客体験を改善し、競合より先に情報を届けられるようになる。**

まずはFAQページの新設（P0）から着手し、1週間で最低限のLLMO対応を整えた上で効果測定に入るのが現実的なロードマップである。改善後も月1回のLLMO定点観測を継続し、AIモデルの更新や競合の動きに追随する。
