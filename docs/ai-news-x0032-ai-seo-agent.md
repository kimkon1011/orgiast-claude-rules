# X-0032: AI SEOエージェントによるミニサイトとワークフロー構築

**AIニュース提案 X-0032**: AIエージェントプラットフォーム（Hermes、OpenClawまたはClaude Code/ChatGPT）+ VPS（月10ドル）+ SEOツール用MCPで、分析・評価・戦略・実行のSEOワークフローを自律実行するエージェントをデプロイする。株式会社オージャストでは自社の展示会ブース・イベントサイトに対しVPS上で同様のエージェントをデプロイし、GSC/GA4データを使った分析と推奨生成を試し、人間確認後に実装する。

観測日: 2026-11-12

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| 提案の核 | AIエージェントにSEOスキル・コンテキスト・トレーニングを与え、分析→評価→戦略→実行をcronで自律ループさせる |
| 必要な基盤 | AIエージェントプラットフォーム（Hermes / OpenClaw / Claude Code / ChatGPT） + VPS（$10/月） |
| SEOツール連携 | MCP経由でGSC・GA4・Ahrefs等へアクセス、Slack・メール・ウェブサイト操作権限も統合 |
| 実証数値 | あるサイトで過去3ヶ月YOYクリック140%増、別サイトで過去3ヶ月比45%増、Google #1獲得 |
| オージャスト適用 | 展示会ブース・イベントサイトのGSC/GA4分析 → SEO推奨生成 → 人間確認 → 実装 |
| ライセンス | 各プラットフォーム依存（Hermes/OpenClawはOSS、Claude Code/ChatGPTは従量課金） |

## 2. エージェント構成とワークフロー

### 2.1 必要なコンポーネント

| コンポーネント | 役割 | 候補 |
|---|---|---|
| AIエージェントプラットフォーム | エージェントの実行基盤・スキル管理・cron | Hermes / OpenClaw / Claude Code |
| VPS | 24時間稼働のホスト（月$10程度） | Linode / Vultr / AWS Lightsail |
| SEOツールMCP | GSC・GA4・Ahrefsデータをエージェントが読める形に | 自前MCPサーバー / n8n / Make |
| コミュニケーション | 分析結果の報告・人間確認の依頼 | Slack / メール / Discord |
| ウェブサイト操作 | CMS操作・ミニサイトデプロイ | WP CLI / Vercel API / Cloudflare Pages |

### 2.2 実行プロセス（cronループ）

```
[分析] GSC/GA4データ取得 → ランキング・インプレッション・CTR・クリック推移を計測
   ↓
[評価] 前回からの変化（減衰・改善）を検出、重要度を判定
   ↓
[戦略] SEO推奨を生成（タイトル修正・コンテンツ追加・内部リンク等）
   ↓
[実行] 人間確認 → 承認後自動実装（ミニサイト展開・メタ更新等）
   ↓
[計測] 実装後の変化を再計測 → ループ継続
```

### 2.3 ミニサイト展開の仕組み

- AIエージェントがGSCの「クエリ→ランディングページ」データから機会を検出
- クエリ単位のテーマ別ミニサイト（5〜10ページ）を自動生成
- VPS上の静的ホスティング（Cloudflare Pages / Vercel）へデプロイ
- サイトごとにGA4トラッキングを埋め込み、パフォーマンス自動計測

## 3. オージャストへの適用判断

### 展示会ブース・イベントサイトSEO（本提案）

**結論: 推奨（ただし人間確認を挟む2段階運用）**

| 用途 | エージェントの活かし方 | 期待効果 |
|---|---|---|
| ブース・イベントサイトのSEO分析 | GSC/GA4データを毎週自動収集→ランキング・CTR・減衰を検出 | 週次のSEO工数削減、変化の見逃し防止 |
| SEO推奨生成 | データに基づいた具体的な修正案（対象ページ・修正内容・優先度）をAI生成 | 人間のSEO判断を補完、優先度の一貫性向上 |
| 修正の人間確認 | AI生成推奨を人間がレビュー→承認後にエージェントが実装 | 意図しない変更を防止しつつ実行を自動化 |
| イベント直後のレポート生成 | 期間中の流入・問合せ実績を自動集計しクライアント報告案を作成 | レポート作成時間の削減 |

- `X-0005`（SEO自動改善ワークフロー）との連携で、推奨→実装→計測のサイクルを統合できる

## 4. 導入優先順位と推奨アクション

### Phase 1（1〜2週間）: データ基盤の構築

1. VPS（Linode $10/月）を契約し、SSH・基本セキュリティ設定を完了
2. GSC・GA4のAPI連携を確立（サービスアカウント認証→定期データ取得cron）
3. 自社展示会ブースサイト1件を対象に、現状の検索パフォーマンス（インプレッション・CTR・順位）をベンチマークとして記録

### Phase 2（2〜3週間）: エージェント立ち上げ

1. AIエージェントプラットフォーム（OpenClaw推奨: OSSでコスト制御可能）をVPSにデプロイ
2. SEOスキル（GSC読み取り・GA4読み取り・推奨テンプレート）を作成しエージェントに実装
3. 週1回の分析cronを設定（月曜6時実行→Slackにレポート通知）
4. AI生成推奨の品質を人間が評価し、テンプレート・スキルをチューニング

### Phase 3（1〜2ヶ月）: 実行の部分自動化

1. 承認された推奨のうち、安全な修正メタ（タイトル・description）のみエージェントが自動適用
2. ミニサイト展開機能を追加（新規クエリテーマLPの自動生成→デプロイ）
3. 実装後のパフォーマンス変化を自動計測し、次のサイクルに反映

## 5. 注意点・リスク

| リスク | 内容 | 対策 |
|---|---|---|
| SEO改悪の可能性 | AI生成推奨を無承認で実装すると検索順位を下げるリスク | Phase 2までは人間確認必須、自動実行は限定項目のみ段階的解放 |
| GSC/GA4 APIの制限 | 日クォータ制限（無料枠）に達するとデータ欠損が発生 | キャッシュ層の導入、更新頻度は週1から開始 |
| VPS運用負荷 | セキュリティパッチ・OSアップデートの管理が必要 | Docker Compose + auto-update で運用負荷最小化、障害時通知 |
| プラットフォーム選定 | Hermes/OpenClaw/Claude Code いずれも開発途中の可能性 | 最初は最も安定している選択肢（Claude Code API推奨）でPoP、OSS移行は課題明確化後 |
| コスト試算 | VPS $10 + AI API従量（推論費用） = 過大にならないか監視 | Phase 1でAPI費用を実測 → 月額上限設定、超えたら頻度調整 |

## 6. 結論

| 用途 | 推奨 | 開始方法 |
|---|---|---|
| 展示会ブース・イベントサイトSEO | **AIエージェント分析＋人間確認の2段階運用** | VPS契約 + GSC/GA4 API連携（Phase 1） |
| SEO推奨の自動生成 | データ駆動推奨 + 人間レビュー | `tools/llm-ask.mjs` にGSCデータ投入テンプレート追加 |
| 週次SEOレポート | 変化検出 + Slack通知 | OpenClaw or Claude Code で分析cron（Phase 2） |
| ミニサイト展開 | クエリテーマ別LPの自動生成 | 静的ホスティング＋デプロイスクリプト（Phase 3） |

週1回のGSC/GA4データ収集から始め、AI生成推奨の品質が安定した段階でミニサイト展開・部分自動実行へ段階的に進める。人間確認を外さないことでSEOリスクを最小化しつつ、データ分析の自動化メリットを早期に得られる構成である。
