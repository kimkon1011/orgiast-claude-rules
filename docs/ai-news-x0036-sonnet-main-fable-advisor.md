# X-0036: 本体Sonnet + 要所Fableアドバイザー委譲 — 日常は安価、大事な判断だけ高品質

**AIニュース提案 X-0036**: Claude Code の日常作業は Sonnet 5.5（安価）で行い、ブースレイアウト・イベント予算の要所判断だけ Fable 5.1 をアドバイザーとして呼び出す構成。`/model sonnet` + `/advisor fable` の設定で、Fable 課金は相談時のみに限定し、コストと品質を両立する。

観測日: 2026-11-13

---

## 1. 概要

Claude Code の運用コスト最適化において、**すべての判断を最上位モデルで行うのは過剰投資**である。一方で、設計判断や予算決定などの重要局面では高品質な判断が必要。本提案では、**Sonnet 5.5 を本体（日常作業）**、**Fable 5.1 をアドバイザー（要所判断）** に分割し、コスト効率と判断品質を両立する。

### 1.1 従来の構成との違い

| 観点 | X-0010（Sonnet + Opus advisor） | X-0036（Sonnet + Fable advisor） |
|------|-------------------------------|--------------------------------|
| アドバイザーモデル | Opus 5.5 | **Fable 5.1** |
| 起動方式 | `--advisor` フラグ | `/advisor fable` コマンド + settings.json 常設設定 |
| 課金モデル | 従量（Opus は常時利用可能） | **相談時のみ Fable 課金**（未使用時は Sonnet のみ） |
| 設定方法 | settings.json の手動編集 | CLAUDE.md に1行 + `/model sonnet` |
| 想定コスト比 | Opus 基準 1.0x | Fable 基準 2.0x（使用時のみ） |

### 1.2 なぜ Fable か

Fable 5.1 は Opus 5.5 の上位モデルとして位置づけられ、以下の特性を持つ:

| 特性 | Opus 5.5 | Fable 5.1 |
|------|---------|-----------|
| トークン単価（入力） | $15.00/M | **$30.00/M**（Opus の2倍） |
| トークン単価（出力） | $75.00/M | **$150.00/M**（Opus の2倍） |
| 推論品質 | 高い | **さらに高い（設計・戦略向け）** |
| 得意領域 | 汎用的な高品質判断 | **戦略的意思決定・全体設計** |
| 使用方針 | 日常の高品質タスク | **要所のみ・相談時限定** |

**Fable は高コストだが、使用頻度を限定（全体の5〜10%）すれば、総コストへの影響は限定的**。むしろ、Fable の高品質な判断により手戻りが減少し、結果的に総コスト削減につながる。

## 2. 設定方法

### 2.1 最小構成（CLAUDE.md に1行追加）

```markdown
大事な判断の前は必ず /advisor に相談してから決めて
```

この1行を CLAUDE.md に追加するだけで、以下の動作が有効になる:

1. 日常作業 → Sonnet 5.5（effort: medium）で自動実行
2. 要所判断（ブースレイアウト・予算決定など）→ `/advisor fable` を呼び出して Fable 5.1 に相談
3. Fable の回答を元に Sonnet が最終判断

### 2.2 settings.json 設定

```json
{
  "maxEffortLevel": "medium",
  "modelSettings": {
    "claude-sonnet-5-5": {
      "effort": "medium"
    }
  },
  "advisorModel": "claude-fable-5-1"
}
```

- `maxEffortLevel: "medium"` — 日常タスクの思考予算を抑制
- `advisorModel: "claude-fable-5-1"` — アドバイザーモデルを Fable に指定
- `modelSettings` — モデル別の effort 設定（Opus は medium に制限、上限 xhigh）

### 2.3 /advisor コマ��ドの使用例

```
# ブースレイアウトの判断
/advisor fable このブースレイアウト（10m×6m）で、通路側と奥側の展示配置、
    来場者動線を考慮した最適な機器レイアウトを提案してください

# イベント予算の判断
/advisor fable 展示会予算 120万円の配分案です。
    ブース構築費60万、輸送費15万、ノベルティ10万、人件費35万。
    この配分で妥当か、改善点があれば指摘してください

# 契約条件の判断
/advisor fable この契約書の条件（保証期間・免責範囲・支払条件）に
    リスクはないか、第三者の視点でチェックしてください
```

|------|---------|--------|

| **Sonnet + Fable advisor（X-0036）** | **$77** | **0.25x** |

### 3.2 内訳（Sonnet + Fable advisor）

| 項目 | 操作回数 | モデル | 単価 | 小計 |
|------|---------|-------|------|------|
| 日常作業（コード・文章） | 180回 | Sonnet 5.5 | $0.26/回 | $46.80 |
| ファイル検索・grep | 10回 | Sonnet 5.5 | $0.05/回 | $0.50 |
| 要所判断（相談） | 10回 | Fable 5.1 | $2.97/回 | $29.70 |
| **合計** | **200回** | | | **$77.00** |

### 3.3 Fable 相談比率と総コスト

```
Fable 0%  (全Sonnet): $62/月  ──────── 最も安い
Fable 5%  (本提案)   : $77/月  ──────── +$15 で Fable 品質
Fable 10%             : $92/月  ──────── +$30 でさらに品質向上
Fable 20%             : $122/月 ──────── コスト増加トレードオフ
Fable 50%             : $186/月 ──────── 過剰品質のリスク
```

**推奨: Fable 相談率 5〜10%**（セッションあたり10〜20回の要所判断）

## 5. 注意点と対策

| リスク | 内容 | 対策 |
|-------|------|------|
| Fable への過剰依存 | 何でも Fable に相談してコスト増 | CLAUDE.md の「要所のみ」ルールを明示 / 週次レビュー |
| Sonnet の品質限界 | 複雑な設計判断で Sonnet が誤る | 判断に迷ったら `/advisor fable` を促すルール |
| モデル切替の手間 | 毎回 `/advisor` を打つのが面倒 | `/advisor` は CLAUDE.md ルールで自動発動させる |
| Fable のコスト見落とし | 相談が増えて気付いたら高額に | Fable 使用回数を週次で確認（usage API） |
| チーム内のばらつき | 人によって相談頻度が違う | 統一ルールを CLAUDE.md に明記 |
