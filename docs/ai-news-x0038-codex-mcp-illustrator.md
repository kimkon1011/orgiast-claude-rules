# X-0038: Codex MCPでIllustrator作業を5分に — 版ずれ風テキストエフェクトの自動化

**AIニュース提案 X-0038**: Codex CLIのMCPサーバー機能を使い、Adobe IllustratorのExtendScriptを自然言語で生成・実行する。文字ツールで中央揃え→フォントとサイズ指定→1文字ずつウエイト変更→塗りM20+Y20%・線K100%1pt→線に変形-2mm→ラフ効果→下方向複製→アピアランス分割とアウトライン→アートボード調整の一連を「5分ぐらい」で完了する。株式会社オージャストではブースサイン・版ずれ風見出し・パネル文字など日常のIllustrator作業の1本を同じ手順で試し、手作業時間と比較する。

観測日: 2026-11-13

| 必要なもの | Codex CLI + Adobe Illustrator + `illustrator-mcp.mjs`（本リポジトリのツール） |

### 1.1 なぜIllustratorなのか

展示会ブース制作では以下の作業が頻発するが、いずれも手作業で行うと15〜30分かかる：

- **版ずれ風見出し**: ブースタイトルやキャッチコピーに印刷表現としての版ずれ効果を付ける
- **パネル文字の量産**: 複数の展示パネルでフォント・サイズ・配置を統一したテキストレイヤーを生成
- **サインの一括調整**: フォント・カラー・サイズを全サインに一括適用
- **アートボードの書き出し**: 全パネルのPDF/PNG一括エクスポート

これらの作業を自然言語で指示 → CodexがExtendScriptを生成 → Illustratorが実行、のパイプラインで処理すれば、1作業あたり5分程度に短縮できる。

## 2. アーキテクチャ

### 2.1 全体構成

```
[Claude Code / Codex CLI]
    │ MCP (stdio)
    ▼
[illustrator-mcp.mjs] ← 本リポジトリのツール
    │ ① 自然言語 → ExtendScript生成（llm-ask / テンプレート）
    │ ② .jsxファイルを保存
    │ ③ Illustrator起動 or COM呼出し
    ▼
[Adobe Illustrator] → ExtendScript実行 → .ai / .pdf / .png出力
```

### 2.2 MCPサーバー構成

`~/.claude/settings.json` に以下を追加するだけで有効になる：

```json
{
  "mcpServers": {
    "illustrator-mcp": {
      "type": "stdio",
      "command": "node",
      "args": ["path/to/tools/illustrator-mcp.mjs"]
    }
  }
}
```

### 2.3 公開ツール一覧

| ツール名 | 機能 |
|---|---|
| `generate_extendscript` | 自然言語の説明からExtendScript (.jsx)を生成 |
| `execute_script` | .jsxファイルをIllustratorで実行（CLI or COM） |
| `create_text_effect` | 版ずれ風・ドロップシャドウ・グラデーション等のテキストエフェクトを生成 |
| `export_artboard` | カレントアートボードをPDF/PNGに書き出し |

### 2.4 スクリプト生成の2経路

1. **LLM生成（推奨）**: `llm-ask.mjs`（Gemini 3.6 Flash）が自然言語からExtendScriptを生成。複雑なエフェクトやカスタム要件に対応
2. **テンプレート**: 版ずれ風・ブースサイン・汎用の3テンプレートを内蔵。LLMが利用不可でも動作

## 3. 実証: 版ずれ風テキストエフェクト

### 3.1 手順（従来の手作業）

| # | 工程 | 手作業の所要時間 |
|---|------|-----------------|
| 1 | 文字ツールでテキスト作成・中央揃え | 1分 |
| 2 | フォントとサイズ指定 | 30秒 |
| 3 | 1文字ずつウエイト変更 | 2分 |
| 4 | 塗りM20+Y20%・線K100%1pt | 1分 |
| 5 | 線に変形-2mm | 30秒 |
| 6 | ラフ効果 | 30秒 |
| 7 | 下方向複製 | 30秒 |
| 8 | アピアランス分割とアウトライン | 1分 |
| 9 | アートボード調整 | 30秒 |
| **合計** | | **8〜10分** |

### 3.2 Codex MCP経由の手順

1. Claude Code上で自然言語で指示:
   ```
   illustrator-mcpのcreate_text_effectで
   effect=misregistration、text="NEW PRODUCT"、font_size=96
   ```
2. 生成されたExtendScriptを確認（任意）
3. Illustratorでスクリプト実行
4. 完了

**所要時間: 約2〜5分**（うちスクリプト生成に30秒、実行に1〜2分）

### 3.3 生成されるExtendScriptの中身

MCPサーバーが生成するExtendScriptは以下の工程を自動化する：

1. ドキュメントの新規作成または既存ドキュメントの取得
2. フォントの検索とフォールバック（Helvetica-Bold → Arial-BoldMT → MyriadPro-Bold）
3. 版ずれ層の作成（シアン・マゼンタ・キーの3層をオフセット配置）
4. 各層のカラー設定（CMYK）、透明度・描画モード（乗算）の設定
5. ドキュメントの再描画

## 6. 注意点・リスク

| リスク | 内容 | 対策 |
|---|---|---|
| Illustrator未インストール | MCPサーバーは起動するがスクリプト実行不可 | `.jsx`ファイルを生成して手動実行できる（ファイルとして残る） |
| COM権限 | WindowsのCOMセキュリティ設定でIllustrator操作がブロックされる可能性 | 管理者権限での初回実行が必要な場合あり |
| ExtendScriptの互換性 | IllustratorのバージョンによってAPIが異なる | テンプレートは2022〜2025で動作確認。LLM生成時はバージョン指定推奨 |
| フォントの不在 | スクリプト内で指定したフォントが存在しないとエラー | フォールバック機構内蔵（複数フォント候補を順に試行） |
| 意図しない編集 | 既存ドキュメントにスクリプトが作用するリスク | `app.documents.length === 0` の場合のみ新規作成。既存ドキュメントは明示指定必須 |
