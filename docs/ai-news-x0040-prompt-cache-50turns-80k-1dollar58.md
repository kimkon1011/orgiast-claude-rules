# X-0040: 50ターン・80K入力を$1.58にするプロンプトキャッシュ再現シナリオ

**AIニュース提案 2026-11-18**: 79Kトークンの固定プレフィックスと1Kトークンの可変入力（総入力80K）を50ターン繰り返し、各ターンを5分TTL内に実行すると、ここで定義するFable 5.2の仮定価格では、20トークンの短い出力を含めて総額は厳密に**$1.5800**になる。キャッシュなしの**$32.08032**に対し、削減率は約**95.07%**である。

> 「Fable 5.2」、5分TTL、各単価、$1.58という結果は、ニュース上の仮定を検算するための再現シナリオである。実在サービスへのAPI実行結果や実測価格ではない。付属CLIは外部API、SDK、認証情報を一切使用しない。

## 再現条件

| 条件 | 値 |
|---|---:|
| ターン数 | 50 |
| 総入力/ターン | 80,000 Tok |
| 固定・キャッシュ対象prefix | 79,000 Tok |
| 非キャッシュ・可変入力 | 1,000 Tok |
| 出力/ターン | 20 Tok |
| ターン間隔 | 240,000 ms（4分） |
| TTL（仮定） | 300,000 ms（5分） |
| 通常入力単価 | $8.00 / 1M Tok |
| キャッシュ書込単価 | $10.00 / 1M Tok |
| キャッシュ読取単価 | $0.08 / 1M Tok |
| 出力単価 | $80.32 / 1M Tok |

固定prefixは入力の先頭に置き、可変値はその後ろに置く。prefixが変わるか、前ターンから5分を超えると次のターンは再書込になる。

## $1.58の式

| 内訳 | 式 | 金額 |
|---|---|---:|
| 初回prefix書込 | 79,000 × $10.00 / 1M | $0.7900 |
| 49回のprefix読取 | 49 × 79,000 × $0.08 / 1M | $0.30968 |
| 50回の可変入力 | 50 × 1,000 × $8.00 / 1M | $0.4000 |
| 50回の出力 | 50 × 20 × $80.32 / 1M | $0.08032 |
| 合計 | $0.7900 + $0.30968 + $0.4000 + $0.08032 | **$1.5800** |

丸めて$1.58に寄せた値ではない。比較対象のキャッシュなし総額は `50 × (80,000 × $8.00 + 20 × $80.32) / 1M = $32.08032`。

## 想定用途と注意点

- ブース制約・施工ルールを固定prefixにし、顧客別条件だけを後置する企画案生成
- 単価表・割引条件を固定prefixにし、対象アイテムだけを後置する見積比較
- 会場制約・スタッフ情報を固定prefixにし、候補日だけを後置する日程調整

| リスク | このCLIでの扱い |
|---|---|
| 5分超の間隔 | `--interval 300001` で全ターン再書込 |
| 固定prefix変更 | `--prefix-change-at N` でNターン目を再書込 |
| prefix後方の可変入力 | `--total-input` と `--cached-prefix` の差を通常入力として課金 |
| 長い出力 | `--output` の値に比例して出力費を加算 |

50件を4分間隔で直列実行すると全体には長時間かかるが、各連続リクエスト間がTTL内ならこの簡略モデルではヒットが継続する。実サービスのTTL更新条件はプロバイダ仕様に従う。この試算の価値は実価格の主張ではなく、固定prefix、TTL、出力長、再書込条件を明示して案を再現可能に検算できる点にある。
