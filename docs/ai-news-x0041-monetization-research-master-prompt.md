## 1. 概要

本マスタープロンプトは、**YouTube動画の内容をNotebookLMで理解し、Claude Codeで加工・変換・商品化する**一連のワークフローを体系化したもの。単なる「動画を要約する」ツールではなく、以下のプロセスを自動化する:

1. **情報抽出**: YouTube動画から事実・意見・手順・数字・制約を完全抽出
2. **横断分析**: 複数動画の比較による市場空白・独自テーマの発見
3. **コンテンツ変換**: SEO記事・note・Threads・スライド・ポッドキャストへの自動変換
4. **商品企画**: 有料商品の設計・品質監査・価格設定
5. **品質管理**: 事実と推測の分離・出典追跡・監査プロセス

### 1.1 なぜ2027年の収益化に効くか

| 要素 | 従来 | 本システム |
|------|------|-----------|
| リサーチ | 動画視聴→メモ取り→整理（数時間） | NotebookLMが自動抽出（数分） |
| コンテンツ化 | 手動で記事・SNS投稿（半日〜数日） | Claude Codeが複数形式を一括生成（数十分） |
| 商品化 | 直感ベースの企画 | データ駆動の商品企画＋品質監査 |
| 品質管理 | 属人的なチェック | 20項目の機械監査＋スコアリング |
| 再現性 | 人依存 | プロンプト＋CLAUDE.mdで完全再現可能 |

### 1.2 株式会社オージャストでの適用イメージ

**展示会ブース制作のAI自動化調査**:
- YouTubeの展示会トレンド動画をNotebookLMで解析
- 競合ブース制作会社の事例動画を横断比較
- ブースデザインの最新トレンドをSEO記事化

**イベントSEO/LLMO調査**:
- SEO/LLMO系YouTubeからベストプラクティスを抽出
- オージャストサイトへの適用手順を自動生成
- 効果測定のためのクエリ設計

**UI改善トレンド調査**:
- UI/UX系YouTubeから改善パターンを収集
- 自社サイトのUI診断と改善提案を自動生成
- 展示会ブースのデジタル接客UIへの応用

## 3. オージャストでの適用計画

### 3.1 展示会ブース制作のトレンド調査

```
[入力] YouTube: 展示会トレンド動画・競合事例・デザイン手法
  ↓ NotebookLMで分析
[抽出] トレンド一覧・競合の強み/弱み・デザインパターン
  ↓ Claude Codeで変換
[出力] SEO記事（自社サイト）・Threads投稿（集客）・ブース企画書（社内）
```

### 3.2 イベントSEO/LLMO調査

```
[入力] YouTube: SEO/LLMO最新手法・ケーススタディ
  ↓ NotebookLMで横断比較
[抽出] 効果検証済み手法・失敗パターン・測定指標
  ↓ Claude Codeで変換
[出力] SEO改善タスクリスト・LLMO測定クエリセット・A/Bテスト計画
```

### 3.3 UI改善トレンド調査

```
[入力] YouTube: UI/UX改善事例・展示会デジタル接客
  ↓ NotebookLMで横断比較
[抽出] 改善パターン・実装手順・効果測定データ
  ↓ Claude Codeで変換
[出力] UI改善提案書・ワイヤーフレーム案・A/Bテスト設計
```

### 3.4 段階的導入計画

| フェーズ | 期間 | 作業 | アウトプット |
|---------|------|------|------------|
| Lv1: 抽出のみ | 1〜3日 | 動画選択→NotebookLM登録→要約保存 | トレンドレポート |
| Lv2: 成果物生成 | 4〜10日 | 要約→記事/投稿生成 | SEO記事3本＋Threads10本 |
| Lv3: 動画追加自動化 | 11〜17日 | inbox管理→自動登録→変換 | 週次トレンドレポート自動生成 |
| Lv4: 公開前まで自動 | 18〜30日 | 全工程自動化＋品質監査 | 月次業界レポート＋商品企画 |

## 5. 結論

本マスタープロンプトは、YouTube動画を起点とした**リサーチ→コンテンツ化→商品化の全工程を体系化**したもの。NotebookLMの深い動画理解力とClaude Codeの自動化能力を組み合わせることで、従来の手作業と比較して**80〜90%の時間削減**が見込める。

株式会社オージャストでは展示会ブース制作のトレンド調査・イベントSEO/LLMO・UI改善の3分野で適用を試し、Lv1（抽出のみ）から段階的に自動化を進めることで、業界調査の生産性を大幅に向上できる。

**導入のポイント**:
- 最初はLv1から始め、安定後に段階的に自動化レベルを上げる
- 事実と推測の分離・出典追跡を徹底し、品質を担保する
- 有料商品化は17章のプロセスに従い、品質監査（23章）を必ず通過させる
- CLAUDE.mdへの運用ルール記載（20章）で再現性を確保する
