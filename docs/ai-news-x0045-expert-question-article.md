# X-0045: 専門家質問で独自AI記事作成 — NYSEO式20〜25問ヒアリング × AI生成で差別化コンテンツ

**AIニュース提案 X-0045**: NYSEOの手法——ユーザーに20〜25個の専門的質問を投げ、回答から独自情報を泥臭く引き出し構成と本文を作成——を、株式会社オージャストのブース制作ノウハウに適用する。施工スタッフ・ディレクターへの構造化インタビュー（成功事例・失敗例・最新トレンドなど20〜25問）の回答をAIに渡し、他社が量産できない独自データ・実体験に基づくSEO/LLMO記事を生成して自社サイトで公開する仕組み。

観測日: 2026-11-14

---

## 1. 概要

**2026年のSEO/LLMO環境では、AIが公開情報から書ける「一般的な解説記事」には検索価値がほぼない。** GoogleのAI Overview・ChatGPT Search・Perplexity等が、複数の情報源を横断して要約を即座に提供するため、表面的な記事は検索流入を得られない。

差別化の唯一の手段は **「公開情報からは得られない一次データ・実体験・独自視点」** を記事に含めること。NYSEOはこの課題に対し、**専門家（クライアントの担当者）に20〜25問の構造化質問を投げ、その回答だけをAIに渡して記事を生成する**手法を採用している。

| 要素 | 一般的AI記事生成 | NYSEO式 専門家質問法 |
|------|-----------------|-------------------|
| 情報源 | ウェブ検索結果のみ | 社内専門家の生回答20〜25問分 |
| 独自性 | 低（他社も同じソースから生成可能） | 極めて高い（社内にしかない体験・数字） |
| E-E-A-T | 低〜中（Experienceが欠落） | 高い（実体験に基づく記述） |
| 検索価値 | AI Overviewに代替される | AI Overviewの引用元になりうる |
| 制作時間 | 30分〜2時間 | 取材1時間 + AI生成30分 |
| 更新頻度 | 高いが価値低下も早い | 低いが持続的価値 |

### 本提案の核心

**「ブース制作のプロの頭の中」を構造化インタビューで引き出し、AIでSEO/LLMO記事に変換するパイプライン**。20〜25問の質問セットを一度設計すれば、施工スタッフ・ディレクターごとに繰り返し使え、10記事・20記事と量産できる。

## 2. NYSEOの専門家質問アプローチ

### 2.1 質問設計の原則

NYSEOの手法では、以下の原則で質問を設計する:

1. **AIが答えられない質問だけを聞く** — 公開情報で調べられることは聞かない
2. **具体的事例を要求する** — 「どう思うか」ではなく「どうだったか」
3. **数量・日付・固有名詞を引き出す** — 「多い」ではなく「昨年比30%増」
4. **失敗・苦労を掘る** — 成功談より失敗談の方が独自性が高い
5. **対比を促す** — 「AとBの違いは？」「導入前と導入後でどう変わった？」

### 2.2 質問カテゴリ（20〜25問の内訳）

| カテゴリ | 質問数 | 目的 |
|---------|--------|------|
| ① 経験・実績 | 4〜5問 | 実体験の具体化（いつ・どこで・誰と） |
| ② 課題・失敗 | 4〜5問 | 独自の困難と克服エピソード |
| ③ 数字・データ | 3〜4問 | 検証可能な定量情報 |
| ④ 比較・対比 | 3〜4問 | 差別化ポイントの明確化 |
| ⑤ トレンド・変化 | 3〜4問 | 業界知見・将来予測 |
| ⑥ アドバイス | 2〜3問 | 読者への実用的示唆 |

### 2.3 回答のAI処理フロー

```
専門家への20〜25問インタビュー（60分）
        ↓
回答テキストを整形・ファクトチェック
        ↓
AIに記事構成を生成させる（構成案）
        ↓
構成を人間が確認・調整
        ↓
AIに本文を生成させる（回答のみを情報源として）
        ↓
人間が校閲・事実確認
        ↓
SEOメタデータ付与 → 公開
```

## 3. オージャスト向け質問セット（設計案）

### 3.1 カテゴリ別質問例（全22問）

#### ① 経験・実績（5問）

1. あなたが携わった展示会ブース制作の中で、**最も反響が大きかった**案件は何ですか？ 具体的に「何の展示会で」「何年に」「どれくらいの規模（小間数・予算）で」「どんな反響があったか」を教えてください。
2. そのブースで**特にこだわったポイント**（デザイン・素材・動線・照明など）は何ですか？ なぜそのこだわりが重要だったのですか？
3. 初めてブース制作を担当したときの**クライアントの要望**と**実際に提供したもの**を教えてください。初回と現在で、最も変わったことは何ですか？
4. これまでで**最も短期間で制作した**案件とそのスケジュール（着手から搬入までの日数）を教えてください。短期間でも品質を落とさなかった工夫は？
5. **予算が限られていた**案件で、最大の効果を出した工夫は何ですか？ 具体的な代替素材やレイアウトの工夫を教えてください。

#### ② 課題・失敗（5問）

6. ブース設営中または設営後に**想定外のトラブル**が発生した事例を教えてください。どう対処しましたか？
7. **クライアントとの認識齟齬**で苦労した経験はありますか？ どうやって解消しましたか？
8. **搬入・搬出で最も大変だった**ケースを教えてください（会場の制約・時間制限・重量制限など）。
9. ブースの**デザインと施工性の間で妥協**せざるを得なかったポイントは？ その判断基準は何ですか？
10. 過去に**「これは失敗だった」と振り返る**案件はありますか？ その原因と、次回にどう活かしたかを教えてください。

#### ③ 数字・データ（4問）

11. あなたが担当した案件の**平均的な工期**（設計着手から搬入まで）は何日くらいですか？ 最短と最長も教えてください。
12. **ブース1小間（2.7m×6m）あたりの平均的な予算帯**と、予算によって変わる要素（素材・照明・什器の違い）を教えてください。
13. リピート率・成約率など、**営業的な数字**で意識している指標はありますか？ 改善傾向にありますか？
14. **年間で何件のブース**を担当していますか？ そのうち新規クライアントとリピートの割合は？

#### ④ 比較・対比（4問）

15. **東京ビッグサイトとインテックス大阪**（または他の主要会場）で、設営のしやすさ・制約・費用の違いを教えてください。
16. **10年前のブースと最近のブース**で、最も変わったと感じる点は？（素材・LED活用・来場者動線・予算等）
17. **国内展示会と海外展示���**のブース制作で、最も異なる点は何ですか？
18. **小規模ブース（1〜2小間）と大規模ブース（6小間以上）** で、設計・施工の考え方の違いは？

#### ⑤ トレンド・変化（4問）

19. 最近の展示会ブースで**よく使われるようになった素材や技術**はありますか？（LED・サステナブル素材・デジタルサイネージ等）
20. **展示会業界全体のトレンド**として、この1〜2年で大きく変わったと感じることは？
21. クライアントの**予算配分の変化**（ブース制作費 vs プロモーション費等）を感じますか？
22. **AIやデジタルツール**で、ブース制作の仕事がどう変わった／変わると予想しますか？

#### ⑥ アドバイス（2問）

23. これから展示会に出展を考えている企業に**最初に伝えたいアドバイス**は何ですか？
24. 展示会ブース制作会社を選ぶときに**見るべきポイント**を3つ挙げてください。

### 3.2 質問の使い方

- **1回の取材で全22問を使う必要はない** — スタッフの得意分野に応じて8〜12問を選択
- **回答は録音＋文字起こし**が理想。最低でもメモを残す
- **質問は事前に渡さない**（初見の即答の方が生の声が出る）
- **1問あたり2〜3分**想定、合計40〜60分の取材時間

## 4. AI記事生成パイプライン

### 4.1 プロンプト設計

```
# 指示
あなたは展示会ブース制作の専門家によるインタビュー回答から、SEO記事を生成するライターです。
以下のインタビュー回答のみを情報源として、SEO/LLMO向けの記事を1本生成してください。
公開情報や一般知識で補完しないでください。

# インタビュー回答
{回答テキスト（20〜25問分）}

# 出力要件
1. タイトル（SEOキーワードを含む、60字以内）
2. リード文（150字以内、検索結果のdescriptionとしても使えるもの）
3. 本文（2,000〜4,000字、h2見出しで区切る）
4. FAQ（3〜5問、構造化データ用）
5. メタデータ（メタdescription 120字以内、キーワード5つ）

# 品質ルール
- 「多くの企業が」「一般的に」などの一般論を書かない
- 具体的な数字・固有名詞・事例はインタビュー回答から引用し「」で囲む
- 意見と事実を明確に区別する
- 誇張表現をしない
- E-E-A-Tを高めるため、経験に基づく記述を優先する
```

### 4.2 記事生成後のチェックリスト

- [ ] 一般論で水増しされていないか（インタビューにない内容をAIが補っていないか）
- [ ] 数字・固有名詞が回答と一致しているか
- [ ] 誇張表現がないか（「業界最高」「日本一」等）
- [ ] 記事の主題が回答の内容の範囲内か
- [ ] FAQは回答から生成されたものか
- [ ] メタデータにターゲットキーワードが含まれているか

### 4.3 記事フォーマット

| 記事の種類 | 質問の組み合わせ | ターゲットキーワード | 公開頻度 |
|-----------|----------------|-------------------|---------|
| 成功事例 | ①経験＋②課題＋④比較 | 「展示会ブース 成功事例」「ブースデザイン 実績」 | 月2本 |
| ノウハウ記事 | ③数字＋④比較＋⑤トレンド | 「展示会ブース 予算」「ブース制作 費用相場」 | 月2本 |
| 失敗から学ぶ | ②課題＋⑤トレンド＋⑥アドバイス | 「展示会 失敗しない」「ブース設営 トラブル対策」 | 月1本 |
| 業界トレンド | ⑤トレンド＋④比較 | 「展示会トレンド 2027」「ブースデザイン 最新」 | 月1本 |
| インタビュー | 全カテゴリから抜粋 | 「ブース制作 インタビュー」「展示会 ���ロに聞く」 | 月1本 |

| 要素 | 従来の記事制作 | 本手法 |

### 5.3 LLMO効果

- **具体的な数字**: 「予算500万円以上のブースでは…」→ 比較クエリで引用されやすい

- **対比情報**: 「A会場とB会場では搬入ルールが異なり…」→ 比較クエリで価値が高い
