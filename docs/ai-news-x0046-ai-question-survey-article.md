## 1. 概要

**2026年のSEOの現実**: 表面的な「展示会ブース 費用」「小間ブース デザイン」といった一般的な記事は、AI OverviewやChatGPT Searchに代替されクリックを獲得できない。

**X-0046の核心**: 「顧客がAIに聞いている生の質問」を調査し、その質問に**ピンポイントで答える記事**を制作する。AIが回答の引用元として選ぶコンテンツを量産し、7週間で問い合わせを約6倍に増やすフレームワーク。

本手法は、DataForSEOやAI SEO Tracker等のツールで「AIがどの質問にどのサイトを引用しているか」を実測し、引用されていない自社の強み領域に記事を追加する——いわば **「AI回答の穴埋め」** である。

| フェーズ | 内容 | 期間 | 効果見込み |
|---------|------|------|-----------|
| ① AI質問調査 | AIアシスタントが回答する展示会関連質問を網羅的に収集・クラスタリング | 1週目 | 記事テーマ確定 |
| ② 回答記事制作 | 各質問に特化した記事を制作（独自データ・実体験重視） | 2〜3週目 | コンテンツ拡充 |
| ③ 技術SEO改善 | サイトの技術的問題を修正（Core Web Vitals・構造化データ等） | 2〜4週目 | インデックス改善 |
| ④ 外部発信 | 外部プラットフォームで情報発信（Qiita・note・Parasite SEO等） | 4〜7週目 | 引用元拡散 |
| ⑤ 効果測定 | AI Overview引用率・検索順位・問い合わせ数の推移を計測 | 毎週 | PDCA |

## 2. AI質問調査（Phase ①）

### 2.1 調査方法

AIアシスタントが展示会ブースに関して参照している情報源と、ユーザーが投げかけている質問を収集する。以下の3経路でデータを取得する：

| 経路 | ツール | 取得できるデータ | コスト |
|------|--------|-----------------|--------|
| AI SEO Tracker | aiseotracker.com | ChatGPT/Perplexityでの自社・競合の引用状況 | 月額$XX |
| DataForSEO | /api/v3/serp/ai_overview/live | Google AI Overviewが引用するURLとクエリ一覧 | 従量（1クエリ約$0.01） |
| 手動プローブ | ChatGPT / Perplexity / Gemini に直接質問 | 各AIアシスタントが返す具体的回答内容 | 無料（API経由で自動化可） |

### 2.2 展示会ブース関連の質問カテゴリ（推定）

実際の調査で確定するが、初期仮説として以下のカテゴリが想定される：

| カテゴリ | 想定質問例 | 意図 |
|---------|-----------|------|
| ① 費用 | 「小間ブース 費用 相場」「展示会 出展 予算 内訳」 | 予算策定の参考 |
| ② デザイン | 「小間ブース デザイン 事例」「展示会 ブース レイアウト おしゃれ」 | ビジュアルイメージ |
| ③ 業者選び | 「展示会 ブース 制作会社 選び方」「施工会社 比較」 | 発注先決定 |
| ④ 期間 | 「ブース 制作 工期」「展示会 申込 いつまで」 | スケジュール感 |
| ⑤ 効果 | 「展示会 出展 ROAS」「ブース 集客 施策」 | 投資判断 |
| ⑥ 運営 | 「展示会 当日 スタッフ 配置」「ブース 運営 マニュアル」 | 実務の準備 |

### 2.3 調査の出力

```
outputs/X-0046/ai-question-clusters.json
  └ 質問クラスタ一覧（カテゴリ・質問文・検索ポテンシャル・競合度）
outputs/X-0046/ai-citation-gaps.md
  └ 自社が引用されていない質問の一覧（優先度順）
```

## 3. 回答記事制作（Phase ②）

### 3.1 記事フォーマットの原則

調査で得た「顧客の生の質問」に直接答える形で記事を構成する。

| 要素 | 一般的なSEO記事 | AI質問回答記事 |
|------|----------------|---------------|
| タイトル | 「展示会ブース費用ガイド」 | 「【2026年】3m×3m小間ブースの制作費相場は？最新価格と内訳」 |
| 見出し | 網羅的な目次 | ユーザーの質問をそのままH2に（「費用はいくら？」「いつまでに申し込む？」） |
| 冒頭 | 一般的な説明 | **その質問の答えを最初の1文で書く**（Featured Snippet / AI Overview対策） |
| データ | 他サイトの引用 | **自社の実績データ・実測値**（独自性の源泉） |
| 構造化データ | FAQマークアップ | QAPage / FAQPage マークアップ（AI引用率向上） |

### 3.2 制作パイプライン

Phase ①の質問クラスタを入力として、以下のパイプラインで記事を量産する：

1. **質問クラスタ→記事構成**: 各クラスタから1記事の構成を生成（H2〜H3・回答内容）
2. **自社データ注入**: 構成の各節に自社の実測値・事例・施工実績をマッピング
3. **本文生成**: AIに下書きを生成させるが、**オリジナルデータの部分は手動で検証**
4. **構造化データ**: FAQPage / QAPage のJSON-LDを記事に埋め込み
5. **レビュー**: ファクトチェック（特に金額・数値・固有名詞）

### 3.3 初期ターゲット記事（10本想定）

| # | 質問 | 記事タイトル案 | 独自データ要否 |
|---|------|--------------|--------------|
| 1 | 小間ブースの制作費っていくら？ | 3m×3m小間ブース制作費のリアルな価格帯【2026年最新】 | 過去案件の平均単価 |
| 2 | ブースデザインはどう選ぶ？ | 展示会ブースのデザイン、4つのタイプと選び方 | 施工事例写真 |
| 3 | 制作会社はどう選べばいい？ | 展示会ブース制作会社10社の比較と失敗しない選び方 | 制作プロセス比較表 |
| 4 | いつまでに準備すればいい？ | 展示会出展　逆算スケジュール【出展決定から当日まで】 | 工程ごとの所要日数 |
| 5 | 小間ブースで集客するには？ | 3m×3m小間ブースで集客する15の具体策 | 実績データ |
| 6 | 予算が少ないけど出展できる？ | 予算50万円からの展示会出展　費用対効果を最大化する方法 | 低予算事例 |
| 7 | はじめての出展で失敗しない方法 | 展示会初出展で絶対に押さえるべき10のチェックポイント | よくある失敗例 |
| 8 | 海外展示会に出展するには？ | 海外展示会出展ガイド　準備・費用・注意点 | 海外施工実績 |
| 9 | リピート出展のコツは？ | 毎年出展する企業が実践する展示会成功のルーティン | リピート事例 |
| 10 | オンライン展示会にも出るべき？ | オンライン展示会の効果と活用方法［ポストコロナの戦略］ | ハイブリッド事例 |

## 4. 技術SEO改善（Phase ③）

### 4.1 診断項目

AI Overview / ChatGPT Searchに引用されるための技術的必須条件：

| 項目 | 対応 | 優先度 |
|------|------|--------|
| Core Web Vitals 合格 | LCP < 2.5s / CLS < 0.1 / FCP < 1.2s / INP < 200ms | MUST |
| 構造化データ | FAQPage / QAPage JSON-LD を全記事に | MUST |
| モバイルファースト | モバイルでの表示速度・操作性をPC同等以上に | MUST |
| インデックスカバレッジ | Google Search Console で有効ページ数の確認・未インデックス対応 | HIGH |
| 内部リンク構造 | 記事間の文脈的リンク（関連記事の相互リンク） | HIGH |
| ページエクスペリエンス | HTTPS / リダイレクト / 404 のクリーンアップ | HIGH |
| サイテーション元の充実 | 外部サイトからの言及（被リンク・引用） | MEDIUM |

### 4.2 AIが引用しやすい構造

ChatGPT / Perplexity / AI Overviewは、以下の特徴を持つページを引用する傾向がある：

1. **質問-回答形式**（QAPage構造化データ）のあるページ
2. **冒頭段落に答えが書いてある**ページ
3. **独自データ・数字**を含むページ
4. **引用可能な事実が箇条書きで整理**されているページ
5. **権威ある外部ソースへのリンク**があるページ

## 5. 外部発信（Phase ④）

### 5.1 発信チャネル

| チャネル | 内容 | 目的 | 優先度 |
|---------|------|------|--------|
| Qiita / Zenn | 展示会テクノロジー・施工ノウハウの技術記事 | 技術層へのリーチ・被リンク | HIGH |
| note | 展示会デザイン・運営の実体験記事 | デザイナー・マーケター層へ | HIGH |
| LinkedIn | 展示会マーケティングの専門的知見 | BtoB 顧客層・業界内認知 | MEDIUM |
| プレスリリース配信 | 新サービス・実績発表 | メディア引用・一般的認知 | MEDIUM |
| ゲスト投稿 | 他メディアへの記事提供 | ドメイン権威の獲得 | MEDIUM |

### 5.2 Parasite SEO / ポッドキャスト活用

- **Parasite SEO**: 高DRドメイン（note・Qiita・LinkedIn・Medium等）に記事を掲載し、自社サイトへのリンクを設置。AIがこれらのプラットフォームを引用する傾向を活用。
- **ポッドキャスト出演**: 展示会マーケティングに関する知見をポッドキャストで発信し、ショーノートから自社サイトへのリンクを得る。

## 9. リスクと対策

| リスク | 対策 |
|--------|------|
| AI Overviewのアルゴリズム変更 | 複数AI（ChatGPT / Perplexity / Gemini）を同時計測し、1つに依存しない |
| 記事の独自性不足 | 自社データ（実測値・事例写真・施工実績）を必ず各記事に入れる |
| 外部発信の効果が出ない | 掲載先のドメイン権威と読者層を事前調査、低DRメディアは避ける |
| Core Web Vitals改善の工数不足 | スコア100%を目指さず、AI Overviewの引用率に直結する指標に絞る |
| B2Bの問い合わせサイクル | 問い合わせ数の計測はフォーム送信＋電話問い合わせ＋メール問い合わせを合算 |
