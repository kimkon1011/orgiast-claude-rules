# X-0050: AIOは記事量産よりサービス詳細 — 2つのゴールを分け、説明を足す

**AIニュース提案 2026-11-20**: AI Overviews（AIO）最適化で「AI回答に自社を登場させること」と「AIに自社を推奨させること」は別のゴールであり、手段も異なる。大量の記事作成は直接的なAI紹介や推薦に直結しない。最初に製品情報・サービス案内へ詳細を足すべきという知見に基づき、2つのゴールの優先順位と実行アプローチを明確にする。

観測日: 2026-11-20

---

## エグゼクティブサマリ

| 項目 | 内容 |
|------|------|
| 核となる発見 | AIOで成果を出すには「社名をAI回答に登場させること（言及）」と「AI回答に自社を推奨させること（推薦）」を**別々のゴールとして戦略を分ける**必要がある |
| 最初にやること | 記事を量産する前に、**自社の製品情報・サービス案内ページに詳細な説明を追記する**。AIの引用元として最も参照されるのはビジネスサイトのサービス詳細 |
| オージャストの戦略 | ブースの仕様・素材・施工工程・納期・選ばれる理由をサービス案内に追記。外部露出（言及）と自社ページの説明強化（推薦）の優先順位を明確に分ける |
| 時間軸 | サービス詳細の充実（P0・1〜2週間）→ 外部露出施策（P1・1〜3ヶ月） |

---

## 1. 背景: AIOの2つの異なるゴール

### 1.1 言及（Citation）と推薦（Recommendation）の違い

AI検索（ChatGPT、Perplexity、Gemini等）が企業名を扱う時、2つの全く異なるモードがある。

| モード | 言及（Citation） | 推薦（Recommendation） |
|--------|-----------------|----------------------|
| 内容 | 「〇〇社が展示会ブースを制作している」 | 「展示会ブース制作なら〇〇社がおすすめ」 |
| 必要なもの | Web上の露出・評判・メディア掲載 | サービス説明・特徴・選ばれる理由の明確な記述 |
| 引用元 | ニュース記事・レビュー・SNS・メディア | 自社サイトのサービスページ・FAQ・事例 |
| 主観性 | 事実ベース（中立的） | 評価ベース（推奨的） |
| 影響の大きいシグナル | Web/YouTube言及、被リンク | 構造化データ、詳細なテキスト説明、FAQ |
| 時間軸 | 半年〜1年かかる | 改善後1〜2週間で反映される可能性あり |
| 自社でコントロール | 困難（第三者に依存） | 容易（自社サイトを編集するだけ） |

**重要な発見**: この2つを混同すると、「記事をたくさん書けばAIに推奨されるようになる」という誤った戦略に陥る。記事量産は言及（外部露出）には貢献するが、推薦（自社説明）にはほとんど貢献しない。

### 1.2 参考事例: 引用元としてのビジネスサイトの重要性

X-0060（AI検索でビジネスサイトが93%のソース）の分析では、AI検索の引用元の93%がレビューサイトやディレクトリではなく**ビジネスサイト**であることが判明した。

AI検索に引用されるビジネスサイトは8要素を明確に記載している：
1. 誰（Who）、2. 何をする（What）、3. どこで（Where）、4. **サービス詳細（Service）**、5. 対象（Target）、6. 費用（Cost）、7. 質問（Questions）、8. 連絡方法（Contact）

オージャストのサイト診断（X-0060）では、**「4. サービス詳細」が「一部不足」**と判定されている。Re:ブースの説明は充実しているが、社内イベントプロデュースやクリエイティブ制作の詳細説明が不足している。

## 2. ゴール①: AI回答での社名言及（外部露出）

### 2.1 目標

ChatGPT・Perplexity・Claude等のAI検索で「展示会ブース制作会社」と質問した時に、回答文の一部として「株式会社オージャスト」の社名が自然に登場する状態を作る。

### 2.2 必要な要素

| 要素 | 重要度 | 説明 |
|------|--------|------|
| Web上の言及 | ★★★★★ | ニュース記事・メディア掲載・ブログでの紹介が最も強力なシグナル |
| YouTube言及 | ★★★★ | X-0051の分析で、被リンクよりYouTube言及の方がAI可視性と強く相関 |
| 第三者レビュー | ★★★★ | 業界メディア・比較サイトでの評価・採点 |
| 被リンク | ★★★ | 重要だがAI回答での言及との相関は他のシグナルより弱い |
| 自社サイトの充実 | ★★★ | 間接的（AIが学習するコーパスになる） |

### 2.3 実行アプローチ

| 施策 | 期間 | コスト |
|------|------|--------|
| 展示会施工事例の業界メディアへのピッチ | 3〜6ヶ月 | 中（記者対応・取材調整） |
| 施工動画・ビフォーアフター動画のYouTube公開 | 1〜3ヶ月 | 低（撮影・編集） |
| 第三者レビューサイトへの掲載依頼 | 1〜2ヶ月 | 低〜中 |
| 業界イベントでの登壇・パネル参加 | 3〜6ヶ月 | 中 |
| 展示会出展企業のインタビュー記事公開 | 1〜2ヶ月 | 低 |

**注**: このゴールは時間がかかる。半年〜1年単位で取り組む中長期戦略として位置づけ、短期的な成果は期待しない。

## 3. ゴール②: AI回答で推奨される（自社説明の強化）

### 3.1 目標

「展示会ブース制作会社を探している」というユーザーに対し、AIが「株式会社オージャストは○○な特徴があり、△△な理由で選ばれている」と具体的な根拠とともに推奨する状態を作る。

### 3.2 必要な要素

| 要素 | 重要度 | 説明 |
|------|--------|------|
| **サービス詳細のテキスト記述** | ★★★★★ | AIが引用できる形でサービス内容が詳細に書かれていること |
| **選ばれる理由の明確な記述** | ★★★★★ | なぜオージャストが選ばれるのか、根拠とともに言語化 |
| **FAQ・Q&A** | ★★★★ | ユーザーの疑問に対応した質問回答形式の情報 |
| **具体的な数値・データ** | ★★★★ | 施工実績数・納期・価格帯・対応地域などの具体値 |
| **構造化データ（JSON-LD）** | ★★★★ | AIが機械的に読み取れる形式のスキーママークアップ |
| **事例の詳細記述** | ★★★ | 単なる作品ギャラリーではなく、課題・解決策・結果のストーリー |

### 3.3 実行アプローチ — オージャストのサービス案内に追記すべき内容

以下の情報を、サービス案内ページ（orgiast.jpの該当ページおよびrebooth.co.jp）に追記する。画像だけでなく**テキスト**として記述することが重要（AIは画像内のテキストを読み取れない）。

#### 3.3.1 ブースの仕様

| 項目 | 記述例 |
|------|--------|
| 対応ブースサイズ | 小間（1小間・2小間・3小間）〜特設ブース（30平米〜100平米以上） |
| 使用可能な構造 | システムパネル、アルミフレーム、鉄骨造、テンション構造 |
| 床材オプション | タイルカーペット（標準色〜特注色）、フローリング、クッションフロア |
| 壁材オプション | 塗装パネル（色指定可）、クロス貼り、コンクリート調、木目調 |
| 照明オプション | LEDダウンライト、スポットライト、レール式、カラーチェンジ可能な調光照明 |
| 什器オプション | カウンター、什器棚、展示ケース、モニター台、パンフレットラック |
| オプション装備 | サインポール、ハンガー、吊り下げサイン、デジタルサイネージ |

#### 3.3.2 素材

| 素材 | 用途・特徴 | 選定理由 |
|------|-----------|---------|
| パネル（アルミ複合・軽量） | 壁面・ディスプレイ | 軽量で搬入・設営が容易、塗装・印刷対応 |
| 構造材（アルミフレーム） | 骨組み・支柱 | 強度と軽量性を両立、再利用可能 |
| 布地（ストレッチファブリック） | 壁面装飾・天井吊り | 染めQ等でグラフィック印刷対応、シワになりにくい |
| 樹脂系床材 | 床敷き | 耐摩耗性、デザイン印刷対応 |
| 木調素材 | 高級感演出 | 自然な風合い、塗装・加工が容易 |

#### 3.3.3 施工工程

| フェーズ | 期間（目安） | 内容 |
|----------|-------------|------|
| 設計・企画 | 展示会の2〜3ヶ月前 | ヒアリング→コンセプト立案→ラフデザイン→レイアウト決定 |
| 詳細設計 | 1〜2ヶ月前 | デザイン確定→素材選定→施工図作成→見積確定 |
| 制作 | 3〜4週間前 | パネル制作・印刷・備品手配・運搬手配 |
| 搬入設営 | 展示会前日〜前々日 | 会場搬入→骨組み組立→パネル設置→什器設置→装飾最終調整 |
| 展示会期間中 | 会期中 | 巡回メンテナンス、緊急対応 |
| 撤去搬出 | 最終日夕方〜翌日 |  dismantle→撤去搬出→廃棄・保管仕分け |
| 完了報告 | 展示会後1週間以内 | 写真納品・施工報告書提出 |

#### 3.3.4 納期

| ブース規模 | 標準納期（目安） | 最短（特急）対応 |
|-----------|----------------|----------------|
| 1小間（約2.7m × 2.7m） | 3〜4週間 | 2週間 |
| 2小間（約5.4m × 2.7m） | 4〜5週間 | 3週間 |
| 3小間（約8.1m × 2.7m） | 5〜6週間 | 3〜4週間 |
| 特設ブース（30〜100平米） | 6〜10週間 | 4〜6週間 |
| 大規模特設（100平米超） | 8〜16週間 | ケースバイケース |

#### 3.3.5 選ばれる理由

| 理由 | 詳細 | 裏付け |
|------|------|--------|
| 全国展開 | 全国8拠点（東京・大阪・埼玉・名古屋・札幌・広島・福岡・沖縄）で対応可能 | 各拠点に自社工場・倉庫を保有 |
| 設計から施工まで一貫対応 | デザイン設計・制作・設営・撤去をワンストップ | インハウスデザイナー・製作スタッフ在籍 |
| 豊富な実績 | 年間200件以上の展示会ブース制作実績 | 事例ページ（rebooth.co.jp/works/）で確認可能 |
| コスト競争力 | システムパネルと特注のバランスで最適なコスト提案 | 料金ページで具体値の開示 |
| 短期対応 | 最短2週間からの特急対応可能 | 特急対応実績の具体事例 |
| アフターサポート | 展示会後の保管・リユース・次回展示会への展開 | 保管サービス・リユース設計対応実績 |

## 4. 優先順位と実行計画

### 4.1 優先度マトリクス

| 優先度 | 施策 | 効果 | 工数 |
|--------|------|------|------|
| **P0** | サービス案内ページに上記の詳細テキストを追記 | 高い（AIの直接引用対象になる） | 低（既存CMS編集） |
| **P1** | FAQページの拡充（Q&A形式でサービス詳細をカバー） | 高い（AIOはFAQを好む） | 低〜中 |
| **P1** | JSON-LDのService/FAQ構造化データ検討（X-0086で指摘済み） | 高い（機械可読性向上） | 中（技術実装） |
| **P2** | 事例ページに課題・解決策・結果のストーリー追加 | 中（推薦の根拠になる） | 中（取材・執筆） |
| **P3** | 業界メディアへの露出（ゲスト記事・インタビュー） | 中（ただし時間がかかる） | 中（ピッチ・調整） |
| **P3** | YouTube施工動画の公開 | 中（X-0051で言及効果を確認） | 中（撮影・編集） |
| **P4** | 第三者レビューサイトへの掲載 | 中〜低 | 低 |
| **P4** | 大量ブログ記事の量産 | 低（AIOへの直接効果は薄い） | 高（執筆本数が多い） |

### 4.2 2週間でできること（P0最優先）

1. **サービスページのテキスト拡充**（3.3節の内容を各ページに追記）
2. **FAQページの作成・拡充**（よくある質問と回答を20項目以上）
3. **JSON-LDのService・FAQスキーマ追加**（X-0086監査結果に基づく）

### 4.3 1〜3ヶ月で取り組むこと（P1〜P2）

4. **事例のストーリー化**（課題・解決策・結果を1事例あたり300〜500字で記述）
5. **業種別ページの充実**（医療・教育・自治体など特定業種への対応ページ）
6. **費用ページの具体化**（価格帯・料金体系・見積条件の明記）

### 4.4 3ヶ月以降（P3〜P4）

7. **YouTube施工動画の定期的公開**
8. **業界メディアへの露出**
9. **レビューサイトへの掲載依頼**

## 5. 結論

AIO（AI Overviews）対策において、**記事の大量生産は優先度が低い**。AIが引用し推奨するために必要なのは：

1. **最初に自社のサービスを詳細に説明する** — ビジネスサイトのサービス詳細がAIの93%の引用元
2. **言及と推薦を分けて戦略を組む** — 言及は外部露出で時間がかかり、推薦は自社サイトの充実で短期に改善可能
3. **「理由」をテキストで書く** — なぜ選ばれるのかを具体的な根拠とともに言語化する

オージャストでは、ブースの仕様・素材・施工工程・納期・選ばれる理由の **5つのカテゴリ** をサービス案内に追記することを最優先とする。記事制作はその後に、各サービス詳細を裏付ける補完的コンテンツとして位置づける。
