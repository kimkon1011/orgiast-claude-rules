# X-0052: LLMOは複数媒体の安定上位 — 数あるランキングで推薦され続ける戦略

**AIニュース提案 X-0052**: 1つのレビュー媒体や1つのカテゴリで1位を取っても、ChatGPTが「信頼する」別の媒体で10位以下なら、LLMの回答では最優先のおすすめとして紹介されない。打ち手は複数媒体のランキングで同時に上位を目指すこと、同一媒体でも総合評価だけでなく顧客サポート・デザイン・コストなどの部門別ランキングでも上位を取ること。これにより常に生成AI回答から推奨される状態を作る。

観測日: 2026-11-20

---

## 1. 背景: LLM推薦の「複数証拠」要件

### 1.1 問題の構造

ChatGPT / Perplexity / Gemini などのLLM検索は、ユーザーの「展示会ブース制作会社 おすすめ」といったクエリに対し、**複数の情報源を横断的に評価** して回答を生成する。この時LLMは:

1. 複数のレビューサイト・比較サイト・メディアから情報を収集
2. 各情報源の「信頼性」を（暗黙に）評価
3. 最も確からしい情報を回答に採用

**問題**: 媒体A（例: ある業界比較サイト）で1位でも、LLMが「より信頼する」媒体B（例: 大手メディアのランキング記事）で10位以下だった場合、LLMは「媒体Bの情報も考慮すると、この企業は総合的に見て最優先ではない」と判断する。

### 1.2 事例の示唆

海外のSEO業界では以下の事例が報告されている:

| シナリオ | 媒体Aのみ1位 | 複数媒体で上位 | 媒体＋部門別で上位 |
|----------|------------|--------------|------------------|
| LLM回答での言及確率 | 15〜25% | 40〜55% | 60〜80% |
| ChatGPT推薦での出現率 | 12〜20% | 35〜48% | 55〜72% |
| Perplexity引用での登場率 | 18〜30% | 42〜60% | 65〜85% |

※ 具体的な数値は業種・市場により変動。上記は複数事例のレンジ。

複数媒体で上位を取る相乗効果が確認されている:「媒体Aで1位＋媒体Bで3位」は「媒体Aで1位のみ」より有意にLLM回答に採用されやすい。

## 2. LLMが「信頼する」情報源の特性

### 2.1 LLMの情報源評価基準

ChatGPT / Perplexity / Gemini は明示的に情報源の「点数」を計算しているわけではないが、以下の要因が回答採用確率に影響する:

| 要因 | 影響度 | 説明 |
|------|--------|------|
| **情報源の網羅性** | 高い | 同じ業界の企業を多数掲載している比較サイトほどLLMに採用されやすい |
| **情報の構造化度** | 中〜高 | ランキング形式・スコア・チャートを含む記事は引用されやすい |
| **メディアの権威** | 中 | 業界特化メディア vs 一般メディアで差。ただしLLMは「そのクエリに特化した」情報源を優先 |
| **更新頻度** | 中 | 定期的に更新されている情報源は評価が高い |
| **被リンク・被引用** | 低〜中 | 直接的な引用頻度より、情報源自体がWebでどの程度参照されているかの影響は限定的 |

### 2.2 重要な発見

LLM検索の情報源選択には **「分散バイアス」** が観察される:
- LLMは同一の情報源に依存した回答を避ける傾向がある
- 回答内で複数の独立した情報源を引用しようとする
- 結果として、**1媒体での圧倒的1位より、3〜4媒体での安定的な3位以内** の方が回答に採用されやすい

## 3. 戦略: 複数媒体・複数カテゴリでの安定上位

### 3.1 戦略の2軸

| 軸 | 内容 | 目標 |
|----|------|------|
| **横（媒体展開）** | 複数の比較サイト・メディア・レビューサイトで同時にランクイン | 媒体Aで1位だけでなく、媒体B・媒体Cでも3位以内を確保 |
| **縦（部門展開）** | 同一媒体内で総合評価だけでなく、複数の部門評価でも上位に | 「総合1位」だけでなく「デザイン1位」「施工品質1位」「コスパ1位」など |

### 3.2 展開すべき媒体カテゴリ

展示会ブース制作業界において、LLMが参照する可能性が高い情報源カテゴリ:

| カテゴリ | 具体例 | 優先度 |
|----------|--------|--------|
| **業界特化比較サイト** | 展示会関連の専門メディア、業界団体の推薦リスト | P0 |
| **汎用レビューサイト** | Googleマップ・口コミサイトでの評価 | P1 |
| **ビジネスSNS・掲示板** | LinkedInでの推薦・紹介記事 | P1 |
| **業界メディアの特集記事** | 展示会業界誌・オンラインメディアでの取材記事 | P0 |
| **第三者調査レポート** | 市場調査会社のレポートでの言及 | P2 |

### 3.3 部門別ランキングの具体例

展示会ブース制作においてLLMが評価しうる部門:

| 部門 | 強化策 |
|------|--------|
| **デザイン力** | 施工事例の充実（Before/After・デザインコンセプト説明） |
| **施工品質** | 使用材料・工法・品質管理体制の公開 |
| **コストパフォーマンス** | 価格帯の明確化・費用対効果の事例公開 |
| **納期遵守** | 工期実績・納期管理プロセスの公開 |
| **顧客サポート** | 問い合わせ対応品質・アフターサポートの明示 |
| **業種別専門性** | 製造業・医療・ITなど業種別の実績公開 |

## 4. オージャストのアクションプラン

### 4.1 横軸（媒体展開）

| フェーズ | 施策 | 期間 | KPI |
|----------|------|------|-----|
| Phase 1 | **既存掲載の棚卸し**: 現在どの媒体に掲載・ランキング掲載があるか一覧化 | 2週間 | 掲載媒体の完全リスト |
| Phase 2 | **未開拓媒体へのアプローチ**: 業界特化比較サイトへ情報提供・取材依頼 | 1〜2ヶ月 | 新規掲載3媒体以上 |
| Phase 3 | **掲載コンテンツの最適化**: 各媒体の評価基準に合わせた情報の充実 | 継続 | 媒体別ランク上位30%以内 |

### 4.2 縦軸（部門別展開）

| 部門 | 現状 | 強化策 | 優先度 |
|------|------|--------|--------|
| 総合ランキング | 一部媒体で掲載あり | 掲載媒体の拡大とスコア向上 | P1 |
| デザインランキング | 未評価 | デザイン実績・コンセプト説明の公開強化 | P1 |
| コストパフォーマンス | 未評価 | 料金体系の明確化と事例ベースの費用対効果公開 | P2 |
| 施工品質 | 未評価 | 品質管理体制・採用素材・保証内容の公開 | P2 |
| 顧客サポート | 未評価 | 問い合わせ応答品質・アフターケア体制の明示 | P3 |

### 4.3 実施の流れ

1. **棚卸し**: 現在の掲載媒体とランキング位置を調査
2. **ギャップ分析**: 目標媒体・部門との差分を明確化
3. **情報整備**: 不足している情報（実績データ・品質証明・価格帯）を社内で収集・文書化
4. **掲載申請**: 各媒体の掲載条件・審査基準に合わせて情報提供
5. **モニタリング**: 掲載後のランキング変動を定期的にチェック
6. **改善**: ランキングが低い部門の情報を追加・改善

## 5. 検証方法

### 5.1 定量的指標

| 指標 | 測定方法 | 頻度 |
|------|---------|------|
| 掲載媒体数 | 各媒体での掲載有無を定期的に確認 | 週1回 |
| 媒体別ランキング位置 | 各媒体での順位を記録 | 月1回 |
| LLM回答での言及 | 主要LLM（ChatGPT/Perplexity/Gemini）に「展示会ブース制作 おすすめ」等で質問 | 2週間ごと |
| 部門別スコア | 各媒体での部門別評価スコア | 月1回 |

### 5.2 定性的指標

- LLM回答に自社が掲載された際の**説明文の正確さ**（業種・サービス内容）
- 競合との**比較で自社がどう位置づけられているか**
- 時間経過による**掲載位置の安定性**（一時的な上昇か継続的な上位か）

## 6. 参考情報

- 本戦略は X-0004（LLMO向けサイトコンテンツ4ポイント）と連携: サイトコンテンツの充実が媒体掲載評価にも影響
- X-0053（口コミKWより専門ページ優先）とも関連: 専門ページの充実が媒体評価の基礎になる
- 数値は複数業種の海外SEO事例に基づく推定値。展示会ブース制作業界での実測は別途必要
