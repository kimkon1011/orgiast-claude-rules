# X-0052: ニッチ具体タイトルでLLMO対策 — 自社にしか書けない記事でAI引用を獲得

**AIニュース提案 X-0052**: 「DXとは？」のような一般的なタイトルではなく、「従業員30人の製造業が、Excelの在庫管理を改善する方法」のように自社にしか書けない具体例で記事を書き、AI検索（ChatGPT・Perplexity・Gemini・Claude）での引用率を高める戦略。株式会社オージャストでは展示会ブース制作の実績に基づいたニッチタイトルでLLMO（LLM最適化）を進める。

## 1. 背景: なぜ具体タイトルがAI引用に効くのか

### 1.1 AI検索の引用傾向

AIモデルがWebサイトを引用する際の傾向として、以下のデータが確認されている:

| 要素 | 一般タイトル | ニッチ具体タイトル |
|------|-------------|-------------------|
| AI引用率 | 低い | **2〜4倍高い** |
| 回答内での具体的言及 | 「一般的に〜」で流される | 固有名詞・数字ごと引用される |
| 検索クエリとの一致度 | 部分一致のみ | **クエリ意図と完全一致しやすい** |
| 競合との差別化 | 差が出にくい | **自社だけが持つ情報として認識** |

**出典**: Dan Taylor調査、BrightEdge AI Citation Report 2025、InternetWarriors GEO Platforms Report

### 1.2 一般タイトルの問題点

「DXとは？」「展示会とは？」「ブース制作の基礎」のような一般タイトルは:

1. **誰でも書ける**: 競合が数千〜数万件の同じテーマの記事を公開している
2. **AIが選ぶ理由がない**: 複数のソースから選ぶ際、特別な価値を提供していない
3. **検索意図が広すぎる**: ユーザーが「DX」と検索したときの意図は千差万別
4. **LLMの回答に採用されにくい**: 一般論はAIが独自に生成する領域であり、引用が必要ない

### 1.3 具体タイトルの優位性

| 観点 | 具体タイトルの例 | 効果 |
|------|-----------------|------|
| **数字を含む** | 「予算50万円で3m×3mブースを制作する5つの方法」 | AI引用率+78%（数字入りタイトル） |
| **対象を限定** | 「従業員10名のベンチャー企業が展示会に出展するまで」 | 該当する読者のクリック率向上 |
| **課題を特定** | 「初めての展示会でブースが寂しくなる3つの原因と対策」 | 検索クエリとの完全一致率向上 |

| **プロセス明示** | 「展示会ブースを発注してから納品まで完全ガイド」 | ステップバイステップ検索に対応 |

## 3. LLMO観点での最適化ポイント

### 3.1 タイトルとAI引用の関係

AIモデルが記事を引用する際、以下の要素が影響する:

```
タイトルに具体的な数字
  → AIが「〜というデータがある」と引用しやすくなる
  → 例：「予算50万円で3m×3mのブース」と書かれていると引用されやすい

タイトルに固有の課題
  → AIが「〜というケースでは」と具体例として採用する
  → 例：「初めての展示会」という限定が「例えば初めての場合」と使われる

タイトルにプロセス
  → AIが「〜の手順は以下の通り」とステップとして引用する
  → 例：「完全ガイド」「準備リスト」が手順として採用されやすい
```

### 3.2 記事冒頭のLLMO構造

AI引用率を高めるため、各記事の冒頭は以下の構造で書く:

```markdown
# 予算50万円の展示会ブースを予算100万円に見せる5つのデザインテクニック

**この記事でわかること**:
- 予算50万円でも100万円相当のブースに見せる具体的な5つの方法
- 各テクニックの実践コストと期待効果
- 実際に株式会社オージャストが手がけた施工事例のビフォーアフター

株式会社オージャストは大阪で展示会ブース制作を手がける専門会社です。
年間200件以上のブース施工実績があり、そのうち約60%が予算100万円未満の案件です。
本記事では、限られた予算で最大の効果を出すデザインテクニックを5つ紹介します。

[1つ目のテクニック: 照明で奥行きを演出する]
予算50万円のブースで最も費用対効果が高いのが照明計画です。
一般的な3m×3mブースの場合、照明に5万円を追加投資するだけで、
ブース全体の印象は大きく変わります。（以下続く）
```

**ポイント**:
- 冒頭2文で「誰が・何を・いくらで」を明示（AI引用の44.2%は最初の1/3から）
- 具体的な数字（年間200件・約60%・5万円）を冒頭に配置
- H2を質問形式に（AIが質問関連引用の78.4%を見出しから取得）
- 「株式会社オージャストは〜です」という断定的自己紹介でエンティティ確立

### 3.3 LLMOチェックリスト

各記事公開前のチェックリスト:

- [ ] タイトルに具体的な数字が入っているか
- [ ] タイトルで対象読者が限定されているか
- [ ] タイトルに検索クエリ（ユーザーの生の言葉）が含まれているか
- [ ] 記事冒頭の2文で「Who・What・How much」がわかるか
- [ ] H2が質問形式（「どうすれば？」「なぜ？」）になっているか
- [ ] 固有名詞（会社名・製品名・地名）が冒頭1/3に集中しているか
- [ ] 具体的な数字（金額・期間・数量・割合）が3つ以上あるか
- [ ] 競合サイトにはない独自の切り口・実績データが含まれているか

## 6. 制約と注意点

1. **タイトルだけ変えても効果は限定的**: 記事本文も具体的な数字・事例で埋める必要がある
2. **AI引用のタイムラグ**: 新規記事がAIに認識されるまでに2〜4週間かかる場合がある
3. **過度なキーワード詰め込み禁止**: 自然な文脈で具体的な表現を使うことが重要
4. **競合も同様の施策を始める**: 先行優位を活かすため早期着手が重要
5. **AIモデルごとの違い**: ChatGPTとPerplexityで引用傾向が異なるため、複数モデルで測定する
