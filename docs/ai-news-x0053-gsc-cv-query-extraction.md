# X-0053: GSC正規表現でCV近いクエリを抽出してページ改善

**AIニュース提案 X-0053**: Google Search Console の正規表現フィルタを使って、購入・成約意図の強いクエリ（CV近いクエリ＝コンバージョンに近いクエリ）を抽出し、ランディングページの料金情報・FAQ・CTAを改善して問い合わせ増を図る。

観測日: 2026-11-15

---

## 1. なぜ「CV近いクエリ」が重要なのか

### 1.1 情報探索クエリと購入意図クエリの違い

| クエリ種別 | ユーザー意図 | コンテンツ対応 | CVまでの距離 |
|-----------|------------|--------------|------------|
| **情報探索（Informational）** | 「〜とは」「〜方法」「〜理由」 | 解説記事・How-to | 遠い（まず知識を得たい） |
| **比較検討（Commercial）** | 「比較」「おすすめ」「違い」 | 比較記事・選び方 | 中程度 |
| **購入意図（Transactional）** | 「料金」「見積もり」「申込」「予約」 | 料金ページ・問い合わせ導線 | **近い（すぐCVしたい）** |

GSCの正規表現フィルタで購入意図クエリを抽出し、そのクエリが誘導しているページの**CTA・価格表示・FAQを改善する**ことで、問い合わせ率を直接的に上げられる。

### 1.2 既存のGSC分析（X-0004）との違い

| | X-0004（既存） | X-0053（本件） |
|---|---|---|
| 対象クエリ | AI Overview引用クエリ（疑問文系） | CV近いクエリ（購入意図系） |
| 目的 | AI Overviewでの引用増＝トラフィック増 | 問い合わせ・申込増＝コンバージョン改善 |
| 改善アクション | 定義ページ・How-to記事の充実 | 料金表示・FAQ・CTAボタンの最適化 |
| 効果測定 | AI Overview引用クエリ数・掲載順位 | 問い合わせ数・CVR・ページ別コンバージョン |
| 補完関係 | トラフィック増（上部漏斗） | CV率改善（下部漏斗） |

両者は補完関係にある。X-0004でトラフィックを増やし、X-0053でそのトラフィックをCVに変える。

## 2. GSC正規表現パターン集（CV近いクエリ用）

### 2.1 汎用パターン（全業種向け）

#### CV1: 料金・価格 — CV欲 最高

```
(料金|費用|価格|コスト|金額|月額|初期費用|ランニングコスト|従量|定額|いくら|いくらぐらい|費用感|予算感|価格帯|価格表|料金体系|相場)
```

**改善アクション**: 該当ページに金額の範囲・目安を明示。「お問い合わせください」だけではCVを逃す。

#### CV2: 見積もり — CV欲 最高

```
(見積もり|見積り|お見積もり|見積|概算|お見積り|見積もり依頼|見積依頼)
```

**改善アクション**: 見積もり依頼フォームへの導線をページ上部と下部に設置。フォーム送信後の返答時間の明示。

#### CV3: 申込・予約 — CV欲 高

```
(申込|申し込み|予約|エントリー|応募|申請|登録|サインアップ|会員登録|空き状況|日程調整)
```

**改善アクション**: 申込ボタンの色・テキスト・配置をABテスト。申込フローのステップ数を最小化。

#### CV4: 相談・問い合わせ — CV欲 高

```
(相談|ご相談|問い合わせ|お問い合わせ|ご依頼|依頼|照会|ヒアリング|打ち合わせ|商談)
```

**改善アクション**: 問い合わせフォームに「よくある質問」を事前表示し、問い合わせの質を向上。チャットボットの併用。

#### CV5: 導入・購入判断 — CV欲 中〜高

```
(導入|購入|発注|注文|買い切り|レンタル|契約|切り替え|乗り換え|リプレース)
```

**改善アクション**: 導入フロー図・導入実績・ケーススタディをページに追加。導入後のサポート体制を明示。

### 2.2 複合パターン（業種別）

#### T1: 展示会・ブース制作業界（オージャスト用）

```
(ブース|展示会|イベント|制作|小間|出展)
.*(費用|見積|相談|申込|予約|料金|価格|いくら|相場|見積もり)
```

**用途**: ブース制作の見積もり・相談を検討しているユーザーを抽出。

#### T2: 製造業（金属加工・試作）

```
(試作|試作品|加工|切削|板金|溶接|機械|部品|金型|試作依頼|図面)
.*(費用|見積|発注|注文|依頼|発注|いくら|金額)
```

#### T3: Web制作・システム開発

```
(ホームページ|WEB|Web|EC|システム|アプリ|ランディングページ|LP|制作会社)
.*(費用|見積|相談|月額|保守|発注|依頼|相場|料金)
```

#### T4: 飲食・物販

```
(メニュー|ケータリング|出張|宅配|デリバリー|おせち|ギフト|詰め合わせ)
```

## 3. GSCでの設定手順

### 手順（Web UI）

1. **Google Search Console** にアクセス（`https://search.google.com/search-console`）
2. 対象プロパティ（`https://www.orgiast.jp` 等）を選択
3. 左メニューから **検索パフォーマンス** を開く
4. 上部の **＋新しいフィルタ** → **検索キーワード** → **カスタム（正規表現）** を選択
5. 上記CVパターンのいずれかを入力
6. 日付範囲を **直近3ヶ月** に設定（最低でも直近28日）
7. **表示されるデータを確認**:
   - **表示回数**（インプレッション）: そのクエリが検索結果に表示された回数
   - **クリック数**: 実際にクリックされた回数
   - **CTR**: クリック率
   - **平均掲載順位**: そのクエリの平均順位
8. **「ページ」タブ**を開き、該当クエリがどのページにランディングしているかを確認

### データの解釈

| パターン | 意味 | 取るべきアクション |
|---------|------|-----------------|
| 表示回数多い × CTR低い | タイトル・メタディスクリプションが検索意図と一致していない | タイトル・メタデスクリプションの改善 |
| クリック多い × 掲載順位が低い（例：8〜15位） | 検索意図とのマッチ度は高いが、上位表示されればさらにクリック増 | SEO改善（コンテンツ充実・内部リンク） |
| クリック多い × ページに料金/CTAがない | **これが最大の改善ポイント** | 料金目安・CTAボタンの追加 |
| クリック少ない × 掲載順位高い（例：1〜3位） | 需要自体が少ないクエリ。CV率が高ければ維持 | CV導線だけ確認して放置でOK |

## 4. ページ改善ワークフロー

抽出したクエリと該当ページに基づき、以下のワークフローでページ改善を実施する。

### 4.1 改善優先度マトリックス

| 優先度 | 条件 | 例（オージャスト） |
|-------|------|------------------|
| **P0（最優先）** | クリック数多く、かつ該当ページに料金表示やCTAがない | ブース制作ページが「展示会 ブース 費用」クエリでクリックされているが、料金が「お問い合わせください」のみ |
| **P1（優先）** | クリック数多く、CTAはあるがFAQ・安心材料が不足 | 見積もり依頼はあるが、「初めてでも大丈夫？」「最短納期」が書かれていない |
| **P2（計画的）** | 表示回数多いがCTRが低い。タイトル・メタデスクリプションを改善すればクリック増 | ブース制作ページが「展示会 出展 費用」で7位表示・CTR 2% |
| **P3（モニタリング）** | クリック数は少ないがCV率は良い。現状維持で継続観察 | ニッチな「バルーン 施工 見積もり」クエリからのCVが安定 |

### 4.2 具体的な改善項目

#### 4.2.1 料金情報の追加

| 改善前 | 改善後 |
|--------|--------|
| 「料金はお問い合わせください」 | スモールブース ￥150,000〜、ミドルブース ￥500,000〜、カスタムブース ￥1,000,000〜（目安） |
| 価格表なし | 価格帯別の代表プランを3〜5種類表示 |
| オプション価格が不明 | オプション一覧＋価格表（例：追加備品〇〇円〜） |

**なぜ効果があるか**: 「お問い合わせください」だけのページは、予算感が掴めずに離脱するユーザーが多い。金額のレンジ（幅）を示すだけで問い合わせ率が向上する（公開情報による業界平均で1.5〜3倍）。

#### 4.2.2 FAQの充実

「料金」「見積もり」「相談」クエリで流入するユーザーが抱える不安をFAQで解消する:

| カテゴリ | FAQ例 |
|---------|-------|
| 料金関連 | 「最小いくらから依頼できる？」「見積もりは無料？」「追加料金は発生する？」 |
| プロセス関連 | 「初めてでも大丈夫？」「申込から納品までの流れは？」「打ち合わせは何回？」 |
| 実績関連 | 「同じ規模の事例は？」「どのくらいの会社が利用している？」 |
| 比較関連 | 「レンタルと買い切りのどちらがお得？」「他社との違いは？」 |

**設置場所**: 料金表示の直下、またはCTAボタンの直前に折りたたみ式（`<details>`）で配置。

#### 4.2.3 CTA（コールトゥアクション）の改善

| クエリ意図 | 最適なCTAテキスト | 配置 |
|-----------|-----------------|------|
| 料金クエリ | 「無料見積もりを依頼する」「料金プランを見る」 | 料金表の直下、画面下部固定 |
| 見積もりクエリ | 「3分で完了！無料見積もり」「概算をすぐ確認」 | ページ上部（ファーストビュー）＋下部 |
| 相談クエリ | 「無料相談を予約する」「専門スタッフに相談」 | ページ中央＋下部＋追従バナー |
| 申込クエリ | 「今すぐ申し込む」「空き状況を確認」 | ファーストビュー＋各所に分散 |

**CTA改善の原則**:
- ボタンは**1ページに1種類の目的**に絞る（「問い合わせ」と「資料請求」を同時に置かない）
- 色はブランドカラーからコントラストの高い色を選ぶ
- テキストは**効用**を明記（「送信」→「無料見積もりをメールで受け取る」）
- ファーストビューに1つ、スクロール追従に1つ、ページ下部に1つの3段配置が効果的

#### 4.2.4 社会的証明（Social Proof）の追加

CV近いクエリで流入するユーザーは「決断」の直前にいる。以下の材料が背中を押す:

| 材料 | 設置場所 | 効果 |
|------|---------|------|
| 導入社数・実績数 | ページ上部（数字で見せる） | 信頼性向上 |
| 顧客の声（引用） | CTA直前 | 共感＋決断促進 |
| 施工事例（写真＋結果） | ページ中央 | 具体イメージの形成 |
| 保証・サポート文言 | CTA直下 | リスク低減 |

## 5. オージャスト実践編

### 5.1 推奨GSCフィルタ

株式会社オージャスト（展示会ブース制作・イベント施工）向けのCV近いクエリ抽出パターン:

#### フィルタ1: ブース制作CV（最優先）

```
(ブース|展示会|イベント|制作|小間|出展).*(費用|見積|相談|申込|予約|料金|価格|いくら|相場|見積もり|発注)
```

#### フィルタ2: 単独CVキーワード（補完用）

```
(見積もり|見積り|お見積もり|見積|費用|料金|価格|相場|予算|いくら|相談|問い合わせ)
```

#### フィルタ3: 施策固有（施工・デザインに絞る）

```
(施工|デザイン|設計|設営|パネル|装飾|レイアウト|製作).*(費用|見積|料金|価格|いくら)
```

### 5.2 具体的な改善ターゲット

クリエイティブ・コモンズのブース制作ページを想定した改善例:

| 現状 | 想定される問題 | 改善案 |
|------|--------------|--------|
| トップページのみCV導線 | 料金クエリ流入者が離脱 | 各サービスごとに料金目安ページを設置 |
| CTAが「お問い合わせ」1種類のみ | 決断のきっかけが弱い | 「資料請求」「無料見積もり」「相談予約」の3種を配置 |
| FAQなし | 不安解消できていない | 料金・納期・初めての方向けFAQを設置 |
| 施工事例が画像のみ | 説得力不足 | 「課題→解決→結果」のストーリー形式事例を追加 |
| 価格が「応相談」のみ | 予算感が掴めない | スモール・ミドル・カスタムの3段階料金目安を掲載 |

### 5.3 実施サイクル（推奨）

| 週 | アクション | KPI |
|----|----------|-----|
| 1週目 | GSCでCV近いクエリを抽出・CSV保存 | 抽出クエリ数、該当ページ一覧 |
| 2週目 | P0のページから料金表示を追加 | ページ別改善数 |
| 3週目 | FAQとCTAを改善 | CTAクリック率（GA4で計測） |
| 4週目 | 社会的証明（事例・実績）を追加 | 改善ページ数 |
| 5週目 | 効果測定（問い合わせ数変化を確認） | CV数・問い合わせ率（改善前後比較） |
| 6週目以降 | P1〜P2に展開、月1回定期モニタリング | 継続改善サイクル |

## 6. 効果測定

### 6.1 GA4での計測設定

GSCから抽出したCV近いクエリが実際に問い合わせに繋がっているかをGA4で計測する:

1. **問い合わせ完了ページ**（サンキューページ）にGA4イベントタグを設置
2. **Search ConsoleのクエリデータとGA4のランディングページデータを結合**:
   - GSC側: クエリ → 該当ページ
   - GA4側: 該当ページ → 問い合わせ完了
3. **GSCクエリ → 該当ページ → 問い合わせ** のパス分析

### 6.2 成功指標

| 指標 | 計測方法 | 目標（3ヶ月後） |
|------|---------|---------------|
| CV近いクエリのCTR改善 | GSC「検索パフォーマンス」で改善前後のCTR比較 | CTR 20%改善 |
| 問い合わせ数 | GA4の問い合わせ完了イベント数 | 月間問い合わせ数30%増 |
| 問い合わせ率 | 問い合わせ数 / CV近いクエリ流入セッション数 | 問い合わせ率 50%改善 |
| CV近いクエリの掲載順位 | GSCで該当クエリ群の平均順位推移 | 平均掲載順位3位上昇 |

## 7. 注意点・リスク

| リスク | 確度 | 影響 | 対策 |
|--------|------|------|------|
| 料金表示で価格競争に巻き込まれる | 中 | 中 | 表示はあくまで「目安」と明記。カスタムブースは「応相談」と併記 |
| GSCデータがサンプリングで正確でない | 高（表示回数少ないクエリ） | 低 | 表示回数の多いクエリから優先。データは方向性の確認に使う |
| 改善後の効果が他の要因で変動 | 中 | 中 | 改善前28日 vs 改善後28日で比較。季節要因を考慮 |
| 過剰なCTAでユーザー体験が低下 | 低 | 中 | 1ページ1目的のCTA設計を守る。ヒートマップで確認 |
| GSCの正規表現フィルタの上限 | 低 | 低 | 1フィルタ=1パターンの制約内で、必要に応じて複数フィルタを使い分ける |
