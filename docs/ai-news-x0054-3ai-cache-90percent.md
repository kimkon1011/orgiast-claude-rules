## 2. 暗黙キャッシュ戦略

### 2.1 キャッシュ発動条件

Anthropic（2026年11月）は直前リクエストと先頭4096トークン以上が一致すると暗黙的にキャッシュする。キャッシュ読取コストは通常の5%（95%オフ）。

| 項目 | 値 |
|------|-----|
| 発動条件 | 先頭4096トークン以上が前回リクエストと一致 |
| キャッシュ読取価格 | 通常の5%（95%オフ） |
| 有効期間 | 同一セッション内・約5分以内 |
| 適用範囲 | 最初の差異までの共通prefix全体 |
| 明示制御 | 不要（自動） |

### 2.2 固定Prefix設計

全リクエストの先頭に以下を固定配置:

```
[固定共通prefix - 4096トークン以上]
  CLAUDE.md 共通ガイドライン（1,500 tok）
  プロジェクト固有ルール定義（1,000 tok）
  スキル定義（1,500 tok）
  頻出テンプレート・事例（500+ tok）

[可変のタスク固有部分]
  今回の具体的指示
```

**最大化条件**:
1. **前方固定**: 不変コンテンツをプロンプト先頭に
2. **変動部は後方**: タスク固有指示は共通prefixの後
3. **同一セッション連続**: 同じprefixでリクエストを連続送信
4. **5分以内**: キャッシュ期限切れ前に次のリクエスト

```json
      "effortLevel": "low",
      "maxEffortLevel": "medium"
```

```javascript

    params: {
      model: "claude-sonnet-5-5",
      max_tokens: 1000,
      messages: [{ role: "user", content: task.prompt }]
```
