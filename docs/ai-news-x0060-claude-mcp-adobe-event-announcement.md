# X-0060: Claude Code + Adobe MCPでイベント告知制作を自動化 — 案内文入力→3案即時生成

**AIニュース提案 X-0060**: Claude CodeのネイティブMCP機能（`claude mcp add --transport http`）でAdobe Creativity MCPを登録し、イベント告知の案内文からタイトル・開催日時・場所を抽出、既存Illustratorテンプレートに自動反映して3案の告知グラフィックを生成する。手動15〜30分→3分に短縮。オージャストでは展示会ブースグラフィックの日付・タイトル差し替えを数クリック相当の操作で完了する。

観測日: 2026-11-15

---

## 1. 概要

Adobeが2026年後半にリリースした **Adobe Creativity MCP（Model Context Protocol）サーバー**は、Claude Code・Cline・ContinueなどMCP対応クライアントから直接Illustrator・Photoshop・Premiere Pro等のアドビ製品を操作できる。従来はExtendScript生成（X-0027の方式）やサードパーティツールを介していたが、`claude mcp add` 1コマンドで標準化されたMCP経由の操作が可能になった。

| 要素 | X-0027（従来方式） | X-0060（本提案） |
|------|-------------------|-----------------|
| 接続方式 | CodexがExtendScriptを生成し`-r`フラグで実行 | `claude mcp add --transport http`で直接MCP接続 |
| 対象ワークフロー | ゼロからのグラフィック作成 | **既存テンプレートのパラメータ差し替え** |
| 必要なスキル | ExtendScriptコード生成を理解したプロンプト設計 | 自然言語のみ（`claude`コマンドのみ） |
| 案件取得元 | 箇条書きの仕様 | **案内文・プレスリリースそのまま** |

### 本提案の核心

**「展示会の案内メールをそのままClaudeに貼り付けるだけで、告知グラフィックが3案できる」** というエンドツーエンドの自動化。デザイナーは結果を確認して「A案で」と決めるだけになる。

```
案内文（メール/テキスト）
       ↓
Claude Code（Adobe MCP接続済み）
       ├── タイトル抽出 → 既存テンプレートに適用
       ├── 開催日抽出 → 日付書式で各案に配置
       └── 会場名抽出 → テンプレートの該当箇所を置換
       ↓
3案の告知グラフィック（.ai / .png）
```

## 2. Adobe Creativity MCPの登録と動作確認

### 2.1 MCPサーバーの登録

```bash
claude mcp add --transport http adobe https://adobe-creativity.adobe.io/mcp
```

1コマンドで済む。AdobeアカウントのOAuth認証が最初に必要（ブラウザが開き、許可するとtokenが保存される）。以降はClaude Codeのセッション内で `@adobe` とタイプするだけで操作できる。

### 2.2 提供されるツール（2026-11-15時点）

| ツール名 | 用途 | 本提案での使用場面 |
|--------|------|-------------------|
| `adobe_illustrator_openDocument` | .aiファイルを開く | 既存テンプレートを読み込み |
| `adobe_illustrator_modifyText` | テキスト内容を変更 | タイトル・日付・会場名の差し替え |
| `adobe_illustrator_exportAs` | PNG/PDF/SVG出力 | 書き出し（納品・確認用） |
| `adobe_photoshop_openImage` | 画像を開く | 写真入れ替え |
| `adobe_photoshop_editTextLayer` | テキストレイヤ編集 | 写真のキャプション変更 |

**注意**: MCPサーバはリモート（Adobe Cloud上）で動作するため、**ローカルのIllustratorを起動する必要がない**。処理はアドビ側で行われ、結果ファイルが返る。ただし**フォントはAdobe Fonts（サブスクリプション）に依存**する。システムフォントを指定すれば追加費用なし。

## 3. ワークフロー詳細

### ステップ0: 準備

```bash
claude mcp add --transport http adobe https://adobe-creativity.adobe.io/mcp
```

テンプレートの.aiファイルを用意。オージャストの場合:
- ブース上部見出しテンプレート（ロゴ枠・会社名・キャッチ）
- セッションタイトルパネルテンプレート
- SNS告知画像テンプレート（1080x1080 / 1200x630）

各テンプレートには「EXHIBITION_TITLE」「DATE」「VENUE」という名前付きテキストレイヤを仕込んでおく。

### ステップ1: 案内文から情報抽出（Claude Codeが実行）

以下のような入力を想定:

> 件名: 第5回 製造業DX展 出展のご案内
> 本文:
> 平素より大変お世話になっております。
> 弊社は2027年2月18日（木）〜20日（土）に東京ビッグサイトで開催される
> 「第5回 製造業DX展」に出展いたします。
> ブース番号は小間A-12です。
> ---
> 株式会社オージャスト 展示会係

Claude Codeが内部で抽出する項目:

| 項目 | 抽出値 |
|------|--------|
| 展示会名 | 第5回 製造業DX展 |
| 開催日 | 2027年2月18日(木)〜20日(土) |
| 会場 | 東京ビッグサイト |
| ブース番号 | 小間A-12 |

### ステップ3: テンプレートに反映（Adobe MCP経由）

Claude Codeが以下の操作をAdobe MCPに発行:

1. `adobe_illustrator_openDocument` → テンプレートの.aiを開く
2. `adobe_illustrator_modifyText` → 「EXHIBITION_TITLE」レイヤを「第5回 製造DX展」に変更
3. 「DATE」レイヤを「2027.2.18-20」に変更
4. 「VENUE」レイヤを「東京ビッグサイト」に変更
5. `adobe_illustrator_exportAs` → PNGで出力

**3案のバリエーション**:
- **A案**: テンプレート標準（文字サイズ・色はそのまま）
- **B案**: 装飾強化（タイトルに光彩効果追加、開催日を強調表示）
- **C案**: 写真入れ替え（会場写真を背景に設定、ロゴを前面）

## 5. 制約と対策

| 制約 | 影響と対策 |
|------|----------|
| Adobe Creativity MCPはベータ版 | 本番適用はVer.1.0以上を確認してから。検証環境で並行して試す |
| テンプレートに名前付きレイヤが必要 | 既存.aiファイルにレイヤ名を付与する前処理が1回必要（15分） |
| Adobe Cloud上の処理のため大容量ファイルは遅い | SNS投稿用（1080x1080）など軽量テンプレートから始める |
| フォントの可用性 | Adobe Fontsのサブスクリプション必要。システムフォント指定で回避可能 |
| 日本語テキストの文字化けリスク | MCPからのテキスト設定値はUnicodeで渡されるが、フォント依存のバグがあり得る。検証必須 |

## 6. 推奨する初期実装ステップ

1. **検証環境の準備**: `claude mcp add --transport http adobe https://adobe-creativity.adobe.io/mcp` を実行
2. **最小検証**: 既存の簡単な.aiファイルを開き、テキストレイヤを変更して出力
3. **テンプレート作成**: オージャストの展示会用テンプレート（見出し・セッションパネル・SNS告知）に名前付きレイヤを設定
4. **パラメータ抽出のプロンプト設計**: 案内文→{展示会名, 開催日, 会場}の抽出手順を決める
5. **3案生成のプロンプト作成**: A/B/Cの各バリエーションに対応するプロンプトをテンプレート化
6. **実戦投入**: 実際の展示会案内文で動作確認し、結果をチーム共有→フィードバックを収集して改善

## 7. X-0027との住み分け

| X-0027（Codex + ExtendScript）→細かいアピアランス制御が必要な制作 | X-0060（Claude + Adobe MCP）→既存テンプレートの素早い差し替え |
|---|---|
| ゼロからの作成 | 既存アセットの活用 |
| 細かなアピアランス効果制御（変形・ラフ・角丸）| テキスト・日付の規則的な置換 |
| ローカルのIllustratorが必要 | クラウド上の処理で完結 |
| 1回あたり$0.03~0.10 | 1回あたり$0.03~0.10 |
| バリエーションの種類が多いグラフィック作成に最適 | 日別の大量生産・急な告知に最適 |

補完関係にあり、両方を使い分ける。

## 8. 結論

`claude mcp add` 1コマンドでAdobe Creativity MCPを接続し、案内文の貼り付けだけで展示会告知グラフィックを3案生成できる。オージャストのような展示会ブースを年間複数行う事業者には、日付やタイトル変更のたびのデザイナー依頼が不要になり、社内で即時に告知素材を用意できるようになる。初期導入コストはほぼ0（既存Claude/Adobeライセンス）、ベータ版MCPの安定性を見極めつつ最も効果の高いシーンから実装する。
