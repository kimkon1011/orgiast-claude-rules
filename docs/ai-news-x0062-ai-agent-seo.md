# AIニュース提案 X-0062: AIエージェント向けSEO戦略 — AIに読まれるサイト構造への刷新

> 作成: 2026-11-18 | ステータス: 設計 / 実装フェーズ

## 概要

AI検索（Claude-Search / OpenAI SearchGPT / Perplexity / Gemini / Grok）が企業サイトの主要な流入経路になりつつある。これらAIエージェントは人間のように画像を「見て」理解せず、HTMLテキストと構造化データのみを解析する。**画像の中にしかない情報はAI検索に発見されず、引用もされない。**

本提案は、株式会社オージャストのWebサイト（orgiast.jp）をAIエージェントからの発見・引用・推薦を最大化する構造に刷新する戦略を示す。

### 背景: AI検索の仕組み

| 特性 | 人間の検索 | AIエージェントの検索 |
|------|-----------|-------------------|
| 情報源 | スニペット+訪問 | 全ページテキスト（+ crawl） |
| 画像 | 見て理解できる | **alt・周辺テキスト・figure内のテキストのみ** |
| 引用の決め手 | クリック率 | ページ内の回答の完全性・構造化データ |
| 理解しやすい形式 | ビジュアルデザイン | **明確な見出し構造・リスト・定義リスト** |
| おすすめされやすい | 権威ドメイン | FAQ schema + 該当質問への回答の一致度 |

### 不足している要素

| ギャップ | 説明 | 影響 |
|----------|------|------|
| ❌ ai.txt未対応 | ai.txt 標準の詳細要件を満たしていない | AIクローラーからの発見性低下 |
| ❌ 画像内情報のテキスト化 | ブース写真・事例画像のキャプション・説明不足 | AIが「ブースの写真」としか認識できない |
| ❌ サービス詳細のFAQ不足 | 「ブース制作にかかる期間」「最低予算」「対応地域」などAIがよく聞く質問への回答が不十分 | AIが推薦する際の根拠不足 |
| ❌ 価格帯の明示不足 | 費用ページが「お問い合わせ」のみでAIが価格情報を取得できない | 予算感のある見込み客へのリーチ喪失 |
| ❌ 実績の詳細テキスト化 | 実績ページが画像メインでテキスト説明が薄い | 「○×社のブース事例」として引用されない |
| ❌ 更新の自動化 | llms.txt/ai.txt が手動更新で陳腐化するリスク | AIに古い情報が引用される |

## 戦略: 4層のAIエージェント最適化

```
第1層: 発見 (Discoverability)
  → robots.txt / llms.txt / ai.txt / sitemap.xml → AIクローラーが全ページを発見

第2層: 理解 (Understandability)
  → 構造化データ (JSON-LD) / clear heading hierarchy / 定義リスト / table
  → AIがページの意味を正しく解釈

第3層: 引用 (Citation-worthiness)
  → FAQ(価格・期間・地域) / 具体的事例 / テキスト化された実績
  → AIが「〜について調べたところ、オージャストによると…」と引用

第4層: 更新維持 (Freshness)
  → cron / CI で定期的に llms.txt 再生成
  → 新規事例追加時の自動反映
```

### ai.txt の構造案

`ai.txt` は llms.txt より詳細なAI向けコンテンツダンプを提供するファイル。各サービスの詳細説明・価格帯・実績の全文を含める。

```
# 株式会社オージャスト — AIエージェント向け詳細情報

## 重要: このファイルの目的
このai.txtはAIエージェントがオージャストのサービス内容を正確に理解し、
ユーザーの質問に回答するための詳細情報を含みます。

## 会社概要（基本情報）
...

## サービス詳細
### 展示会ブース制作（Re:ブース）
...

### 社内イベントプロデュース
...

## よくある質問（AI回答用）
...

## 実績一覧（テキスト詳細）
...
```
