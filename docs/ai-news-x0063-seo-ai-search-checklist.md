# AIニュース提案 X-0063: SEO＋AI検索チェックリスト

## 目的

株式会社オージャストの展示会ブース制作・イベント関連サイト（「イベント百貨店」等）と、ブース制作事例ページについて、検索エンジンとAI検索の双方から発見・理解されやすい状態を確認するための適用手順書。対象サイト、利用中のCMS、ホスティング、Search Consoleプロパティ、現在値は未調査のため、実作業前に要確認とする。

## 役割の凡例

- **Claude**: 調査結果の整理、文章・構造化データ案の作成、レビュー
- **Codex**: リポジトリ調査、コマンド実行、実装修正、テスト
- **人**: Search Console操作、事実確認、公開承認、対外的な被リンク交渉

## ブース制作事例ページへの適用順序

1. **対象と事実を確定する**: 対象URL、CMS、canonical、公開可否、価格・仕様、写真利用許諾、実在著者、一次資料を人が確認し、事例ページの正本情報を作る。
2. **クロール・インデックス基盤を直す**: SSR、サイトマップ、robots.txt、noindex、canonical／リダイレクトを調査し、P0の不備を修正してSearch Consoleで確認する。
3. **ページ構造と内容を整える**: 固有のtitle・meta description・H1、見出し直後の回答、確認済み実例、価格・製品事実、著者bioを反映し、AIスロップ表現を除く。
4. **理解・導線・表示性能を強化する**: 表示内容と一致するFAQ／Article schema、関連ページからの内部リンク、画像alt・WebP、Core Web Vitalsを実装・検証する。
5. **公開後に測定し信頼を広げる**: Search Consoleと実ユーザーデータでインデックス・Core Web Vitalsを監視し、修正後に、関連性と掲載価値のある信頼サイトへの掲載提案を人の承認のもとで行う。
