# X-0064 ブース会話録音からのAIリードフォローアップ

> 出典: AIニュース提案「Claudeで2時間で構築するブース会話録音AIリードフォローアップ」
> 観測日: 2026-11-17
> 実装: `apps/booth-conversation-ai/`（Next.js 14 App Router）

## 概要

展示会ブースでの来場者対応において、会話録音・リードスコアリング・フォローアップメール生成・CRM連携を1つのアプリケーションで完結させるプロトタイプ。バッジスキャン（QRコード）から入力を始め、ブーススタッフが来場者と話しながら録音し、その場でリード評価、会話内容を反映したフォローアップメールの生成、模擬CRMへの保存までをシームレスに行う。

## デモンストレーションの流れ（80人セミナー想定）

```
来場者受付（QRコード発行・バッジスキャン）
  → 会話録音（ブラウザ音声認識＋手動メモ）
    → ライブリードスコアリング（キーワードベース）
      → 文字起こし・会話内容の確定
        → フォローアップメール生成（会話のキーワードを使用）
          → CRM連携（模擬CRMへJSON保存）
```

## アプリケーション構成

### フロントエンド
- **Next.js 14 App Router** + TypeScript
- **Tailwind CSS**（shadcn/ui スタイルのカスタムコンポーネント）
- **lucide-react** アイコン
- **QRコード**: `qrcode` ライブラリで来場者IDをQRコード化・表示
- **音声認識**: Web Speech API（ブラウザ標準の日本語音声認識、録音と並行動作）
- **録音**: MediaRecorder API（Opusコーデック、1秒間隔チャンク）

### API Routes（サーバーサイド）
| Route | 機能 | 実装方式 |
|---|---|---|
| `/api/visitors` | 来場者一覧取得・新規登録 | JSONファイル保存 |
| `/api/score` | リードスコアリング | キーワードルールベース（辞書マッチ＋否定表現検出） |
| `/api/email` | フォローアップメール生成 | 会話キーワード抽出＋スコア別テンプレート |
| `/api/transcribe` | 文字起こし検証 | ブラウザ認識結果の受け渡し＋バリデーション |
| `/api/crm-webhook` | CRM連携（模擬） | JSONファイル保存（atomic write） |

### データモデル
- `Visitor`: ID, 氏名, 会社, 役職, メール, 電話, 登録日時
- `LeadScore`: 関心度/予算感/決定権/タイムラインの4軸（各1-10）＋総合スコア＋推奨アクション
- `EmailDraft`: 件名＋本文（会話のキーワードを反映）
- `CrmExport`: 来場者＋会話＋スコア＋メールをまとめて保存

## 主要機能の詳細

### 1. 来場者登録・バッジスキャン
- 来場者情報をフォーム入力 → APIで保存 → QRコード発行（来場者IDをエンコード）
- 登録済み来場者はサイドバーに一覧表示、クリックで詳細・操作画面へ
- QRコードは印刷・バッジ貼付を想定、再来場時にスキャンで呼び出し

### 2. 会話録音・文字起こし
- MediaRecorder + Web Speech API を同時起動
- 録音中はブラウザの日本語音声認識がリアルタイムで文字起こし
- 録音停止後、音声ファイルと認識テキストをサーバーへ送信（バリデーション）
- 手動での会話メモ入力・修正にも対応（テキストエリア）

### 3. ライブリードスコアリング
- キーワード辞書によるルールベース評価（LLM不使用）
- 4軸評価: **関心度**（興味語検出）/ **予算感**（金額・予算語）/ **決定権**（決裁関連語）/ **タイムライン**（時期・緊急度）
- 否定表現の検出（「予算がない」「興味ありません」など）でスコアを自動減点
- 総合スコア1-10 + おすすめアクション（例: 「☆☆☆☆☆ 優先フォロー — 今すぐアポイント調整」）
- 視覚的なゲージ・バー・色分け表示

### 4. フォローアップメール生成
- 会話テキストからキーワードを自動抽出（最大5個）
- スコアに応じた次のアクション文を選択（高スコア→打ち合わせ提案、中→情報提供、低→気軽に連絡）
- 件名: 「【展示会ご来場のお礼】株式会社〇〇 〇〇様」
- 本文: 会社名・氏名＋当日の会話キーワード＋次のアクション
- クリップボードコピー機能

### 5. CRM連携（模擬）
- 来場者情報＋会話内容＋リードスコア＋メール案をJSONとして保存
- Atomic write（一時ファイル→リネーム）で同時書き込み対応
- 同一来場者の再エクスポートは最新状態で上書き
- エクスポート内容のサマリー表示（各項目の✅/⚠️状態）

## オージャストでの活用方法

### クライアントブース運営での利用
- 展示会ブース制作クライアントのブース運営ツールとして提供
- ブーススタッフのタブレットで動作（特別なサーバー不要）
- 会話内容を記録・評価し、展示会後のフォローアップ営業を効率化
- 導入コストゼロ（Next.jsアプリをホスティングするのみ）

### 自社イベント営業での利用
- オージャストが出展する展示会・イベントで自社リー��獲得に活用
- ブース来場者の会話からリードスコアリングし、優先度順のフォローが可能
- 会話のキーワードを使ったパーソナライズドメールで返信率向上

### フォローワークフローでの効率化ポイント
1. **手入力削減**: QRコードスキャン＋音声認識で来場者情報・会話内容を自動取得
2. **即時評価**: 会話終了後すぐにリードスコアを算出、優先度判断を高速化
3. **メール作成時間短縮**: 会話内容を反映したメール案を自動生成（編集はワンクリックでコピー）
4. **データ連携**: CRMエクスポートにより、既存の顧客管理プロセスと統合可能
5. **トレーニング不要**: ブラウザだけで動作、直感的なUIでスタッフ誰でも使用可能

## 今後の拡張案

- **LLM連携**: キーワードルールベースからLLM（DeepSeek/Gemini）による高度なスコアリング・メール生成への切り替え
- **リアルCRM連携**: HubSpot / Salesforce / kintone 等とのAPI連携
- **複数ブース同時運用**: イベント全体のダッシュボード
- **エクスポート形式追加**: CSV出力、Google Sheets連携
- **オフライン対応**: PWA化してネットワーク不確定な会場でも動作

## 制約・注意点

- 音声認識はブラウザのWeb Speech APIに依存（Chrome推奨）
- データ保存はローカルJSONファイル（本番運用にはデータベースが必要）
- リードスコアリングはキーワードルールベース（LLMと比較して精度は限定的）
- HTTPSまたはlocalhostでのみ録音機能が動作
