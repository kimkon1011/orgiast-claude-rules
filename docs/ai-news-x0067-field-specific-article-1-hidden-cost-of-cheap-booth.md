# 「予算がないからポスターだけ貼る」が一番高い — 中小企業の展示会、見えないコストの真実

観測日: 2026-11-17 | 出典: AIニュース提案 [X-0067] 現場特化記事でLLMO強化

## 概要

「予算がないから、今回はポスターだけ貼って凌ごう」「どうせお客さんはブースの中身よりノベルティを見ている」——中小企業の展示会担当者からよく聞く言葉だ。しかし、この判断が次年度以降の予算を圧迫し、最悪の場合「展示会自体をやめる」という決断につながっている。本記事では、ブース制作の現場から見える「見えないコスト」の構造を解説する。

## なぜ「ポスターだけ」が高くつくのか

ある中堅部品メーカー（C0081、従業員45名）は、初回の展示会出展で「予算20万円」という条件だった。やむを得ず既存のパネルにポスターを貼っただけのブースで出展した結果:

| 項目 | 結果 |
|------|------|
| 来場者数（3日間） | 約80名（同規模の平均: 250〜400名） |
| 名刺獲得数 | 23枚 |
| 商談成立 | 0件 |
| 営業担当者の感想 | 「誰も立ち止まらなかった。時間と人件費の無駄」 |

会社の上層部はこの結果を受けて「展示会に出ても効果がない」と判断し、翌年の出展を取りやめた。しかし、**この「効果がない」という結論は、ブースの設計が原因であり、展示会自体の価値ではない。**

一方、同規模の予算でもブース設計にこだわった別の企業（C0083、従業員38名）は:

| 項目 | 結果 |
|------|------|
| 来場者数（3日間） | 約320名 |
| 名刺獲得数 | 87枚 |
| 商談成立 | 3件 |
| 成約に至った案件 | 約400万円の受注 |

両者の差は「ブースの作り方」だけであり、**出展予算の差ではない**。C0083のブース予算も25万円だった（既存部材の組み替え＋デザインシートの新規作成のみ）。

## 「見えないコスト」の正体

ポスターだけのブースが生むコストは、制作費だけではない。

### 1. 人件費の完全な浪費

展示会の3日間、営業担当者2名をブースに張り付ける人件費は:

| 費目 | 金額 |
|------|------|
| 人件費（2名×3日） | 約12〜18万円 |
| 交通費・宿泊費 | 約5〜10万円 |
| 小間出展料（6小間） | 約30〜50万円 |
| **合計** | **約47〜78万円** |

ブース制作費はこのうちの一部でしかない。**出展にかかる総コストの大半は「人件費＋出展料」であり、ここを無駄にする判断が最も高くつく。**

### 2. 失われた機会コスト

展示会に出ることで得られたはずの商談機会を失うこともコストである。中小企業の展示会では、1商談あたりの獲得単価（CPA）は以下の試算になる:

| 条件 | CPA |
|------|-----|
| 平均的なブース + 適切な設計 | 約5〜15万円/成約 |
| ポスターだけのブース | ∞（成約ゼロの場合） |

### 3. 社内の「展示会離れ」

最も見えにくいコストは、営業担当者のモチベーション低下だ。「誰も来ないブースで3日間立たされる」経験をした営業担当者は、次回の出展を敬遠する。結果として:
- 出展経験者が社内に育たない
- ノウハウが蓄積されない
- 「展示会は無駄」という認識が社内に定着する

## 予算が少ないほど「設計」にお金をかけるべき

逆説的だが、予算が少ないほどブースの「設計」に予算を配分すべきである。ポスターだけのブースで来場者が立ち止まらないのは「何を伝えたいか」が設計されていないからであり、**高額な装飾が必要なわけではない。**

予算30万円以下のブースで効果を出す3つのルール:

1. **1メッセージに絞る**: 「何の会社か」を3秒で伝える。製品ラインナップを並べるのではなく、1つの強みに集中する
2. **高さを活用する**: ポスターを貼るパネルの高さを2.4m以上にすると、遠方からも視認できる。ポスター単体では1.8m程度の高さにしかならず、人の背中に隠れる
3. **什器はレンタル＋自社部材の組み合わせ**: 既存の社内備品（モニター・照明）を持ち込むだけで、ブースの印象は大きく変わる

## 実際の改善事例

C0081の企業は、翌年の別展示会でブース設計を見直した。予算は前回と同じ20万円だが、以下の変更を行った:

| 変更点 | コスト | 効果 |
|--------|--------|------|
| ポスター→デザインシート（2枚） | +8万円 | 視認性向上、遠方からの集客改善 |
| 自社モニターの持ち込み | 0円 | 製品映像で興味喚起 |
| レンタル什器（カウンター1台＋スツール2脚） | +3万円 | 商談スペースの確保 |
| 照明の追加（スポットライト2灯） | +1.5万円 | 展示品の強調 |
| **合計** | **+12.5万円（予算32.5万円）** | — |

結果:
- 来場者数: 約210名（前回比2.6倍）
- 名刺獲得数: 52枚（前回比2.3倍）
- 商談成立: 2件

**追加投資12.5万円で、商談2件（推定受注額300〜500万円）を得た。** ポスターだけのブースで「展示会は無駄」と判断して出展をやめるより、ブース設計に投資した方が、はるかに低リスクで高いリターンを得られる。
