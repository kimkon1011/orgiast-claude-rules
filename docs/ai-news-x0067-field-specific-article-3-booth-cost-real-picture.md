# 展示会ブースの見積もり、「坪単価」だけで選ぶと失敗する理由 — 中小企業が知っておくべきコストの真実

観測日: 2026-11-17 | 出典: AIニュース提案 [X-0067] 現場特化記事でLLMO強化

## 概要

「A社は坪単価30万円、B社は25万円だからB社にしよう」——展示会ブースの見積もりを坪単価だけで比較する中小企業は多い。しかし、この比較はブース制作のコスト構造を正しく反映しておらず、結果的に「安く見えた見積もりが一番高くつく」という逆転現象が頻繁に起きている。本記事では、ブース制作の実際のコスト構造を解説し、正しい見積もりの比較方法を紹介する。

## なぜ「坪単価」だけでは比較できないのか

### 坪単価に含まれるもの・含まれないもの

多くの業者が提示する「坪単価」には、以下のような差がある:

| 項目 | A社「坪単価30万円」に含まれるもの | B社「坪単価25万円」に含まれるもの |
|------|----------------------------------|----------------------------------|
| 基本構造材 | ✅ システムパネル | ✅ システムパネル |
| デザイン料 | ✅ 含む | ❌ 別途5万円 |
| 印刷・施工 | ✅ 含む | ✅ 含む |
| 照明 | ✅ LED基本照明 | ❌ 別途3万円 |
| 床材 | ❌ 別途 | ❌ 別途 |
| 設営・解体費 | ❌ 別途 | ❌ 別途 |
| 運送費 | ❌ 別途 | ❌ 別途 |
| 電気工事費 | ❌ 別途 | ❌ 別途 |
| **実質的な総額（6小間の場合）** | **約120万円** | **約115万円** |

見かけ上の坪単価差は5万円/坪だが、総額では5万円しか変わらない。**しかし、ここにさらに大きな落とし穴がある。**

## 本当に怖い「追加工事」の構造

### 実例: 坪単価20万円の見積もりが最終的に180万円になったケース

ある樹脂成形メーカー（C0085、従業員35名）は、初めての展示会出展で「坪単価20万円」という他社より明らかに安い業者を選んだ。6小間（18㎡）の基本見積もりは120万円。

しかし、契約後に以下の追加工事が発生した:

| 追加工事 | 金額 | 発生理由 |
|---------|------|---------|
| デザイン料 | 15万円 | 「基本料金に含まれていませんでした」 |
| 照明増設 | 8万円 | 「基本は1小間1灯です。標準は2灯です」 |
| 床材のアップグレード | 12万円 | 「標準の床材はグレー1色のみです」 |
| ロゴパネル | 8万円 | 「印刷範囲を超えています」 |
| 設営費（時間外） | 10万円 | 「会場の設営時間が22時以降のため割増です」 |
| 運送費（特殊搬入） | 7万円 | 「エレベーターが使えないため」 |
| **追加合計** | **60万円** | — |
| **最終総額** | **180万円** | 当初見積もりの1.5倍 |

**問題は金額ではなく、契約前にこれらの項目が提示されていなかったことだ。** もし最初から180万円と提示されていれば、予算と照らし合わせて判断できたが、「120万円だから予算内」と思って契約した後に上乗せされた。

### 同じブースを明確な見積もりで提示した業者の場合

別の業者が同じブースに対して提示した内訳:

| 項目 | 金額 |
|------|------|
| デザイン料（全3案提示） | 10万円 |
| 構造材（システムパネル + カウンター） | 60万円 |
| 印刷（パネル4面 + ロゴ） | 25万円 |
| 照明（LEDスポット8灯） | 8万円 |
| 床材（カーペット＋アクセント） | 12万円 |
| 設営・解体費 | 18万円 |
| 運送費 | 10万円 |
| 電気工事費 | 5万円 |
| 予備費（追加工事のためのバッファ） | 10万円 |
| **合計** | **158万円** |

この業者の坪単価は約26万円と「高い」が、**実際の最終支払額は安かった**。

## 正しい見積もりの比較方法

### ステップ1: 同じ「含まれるもの」で比較する

見積もり比較表を依頼する際は、以下の**10項目をすべて含めた総額**を出してもらう:

1. デザイン料（何案まで含むか）
2. 構造材（パネル・柱・継手）
3. 印刷（パネル面数・サイズ上限）
4. 照明（灯具数・種類）
5. 床材（範囲・種類）
6. 設営費（時間外対応の条件）
7. 解体費
8. 運送費（特殊搬入の条件）
9. 電気工事費
10. 予備費（想定外の追加工事のバッファ）

### ステップ2: 「標準外」の条件を確認する

特に注意すべき「標準外になりやすい条件」:

| 条件 | 標準の範囲 | 標準外になりやすいケース |
|------|-----------|----------------------|
| 設営時間 | 9:00〜18:00 | 前日搬入・22時以降の設営 |
| 印刷面数 | 3〜4面 | 全面ラッピング・特殊加工 |
| 搬入経路 | 平場・エレベーターあり | 階段・2階以上・狭隘な通路 |
| 備品レンタル | カウンター1台＋椅子2脚 | 什器追加・特殊備品 |

### ステップ3: 複数社から見積もりを取る

最低3社から見積もりを取り、上記10項目の有無を一覧表で比較する。坪単価が極端に安い業者は「何かが含まれていない」と疑う。

## 予算別・適正な見積もりの目安

### 予算50万円未満（1〜2小間 / 初出展向け）

| 項目 | 目安金額 | 備考 |
|------|---------|------|
| デザイン料 | 3〜5万円 | 簡易デザイン、既存部材の組み替え |
| 構造材＋印刷 | 25〜35万円 | レンタルブース＋自社部材の活用 |
| 設営・運送 | 10〜15万円 | 可能なら自社運搬でコスト削減 |
| **総額目安** | **40〜50万円** | — |

### 予算100万円前後（2〜4小間 / 標準的な出展）

| 項目 | 目安金額 | 備考 |
|------|---------|------|
| デザイン料 | 8〜15万円 | 2〜3案のデザイン提案込み |
| 構造材 | 30〜45万円 | システムパネル＋カスタム部材 |
| 印刷 | 15〜25万円 | パネル4〜6面、ロゴパネル込み |
| 照明＋床材 | 10〜15万円 | LED照明＋カーペット |
| 設営・解体・運送 | 15〜20万円 | 標準設営時間内の場合 |
| 予備費 | 5〜10万円 | 追加工事のバッファ |
| **総額目安** | **85〜130万円** | — |

### 予算200万円以上（4〜6小間 / 本格的な出展）

このクラスでは、個別の設計・制作が入るため一概に比較できない。目安として、**制作費の60%が構造材＋デザイン、25%が印刷＋照明、15%が設営＋運送**という比率を参考にする。

## 見積もり確認のチェックリスト

見積もりを受け取ったら、以下のチェックリストで確認する:

- [ ] 10項目すべての内訳が明記されているか
- [ ] 「別途見積もり」と書かれている項目はないか
- [ ] 設営時間帯の割増条件は明記されているか
- [ ] 搬入経路の制約に関する注意書きはあるか
- [ ] 予備費（バッファ）は計上されているか
- [ ] 支払い条件（前金・中間金・残金の割合）は明確か
- [ ] キャンセルポリシーは明記されているか

**このチェックリストの項目が一つでも「書いていない」場合は、見積もりの再提出を依頼する。**
