# X-0068: Python技術SEOクローラーをAIプロンプトで自作 — 5ステップ＋6CSVでサイト課題を自動検出

**AIニュース提案 X-0068**: コピーペースト可能なプロンプト1発で、Pythonの標準ライブラリのみに依存する技術SEOクローラーをAIに生成させる手法を確立した。BFSクロール→HTML解析→SEOチェック→CSV出力までを1スクリプトに集約。依存ライブラリ0、コピペで即実行可能。オージャストでは展示会ブースサイトのH1欠如・タイトル重複・description欠落・リンク切れを自動チェックして改善に活用する。

観測日: 2026-11-16

---

## 1. 概要

SEOクローラーを個別のプロジェクトとして開発すると、ライブラリ選定・認証・デプロイ・メンテナンスに工数がかかる。本手法はAIプロンプト1枚で完結する自己完結型のSEOクローラー生成を確立し、以下の課題を解決する：

| 課題 | 従来 | 本手法 |
|------|------|--------|
| ライブラリ依存 | requests, beautifulsoup4, lxml 等のインストールが必要 | Python標準ライブラリのみ（http.client, html.parser, csv） |
| 環境構築 | pip install, venv, Docker 等 | Python 3.11+ のみ。コピペで即実行 |
| カスタマイズ | フレームワークの学習が必要 | プロンプトを編集してAIに再生成させるだけ |
| 動作確認 | テストコードとCIが必要 | `python seo_crawler.py https://example.com` の1コマンド |

### 本提案の核心

**「AIに『Pythonで技術SEOクローラーを作って』と頼むための、実証済みのプロンプトを公開する」**。開発の手間をゼロにし、出力されたスクリプトをそのまま本番サイトの診断に使える。

## 2. プロンプトの設計 — 5ステップ方式

AIに生成させる指示は以下の5ステップで構成する：

| STEP | 機能 | コード量の目安 |
|------|------|---------------|
| STEP1 | ドメインURL入力とバリデーション | ~30行 |
| STEP2 | BFSキューによる内部リンク発見（重複回避） | ~50行 |
| STEP3 | HTMLパースとSEO要素抽出 | ~120行 |
| STEP4 | 7種のSEOチェック（HTTP Status/Title/H1/Description/Canonical/Noindex/リンク切れ） | ~80行 |
| STEP5 | 6種類のCSV + JSONサマリー出力 | ~60行 |

### AIに渡すプロンプトの全文構造

```
[役割定義]
あなたはPythonの技術SEOクローラーを生成する専門家です。
Python標準ライブラリのみを使用し、外部ライブラリは一切使いません。

[要件: STEP1〜5]
（上記5ステップを詳述）

[出力フォーマット]
- 単一の .py ファイルとして出力
- argparse でコマンドライン引数を受け付ける
- CSVはUTF-8 BOM付き、JSONはpretty-print
- 型ヒントとdocstringを付ける

[テスト条件]
https://example.com でテストし、以下を確認：
1. タイトル "Example Domain" が抽出できる
2. H1 欠落が検出できる
3. description 欠落が検出できる
4. 5つのCSV+JSONが正しく出力される
```

## 3. 実装したスクリプトの機能

`tools/seo_crawler.py`（826行）に実装。以下の機能を持つ：

### 3.1 コマンドラインインターフェース

```
python seo_crawler.py https://example.com --max-pages 50 --output-dir ./seo_report --timeout 10 --verbose
```

| 引数 | 既定値 | 説明 |
|------|--------|------|
| `URL` | 必須 | クロール開始URL |
| `--max-pages` | 50 | 最大クロールページ数 |
| `--output-dir` | `./seo_report` | CSV出力ディレクトリ |
| `--timeout` | 10 | 1ページあたりのタイムアウト秒数 |
| `--verbose` | false | デバッグ出力の有効化 |

### 3.2 出力ファイル

| ファイル | 内容 | 活用例 |
|----------|------|--------|
| `01_titles.csv` | 全ページのタイトル・長さ・問題 | タイトル重複の発見と修正 |
| `02_h1s.csv` | H1の数・本文・問題 | H1欠如または複数H1の検出 |
| `03_descriptions.csv` | meta description・長さ・問題 | description欠落の検出 |
| `04_canonicals.csv` | canonical・noindex情報 | canonical設定漏れの発見 |
| `05_broken_links.csv` | リンク切れの一覧 | 404リンクの修正 |
| `06_summary.json` | クロール統計JSON | CI/CDパイプラインとの連携 |

### 3.3 実測パフォーマンス

| 対象 | 結果 |
|------|------|
| example.com (1ページ) | 0.03秒 / H1欠如+description欠落を検出 |
| orgiast.jp (1ページ) | 1.32秒 / SEO課題0（トップページは健全） |

## 4. オージャストでの使い方

### 展示会ブースサイトのSEO診断

```bash
# 特定のブースサイトをクロール
python seo_crawler.py https://orgiast.jp/booth/example --max-pages 30

# 出力CSVからH1欠如ページを抽出
grep "missing" seo_report/02_h1s.csv

# タイトル重複を確認
cut -d, -f2 seo_report/01_titles.csv | sort | uniq -d
```

### 期待される効果

1. **H1欠如の発見**: ブースページにH1がない場合、SEO的にタイトルとの差別化が不十分 → 改善
2. **タイトル重複の解消**: 全ページで同一タイトルを使っている場合、検索結果での差別化が困難 → 個別最適化
3. **description欠落の補完**: 検索結果にスニペットが表示されない → CTR低下 → 対策
4. **リンク切れの修正**: 展示会終了後の外部リンク切れがユーザー体験を損なう → 定期的なスキャン
