# X-0071: AI引用はコンテンツ前半1/3に集中させる — 展示会ブース制作ページへの適用

観測日: 2026-11-17。出典: AIニュース提案 [X-0071]。 目的: AI引用の配置ルールを展示会ブース制作ページに適用し、情報伝達効率を向上させる。

## 1. 背景と数値
- 投稿の報告値: ChatGPT引用の44.2%が最初の1/3、中盤31.1%、後半24.7%。
- 質問関連引用の78.4%が見出し由来。
- 高引用テキストの固有名詞密度は約20.6%、通常テキストは5-8%。
- これらは投稿の報告値であり、オージャストでの実測ではないことを明記。

## 2. 書き方ルール
1. **断定表現**を基本とし、根拠が不明な場合は「可能性がある」程度に留める。  
2. **質問形の見出し (H2)** の直下に**回答**を配置する。  
3. **重要な定義・事実・エンティティ**は本文前半に配置し、読者の注意を引く。  
4. **固有名詞**（企業名・サービス名・技術名など）を意識的に増やし、密度を前述の20.6%に近づける。

## 3. 適用チェックリスト
| 項目 | 必須内容 | チェック |
|------|----------|----------|
| 会社名・サービス定義 | [会社名] が提供する [サービス名] を冒頭で明示 | ☐ |
| 具体事例 | 成功事例や導入事例を1つ以上記載 | ☐ |
| H2 を質問形 | 「〇〇とは？」など質問形に統一 | ☐ |
| 会場名・ブース種別 | [会場名] の [ブース種類] を固有名詞として記載 | ☐ |

## 4. ビフォー／アフター例

### 例1
- **ビフォー**: 「当社は展示会ブースを制作します。」（引用なし、固有名詞が少ない）  
- **アフター**: 「[会場名] で展開する当社の [ブース種類] は、[技術名] を活用し、[事実確認済みの成果]を実現しました。」（引用を前半に配置し、固有名詞密度向上）

### 例2
- **ビフォー**: 「展示会での効果測定は行っています。」（曖昧な表現）  
- **アフター**: 「[会場名] において、[実績期間] の間に導入した [技術名] が、[事実確認済みの成果]につながりました。」（断定的かつ具体的）

## 5. 効果測定
- **週次チェック**: 「展示会ブース おすすめ会社」を ChatGPT 等に投げ、当社言及の有無を **YES/NO** で記録。  
- **留意点**: 実測データが蓄積されるまで、効果を断定しない。数値は記録だけに留め、分析結果は次回以降に報告。

## 6. 次の一手
1. 現行ページの冒頭1/3に、定義・事実・固有名詞が来るようリライト。  
2. チェックリストに基づき、**固有名詞** を [会場名]、[ブース種類]、[技術名] で埋める。  
3. 週次効果測定を開始し、**3か月後** に改善レポートを作成。  
4. 実測データが得られ次第、**数値目標**（自社の実測値から設定）を設定し、社内共有。

> **注記**：本文中の `[会場名]`、`[実績期間]`、`[規模]`、`[価格帯]` などの角括弧は、貴社が事実確認済みのデータで置換してください。創作・推測データの記載は禁じられています。
