# X-0072: AIサイト同質化を防ぐデザインリファレンス指定 — プロンプトに含めるUIリファレンスリスト

観測日: 2026-11-17。出典: AIニュース提案 [X-0072]。
本稿は、AIコード生成時にデザインリファレンスサイトをプロンプトに明示的に指定することで、AIサイトの同質化（「AI臭さ」「どのサイトも同じ見た目」）を防ぎ、オージャストの展示会ブース紹介LP・自社サイトにオリジナルUIを生成する手法を提案する。

---

## 背景: AI生成UIの同質化問題

AIコーディングエージェント（Claude Code, Cursor, Codex, v0, Bolt等）に「サイトを作って」と依頼すると、学習データの偏りから以下のような同質化が発生する:

- 同じようなカードレイアウト（角丸・影付き白カード）
- 同じグラデーションヒーロー（黒→紫 or 白→青）
- 同じフォント選択（Inter / System UI / 未指定）
- 同じアニメーション（フェードイン・上からのスライド）
- 装飾目的の半透明オーバーレイ

**原因**: AIの学習データにおける「よくあるWebデザイン」の分布が偏っているため、確率的に最も平均的なUIが選ばれる。

**対策**: プロンプトに具体的なデザインリファレンスサイトを列挙し、「これらのサイトを参考にしつつ、指定された展示会ビジュアルに合わせて独自のUIを生成せよ」と指示する。リファレンスサイトは多様なデザイン方向をカバーすることで、AIの出力分布を拡げる。

## プロンプトテンプレート

### 汎用版

```
あなたは一流のフロントエンドデザイナーです。
以下のデザインリファレンスサイトを参考に、これらの水準に合うオリジナルUIを生成してください:

- inspora.design (高品質UIギャラリー)
- collectui.com (UIデイリーチャレンジ)
- 21st.dev (モダンWebデザイン)
- banani.co (実験的・クリエイティブ)
- siteinspire.com (厳選Webデザイン)

ただし、以下の展示会ビジュアルに合わせてカスタマイズすること:
[ビジュアルの説明/カラーコード/参考画像URL]

AI臭さ（均一なカード・グラデーション・フェードインのみのアニメーション）を避け、
各リファレンスの特徴を活かした独自の組み合わせを生成してください。
```

### オージャスト展示会LP用

```
あなたは展示会ブース紹介サイトのUIデザイナーです。
以下のリファレンスサイトをデザインの方向性として参照しつつ、
オージャスト（東京のイベントプロデュース会社）のブース紹介LPを生成してください:

リファレンス:
- inspora.design: 洗練されたカードレイアウトと余白設計
- collectui.com: 直感的なUIパターンとフォーム設計
- 21st.dev: モダンでタイポグラフィの効いたポートフォリオ風
- banani.co: 実験的なグリッドとホバーエフェクト
- land-book.com: ランディングページの情報設計とCTA配置

展示会ビジュアル:
- メインカラー: [カラーコード]
- アクセント: [カラーコード]
- フォント: [フォント名]
- 参考画像: [URL]

禁止: 白カードの均一グリッド・紫グラデーションヒーロー・フェードインだけのアニメーション・半透明オーバーレイ
```

## オージャストでの活用フロー

```
1. 案件の展示会ビジュアル決定
2. ビジュアル（カラー・フォント・参考画像）を↑のテンプレートに埋める
3. プロンプトをAIコード生成ツール（Claude Code / v0 / Cursor等）に渡す
4. 生成されたUIを確認→修正指示を出す
5. 完成後、展示会のビジュアルと合っているか実ブラウザ確認
```

### 推奨する組み合わせ

| 用途 | リファレンス候補 | 理由 |
|------|----------------|------|
| 展示会LP（全体的） | inspora.design + land-book.com + banani.co | 余白設計＋LP情報設計＋実験的表現 |
| ブース一覧ページ | 21st.dev + siteinspire.com | ポートフォリオ風＋厳選クオリティ |
| フォーム（来場予約等） | collectui.com + checkout.fyi | UIパターン＋決済フロー設計 |
| ブランドページ | banani.co + godly.ai | 実験的＋トレンド推薦 |
| アニメーション演出 | magicui.design + aceternity.ui | Framer Motion＋アニメーションUI集 |
