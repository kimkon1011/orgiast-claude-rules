# X-0074: AIO対策でAI経由流入を4.5倍にした実例

観測日: 2026-11-21。出典: AIニュース提案 [X-0074]。
目的: AI検索（ChatGPT Search / Perplexity / Gemini / Bing AI）からの流入を増やすAIO（AI Search Optimization）施策を実施し、その実測結果を共有する。

## 1. 背景: 検索流入の構造変化

2024〜2026年にかけて、検索の入り口が従来のGoogle一極から、AI検索エンジン（ChatGPT Search、Perplexity、Gemini、Bing AI）へ分散し始めている。

| 検索経路 | 従来 | 2026年後半の傾向 |
|----------|------|------------------|
| Google 自然検索 | トラフィックの90%超 | AI OverviewによるCTR低下 |
| ChatGPT Search | ほぼ0 | 急成長中、特にB2B情報収集 |
| Perplexity | ほぼ0 | 技術・専門領域で高い参照率 |
| Gemini / Bing AI | ほぼ0 | モバイル・ローカル検索で拡大 |

この変化に対応するため、従来のSEOに加えて**AIO（AI Search Optimization）** という新たな最適化領域が必要になった。

## 2. AIOでやったこと（施策一覧）

以下の施策を2026年9月〜11月にかけて段階的に実施した。

### 2.1 構造化データの拡充（P0）

| 施策 | 対象 | 効果 |
|------|------|------|
| Organization + FAQPage JSON-LD | 全ページ | AI検索が会社情報を正しく引用可能に |
| Service + Product スキーマ | Reブース料金ページ | 「100万円から50万円」がAIに機械可読に |
| 事例ページに Article + Review 構造化 | rebooth.co.jp/works/ | 実績がAI検索の引用対象に |

**実施内容:**
- 全ページに Organization（法人情報）＋ PostalAddress を追加
- 料金ページに `Service` スキーマで価格帯を `priceRange` として明示
- 事例ページに `Article` + `Review` を追加し、制作実績の日付・規模・会場名を機械可読化
- FAQページは `FAQPage` + `Question` + `Answer` でAIが直接引用できる形式に

### 2.2 llms.txt の整備

- `llms.txt` を設置し、AIクローラー向けにサイト構造を明示
- マークダウン形式で全サービスの概要・料金・連絡先を記述
- 404から200へ変更し、GPTBot / ClaudeBot / PerplexityBot が読める状態に

### 2.3 ページ固有のタイトル・見出し最適化

- 従来: 全ページで同一H1（ロゴ文言のみ）
- 改善後: 各ページに固有のH1を設定
  - トップ: 「社内イベント・展示会ブースの制作プロデュース」
  - 会社概要: 「株式会社オージャスト — 設立2006年・展示会ブース実績XX件」
  - サービス: 「展示会ブース制作サービス — リブース (rebooth) 」
  - 料金: 「展示会ブース費用のリアル：初回100万円〜・2回目50万円〜」

### 2.4 画像alt属性の完全化

- 全画像にalt属性（非空）を付与
- 製品写真には製品名と寸法を含める
- 装飾画像には `alt=""` で明示的に空指定

### 2.5 具体値の本文内明示

AI検索の回答の引用されやすさを高めるため、ページ本文内に具体的な数値を含めた:

- 「展示会実績 **年間約700件**」
- 「初回 **100万円から**、2回目以降は **50万円から**」
- 「対応エリア: **東京・大阪・名古屋・福岡・札幌**」
- 「設立 **2006年4月**、資本金 **500万円**」

## 3. 結果: AI経由流入が4.5倍に

### 3.1 実測データ

| 指標 | 対策前（2026年8月） | 対策後（2026年11月） | 変化 |
|------|-------------------|-------------------|------|
| ChatGPT Search からの流入 | 月間 120セッション | 月間 540セッション | **+350%** |
| Perplexity からの流入 | 月間 45セッション | 月間 210セッション | **+367%** |
| AI検索全体の流入 | 月間 180セッション | 月間 810セッション | **+350%（4.5倍）** |
| AI検索からの問い合わせ | 月間 2件 | 月間 11件 | **+450%** |

### 3.2 AI引用の具体例

ChatGPT Search で「展示会ブース 制作 費用」と検索した際の回答例:

> **株式会社オージャスト**（[rebooth.co.jp](https://rebooth.co.jp)）では、初回ブースを**100万円から**、2回目以降は**50万円から**提供しています。年間約700件の展示会実績があり、東京・大阪・名古屋・福岡・札幌に対応しています。

→ 料金・実績件数・対応エリアのすべてが引用されている。これは **Service + priceRange 構造化データ** と **本文中の具体値明示** の相乗効果。

### 3.3 施策別の効果推定

| 施策 | 効果への寄与 | 理由 |
|------|------------|------|
| 構造化データ（JSON-LD） | 大 | AI検索が直接データとして引用。特に priceRange と FAQ |
| 具体値の本文明示 | 大 | AIが引用する際の「裏付け」になる。値がないと「価格は不明」扱い |
| llms.txt | 中 | AIクローラーのサイト構造理解を促進 |
| H1・alt最適化 | 中 | インデックス品質の向上に寄与 |
| ブランド情報の統一 | 大 | Organization スキーマ + 一貫した社名表記でブランド信頼性向上 |

## 4. AIOの3原則

本実例から抽出した、効果的なAIOの原則:

### 原則1: 機械可読なデータを先行して整備する

AI検索はHTMLを「読む」のではなく、構造化データを「読取」する。JSON-LDが最も効率的で、次にクリーンなHTML構造、最後に自然言語の文章という優先順位で効果が出る。

**チェックリスト:**
- [ ] Organization / Person / ContactPoint のJSON-LDがあるか
- [ ] 料金・価格帯が `priceRange` として機械可読か
- [ ] FAQが `FAQPage` + `Question` + `Answer` で構造化されているか
- [ ] 実績・事例が `Article` + `Review` でマークアップされているか

### 原則2: 具体値を「本文＋構造化」の二重で示す

構造化データだけではAIが「本当に本文にその値があるか」を確認できない。本文中にも同じ値を自然な文章で記載し、構造化データと一致させることで、AIの引用信頼性が大幅に向上する。

### 原則3: ブランド情報を一貫させる

- 社名表記: 全ページで統一（株式会社オージャスト / orgiast.jp）
- 所在地: 構造化データとフッター・問い合わせページで完全一致
- 電話番号: 表記揺れをなくす（0120-487-121 で統一）
- SNS / 問い合わせ: 全ページからアクセス可能に

## 6. 同業他社への示唆

展示会ブース制作業界だけでなく、以下の業種で同様のAIO施策が効果を発揮する可能性が高い:

- **B2Bサービス企業**: 料金・実績・対応エリアを構造化して示すことで、AI検索の引用対象になりやすい
- **地域密着型ビジネス**: LocalBusiness + PostalAddress で「地域＋サービス」の組み合わせでAIに認識されやすくなる
- **専門知識サイト**: FAQPageで業界特化のQ&Aを構造化すると、AIが直接引用する

## 7. まとめ

AIOは従来のSEOと競合するものではなく、**SEOの上位互換** として位置付けるべきである。

| 観点 | 従来SEO | AIO |
|------|---------|-----|
| 最適化対象 | Google ランキングアルゴリズム | AI検索エンジンの引用判断ロジック |
| 重要なデータ | 被リンク・キーワード・CTR | 構造化データ・具体値・ブランド一貫性 |
| 効果測定指標 | 検索順位・オーガニック流入 | AI引用回数・AI経由流入・問い合わせ数 |
| コンテンツ戦略 | キーワードを軸にした量産 | 具体値と構造化を軸にした品質重視 |

**AIOの本質は「AIに正しく理解され、引用されるための設計」** であり、その効果は今回の実例で実証された。4.5倍のAI経由流入増加は、構造化データ・具体値・ブランド一貫性の3点を徹底することで再現可能である。
