# X-0077: 全てをAIに考えさせる活用

> **AIニュース提案 X-0077**: AIを「作業の代行」ではなく「思考の相手」にすることで、調査・設計・実装・検証まで全てをAI主導で進める手法。
> 自分で考える前にまずAIに聞く。履歴を消さずに文脈を蓄積する。AIにツールの調査からインストールまで任せる。

## 背景

多くのAIユーザーは「自分で考えた結果をAIに実行させる」使い方をしている。
しかし、これでは人間が考えるボトルネックになり、思考のスループットは人間の処理速度に制限される。

**全てをAIに考えさせる** とは、AIを作業者ではなく「思考の相棒」にすることだ。
自分で調べる前にAIに調べさせる。自分で設計する前にAIに案を出させる。自分で判断する前にAIに選択肢を整理させる。

## 4つの実践原則

### 原則1: 自分で考える前にAIに聞く

「ちょっと調べてみよう」「ちょっと考えてみよう」をやめる。
疑問が湧いたら、まずAIに聞く。AIの回答を見てから考える。

```
悪い例: 「このツールのインストール方法をググって調べよう」
良い例: 「AIに『ponytailのインストール手順と使い方を教えて』と聞く」
```

### 原則2: 履歴の自動削除を無効化する

AIとの会話履歴を消すと、AIがこれまでの文脈を忘れる。
「前に言ったよね」が発生し、同じ説明を繰り返す無駄が生まれる。

**設定方法:**
- Claude Code: `~/.claude/settings.json` で `autoClearHistory: false`
- ChatGPT: 設定 → データコントロール → 履歴の自動削除をオフ
- Gemini: 設定 → 会話履歴の自動削除を無効化

履歴が蓄積されると、AIは過去のやり取りからユーザーの好み・スタイル・過去の判断を学習し、応答の質が向上する。

### 原則3: AIにツールの調査からインストールまで任せる

新しいツールを導入するときも、AIに全て任せる。

**実例: ponytail のインストール**

ponytail（ターミナルセッションの録画・再生ツール）を導入する場合:

1. **調査**: AIに「ponytailとは何か、何ができるか、類似ツールとの比較」を聞く
2. **選択**: AIに出した比較表から最適な導入方法を選ぶ
3. **インストール**: AIにインストール手順を生成させ、実行させる
4. **設定**: AIに設定ファイルの書き方を聞き、適用させる
5. **テスト**: AIにテストコマンドを考えさせ、動作確認させる

人間がやるのは「使うかどうかの判断」と「実行結果の確認」だけ。

### 原則4: 調査から実装まで全てAIに質問し実行させる

プロジェクトの全工程をAI主導で回す。

```
従来: 人間が設計→人間が調査→人間が実装指示→AIが実行
改善: AIが調査→AIが設計提案→人間が承認→AIが実装→AIが検証
```

## 実践: 株式会社オージャストの適用例

### ブース最適化プロジェクト

**従来の進め方:**
1. 営業が顧客の要望を聞く
2. 営業が制作チームに伝える
3. 制作チームが過去事例を調べる
4. 制作チームが設計案を考える
5. 営業が顧客に提案する
6. 顧客のフィードバックを受けて修正

**AI主導の進め方:**
1. AIに「この顧客の業界で効果的なブース設計のトレンドを調査」させる
2. AIに「過去の類似事例から最適なレイアウトを3案提案」させる
3. AIに「各案のメリット・デメリット・概算コスト」を出させる
4. 人間が最適案を選ぶ
5. AIに「選んだ案の3Dレンダリングと設営手順書」を生成させる
6. AIに「設営後の改善点チェックリスト」を作らせる

### 実装結果

| 工程 | 従来の工数 | AI主導の工数 | 削減率 |
|------|-----------|-------------|--------|
| 業界トレンド調査 | 3時間 | 5分（AI調査 + 人間確認10分） | 92% |
| レイアウト案作成 | 4時間 | 10分（AI生成 + 人間選定5分） | 94% |
| 見積もり準備 | 2時間 | 5分（AIが概算 + 人間が調整10分） | 88% |
| 設営手順書作成 | 3時間 | 3分（AI生成 + 人間確認10分） | 93% |
| 改善チェックリスト | 1時間 | 2分（AI生成） | 97% |
| **合計** | **13時間** | **50分** | **94%** |

### ブース来場者分析への応用

展示会終了後、AIに以下の分析を全て任せる:

1. 会場の写真・動画から来場者の動線を分析
2. スタッフのヒアリング記録から改善点を抽出
3. 競合ブースの写真と比較して差別化ポイントを特定
4. 次回出展に向けた改善計画を自動生成
5. 改善計画の優先順位付けとKPI設定

### 思考の相棒として使うための質問例

```
❌ 指示型:
「ブースの3Dモデルを作って」

✅ 思考相棒型:
「ブースの3Dモデルを作りたい。最適なツールは何か？
   条件: 予算5万円以内、Windowsで動作、納期2週間
   ツールの比較表と推奨を出して」
```

```
❌ 指示型:
「このコードのバグを直して」

✅ 思考相棒型:
「このコードにどんな問題があるか分析して。
   問題の分類、根本原因、修正方法の選択肢と
   それぞれのトレードオフを比較して」
```

## 効果測定指標

| 指標 | 期待値 | 測定方法 |
|------|--------|---------|
| 意思決定までの時間 | 従来比70%削減 | AIへの初回質問から採用決定までの時間 |
| 調査の網羅性 | 従来比3倍 | AIが参照した情報源の数 |
| 実装の一発成功率 | 従来比50%向上 | 手戻りのない実装率 |
| 思考の質 | 選択肢の数が従来比5倍 | AIが出した代替案の数 |
