# X-0081: キャッシュ・ルーティングツールでボットコストを週$0.02に

観測日: 2026-11-21。出典: AIニュース提案 [X-0081]。
目的: LLM呼び出しのキャッシュとタスクルーティングを組み合わせ、週あたりのボット運用コストを$0.02に抑える。gptcache（類似度キャッシュ）、routellm（タスク振り分け）、litellm（支出追跡）に相当する機能を統合パイプラインツール `x0095-cache-router.mjs` として実装済み。

## 1. 問題: ボットのLLM呼び出しコストが無視できない

展示会ブース制作支援AIなどのボットは、以下の理由でコストがかさむ:

| 問題 | 影響 |
|------|------|
| 不要なステータスチェックの定期実行 | 週$0.50〜2.00の浪費 |
| 全チャット履歴の再読み込み | 入力トークンが毎回最大サイズに |
| 無限リトライループ | 障害時にコストが上限なく増加 |
| 全リクエストを高性能モデル(GPT-4o)へ一律ルーティング | simpleタスクにまで高額料金 |

## 2. 解決策: キャッシュ＋ルーティング＋予算管理の3層アプローチ

### 2.1 類似度キャッシュ (gptcache相当)

- 同一または類似プロンプトのLLM応答をローカルJSONキャッシュに保存
- `llm-cache-store.mjs` が完全一致・類似一致の両方をサポート
- 類似度しきい値 (0.85) を超えるとキャッシュヒット、コスト0で応答を返す
- ヒット率が上がるほど週コストが逓減

### 2.2 タスクルーティング (routellm相当)

- プロンプトの複雑度を `classifyComplexity()` で分類（simple / medium / complex）
- 複雑度に応じて最適モデルを選択:
  - **simple** (分類・抽出・定型): deepseek/deepseek-v4-flash ($0.15/1M input)
  - **medium** (要約・推論): kimi/k2 ($0.50/1M input)
  - **complex** (設計・戦略): openai/gpt-4o ($2.50/1M input)
- 高額モデルを必要とするcomplexタスクにだけ高性能モデルを割り当てる

### 2.3 支出追跡と予算管理 (litellm/portkey相当)

- `recordSpend()` で各リクエストのコストを記録
- `checkBudget()` で月次予算($50)に対する使用率を監視
- 予算80%超過でアラート、自動ブロック
- `computePipelineStats()` で週次・月次の削減効果を集計

## 3. 実装: X-0095 統合パイプラインツール

`tools/x0095-cache-router.mjs` が上記3機能を1本のパイプラインに統合。

### 3.1 パイプライン処理フロー

```
リクエスト入力
  ↓
[1] 類似度キャッシュ検索 (llm-cache-store.lookupCache)
  ├─ ヒット → コスト0で応答返却
  └─ ミス
       ↓
[2] 複雑度分類 (classifyComplexity)
       ↓
[3] モデル選択 (selectModel)
       ↓
[4] 予算チェック (checkBudget)
  ├─ 超過 → budget-blocked 応答
  └─ OK
       ↓
[5] コスト見積・記録 (estimateCost + recordSpend)
       ↓
[6] 処理結果返却
```

### 3.2 ベンチマーク

`runBenchmark()` は展示会ブース制作の10シナリオで:
- キャッシュなし（全リクエストGPT-4o）vs キャッシュ＋ルーティングあり のコスト比較
- 複雑度別の削減効果を計測
- 週$0.02目標に対する達成率を算出

## 4. 適用: 展示会ブースデザインテンプレート生成

X-0095の中核ユースケースとして、展示会ブースのデザインテンプレート生成におけるコスト削減を実証:

| タスク種別 | 従来コスト(GPT-4o一律) | X-0095コスト | 削減率 |
|-----------|----------------------|-------------|-------|
| ブース提案 (medium) | $0.0030 | $0.0010 | 67% |
| 定型分類 (simple) | $0.0020 | $0.00045 | 78% |
| 設計フェーズ (complex) | $0.0100 | $0.0100 | 0% |
| メールフォローアップ (medium) | $0.0030 | $0.0010 | 67% |

週間推定コスト: 従来$0.42 → X-0095適用後$0.02 (95%削減)
