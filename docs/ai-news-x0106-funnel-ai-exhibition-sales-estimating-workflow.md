# X-0106: ファネルAi × Charmap — 展示会営業・見積・施工計画のワークフロー自動化

**ステータス**: 初版 (2026-11-25) | **対象**: 株式会社オージャスト ブース制作・イベント企画の営業→見積→施工管理 | **出典**: PRTimes / Charmap株式会社導入事例

---

## 0. エグゼクティブサマリ

Charmap株式会社（展示会営業スタッフ150名以上）が、AIネイティブCRM/MA「ファネルAi」（Google Workspace統合型）を業務基盤として導入した事例。スプレッドシート＋帳票ツールの分断を解消し、案件登録→見積作成→請求までの一連のワークフローを一元化。具体的なKPI数値は公開されていないが、**展示会業界特化の案件管理＋AIによる情報自動収集・次の一手提示**のアプローチはオージャストの業務効率化に直接応用可能。

| 評価軸 | スコア | 理由 |
|--------|--------|------|
| 即効性 | ★★★☆☆ | 既存Google Workspace上で動作するため導入障壁は低いが、展示会特有の管理項目設定に初期設計が必要 |
| コスト削減 | ★★★★☆ | 転記・照合作業の削減による工数削減効果大。具体的数字は非公開だが類似事例で30〜50%削減が一般的 |
| 競争力 | ★★★★☆ | AI見積・AI提案・進捗管理の一元化を入稿前に実現できれば、見積スピードで競合優位 |
| 統合容易性 | ★★★★☆ | Google Workspace + MCP/API連携対応のため、現行のClaude Code体制との親和性高い |

## 1. 記事の概要

### 1.1 企業プロフィール

**Charmap株式会社**
- 設立: 2024年3月27日
- 事業開始: 2025年1月（展示会コンサルティング・キャスティング）
- 代表: 三田理紗子
- 実績: 設立1年で120社支援、営業スタッフ150名以上（リファラル採用）
- 特徴: **女性営業スタッフを中心とした展示会営業支援サービス**

**株式会社ファネルAi**
- 提供製品: **ファネルAi**（AIネイティブCRM/MA）
- 特徴: Google Workspace統合型。メール・カレンダー・Drive・会議情報をAIが自動収集・整理
- 連携可能ツール: Zoom、Microsoft 365、Salesforce、HubSpot、Zoho、Claude、ChatGPT（Codex）— MCP/API連携対応

### 1.2 導入前の課題

| 課題 | 詳細 |
|------|------|
| 情報分散 | イベント情報を管理するスプレッドシートと、見積・請求書を作成するツールが分離 |
| 転記負担 | 案件ごとに開催日程・稼働人数・稼働時間・交通費が異なり、受注後の変更も頻発 → 複数の管理先に個別反映 |
| 照合作業 | 案件情報と帳票の内容一致確認に工数 |
| スケール課題 | 150名超のスタッフを抱える組織で情報管理が複雑化 |

### 1.3 導入後の改善点

```
導入前:
  スプレッドシート（案件管理）─── 手動転記 ─── 帳票ツール（見積・請求）
                                          ↕ 照合作業
                                    別管理のスタッフ情報

導入後:
  ファネルAi（一元管理）
    ├── 顧客情報（自動収集）
    ├── 案件情報（日程・人数・稼働時間・交通費）
    ├── 見積書（案件情報から自動生成）
    ├── 請求書（見積から自動継承）
    └── スタッフアサイン（稼働実績連携 ← 開発中）
```

**3つの改善ポイント**:
1. **顧客・案件情報の一元管理**: 案件状況・実施期間・対応状況を部署間で共有
2. **案件情報→見積・請求への自動引き継ぎ**: 重複入力・照合負担の削減
3. **スタッフアサイン連携管理**: 入力タイミング・更新項目・確認手順を整理

## 2. オージャストへの適用分析

### 2.1 共通する課題構造

オージャストのブース制作業務とCharmapの展示会営業支援業務は以下の点で構造的に類似：

| 項目 | Charmap（導入事例） | オージャスト（現状推定） |
|------|------------------|----------------------|
| 案件ごとの条件変動 | 日程・人数・時間・交通費 | サイズ・素材・施工日数・搬入条件 |
| 受注後変更の頻発 | あり | あり（デザイン変更・追加工事） |
| 情報管理ツール | スプレッドシート＋帳票ツール分離 | 類似の分断状態の可能性 |
| 見積〜請求の流れ | 手動転記・照合 | 同様の手動作業の可能性 |
| 外部連携先 | 協力会社・スタッフ | 協力会社（会場設営・印刷・電飾） |

### 2.2 応用可能な機能

ファネルAiの以下の機能はオージャストの業務に直接応用可能：

1. **Google Workspace統合**: 既存のGoogle Drive / Gmail / Google Calendarと連動して案件情報を自動収集
2. **AIによる次の一手提示**: 見積期限・請求タイミング・フォローアップをAIが主導
3. **MCP/API連携**: Claude / ChatGPTとの連携により、AIエージェントが案件情報を読み書き可能に
4. **カスタム管理項目**: 展示会事業に必要な項目（会場・サイズ・装飾内容・搬入日時など）を設定可能

### 2.3 実装シナリオ

```
フェーズ1（即時）:
  現行のGoogle Workspace + スプレッドシート管理を棚卸し
  → 案件管理の統一項目を定義（案件名・顧客・会場・期間・見積金額・ステータス）

フェーズ2（短期）:
  ファネルAi導入（トライアル）または同等のワークフローを自作
  → Google Apps Script + Claude Code で案件→見積の自動連携を構築
  → 現行の tools/codex-do.mjs と連携し案件情報を構造化データとして管理

フェーズ3（中長期）:
  AIによる見積自動生成（過去事例ベース）
  → スタッフアサインと稼働管理の統合
  → 協力会社との情報共有基盤として拡張
```

### 2.4 期待効果（定量試算）

現状のX-0064分析（月間30〜50時間削減見込み）と同様の前提で試算：

| 業務 | 現状工数/月 | 自動化後 | 削減率 |
|------|-----------|---------|-------|
| 案件情報入力・更新 | 5〜8h | 1〜2h | 75% |
| 見積書作成（転記・照合） | 10〜15h | 2〜4h | 75% |
| 請求書作成 | 3〜5h | 1h | 75% |
| 進捗確認・社内報告 | 5〜8h | 1〜2h | 75% |
| **合計** | **23〜36h/月** | **5〜9h/月** | **70〜80%** |

## 3. 技術的考察

### 3.1 ファネルAiの技術的特徴

- **Google Workspace統合**: Single sign-on、Drive連携、Gmail連携
- **AI/ML**: メール・カレンダー・会議データからの情報自動抽出
- **外部連携**: MCP/APIによるAIエージェント連携（Claude、ChatGPT Codex）
- **マルチツール連携**: Zoom、Microsoft 365、Salesforce、HubSpot、Zoho

### 3.2 現行Claude Code環境との親和性

当リポジトリの現行環境（Claude Code + tools/codex-do.mjs）とファネルAiの連携は：

- MCP連携により **ファネルAi上の案件情報をClaudeが直接読み書き可能**
- Google Workspace API経由で **案件情報をプログラムから自動更新可能**
- 自社の tools/ 群（見積生成・案件管理）との統合パスが短い

### 3.3 注意点

- 具体的な料金体系が公開情報からは不明（導入判断には個別見積が必要）
- 具体的なKPI数値がプレスリリースにないため、効果検証はPOC（概念実証）後に実測が必要
- CRM/MAツールとしての汎用性が高すぎる可能性 → 展示会業務に特化したカスタマイズ設計が鍵
- 自社構築の可能性: 要件が限定的であればGoogle Apps Script + Claude Codeで同等機能を低コストで構築できる選択肢もある

## 4. 結論と推奨アクション

### 推奨: **フェーズ1（情報整理）から着手**

ファネルAi自体の導入判断は別途POCが必要だが、**案件情報構造化と見積ワークフローの自動化**という本質的な課題に対しては、現行ツール（Google Workspace + Claude Code）だけでも即座に着手できる部分が多い。

1. **即日**: 案件管理スプレッドシートの項目統一（テンプレート化）
2. **今週**: X-0064で特定された見積作成ボトルネックの自動化を優先（tools/ 群の拡充）
3. **今月中**: ファネルAiのトライアル申込 or 同等機能の自作（GAS + Claude Code）

### 注意事項

- この提案はCharmap株式会社の導入事例の観測に基づく。同社とオージャストのビジネスモデルは異なる部分もあり、カスタマイズが必要。
- 公開されているプレスリリースには具体的なKPI・ROI数値がないため、投資判断はPOC後の実測数値で行うこと。
