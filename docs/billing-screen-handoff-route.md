## 3. 正しい手渡しの作り方

1. **見ていない画面の多段手順を推測で書かない。**「一般的な構成に基づく手順」＋「違ったら教えてください」は往復を強制するので rule 5 違反。画面を見ていないなら、書かないのが正解。
2. **購入前後にスクショを求めない。** 押下前の画面を確認したい気持ちは分かるが、それは user に余分な手作業を足す（rule 6）。求めていいのは**結果の報告だけ**。
3. **kim 1人が同じ画面で購入まで完結する1回の手順**を渡す。途中で Claude に戻らせない。押下後にどの画面が出ても、そのまま本人が進められる粒度で書く。
4. **照会できない設定値は断定しない。** 自動チャージのしきい値・補充額・月上限のように、画面を見ないと確定できない値を「オンです」「$25 です」と書かない（rule 4）。「未確認」と明記する。
5. 支払いが済んだら、**残高の実画面は user から1枚受け取る**（Claude 側に読み取り経路が無いため、ここだけは受け取るのが最短）。
