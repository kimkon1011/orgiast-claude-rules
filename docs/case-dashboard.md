# case-dashboard — 案件一覧静的HTMLダッシュボード（X-0032試作）

案件一覧スプレッドシートから、列名と型情報だけを使った静的HTMLダッシュボードを生成する。

## コンセプト

AIに渡すのは**列名と型だけ**（行データ＝お客様名・金額などの中身は渡さない＝`--schema-only`）。
HTMLのダッシュボードには行データを埋め込むが、出力先はローカルファイル限定。

## 使い方

```bash
# 列名+推定型を確認（スプレッドシートの中身は出力しない）
node tools/case-dashboard.mjs --schema-only

# HTMLダッシュボード生成
node tools/case-dashboard.mjs --out report.html
```

## オプション

| 引数 | 説明 |
|------|------|
| `--schema-only` | 列名と推定型をJSONでstdoutに出力。行データは一切出力しない |
| `--out <path>` | 静的HTMLを生成して指定パスに書き出す |

## 環境変数

| 変数 | 既定値 | 説明 |
|------|--------|------|
| `CASE_SHEET_ID` | （運用中の案件一覧シートID） | 別のシートを指定する場合 |

## 認証

既存の `tools/lib/sheets-dwd.mjs`（DWD／サービスアカウント経由）をそのまま使う。
新しい認証方式は追加しない。

## 出力HTMLの構成

- **状態別件数カード**（状態/フェーズ列がある場合）
- **担当者別件数**（担当者列がある場合）
- **今月〜来月の予定一覧**（日付列がある場合）
- **全件テーブル**（列ごとのフィルタと並べ替え）

全て1ファイル完結（外部CDNなし、CSS/JSインライン）。

## 制約

- ネットワーク・LLM呼び出しはしない
- 生成HTMLはコミットしない（`.gitignore` 不要、単に `add` しない）
- 行データ（お客様名・金額・連絡先）をログやコミットに書き出さない
