# 低価格GPUへのハードウェア刷新の可否（P-0124）

> 判定日: 2026-09-21 / 判定: **見送り（購入しない）**
> 提案原文: 「現在使用中の高価GPUを3090（19万円）や4000 Ada（22万円）に置き換える検証を実施する。」
> 先行判定 [[feedback_local_llm_hardware_roi]]（2026-08-23）・P-0125（2026-09-20・docs/local-llm-api-cost-reduction.md）と同じ問いの再発。

## 結論

**見送り。2つの独立した理由があり、どちらか一方だけでも刷新は成立しない。**

1. **前提の「現在使用中の高価GPU」が存在しない。** 到達可能な kim-PC（DESKTOP-2D0R4LI）の実測は
   `nvidia-smi` で **GeForce GTX 1070 Ti（8GB・2017年発売）**。2026年の中古実勢は1〜2万円級であり
   「高価GPU」ではない。19〜22万円のカードへ「置き換える」元手は最初から無い。
2. **仮に買っても削減効果は月136円（$0.88）。** P-0125 と同一の計算で、従量課金AIの直近30日支出は
   $3.03/月、うちオープンウェイトで置き換えられるのは $0.88/月。19万円 ÷ 月136円 = **回収117年**
   （電力費込みで永久に回収しない）。Claude Code 本体は定額シート課金なので1円も減らない。

## 2. 現用GPUの実測

```
nvidia-smi --query-gpu=name,memory.total
→ NVIDIA GeForce GTX 1070 Ti, 8192 MiB
```

- ドライバ 560.94 / 待機時 38W。AI学習・推論の常時ワークロードは乗っていない
  （ローカルLLM経路の `tools/ollama-ask.mjs` は CPU 固定、P-0125 で導入見送り済み）。
- 1070 Ti の中古実勢は1〜2万円級。「高価GPUを安いGPUに置き換える」という提案の筋書き自体が
  逆（1〜2万円のカードを19万円のカードに**上げる**話になってしまう）。
- 到達範囲の限界: この実測は kim-PC 1台。他の fleet PC に高価GPUが載っている可能性は
  本セッションでは**未確認**と記す（未確認を否定しない）。ただし fleet のAI処理は
  全てクラウドAPI従量課金（executor-usage.jsonl 台帳）で、どのPCにもGPU必須の業務は無い。

## 3. ローカルLLM導入の3条件（再掲・3つとも偽のまま）

1. 機密データを絶対に外に出せない → 偽
2. 月 $300 以上の従量課金がある → 偽（**$3.03**・しきい値の1%）
3. オフライン必須 → 偽

## 4. 判定と、代わりにやること

**購入しない。** 3090/4000 Ada の 24GB/20GB VRAM が業務価値を持つのは上の3条件のどれかが真になった時だけ。
再調査の条件も P-0125 と同じ: 従量課金が月$300超 / 外に出せない機密業務の発生 / オフライン必須化。

代わりに効くこと（コストゼロ）:
1. **委託率の改善** — ハード購入より効果が桁違いに大きい（先行判定と同一の結論）
2. **現状維持** — Groq / DeepSeek / OpenRouter / Kimi で月数百円
