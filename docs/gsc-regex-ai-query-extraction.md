# GSC正規表現でAIクエリ抽出 [X-0004]

## 概要

Google Search Console の「検索パフォーマンス」レポートには、**フィルタ → 検索キーワード → カスタム（正規表現）** でクエリを絞り込む機能がある。
本ドキュメントは、この正規表現フィルタを使って **AI Overview に引用されやすいクエリ**（疑問文系・依頼文系）を抽出し、コンテンツ改善に活用するためのパターン集である。

## GSC 正規表現フィルタの制約

- クエリ全体に対する部分一致（暗黙の `.*` が前後に付く）
- 日本語（Unicode）対応
- 大文字小文字は区別しない（Google 検索の仕様に準じる）
- パターン内の空白はリテラルとして扱われる（OR は `|` で明示）
- **1 フィルタに 1 パターンのみ**（複数フィルタを AND 追加できる）
- パターン長の明示的な上限はないが、実用上 200 文字以内が無難

## 疑問文系パターン（Question / Informational）

AI Overview が最も引用しやすいクエリ。How-to・定義・比較・料金などの情報探索意図を持つクエリを抽出する。

## LLMO（Large Language Model Optimization）複合パターン

以下の複合パターンは、AI Overview の引用を最大化するために複数の意図を組み合わせる。

### L1: ブース制作 How-to（AI回答率 極高）

```
展示会|ブース|イベント|小間|出展
.*(作り方|方法|手順|コツ|ノウハウ|進め方|費用|料金|予算|相場|おすすめ|選び方)
```

**用途**: 展示会ブース業界に特化した How-to + 料金の複合クエリ。最も実用的。

### L2: 業種別AIクエリ（製造業・医療・飲食 etc.）

```
製造業|医療|ヘルスケア|介護|食品|飲食|美容|コスメ|教育|IT|テクノロジー
.*(展示会|ブース|イベント|見本市)
.*(作り方|方法|料金|おすすめ|事例|成功)
```

**用途**: 業種別の展示会ブース・イベント出展でAIに取り上げられやすいクエリ。

## GSC での設定手順

### 手順（Web UI）

1. **Google Search Console** にアクセス（`https://search.google.com/search-console`）
2. 対象プロパティ（`https://www.orgiast.jp` 等）を選択
3. 左メニューから **検索パフォーマンス** を開く
4. 上部の **＋新しいフィルタ** → **検索キーワード** → **カスタム（正規表現）** を選択
5. 上記のパターンを入力
6. 日付範囲を **直近 3 ヶ月** に設定
7. 結果を CSV エクスポートし、`tools/ai-query-extract.mjs --gsc <csv>` で LLMO 分析

### 複数パターンの適用方法

GSC では 1 フィルタに 1 パターンのため、複数のパターンを試すには：

- **方法 A**: パターンを 1 つずつ適用し、データを個別にエクスポート
- **方法 B**: 複数の正規表現を `|` で結合し、1 つのフィルタで広く抽出 → 後で `ai-query-extract.mjs` で分類

**推奨**: まず **方法 B** で広く抽出し、CSV をツールで分類する。

```
# 全疑問文系（1フィルタ）
作り方|方法|手順|コツ|ノウハウ|とは|料金|費用|価格|相場|比較|違い|メリット|おすすめ|選び方|なぜ|理由|条件|いつ|事例

# 全依頼文系（別フィルタ）
見積もり|資料請求|カタログ|申込|予約|相談|問い合わせ|依頼
```

### 分析ツールとの連携

エクスポートした CSV を既存の `tools/ai-query-extract.mjs` で分析：

```bash
# GSC CSV を読み込み、クエリ意図を自動分類
node tools/ai-query-extract.mjs --gsc queries.csv --llmo

# JSON 出力して詳細分析
node tools/ai-query-extract.mjs --gsc queries.csv --llmo --json

# 低IMP フィルタ（200 IMP 未満を除外）
node tools/ai-query-extract.mjs --gsc queries.csv --min-imp 200 --top 30
```

## AI Overview に引用されるためのクエリ別コンテンツ設計

抽出したクエリごとに以下のコンテンツ戦略を適用する。

| クエリ意図 | 推奨コンテンツ形式 | AI Overview が引用しやすい構造 |
|-----------|-----------------|--------------------------|
| How-to | ステップバイステップガイド | 番号付きリスト、各ステップに見出し |
| 定義（とは） | 解説記事（What-is） | 冒頭1文で定義、図解、箇条書き |
| 比較 | 比較表・比較記事 | 表形式、メリット/デメリット対比 |
| 料金 | 料金表・価格ガイド | 金額の範囲、オプション別価格 |
| おすすめ | ランキング形式 | 順位付きリスト、理由付き |
| 理由 | 理由解説 | 「理由1・理由2…」の構成 |
| 事例 | 事例紹介 | 問題→解決→結果のストーリー |
| 条件 | チェックリスト | 箇条書き、必須条件の一覧 |

## 定期モニタリング

収集したクエリの推移を追跡するために、月1回の GSC データエクスポートと `ai-query-extract.mjs` 分析を推奨する。

```bash
# 月次分析レポート生成
node tools/ai-query-extract.mjs --gsc monthly-queries.csv --llmo --json > reports/gsc-llmo-$(date +%Y%m).json
```
