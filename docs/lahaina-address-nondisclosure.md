対象 TODO: next-session #10「代表取締役の住所非表示措置を申し出るか（引き継ぎ書では「希望する」、費用・時期は司法書士回答待ち）」

## 結論

**申し出る。かつ、可能なら「設立の登記と同時」に申し出る（＝今が唯一の好機）。**

引き継ぎ書の「希望する」を、制度要件の一次情報照合のうえで方針として確定させた。TODO が残していた「費用・時期は司法書士回答待ち」は、**① 設立登記が既に申請済みか ② 追加報酬額 ③ 反映時期** の3点に収束する（§5 に質問文）。

## 1. なぜ「今」しかないのか（決定の核）

住所非表示措置は**単独では申し出られない**。法務省ページ原文:

> 設立の登記や代表取締役等の就任の登記、代表取締役等の住所移転による変更の登記など、代表取締役等の住所が登記されることとなる登記の申請と同時にする場合に限り申し出ることができます。

加えて、重任の登記・本店を管轄外に移転した場合の新本店所在における登記で、**既登記の住所から変更がない場合**も申出可。

ラハイナは今まさに**設立の登記**の最中にある（未送信の Gmail 下書きの件名が「設立登記の進捗確認・払込証明の送付・証明書発行のお願い」＝申請の前段階）。したがって:

- **設立登記を出すその瞬間が、追加コスト最小・書類が最も揃う唯一の機会。**
- 逃すと次の機会は「代表取締役等の住所移転による変更の登記」（＝代表者が引っ越すとき）か「重任の登記」（通常は任期満了＝2年後）。

## 2. 制度の実測（一次情報のみ）

| 項目 | 実測 | 出典 |
|---|---|---|
| 対象 | **株式会社**の代表取締役・代表執行役・代表清算人の住所（持分会社の代表社員等は対象外） | 法務省 |
| 表示範囲 | **最小行政区画まで**（市区町村／東京都は特別区／指定都市は区）。番地・建物名は登記事項証明書等に出ない | 法務省 |
| 対象となる住所 | 申出と併せて申請される登記によって記録される住所に限られる | 法務省 |
| 申出タイミング | 上記の同時申請のみ（**単独申請は不可**） | 法務省 |
| 手数料・登録免許税 | **法務省ページに記載なし**（＝措置自体に国へ払う費用は無い）。同時に行う登記の登録免許税は別途 | 法務省 |
| 施行日 | 令和6年10月1日（商業登記規則等の一部を改正する省令＝令和6年法務省令第28号） | 法務省 |
| 非上場会社の必要書類 | (1) 本店所在場所の実在性を証する書面（**本店宛に配達証明郵便で送付されたことを証する書面**＝配達証明書＋郵便物受領証、または**資格者代理人による実在性確認書面**）／(2) 代表取締役等の氏名・住所が記載された**市町村長等の証明書**（同時申請の登記申請書に添付済みなら不要）／(3) **実質的支配者の本人特定事項を証する書面**（犯収法に基づく確認記録の写し、公証人法の認証を受けた供述書面、定款認証時の申告受理及び認証証明書など。**実質的支配者リストの保管申出をしていれば不要**） | 法務省 |
| 上場会社の必要書類 | 「株式が上場されていることを認めるに足りる書面」のみ。既に措置済みなら添付不要 | 法務省 |
| 申請書への記載 | 「代表取締役等住所非表示措置を希望する旨」＋対象者の資格・氏名・住所。オンラインは「その他の申請書記載事項」 | 法務省 |
| 終了（非表示をやめる） | 職権終了の事由4つ＝①希望しない旨の申出（**単独で可**）②本店所在場所の実在性が認められない場合 ③上場会社でなくなった場合 ④閉鎖登記記録に復活事由がある場合 | 法務省 |
| 継続・失効の罠 | 住所が同一のまま登記される場合（住所変更のない重任・本店移転の新本店登記）は**申出なしで措置が継続**。逆に**住所変更がある登記では改めて申出が必要**で、申出せずに申請すると**新住所は非表示にならない** | 法務省 |

## 3. ラハイナへの当てはめ（3点セットの手当て）

| 必要書類 | 新設の設立ならどうなるか | 本セッションでの状態 |
|---|---|---|
| (1) 本店所在場所の実在性 | 本店宛の配達証明郵便はまだ届いていないのが通常 → **受任司法書士の「実在性確認書面」で代替**するのが最短 | **未確認**（本店所在地が宿か別住所かも未確認） |
| (2) 代表者の氏名・住所の証明 | 設立登記の申請書に住民票等を添付済みなら**追加不要** | **未確認** |
| (3) 実質的支配者 | 設立なら**定款認証時の「実質的支配者情報申告受理及び認証証明書」**がそのまま使える | **未確認**（設立手続で取得済みのはず） |

→ **新設の設立登記は、3点のうち (3) が既に手元にあるのが通常**で、この制度を使うのに最も有利なタイミング。追加で集める書類は実質 (1) だけになりやすい。

## 4. 費用・手間の比較（3案）

| | 案A: 設立登記と同時に申し出る（**推奨**） | 案B: 申し出ない | 案C: 後日（住所変更・重任登記のとき）に申し出る |
|---|---|---|---|
| 国へ払う費用 | 0円（措置自体） | 0円 | 0円 |
| 司法書士報酬（追加分） | 相場 **1〜3万円**（設立セットに含む／0円の事務所もある） | 0円 | 同程度＋**その時の登記の報酬と登録免許税**（住所変更なら1万円〜）が別途 |
| 必要書類の手間 | 3点。新設なので (3) は取得済み・(2) は流用可 → 実質 (1) のみ | なし | 3点を改めて手配＋引っ越し／重任の登記費用 |
| 得られる効果 | 以後発行される登記事項証明書等で**番地以降が非表示** | 代表者の自宅番地が誰でも取得できる状態が続く | 遅れて同じ効果 |
| 主なリスク | 銀行・不動産取引で住民票等の**追加提出を求められる**（法務省が明記） | 住所特定・DM・押しかけ等のリスクが残る | **次は2年後**。それまで住所が公開され続ける |

**推奨は案A。** 案B は「0円で済む」以外の利点がない。案C は同じ効果をより高い手間と遅延で買うことになる。

※報酬1〜3万円は複数の司法書士事務所が公表している追加報酬額の幅（二次情報）。確定額は司法書士回答待ち。
