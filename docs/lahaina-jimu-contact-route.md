## 結論（決定）

**司法書士への連絡は「Gmail 下書きの直送（メール）」を唯一の経路にする。伊藤氏経由 LINE では司法書士へ依頼しない。**

| 相手 | 経路 | 使うもの |
|---|---|---|
| 司法書士 中央ライズアクロス | **メール直送のみ** | 既存 Gmail 下書き（`kaisha-setsuritsu@riseacross.com` 宛） |
| 伊藤和晃氏 | LINE「ラハイナ PJ(7)」のみ | 送付文書集 第2章（保健所・口座・代金・OTA） |

- 司法書士への依頼（登記進捗・払込証明・住所非表示・証明書発行）は **メールにだけ載せる**。
- 伊藤氏への LINE には **司法書士への依頼を載せない**（第2章【2】は「司法書士へ確認中」という *報告* であって依頼ではない）。
- → 同じ依頼が メール と LINE の両方から司法書士へ届く経路が **構造的に消える** ＝ 二重送信のリスクを経路設計でゼロにする。

## なぜメール直送なのか（実データに基づく理由）

1. **宛先が確定している（直送可能）**。送付文書集 第1章に `kaisha-setsuritsu@riseacross.com`
   （司法書士法人中央ライズアクロス 久保田様／cc 高橋様）と明記。中間者を挟む必要が無い。
2. **質問の性質が「司法書士にしか答えられない専門事項」**。住所非表示措置の可否・必要書類・費用、登記完了日、
   証明書の発行部数は司法書士業務の範囲。伊藤氏（三洋環境側の窓口）は代弁できない ＝ 経由すると往復が1回増える。
3. **譲渡日 10/16 まで残り2日**（本日 10/14）。往復回数を最小化できる直送が有利。
4. **証跡が残る**。メールは送信記録・日時・宛先が残り、後で「いつ何を依頼したか」を参照できる。
   LINE は伊藤氏の伝達に依存し、こちら側に一次記録が残らない。
5. **文面がすでにメール形式で完成している**（宛名・件名・署名・送付先住所入り）。LINE に流すと形式が合わない。
6. **送付文書集 第0章の表も同じ設計**（司法書士＝「メール（Gmail下書きあり）」／伊藤＝「LINE『ラハイナ PJ(7)』」）。
   2026-10-13 の引継ぎメモが「伊藤氏経由 LINE で送る方針」と揺れていたが、**正本（送付文書集）は直送**。
   本決定はその正本に合わせて揺れを解消するもの。

## 二重送信を型で防ぐ（確定後の運用）

- 司法書士への依頼文を **伊藤氏へ LINE で転送しない**。第2章には司法書士への依頼文を載せない（現在も載っていない）。
- 送信が済んだら、下書きは Gmail 上で `DRAFT` から消える（＝「未送信の下書きが残っている」という誤読の元が消える）。
- 次に司法書士へ連絡する用事ができたときも、**同じメールスレッド**（threadId `1a124caf7832546c`）に返信で足す。
  新しい宛先や LINE を増やさない。
