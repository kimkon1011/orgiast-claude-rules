## 3. プレスリリース① 営業継続と新運営開始のお知らせ

### リード文
ペットと泊まれるプチホテル「ラハイナ」（所在地：岡山県瀬戸内市牛窓町鹿忍6348-6）は、2026年10月16日付で三洋環境株式会社から株式会社ラハイナ（代表取締役：野村功勇）へと事業が譲受され、新体制のもと営業を開始いたします。瀬戸内海を一望できる全6室のプライベートな空間と、約2,800㎡の敷地を活かしたドッグランを備え、愛犬と飼い主様が安心して過ごせる宿泊体験を今後も提供してまいります。

### 本文
**■ 事業譲受の背景と今後の運営について**  
岡山県瀬戸内市牛窓町の西脇ビーチ手前に位置する「ワンちゃんと泊まる宿 ラハイナ」は、全室禁煙・空気清浄機完備の清潔な空間と、瀬戸内の自然を満喫できる宿泊施設として親しまれてまいりました。この度、2026年10月16日付で株式会社ラハイナが事業を譲受し、営業を継続する運びとなりました。これまでの安心・安全な宿泊環境を守りつつ、より充実したサービスと地域資源を活かした体験価値の提供を目指してまいります。

**■ 施設の特徴**  
* **瀬戸内海を一望する客室:** 全6室・3タイプの部屋から選択可能。各室から穏やかな瀬戸内の海を望めます。全室禁煙（電子タバコ含む）で、空気清浄機および充実したワンちゃん用アメニティを完備しています。
* **約2,800㎡の起伏に富んだドッグラン:** 敷地面積約2,800㎡の広大なドッグランは、傾斜のある起伏に富んだ造りで、ワンちゃんが自然の中で思い切り走り回ることができます。牛窓の海岸へも車で10分の好アクセスです。
* **地元・牛窓の食材を活かしたお食事:** 地元岡山・牛窓の食材を使用し、季節に合わせたお料理を提供いたします（夏季はバーベキュー、冬季はお鍋）。

**■ 年末年始の予約受付について**  
2026年12月30日(水)〜2027年1月3日(日)の年末年始宿泊予約は、2026年10月25日(日)正午より電話受付にて開始いたします。

### 写真指定
