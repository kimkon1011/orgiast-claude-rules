### 01 token-savior

- **評価:** 既存の compact 系ツールで同等の効果あり。VS Code 拡張の追加価値は限定的
- **推奨:** △ 優先導入不要

### 02 claude-token-efficient
- **概要:** CLAUDE.md に冗長さを抑える 11 ルールを追加
- **既存対応:** §1.13（トークン効率）・§1.17（費用対効果）・§1.13.1（effortLevel）で大部分をカバー
- **gap:** 「質問文を短く」「背景説明を削減」「回答は結論から」など caveman レベルの明示ルールが §1.13 の「出力は Caveman」1文に集約されており、11項目の内訳がない
- **推奨:** ○ `docs/token-efficient-rules.md` として 11 ルールの内訳を追加

### 03 caveman
