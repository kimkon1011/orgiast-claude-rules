# 100問測定の再開手順（未実行）

対象は次セッション原文 X-0006「6ヶ月AEO」。同題名の既存資料は X-0007 にある。別題名の X-0006 資料とは分ける。

prompts-100.csv は既存20問×5文脈の新規計画。過去の105問とは別セットであり、旧結果の続きとして合算しない。文脈変種は独立した100意図ではない。指名20問と非指名80問を分け、社名を質問に含む比較質問も別集計する。

現セッションでは外部送信・課金禁止のため実行しない。対象URLの稼働やブース制作サイトの正規URLも未確認。ネットワーク実行が許可された段階で公式サイトの事業・正規URLを確認し、検索対応の非Claudeプロバイダーを固定する。Claude API/CLIへの分岐やフォールバックは設けない。

1. モデル・検索有無・日時・対象URL・地域・言語を固定し、各問を新規会話で3回実行する（1モデル300応答）。複数モデルは別集計。
2. prompt_id、trial、完全な質問と回答、回答が提示した引用URL、モデル識別子、検索条件、エラーを保存する。失敗を否定回答や引用なしとして扱わない。
3. 社名言及、公式URL引用、第三者URL引用、情報正確性を別々に判定。URLのホストを厳密照合し、文字列の部分一致で公式と判定しない。引用URLの存在だけでは引用先の根拠性は証明できないため、人手で回答との対応を確認する。
4. 公式URL引用率は「公式URLを実際に引用した有効応答数 / 有効応答数」。実行率は「有効応答数 / 予定300応答」。未実行をゼロ引用として分母に混ぜない。指名・非指名・各カテゴリを別報告する。
5. 正確性は確認済み公式情報に照合し、未確認項目は不明とする。旧レポートの83.3%は社名言及とURL引用が混在し、そのまま採用しない。
6. 競合は回答全文から社名・公式ドメインを正規化し、応答単位の登場数と引用数を別集計して上位10社を作る。既存候補表を測定上位10社として扱わない。

完了条件は全問の実応答・試行数・エラー内訳と引用根拠が検証可能なこと。現状は準備完了、実測未完了。
