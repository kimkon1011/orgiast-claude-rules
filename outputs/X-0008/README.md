# X-0008 出力ディレクトリ — コーディングエージェントと毎日1本のSEOガイド

このディレクトリは、AIニュース提案 X-0008「コーディングエージェントと毎日1本のSEOガイドでサイトを成長」の
出力成果物を置く場所です。
毎日1本、GSC高IMP低CTRキーワードをもとに高品質なSEOガイドを生成します。

## ディレクトリ構造

```
outputs/X-0008/
├── README.md          # 本解説
├── ledger.json        # 生成履歴（キーワード・日付・ファイル名）
└── guides/            # 生成されたSEOガイド
    ├── 2026-11-10-{slug}.md
    └── ...
```

## ワークフロー

```
毎朝の自動実行:
1. GSCデータ（CSVエクスポートまたはgsc-keyword-finderのJSON）を読み込む
2. 未カバーで優先度の高いキーワードを1件選択
3. 安価AI（gemini/deepseek/groq）でSEOガイドを生成
4. 内部リンク・CTAを追加してguides/に保存
5. ledger.jsonに生成履歴を記録
```

## キーワード選択基準

- 表示回数≥1,000 / 掲載順位≥30位 / CTR≤5% の条件を基本とする
- 展示会ブース関連キーワード（展示会、ブース、イベント、出展、小間、装飾、設営、施工）を優先
- 優先度スコア = impressions × (1 - ctr) × max(30, 100 - position) / 100

## 生成ガイドの構造

各ガイドは以下の構造で生成されます:

```
---
frontmatter（日付・キーワード・GSCデータ）
---

# タイトル（キーワード含む）

導入文（100-150字）

## H2見出し1
本文

## H2見出し2
本文

...

## まとめ

---

## 関連サービス（内部リンク）
- サービスページへのリンク

---

### この記事を書いた人
CTA（お問い合わせ）
```

## 使用ツール

- `tools/daily-seo-guide.mjs` — メインのガイド生成ツール
- `tools/llm-ask.mjs` — 安価AIへの問い合わせ
- `tools/gsc-keyword-finder.mjs` — GSCデータからのキーワード抽出

## 測定と改善サイクル

1. 毎日実行してガイドを生成
2. 生成されたガイドをサイトに追加
3. 7-14日後にGSCで掲載順位・CTRの変化を確認
4. ガイドの構成・キーワード選択ロジックを反復改善
