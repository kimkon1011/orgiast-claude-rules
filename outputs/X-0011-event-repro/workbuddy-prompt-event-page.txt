# WorkBuddy Code 投入プロンプト — イベント情報ページ再現

## Codeタブ設定（実行前に選択）
- Template: Website
- Agents: Frontend Developer + UI Designer
- Model / thinking: Hy4 / High thinking
- Attachments: `orgiast-event-desktop.png` を必須添付。利用許諾済みのイベント写真・ロゴがある場合だけ追加添付
- このパッケージはWorkBuddy未認証環境で作成した再現用入力であり、WorkBuddy上での実行済み成果物ではない

## スクリーンショット参照
添付した `orgiast-event-desktop.png` をデザイン言語の参照元とする。内容を複製するのではなく、黒い二段ナビゲーション、シアンのアクセント、白い余白、円形サムネイル、点線区切り、情報密度の高い2カラムという視覚特徴をイベント詳細ページへ展開する。

## ユースケース
イベント詳細ページ — 過去イベント名刺やフライヤーのスキャンから出展情報ページを生成

## 構造指定
skip-link + site-header（ブランド、ナビ、問い合わせ）+ event-hero（タイトル、日時、会場、CTA）+ overview + schedule + local-map + gallery + register + footer

## ブランド指定
Orgiastらしい黒 #101417、シアン #00afd5、濃いシアン #007e9d、白 #ffffff を基本にする。電話番号だけライム色を補助的に使う。角丸やドロップシャドウを多用せず、直線・点線・タイポグラフィで端正に構成する。

## レイアウト指定
最大幅1080px。デスクトップはヒーロー/概要/アクセス/申込を2カラム、実績を3カラム、プログラムを縦タイムラインにする。850px以下は1カラム。520px以下でも横スクロールを発生させず、CTAとフォームを全幅にする。

## インタラクティブ要素
モバイルメニュー（aria-expanded同期、リンク選択で閉じる）、ページ内スムーススクロール（reduced-motion尊重）、フォームのblur/submitバリデーション、フォーカス移動、role=status。外部API、CDN、Webフォント、Google Mapsは使用せず、地図はHTML/CSSの模式図と住所テキストで表現する。

## コンポーネント一覧
1. イベントヘッダー（日時/会場/タイトル、背景グラデーション）
2. 概要セクション（テキスト+キービジュアル）
3. タイムテーブル（時間・セッション名・登壇者）
4. アクセスマップ（ローカル完結の模式図＋住所＋公共交通）
5. 実績ギャラリー（CSSビジュアルまたは添付済みローカル画像）
6. 参加申込フォーム（会社名/氏名/メール/電話/備考）
7. フッター（主催者情報+プライバシーリンク）

- キャッチ: 伝わるブースは、設計から変わる。
- 日時: 2026年12月4日（金）13:30

- 参加: 無料・事前予約制・定員80名

- フォーム: 会社名、氏名、メール、質問（送信はデモで外部送信しない）

## 技術要件
セマンティックHTML5 + CSS3 + Vanilla JSのみ。ビルド不要で `index.html` を直接開いて動くこと。外部通信・外部依存なし。CSS custom properties、clamp、gridを使用可。JS無効時も情報を読める。Chrome/Edge最新版を主対象とする。

## 出力形式
- `index.html`、`styles.css`、`app.js` の3ファイル
- レスポンシブ対応
- アクセシビリティ対応（ランドマーク、見出し階層、skip-link、aria-expanded、aria-live/status、ラベル、キーボードフォーカス、十分なコントラスト、prefers-reduced-motion）
- 日本語テキストは実際のコンテンツで記入（プレースホルダー不可）

## 生成後に必ず提示するレビュー表
次の列を持つ表を出す: 対象 / 参照スクショの特徴 / 生成結果 / 差分 / 最適化。最低でもヘッダー、色、書体、余白、ヒーロー、情報階層、モバイルナビ、フォーム、アクセシビリティを比較する。続けて、ファイル構成、desktop 1440x1000 と mobile 390x844 のプレビュー、メニュー開閉、アンカー遷移、未入力/不正メール/正常入力の検証結果を提示する。実行できなかった検証は未実施と明記し、成功と推測しない。
