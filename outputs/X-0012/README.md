## 検証基準（証拠ゲート）

本提案の検証は以下の基準で行う:

1. ✅ 各スキルの作成者・インストールコマンド・バージョンが明記されている
2. ✅ 各スキルの主要機能と出力形式が説明されている
3. ✅ オージャスト固有のユースケースが各スキルについて定義されている
4. ✅ 週次マイルストーンを含む実装計画がある
5. ✅ スキル間の連携・選択基準が示されている
6. ✅ 期待効果が数値で示されている
7. ✅ 制約・注意点（Node要件・API費用・競合など）が明記されている
