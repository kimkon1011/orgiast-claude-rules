# X-0014: オージャストユースケース分析

2026-11-09 自動セッションで作成。株式会社オージャストの展示会ブース・イベントサイトに特化した 5 つのユースケースとその生成戦略。

---

## ユースケース 1: 標準ブース提案LP

**目的**: ブース写真・レイアウト図のスクショから提案先用ランディングページを生成

**スクショ準備**:
- ブース全景写真（複数アングル）
- レイアウト平面図（PDFまたは画像）
- 過去の提案書（Word/PDF）のキーページ
- 参考となる競合ブースの写真

**WorkBuddy 設定**:
| 項目 | 設定値 |
|---|---|
| テンプレート | Website |
| エージェント | Frontend Developer + UI Designer |
| 思考モード | Hy4 (高思考) |
| 生成モード | full |

**アウトプット例**: 7セクションLP（hero/about/gallery/features/CTA/footer）＋レスポンシブ対応

**メリット**: ブース施工の実績写真をそのままWebデザインに転用でき、提案のターンアラウンドを 3→1 日に短縮

---

## ユースケース 2: イベント詳細ページ

**目的**: イベントフライヤー・名刺スキャンから出展情報ページを生成

**スクショ準備**:
- イベントフライヤー（PDF/画像）
- 主催者名刺（登壇者情報）
- 過去の出展案内文書
- 会場マップ（画像）

**WorkBuddy 設定**:
| 項目 | 設定値 |
|---|---|
| テンプレート | Website |
| エージェント | Frontend Developer |
| 思考モード | Hy4 |
| 生成モード | scaffold → 手動調整後 full |

**アウトプット例**: イベントヘッダー＋概要＋タイムテーブル＋アクセスマップ＋フォーム

**メリット**: 毎月複数のイベント出展があるオージャストで、イベントごとの専用ページを統一品質で生成

---

## ユースケース 3: 施工実績ギャラリー

**目的**: パンフレットスキャンから施工実績一覧を生成

**スクショ準備**:
- 会社パンフレット全ページ
- 施工事例カタログ
- ブース完成写真（各案件1枚以上）

**WorkBuddy 設定**:
| 項目 | 設定値 |
|---|---|
| テンプレート | Website |
| エージェント | UI Designer |
| 思考モード | Hy4 |
| 生成モード | full |

**アウトプット例**: フィルター付きグリッド＋モーダル詳細＋ページネーション

**メリット**: 新規問合せ時に施工実績をすぐに見せられる。カテゴリフィルターで「飲食系」「電機系」などの絞り込みに対応

## ユースケース 4: お問い合わせフォーム

**目的**: 既存フォームのスクショからレスポンシブ問合せフォームを生成

**スクショ準備**:
- 既存サイトのお問い合わせフォームスクショ
- 現在のフォーム送信先メールアドレス・API仕様
- 必須項目一覧

**WorkBuddy 設定**:
| 項目 | 設定値 |
|---|---|
| テンプレート | Website |
| エージェント | Frontend Developer |
| 思考モード | 標準 or Hy4 |
| 生成モード | full |

**アウトプット例**: 7フィールドフォーム＋バリデーション＋送信完了トースト

**メリット**: スパム対策（Honeypot・レート制限）が組み込まれた安全なフォームをスクショから直接生成

---

**スクショ準備**:

- 見積比較PDFの該当ページ
- 各プランの特徴一覧

**WorkBuddy 設定**:
| 項目 | 設定値 |
|---|---|
| テンプレート | Website |
| エージェント | Frontend Developer + UI Designer |
| 思考モード | Hy4 |
| 生成モード | full |

**アウトプット例**: ソート可能テーブル＋カードビュー切替＋CSVエクスポート

**メリット**: 「スモール」「スタンダード」「プレミアム」などブースプランの比較を、顧客が自分でソート・フィルターできる形で提案できる
