# Craft Anything: 競合サイト再現構築 — 検証レポート

## 概要

AIニュース提案 [X-0015] **Craft Anythingによるサイト再現構築** の実証実験。
競合ブース制作会社のサイトを分析し、自社（オージャスト）の強みを加えた改善版を構築・比較した。

## ワークフロー

1. **競合選定**: 展示会ブース制作業界の主要企業から **サクラインターナショナル株式会社** を選定
2. **リサーチ**: 公式サイト (https://www.sakurain.co.jp/) をクリーンルーム方式で分析
3. **改善版構築**: 競合の優れた点を取り入れつつ、自社の強みを反映したランディングページをHTMLで作成
4. **比較検証**: 要素ごとに差分を評価

## 選定した競合: サクラインターナショナル

**選定理由**:
- 展示会ブース業界で確固たる地位（売上71億円、大手クライアント多数）
- 「RGV（Real × Glocal × Virtual）」の3軸フレームワークが明確
- SRDS2（リユーザブルディスプレイシステム）という自社リユーザブル製品を持つ → OrgiastのRe:ブースと直接比較可能
- Webサイトがプロフェッショナルで情報設計が明確

## Orgiast（自社）の強み（今回反映した要素）

| 要素 | 反映箇所 | 競合との差別化 |
|------|----------|---------------|
| **Re:ブース** | ヒーローセクション直下に専用スポットライト | 77% CO2削減・40%コスト削減の数値が明示的。競合SRDS2より環境価値を前面に |
| **社内イベント専門性** | 3軸フレームワークの1つ（EVENT）として独立 | サクラには無い社内イベント特化（総会・IPO・周年行事） |
| **IPOの鐘レンタル** | サービス詳細で明示 | 完全な差別化要素。競合には無いニッチな強み |
| **デジタルツール** | DIGITAL軸として独立・専用セクション | 自社開発アプリ（expo-apply等）を具体的に紹介 |
| **価格透明性** | Re:ブースの価格帯（初回100万円〜等）を明示 | 競合は価格非公開。見込み客の初期判断を容易に |
| **LINE相談** | コンタクトセクション | スマホから即相談可能。競合は電話・フォームのみ |
| **SNS連携** | フッターにInstagram/TikTok/Facebook | 競合よりカジュアルな情報発信チャネル |

## 改善点と採用したデザイン判断

### 競合から学んだ要素
- **白×濃紺のクリーンなカラースキーム**: 信頼感とプロフェッショナルさを表現
- **実績の数値化**: 競合と同等以上の具体性で信頼感を構築
- **認証・認定の可視化**: フッターだけでなく専用バーで強調
- **明確な情報階層**: ヒーロー → フレームワーク → 主力製品 → サービス詳細 → 実績 → 問い合わせ

### 自社の強みを加えた独自要素
- **Re:ブースの数値比較（CO2 77%削減・コスト40%削減）**: 環境意識の高い企業への訴求力
- **社内イベント特化の明確化**: 競合には無い独自ポジショニング
- **デジタルツールの可視化**: AI・アプリ開発力のPR
- **価格帯の明示**: BtoBでも透明性を重視
- **LINE導線**: スマホからの相談を可能に

### 今回の改善版で強化したOrgiastのフレームワーク
競合の「RGV（REAL/GLOCAL/VIRTUAL）」を参考にしつつ、
Orgiast独自の **「REAL（展示会ブース）/ EVENT（社内イベント）/ DIGITAL（デジタルツール）」** の3軸を定義。
