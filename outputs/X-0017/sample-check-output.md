# X-0017 キャッシュ状態チェック サンプル出力

実行例: `node tools/x0017-prompt-cache-usage.mjs --check`

```
=== キャッシュ状態チェックリスト ===

🔴 [model_switch] モデル切替
   説明: セッション中にモデルを切り替えていないか
   推奨: セッション開始時にモデルを決定し、終了まで変更しない。切替は会話ID再生成＝全キャッシュ消失。

🔴 [idle_time] 長時間中断
   説明: 1時間以上の休憩が入っていないか
   推奨: キャッシュTTLは約1時間。休憩前は /compact で要約保存。

🟡 [compact_timing] コンパクトのタイミング
   説明: コンパクトを自然な区切りで実行しているか
   推奨: コンパクトはPR作成後・タスク完了時など自然な区切りでのみ実行。「とりあえずコンパクト」は禁止。

🟡 [system_prompt] システムプロンプトの活用
   説明: CLAUDE.md/memoryに恒久設定を移せているか
   推奨: 毎回のプロンプト冒頭の前提説明はCLAUDE.mdに移す。システムプロンプトのキャッシュはモデル変更でのみ無効化。

🟢 [session_purpose] セッション1目的
   説明: 1つのセッションで1つの目的に集中しているか
   推奨: 複数目的は別セッションに分割。セッション開始時の目的設定を守る。

🟢 [check_usage] ヒット率確認
   説明: /usageでヒット率を定期的に確認しているか
   推奨: 2時間ごとに /usage を実行し、ヒット率が50%未満なら改善アクション。

全6項目 | 推奨アクションは各項目を参照
```
