# X-0020: Grok Bot監視頻度最適化によるトークン削減

## 概要

Grok Botの監視間隔を1分ごと（1日1440回）から15分ごと（1日96回）に変更し、チェック回数とトークン消費を約93%削減する提案。

## 主な変更点

- **監視頻度緩和**: 全監視対象を1分→15分（一部30-60分）に変更
- **段階的監視（2ステージ）**: 第1段階で変化検出のみ、変化時のみ第2段階で詳細分析
- **差分監視**: 前回確認時の状態スナップショットとの差分のみを取得
- **通知最適化**: 変化なし時はSTATUS: NO_CHANGEのみローカル記録、通知なし
