## 6つの推論コスト最適化手法

| # | 手法 | 原理 | 効果目安 |
|---|---|---|---|
| 1 | **プレフィックスキャッシング** | 同じトークンプレフィックス（システムプロンプト・共通指示）をKVキャッシュして再利用 | prefillコスト30〜90%削減 |
| 2 | **連続バッチング** | 終了リクエストを除去し待機リクエストを投入、GPUを遊ばせない | GPU利用率20〜50%向上 |
| 3 | **PagedAttention** | KVキャッシュを固定長ブロックに分割、非連続マッピングでメモリ断片化を防止 | メモリ利用率30〜60%改善 |
| 4 | **Chunked Prefill** | 長いprefillを分割しdecodeフェーズとインターリーブ、全体スループット向上 | 最大10倍のスループット |
| 5 | **投機的デコード** | 軽量ドラフトモデルが複数トークンを提案し、ターゲットモデルが検証 | レイテンシ1.5〜3倍改善 |
| 6 | **Prefill/Decode分離** | 特性の異なるprefill（compute-bound）とdecode（memory-bound）を別プールで実行 | 各フェーズ専用最適化で効率化 |


- レイテンシもprefill段階が不要なため約60〜80%短縮

## 株式会社オージャストでの試入手順

1. **共通プレフィックスの作成**: 展示会ブース制作の共通ブランドガイドライン・仕様テンプレートを1つのシステムプロンプトにまとめる
2. **キャッシュ対応クライアントの設定**: Anthropic API の `betas: ["prompt-caching"]` を有効化、または本ツールの簡易キャッシュストアを利用
3. **各イベントのカスタム部分のみ生成**: イベント名、日程、出展製品など可変部分だけをプロンプト末尾に追加
4. **削減率の測定**: プレフィックスあり／なしの同一ジョブを実行し、トークン消費・レイテンシ・コストを比較
5. **全6手法の評価**: 連続バッチング・PagedAttention・Chunked prefill はAPIプロバイダ側の設定、投機的デコード・分離デプロイは専用インフラで評価
