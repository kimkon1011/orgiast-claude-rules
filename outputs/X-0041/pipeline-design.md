# X-0041: AI 7役割委譲パイプライン — 展示会告知コンテンツ制作の完全自動化

## 概要

オージャストの展示会告知コンテンツ（orgiast.jp/works, /booth-construction 等のランディングページ・SEO記事・SNS投稿）を7つのAI役割で分担制作し、人件費を削減する。人間はテーマ決定・最終検品・承認のみ。

## 7役割の委譲設計

```
人間（kim）
  ├── Theme: テーマ決定（どの展示会の告知か）
  └── Final Inspection: 検品・承認
       │
       ▼
┌─────────────────────────────────────────────────────┐
│               AI 7役割委譲パイプライン               │
├─────────────────────────────────────────────────────┤
│ ① GrokBot: 市場調査                                │
│    展示会トレンド・競合施策・業界キーワードの収集     │
│  → ② Gemini: 競合分析                              │
│     競合サイトのコンテンツ戦略・SEOギャップ分析      │
│  → ③ Claude Code: 企画                            │
│     コンテンツ構成・キーワードマップ・配信計画       │
│  → ④ Codex/Gemini: 4000字執筆                     │
│     SEO記事・ランディングページ本文の生成            │
│  → ⑤ Claude: 検品                                 │
│     事実確認・引用検証・SEO基準チェック              │
│  → ⑥ Grok: X投稿30本                              │
│     展示会告知・業界トピック・導線投稿の量産         │
│  → ⑦ Gemini/Claude: 分析                          │
│     効果指標・改善点・次回サイクルへの反映           │
└─────────────────────────────────────────────────────┘
```

## 役割別詳細

### ① GrokBot 市場調査
| 項目 | 内容 |
|------|------|
| AI | Grok (xAI) — リアルタイム検索＋トレンド分析 |
| 入力 | 展示会テーマ・業界キーワード・ターゲット業種 |
| 出力 | 市場レポート（500〜1000字）：競合の展示会出展動向・業界ハッシュタグ・話題のトピック |
| コスト | ~$0.15/回（Grok API従量） |
| 禁止 | 市場に存在しない数字の生成・自社に不利益な情報の除外 |

### ② Gemini 競合分析
| 項目 | 内容 |
|------|------|
| AI | Gemini 2.0 Flash — 高速Web検索＋ページ解析 |
| 入力 | 競合5社のURL + ①の市場調査結果 |
| 出力 | 競合分析シート：SEO状況・コンテンツギャップ・差別化ポイント |
| コスト | ~$0.02/回（Gemini API） |
| 禁止 | 自社サイトの否定を目的とした分析・攻撃的表現 |

### ③ Claude Code 企画
| 項目 | 内容 |
|------|------|
| AI | Claude Code (Sonnet 5.5) — 構造化計画 |
| 入力 | ①+②の分析結果・テーマ・ターゲットKW |
| 出力 | コンテンツ企画書：記事構成（H1〜H4）・内部リンク計画・CTA設計 |
| コスト | ~$0.30/回（Claude Code従量） |
| 禁止 | 既存コンテンツと重複する見出し構造・実現不可能なCTA |

### ④ Codex/Gemini 4000字執筆
| 項目 | 内容 |
|------|------|
| AI | Codex (GPT-5.6 Sol) または Gemini 2.0 Pro |
| 入力 | ③のコンテンツ企画書 + 参考URL + トーン指示 |
| 出力 | 4000字のSEO記事本文（Markdown）＋メタデータ（title/description/KW） |
| コスト | ~$0.50/回（Codex定額枠内なら$0） |
| 禁止 | ハルシネーション・無断引用・他サイトの転載・KW詰め込み |

### ⑤ Claude 検品
| 項目 | 内容 |
|------|------|
| AI | Claude (Haiku 5.5) — 安価な検品専用 |
| 入力 | ④の記事本文 + 出典リスト + SEO基準 |
| 出力 | 検品レポート：事実正確性・出典確認・SEOスコア・修正箇所 |
| コスト | ~$0.05/回 |
| 禁止 | 「問題なし」とだけ書く・修正箇所を検出しない |

### ⑥ Grok X投稿30本
| 項目 | 内容 |
|------|------|
| AI | Grok (xAI) — XネイティブAPI |
| 入力 | ④の記事本文 + ⑤の検品結果 + 投稿トーン |
| 出力 | 30本のX投稿（1投稿あたり280〜400字）＋投稿スケジュール案 |
| コスト | ~$0.20/30本（Grok API） |
| 禁止 | 事実と異なる主張・過剰なセールス・スパム判定を受ける表現 |

### ⑦ Gemini/Claude 分析
| 項目 | 内容 |
|------|------|
| AI | Gemini 2.0 Flash（定量）+ Claude（定性） |
| 入力 | 全工程のログ + 投稿エンゲージメント + サイトアクセス |
| 出力 | サイクル分析レポート：改善点・担当AIの再調整・次回投資対効果 |
| コスト | ~$0.10/回 |
| 禁止 | 根拠のない「改善されました」結論・サンプル未達での統計主張 |

## 実装スケジュール

| Phase | 期間 | 内容 | 人間の作業 |
|-------|------|------|-----------|
| Phase 0 | 即日 | パイプライン設計・各AIのAPI接続確認 | 認証設定（1回） |
| Phase 1 | 1週目 | 既存展示会実績を題材に①〜⑤をテスト実行 | テーマ決定・検品 |
| Phase 2 | 2週目 | 本番展示会告知で①〜⑤の実運用開始 | リンク確認・承認 |
| Phase 3 | 3週目 | ⑥Grok X投稿の試験運用（手動承認モード） | 投稿承認 |
| Phase 4 | 4週目 | ⑦分析の導入 + 全工程のCI/CD自動化 | 月次レビュー |

## 制約・注意点

1. **事実の検証（⑤検品）は省略しない** — AI生成コンテンツの最も重要な安全弁
2. **X投稿（⑥）は手動承認モードで開始** — ブランド毀損リスクの最小化
3. **コストは全て従量制** — 月$10〜30の想定、オートチャージで上限設定推奨
4. **各AIのAPIキー管理** — 環境変数 + key-owners.json で一元管理
5. **外部送信（X投稿）は社内承認後** — 本プランでは出力のみ、送信は別工程
