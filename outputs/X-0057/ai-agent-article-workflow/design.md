# X-0057 AIエージェント記事制作ワークフロー 設計書

## 目的
AIエージェント（Codex/Claude/Gemini）に1回の指示で、記事ネタからWordPress公開までの全10工程を一括実行させる。
見本（サンプル事例）・役割定義・作業フローをワンセットで渡すことで、毎回の指示を削減する。

## 想定ユーザー
- オージャスト制作チーム（佐藤さんなど）が記事制作をAIに依頼する
- 入力: 記事テーマ（例: 「◯◯展示会のブース制作事例」）
- 出力: WordPress公開済み記事

## アーキテクチャ

```
記事テーマ
  │
  ├── [1] ニーズ分析と見出し構成 → 見出し案
  ├── [2] 記事本文執筆 → 本文Markdown
  ├── [3] サムネイル作成 → サムネ画像
  ├── [4] 挿入画像選定・生成 → 本文画像
  ├── [5] スクリーンショット・図版作成 → 図版
  ├── [6] 口コミ・Xポスト収集 → 引用素材
  ├── [7] WordPress投稿 → 下書き/公開
  ├── [8] 文字装飾・見出し設定 → 装飾済みHTML
  ├── [9] 内部リンク・外部リンク設定 → リンク埋め込み
  └── [10] メタ設定・SEO最適化 → 完了
```

## ファイル構成
```
outputs/X-0057/ai-agent-article-workflow/
├── design.md                   ← この設計書
├── README.md                   ← 使い方
├── sample-booth-case.md        ← 見本（既存ブース制作事例）
├── agent-role-definition.md    ← AIエージェントの役割定義
└── 10step-workflow.md          ← 10工程一括指示書
```

## 成功条件
- AIエージェントが見本・役割・ワークフローを読み、1回の指示で記事を完成させる
- 10工程のうち工程1〜6を自動生成、工程7〜10をWordPress操作可能な範囲で実行
- 制作時間: 従来の手作業比 80% 削減
