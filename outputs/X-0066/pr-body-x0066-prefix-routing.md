# AIニュース提案 [X-0066]: プレフィックス認識ルーティングでキャッシュヒット4.5%向上

## 概要

同一の静的プレフィックス（システムプロンプト・ツール定義）を持つリクエストを同じワーカーへルーティングする**プレフィックス認識ルーティング**を実装。ランダムルーティング（8ワーカー時12.5%）から約4.5%のシステム全体キャッシュヒット率向上を見込む。

## 提案の核

### 問題: ランダムルーティングの非効率

- KV キャッシュは同一プレフィックスが**同一ワーカー**に届いた場合のみヒット
- 8ワーカーでランダムルーティング: ヒット確率 = 1/8 = **12.5%**
- 残り87.5%は別ワーカーへ送られフル課金

### 解決: プレフィックス認識ルーティング

- プレフィックスのハッシュ値でワーカーを決定（一貫性ハッシュリング）
- 同一プレフィックス → 100%同一ワーカー
- ワーカー増減時も影響範囲 1/N に限定
