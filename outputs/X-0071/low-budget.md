# 初出展の小規模製造業が、装飾関連30万円・1小間で見積もりを比較する手順

原稿v3・未公開。以下はオージャストのコンテンツ検討用の仮想例であり、制作実績や販売価格ではありません。30万円は相場ではなく検討用の税込予算上限です。1小間の寸法・条件は主催者資料で確定してください。

初出展で専任担当者がおらず、見本展示と相談受付を両立したい製造業を想定します。最初に削る装飾を決めるより、予算に含める範囲をそろえて比較しましょう。本稿の30万円は装飾・印刷・輸送・設営・撤去等に充てる枠とし、出展料、旅費、人件費は別枠です。会社の総予算が30万円なら、別枠費用を先に引き、残額で成立するかを改めて確認します。

## 1. 発注条件を1枚にそろえる

担当者は主催者から小間図、出展要項、申請期限を集め、見本の寸法・重量、必要な電源、搬入方法を記入します。会場条件を確認できるまでは施工方法を確定しません。相談受付を優先するなら、展示品は代表品に絞る案を作り、説明する製品と来場者に持ち帰ってほしい情報を一つずつ書きます。

## 2. 同じ範囲で見積もりを依頼する

| 確認欄 | 見積もりで聞くこと |
| --- | --- |
| 造作・備品 | 壁、机、展示台の数量、レンタル期間、返却条件 |
| 印刷 | データ作成、校正、出力、貼付、差し替えの費用 |
| 電源・照明 | 申請や工事が誰の担当か、別請求があるか |
| 物流 | 往復輸送、荷受け、梱包、保管の有無 |
| 設営・撤去 | 作業範囲、会場指定作業、処分・返却の扱い |
| 変更 | 校了日、変更料、取消条件、税込総額 |

未記載の項目は無料とせず「未確認」とします。主催者パッケージを使う案と、必要な展示台等を追加する案を、同じ条件表で比較します。特定方式が必ず安いとは判断しません。

## 3. 上限を超えたときの判断を決める

仮に必須項目の見積額が税込27万円、変更用に確保したい枠が3万円なら合計30万円です。これは計算例で、実際の見積額ではありません。別途輸送費が2万円と判明したら合計32万円となり上限を超えます。印刷面数や追加什器を減らした再見積もりを取り、承認済み予算に戻るか確認します。会場の必須条件に関わる作業を予算合わせで省略しません。

## 4. 比較表に記入して発注可否を決める

以下は未記入の作業用表です。金額は税込にそろえ、同じ費用を二重に足さないよう見積書の項目番号も控えます。見積もりに含まれるものは「含む」、金額が分からないものは「未確認」と記入し、空欄を0円に置き換えません。

| 比較項目 | 案A | 案B |
| --- | --- | --- |
| 見積日・有効期限・対象小間 | 要記入 | 要記入 |
| 造作・備品・印刷の税込小計 | 要記入 | 要記入 |
| 電源・照明の別途費用 | 要記入 | 要記入 |
| 往復輸送・設営・撤去の別途費用 | 要記入 | 要記入 |
| 変更用に確保する枠 | 要記入 | 要記入 |
| 上記の合計と30万円との差額 | 要記入 | 要記入 |
| 別枠の出展料・旅費・人件費 | 要記入 | 要記入 |
| 未確認項目・回答者・回答期限 | 要記入 | 要記入 |

合計が30万円以下でも、必須費用に未確認があれば「判断保留」です。全項目が確認済みで、変更枠を含めた合計が上限以内なら承認者へ提示します。超過なら削減候補と失う機能を併記して再見積もりし、必須条件を満たせない場合は予算または出展計画を承認者と見直します。最安値だけで採用案を決めず、見本展示と相談受付が成立するかも照合します。

### 記入例: 輸送費が「含む」と「未確認」の2案

以下は表の使い方を示す架空の記入例です。業者の実見積もり・価格相場ではありません。単位は万円、全て税込とし、両案とも同じ展示内容・必要作業を依頼した想定です。

| 費目 | 案A | 案B |
| --- | --- | --- |
| 基本見積額（造作・備品・印刷） | 24 | 22 |
| 電源・照明の追加費用 | 1 | 1 |
| 往復輸送・設営・撤去 | 基本見積額24に含むと書面確認済み | 設営・撤去は22に含む、往復輸送は未確認 |
| 変更用の枠 | 3 | 3 |
| 確認済み金額と変更枠の合計 | 28 | 26＋未確認の輸送費 |
| 上限30との差 | 2の余裕 | 未確定（4の余裕とは判定しない） |
| 判断 | 別枠費用と展示機能も確認し、承認者へ提示 | 輸送費の回答まで保留 |

案Aの「含む」は追加0として計算しますが、サービスが無料という意味ではありません。基本見積額の該当項目番号を控え、輸送費を再び足さないようにします。案Bは見えている合計26だけで安いと判断できません。輸送費が仮に5と回答されたら合計31で、上限を1超えます。展示機能を維持できる削減候補で再見積もりを依頼し、合計が下がっても未確認項目が残れば保留を続けます。

これは比較の計算例で、案Aの発注や案Bの削減が実際に可能だと確認したものではありません。実際の表では別枠の出展料・旅費・人件費も記入し、会社の総予算に収まるか別途照合します。

## 5. 発注前に残すもの

担当者は「採用案、税込総額、別枠費用、未確認項目、回答期限、承認者」を1枚に記録します。未確認費用が残るなら、上限内と断定せず、回答を得てから発注判断をします。オージャストへ相談する際にも、この条件表を渡し、対応可否と正式見積もりを確認してください。本稿は同社の価格・納期・提供範囲を保証するものではありません。
