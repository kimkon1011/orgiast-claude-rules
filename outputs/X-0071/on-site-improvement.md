# 説明員2人の1小間ブースで受付が詰まるとき、次の時間帯に試す配置改善

原稿v3・未公開。説明員2人、1小間、見本展示と相談受付を行う製造業という仮想条件です。実在の案件や改善実績ではありません。成果を保証する手順ではなく、現場で原因を切り分けるための編集提案です。

「人は来るが話せない」とき、机の配置だけが原因とは限りません。説明が長い、受付と製品デモが重なる、資料を探して担当者が離れる、といった別の原因も記録してから変えましょう。

## 1. 変更前に詰まる場面を記録する

担当Aを受付、担当Bを説明と仮に分け、交代時の引き継ぎも決めます。まず同じ長さの観察枠で、受付件数、説明開始件数、待って離れた件数、説明員が不在になった場面を集計します。個人名や顔写真を記録する必要はありません。受付件数と説明開始件数の定義をそろえ、数えられなかった時間帯は欠測とします。

### この試行での数え方と記入欄

以下は実測結果ではなく、担当A/Bで事前に合意するための定義案です。同じ組の来場者を1件とし、一連の応対中の再質問は追加計数しません。再訪を識別できない場合はその限界を記し、個人を追跡するための情報は集めません。

- 受付件数: 担当者が用件を聞き始めた組の数。通行人や掲示を見るだけの人は含めません。
- 説明開始件数: 受付後に製品説明・相談を始めた組の数。受付を経ず説明した場合は別欄に残します。
- 待機離脱件数: 応対待ちと観察でき、応対開始前に離れた組の数。単なる通過か判別できない場合は不明欄に残します。

| 記録欄 | 変更前 | 変更後 |
| --- | --- | --- |
| 観察の開始・終了時刻 | 要記入 | 要記入 |
| A/Bの役割・変更した配置や文言 | 要記入 | 要記入 |
| 受付／説明開始／受付なし説明の件数 | 要記入 | 要記入 |
| 待機離脱／判別不明の件数 | 要記入 | 要記入 |
| 数えられなかった時間・理由 | 要記入 | 要記入 |
| 来場の波・交代・セミナー等の条件差 | 要記入 | 要記入 |

数えられなかった欄は「欠測」とし、実際に観察して0件だった欄と分けます。応対と計数を両立できなければ、応対を優先して欠測を残し、記憶で数を埋めません。観察枠をまたいだ受付と説明があるため、この集計の説明開始件数÷受付件数を、そのまま同じ来場者群の転換率と解釈しません。

## 2. 原因に対応する変更を一つ選ぶ

| 観察された場面 | 次に試す変更案 | 確認すること |
| --- | --- | --- |
| 受付とデモの人が同じ場所に集まる | 小間内で受付位置とデモ位置を分ける | 入り口から説明場所まで移動できるか |
| 資料を探して説明が止まる | 小間内の手が届く位置に資料をまとめる | 受付を離れる回数が変わるか |
| 何の展示か聞かれて説明が長くなる | 対象者と相談内容を示す案内文を試す | 質問内容と説明開始までの流れが変わるか |

会場担当者・主催者の許可範囲と自社責任者の確認が取れた変更だけを実施します。通路へのはみ出しや避難動線を塞ぐ配置は採用しません。固定物・電源・施工物の変更が必要なら、その場で動かさず施工担当へ確認します。

### 受付とデモが重なる場合の試し方

以下は配置改善の仮想案で、会場寸法に合わせた施工図ではありません。現状の机・見本・入口・固定物を紙に描き、担当Aが用件を聞く場所と、担当Bが見本を説明する場所を小間内で別々に印します。来場者が受付から見本へ移る経路と、説明中の人が退出する経路をたどり、重なる場所を確認します。入口が一つなら、退出する人を待たせる配置になっていないかも確認します。

最初の比較では、許可された可動受付机の位置だけを変え、見本、案内文、担当の役割はそろえます。机を動かさず案内位置だけを変えるなら、それを唯一の変更として記録します。Aは用件を聞いてBへ引き継ぎ、Bが応対中なら次の来場者へ待ち時間を確約せず、待つか後で戻るかを確認します。Aまで長い製品説明を始めて受付が無人になった場合は、その時間を配置の問題と分けて記録します。

開始前にA/Bが来場者役と説明員役を交代し、小間内だけで受付・引継ぎ・退出をたどります。展示品や固定物を動かさないと通れない、受付が通路へ出る、説明中の人が退出できない場合はこの案を試しません。開始後も同じ問題が起きたら試行を止め、問題がなかった元の配置へ戻せるか責任者に確認します。戻せない場合は別の配置を即興で試さず、責任者・施工担当へ相談します。

2人とも応対中なら、離脱を連続して観察できないことがあります。その時間は欠測として残し、離脱が減ったとの判断には使いません。配置を分ける余地がない場合も「変更未実施」と記録し、資料整理など別の原因に対応する一変更を次の試行候補にします。

## 3. 変更後も同じ定義で数える

仮に変更前後を各30分と決めたら、実施時刻、担当者、案内文、配置図、受付件数、説明開始件数、離脱件数、欠測時間を残します。30分は仮の観察枠で、来場者が少なければ比較材料が足りないと記録します。来場の波、セミナー終了、説明員交代が重なれば、その影響と配置の影響を分離できないため、配置が効いたとは断定しません。

## 4. 終了時の判断を翌回へ渡す

「継続候補」「元に戻す」「判断保留」のいずれかを選び、その理由と次に比べる条件を残します。受付は円滑でも製品説明が減るなら、目的に合っているかを再確認します。件数の増減だけで商談や売上が増えたとは扱いません。次回制作を相談する際は、匿名の集計、変更前後の配置図、現場で動かせなかった条件をオージャスト等の相談先に渡すと、検討する課題を共有できます。同社の対応範囲は個別確認が必要です。
