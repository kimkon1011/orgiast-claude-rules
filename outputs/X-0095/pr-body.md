# AIニュース提案 X-0095: セッションプレフィックス保護でキャッシュ96%

## 概要

セッションの先頭プレフィックス（ブランドガイド・過去事例・固定指示）を保護することで、プロンプトキャッシュのヒット率を96%に維持し、1.9Bトークンの処理をわずか3.1Mトークンの書き込みで実現する設計パターンを提案する。

## なぜ重要か

Anthropic prompt cachingの「20ブロック・ルックバック」制約により、セッションが長くなると先頭のキャッシュが無効化される。従来のキャッシュ戦略（X-0035）は単一リクエストや短期連続呼び出しを前提としており、**長期セッション（数十ターン以上）でのキャッシュ維持には特化していなかった**。本提案は、プレフィックスを完全に静的に保つ設計パターンにより、長期セッションでもキャッシュを維持する方法を提供する。
