# カレンダー空き日程の出し方（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: 以下の手順を読んで、ユーザーの「空いてる時間」「日程調整」「○日の空き」などの依頼に応えてください。判断ルールと手順は全てここに書かれています。シェルがある環境では専用スクリプトを優先し、ない環境（ChatGPTアプリ・Geminiアプリ等）ではカレンダー連携機能で同等の処理をしてください。

## 対象カレンダー

オージャストの業務カレンダーは**2本**あります。両方を必ず確認し、空き時間は両方の予定を合算して算出します。

| カレンダー | 用途 | 注意 |
|---|---|---|
| kim@orgiast.jp | 経営者個人の予定 | 全部含める |
| seisaku-team@orgiast.jp | 制作チームの予定 | kimが招待されていない打ち合わせも入っているので必須 |

片方だけ見ると、埋まっている枠を空きと誤案内します。

## 専用スクリプトがある場合（最優先）

`node tools/calendar-free-slots.mjs` が使える環境では、これを最優先で使います。

```sh
# オンライン（地域不問）の空きを取得
node tools/calendar-free-slots.mjs --from YYYY-MM-DD --to YYYY-MM-DD --mode online

# オフライン（例: 東京）の空きを取得
node tools/calendar-free-slots.mjs --from YYYY-MM-DD --to YYYY-MM-DD --mode offline --region 東京

# JSONで取得
node tools/calendar-free-slots.mjs --from YYYY-MM-DD --to YYYY-MM-DD --json
```

### 引数一覧

| 引数 | 既定値 | 説明 |
|---|---|---|
| `--from` | 今日 | 開始日（YYYY-MM-DD） |
| `--to` | 今日+6日 | 終了日 |
| `--mode` | online | online / offline |
| `--region` | 大阪 | offline時の地域 |
| `--start` | 09:00 | 営業開始時間 |
| `--end` | 18:00 | 営業終了時間 |
| `--slot` | 30 | スロット幅（分） |
| `--min` | 30 | この分数以上の連続空きだけ出す |
| `--calendars` | kim@…,seisaku-team@… | 対象カレンダー |
| `--json` | - | JSON出力 |
| `--fixture` | - | テスト用fixtureファイル |
| `--weekends` | - | 土日も含める |

## スクリプトがない場合（Geminiアプリ・ChatGPT等）

カレンダー連携機能（Gemini アプリの「@Google カレンダー」、ChatGPT の Google カレンダー連携など）で以下の2つのカレンダーを読み、下記ルールで手計算します。NotebookLM はカレンダーを読めないので、この手順には使えません。

- 使っているアカウントに2本のカレンダーの閲覧権限がないと読めません。読めないカレンダーがあれば、空きを推測で出さずに「○○のカレンダーが読めません」とユーザーに伝えてください。
- 片方だけで空きを出すのは禁止です（誤案内になります）。

1. **kim@orgiast.jp** の primary カレンダーを読む（イベント一覧を取得）
2. **seisaku-team@orgiast.jp** の primary カレンダーを読む
3. 両方のイベントを合算する

## 予定の分類ルール

| マーカー/状態 | 扱い |
|---|---|
| 【調整可】/【調節可】 | ブロックしない（重複可） |
| 【調整不可】 | 確定（ハードブロック） |
| マーカーなし | **確定扱い**（安全側） |
| transparency=transparent / free | ブロックしない |
| responseStatus=declined | ブロックしない（辞退済み） |

## 略字（タイトル接頭辞）

| コード | 意味 | バッファ |
|---|---|---|
| G: / G： | 訪問（外出先） | 前後±1時間バッファ（移動時間） |
| C: | クライアント来訪 | なし |
| M: | オンライン会議 | なし |
| I: | 取材 | なし |
| T: | タスク | なし |
| L: | 会場下見 | なし |
| P: | 提案 | なし |
| N①: | ネガチェック【調整可】 | なし（【調整可】で処理） |

## 地域判定

終日予定（all-day event）で1日の地域を決めます。

| 条件 | 地域 |
|---|---|
| kimの終日予定に地域名（東京/浜松/福岡等）あり | その地域 |
| 地域名のみの終日（例「東京」） | その地域（時間はブロックしない） |
| kimの終日に地域名なし、または全日予定なし | 大阪 |
| seisaku-teamの終日予定 | 地域判定に使わない |

### 東京出張の考慮（オフライン大阪の場合）

東京出張中（複数日の終日「東京出張」「東京」「東京○○」）と、その**前後±1日**も、大阪での面談候補から外します。

## 空き時間の計算手順

1. 期間の全予定を取得（終日含む）
2. 【調整可】/declined/transparent 以外を確定予定とする
3. G: の予定には前後±1時間のバッファを付ける
4. **09:00–18:00 を30分スロット**に分割
5. 確定予定を除外し、空きスロットを連続レンジに統合
6. オフライン指定時は地域が一致する日だけ候補化

## 出力例

```
オンライン候補:
11月10日(月) 10:00〜12:00、14:30〜18:00　※大阪
11月11日(火) 13:00〜18:00　※東京
```

## 土日祝の扱い

- 土日: 既定で除外（`--weekends` で含める）
- 祝日: 対象外（別途考慮が必要）
