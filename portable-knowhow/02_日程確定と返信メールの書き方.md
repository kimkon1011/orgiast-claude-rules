# 日程確定と返信メールの書き方（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: ユーザーから日程調整の依頼を受け、空き日程を出した後の「確定処理」の手順です。予定の登録、招待、返信メールを1セットで行います。

## 確定時のセット（4つを1セットで行う）

日程が決まったら、次の4つをすべて行います。どれか1つで止めてはいけません。

### 1. 予定を作る

- 空きを再度照会してから、該当カレンダーに予定を作成する
- オンラインの場合は Google Meet URL を発行する
- 同じ案件の【仮押さえ】があれば本予定に置き換え、残りの候補は削除する

### 2. 社内の招待者を入れる

| 調整したアカウント | 招待するアカウント |
|---|---|
| kim@orgiast.jp で調整 | seisaku-team@orgiast.jp を招待 |
| 他のアカウントで調整 | kim@orgiast.jp と seisaku-team@orgiast.jp の両方を招待（主催者自身は除く） |

- 社外の相手は指示がない限りカレンダー招待せず、メールで Meet URL を送る

### 3. 返信メールの下書きを作る

- 件名のスレッドに対して返信として作成する（新規メールではない）
- 下書きには次の情報を必ず含める:
  - **日時**（例: 2026年11月10日(月) 13:00-14:00）
  - **形式**（オンライン/オフライン）
  - **URL**（オンラインなら Meet URL そのもの。電話番号と PIN は書かない）
- 「招待をお送りしました」だけで済ませず、上記詳細を本文に直接書く
- 古い下書きは削除する

### 4. 送信はユーザーの承認を得てから

- 送信は「送って」と言われてから行う
- 送る前に重複と矛盾を照会する

## 候補日時の出し方

社外のお客様へ日程を依頼するときは、予約URLを本文に入れない（2026-11-17 kim 決定。2026-11-16 の「URLだけを貼らない」を更新）。

1. 秘書の空き日程ツール https://claude-pc.tailc5d751.ts.net/secretary/book から、kim@orgiast.jp と seisaku-team@orgiast.jp の**両方が空いている**日時を取る。このURLと claude-pc.tailc5d751.ts.net/secretary 配下は社内の空き調べ専用で、お客様に送らない。
2. 本文に具体的な候補を **4〜5枠** 書く。日時と曜日を付ける。オフラインなら地域の注釈を付ける。URLは書かない。
3. 候補が合わないときは、お客様に別日を聞くか、AI側で追加の候補を出す。
4. 悪い例:「下記からご都合のよい日時をお選びいただくか、候補日時をお知らせください。（URLのみ）」および、候補のあとに予約URLを添える文。
5. ツールが読めないときは仮の枠を作らず、URLも送らない。

## 予定登録の既定値

| 項目 | 既定値 |
|---|---|
| 時間帯 | 09:00–18:00（指定がなければ） |
| 調整時間 | 1時間（指定がなければ） |
| 登録先カレンダー | 調整したアカウントの primary |
| タイトル接頭辞 | オンライン → M:、来訪 → C:、訪問 → G: |

## 完了報告のフォーマット

オンラインの場合:
```
2026年11月10日(月)13:00-14:00
M：会社名 様
https://meet.google.com/xxx-xxxx-xxx
```

オフラインの場合:
```
2026年11月10日(月)13:00-14:00
C：会社名（来社）
場所: オージャスト大阪本社
```
