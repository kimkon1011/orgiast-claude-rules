# 会食先の選び方（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: ユーザーから「会食先探して」「○○さんと会食する店」「東京で接待」「飲み会の店」などの依頼があった場合の手順です。場所・人数・予算・料理ジャンル・参加者の好みを踏まえて3〜5件を提案します。

## 最初に確認する項目

最低限「場所」「人数」「日付（候補）」を最初に確定し、足りなければ追加で聞きます。

| 項目 | 必須/任意 |
|---|---|
| 場所エリア | 必須（「東京・銀座」「大阪・北新地」等） |
| 人数 | 必須 |
| 日付 | 推奨 |
| 予算/人 | 推奨（1.5万円、3万円等。指定なければ2万円前後） |
| 料理ジャンル | 任意（日本料理、焼肉、鉄板、中華、フレンチ等） |
| 目的 | 任意（契約後の御礼、初顔合わせ、成約祝い等） |
| 参加者の特性 | 任意（アレルギー、年齢層、女性比率、外国人含む等） |
| 個室希望 | 任意（個室必須/半個室可） |
| 雰囲気 | 任意（落ち着いた/賑やか/カジュアル/フォーマル） |

## リサーチ手順

1. **過去の会食履歴を確認する**: 同じエリア＋同じ目的の過去案件があれば候補に含める（評価4以上、次回利用OKのもの優先）。同一参加者と既に行った店は避ける。
2. **Web検索**: 「{エリア} {ジャンル} {予算帯} 個室 接待」等のキーワードで検索。食べログ・ぐるなび・ヒトサラ等の情報を整理する。接待・会食用途の店リスト記事も有効。
3. **裏取り**: 候補ごとに必ず公式URLまたは食べログURLを確認。Google Maps の検索URLを生成して営業時間・定休日・予約方法を確認する。

## 出力フォーマット

```
【会食先候補】
日程: 6月12日(木) 19:00–21:00
場所: 東京・銀座
人数: 4名
予算: 2-2.5万円/人

1. ◯◯（鮨）★★★★☆   ※過去利用: 2025-11-10、評価5
   個室4名、予算2万円、徒歩5分。落ち着いた雰囲気で接待向き。
   食べログ: https://tabelog.com/.../
   Google Maps: https://www.google.com/maps/search/?api=1&query=...

2. ...（最低3件、最大5件）
```

## 時間帯の目安

- 会食時間: **18時〜20時の2時間**
- 移動含め **17時〜21時**で日程確保
- カレンダー空き確認は上の「空き日程の出し方」の手順で行う

## やってはいけないこと

- 食べログ等を見ずに憶測で店名を作らない（必ず実在確認）
- Google Maps URL の `query=` パラメータに日本語をそのまま入れない（URLエンコードする）
- 過去履歴に「次回利用NG」の店を再提案しない
- アレルギー情報を聞いた後にそれを無視した店を提案しない
- 広すぎる検索URL（「銀座 高級 個室」のみ等）を出さない  
- 必ず**店名特定済みのURL**を出す

## 推奨情報源

- 食べログ / ぐるなび / OZmall / ヒトサラ
- エリア×ジャンルの接待向け記事
- 自社の会食履歴シート（ある場合）
