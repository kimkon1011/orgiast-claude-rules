# 請求から入金確認まで（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: 請求書を発行・送付したら、入金確認まで追いかける手順です。ユーザーに「入金されたか見て」と言わせずに完了させます。

## 絶対ルール

| ルール | 内容 |
|---|---|
| 個別送信 | **催促は必ず1対1のメッセージで送る。グループ（複数人見える場所）には送らない** |
| 名乗り | 冒頭で「キムコンに代わってClaude Codeが入金確認をしています」と名乗る（AIアシスタントと分かる形） |
| 行き違い | 「行き違いでしたらごめんなさい！」を必ず添える（銀行明細の同期遅れがあるため） |
| 送信後表示 | 送った本文全文を必ずチャットに表示する |
| 入金判定 | 入金の判定は銀行明細の実データだけで行う。相手の「振り込みました」発言は参考情報で、消し込みの根拠にしない |

## 1. 請求書発行→台帳登録

請求書を発行・送付したら、台帳に以下の情報を登録します。

| 項目 | 内容 |
|---|---|
| 請求書番号・件名 | ユニークな識別子 |
| 請求先 | 会社名・担当者名 |
| 請求額 | 税込・円・整数 |
| 発行日・支払期限 | YYYY-MM-DD |
| 振込名義カナ | 会社名の略カナ＋個人姓カナ |
| 連絡先 | 種類（メッセンジャー/メール等）・表示名 |
| ステータス | unpaid / 空の配列 |

## 2. 入金確認

銀行口座の入金明細を発行日〜今日の範囲で取得し、以下のルールで消し込みます。

| 条件 | 対応 |
|---|---|
| 金額一致＋振込名義に名義カナを含む | 自動消し込み（台帳を done に更新） |
| 金額一致・名義不一致 | 要確認としてユーザーに報告（個人名義・親会社名義の可能性） |
| 銀行明細の最新日付が2日以上古い | 同期遅れの可能性があるため催促を見送る |

## 3. 催促（個別メッセージ）

### 本文テンプレート

```
{姓}さん
お疲れさまです！{日付} {件名}の件で、キムコンに代わって
Claude Code（AIアシスタント）が入金確認をしてご連絡しています🙏

{姓}さんの分（¥{金額}）のご入金がまだ確認できていなかったので、
お手すきの際にお振込みをお願いできますか？（お支払期限 M/D）

【お振込先】PayPay銀行 ビジネス営業部（005）普通 1092408 カ）オージャスト
請求書: {請求書のURL}

行き違いでしたらごめんなさい！
```

### 送信手順

1. 本文をファイルに書き出す
2. 必ず `--dry-run` で事前確認
3. 確認後に本送信

## 4. 自動追いかけ

- 毎日、期限超過・前回催促から3日以上・自動催促3回未満のものを自動送信する
- 入金を検知したらユーザーに通知する
- 自動催促3回でも未入金ならユーザーに判断を仰ぐ（電話・別経路）

## 5. 振込先情報

- 振込先は請求書に記載のもの（会計ソフトの口座設定が正本）を使う。このドキュメントには口座番号を書かない
