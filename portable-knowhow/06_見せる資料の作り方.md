# 見せる資料の作り方（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: 提案書・企画書・営業資料・プレゼンなど、見た目が評価対象になる資料を作る手順です。

## ハイブリッド企画書モデル

見せる資料は「ハイブリッド企画書モデル」で作ります。複数のAIを役割分担して使い、それぞれの得意領域を活かします。

| 担当 | 役割 |
|---|---|
| 構成・原稿・文字と数字の組版（Claude等） | HTML/CSSで組版。編集可能なテキストとして残す |
| 写真ビジュアル合成（Gemini等の画像生成AI） | 実写真2〜4枚から文字なしの大きな写真ビジュアルを合成 |
| 3Dパース（ChatGPT等の画像生成AI） | 展示会ブースのパースを3案作成 |
| 配置レイアウトの参考（Genspark等） | 写真配置の面積比・余白を学習する参考としてのみ使う。成果物をそのまま採用しない |

## 手順

### 1. 写真素材を集約・選別する

- Drive の素材フォルダに写真を集約する
- ファイル名だけで選ばず、全候補を目視する
- 選ぶべき: 完成状態の写真、賑わい、接客・商談、清潔な施工完了写真
- 避けるべき: まばらな会場、設営・搬入中、床にゴミ・養生材・資材がある写真、社員だけの私的集合写真
- 他社ロゴが大きければモザイクをかける

### 2. 構成を決める

- 見出しは14字以内、導入本文は3行以内に収める
- 重要な数字は大きく（96px級）表示する
- 表・図解は編集可能なHTML/CSS/SVGで作る（画像に文字を焼き込まない）

### 3. 文字なしビジュアルを合成する

- 実写真2〜4枚を画像生成AIに渡し、文字のないクリーンなビジュアルを生成する
- 人物は自然に、顔の重複なし
- 文字・ロゴ・数字・表・図解・透かしを描かない
- 看板・衣服は無地に指定する

### 4. 組版する

- 1ページずつ、HTML/CSSで組版する
- 写真ページの写真面積は40%以上確保する
- 余白は96px以上取る
- 写真をフィルタや透明度で暗くしない
- 小さな飾り写真にしない

### 5. 全ページを目視確認する

各ページを次の5観点で確認します:

1. 写真の質と内容
2. 余白
3. 文字量
4. 数字の見せ方
5. 全体の一貫性

1項目でも不良があれば修正して作り直す。

## 展示会ブースの提案書の場合

- **必ずパースを3案入れる**（ChatGPT等の画像生成で作成）
- 3案は見積の松竹梅（シンプル/スタンダード/インパクト）と対応させる
- 各案の違い（展示台・ロゴボックス・光る壁・上部サイン・モニター台数等）を絵で見分けられるようにする
- 高さと明るさは必ず入れる（高さは出展要項の上限を確認、照明は全案に入れる）
- パースには「イメージ（AI作成）。実際の寸法・仕上がり・文字は設計時に確定します」と注釈を入れる

## やってはいけないこと

- 文字・数字・表・図解を画像生成AIに作らせない（必ずHTML/CSS/SVGで編集可能に残す）
- Genspark の成果物をそのまま採用しない
- Canva は使わない（公開URLが必要だが安定した写真投入経路がない）
- 写真をフィルタやopacityで暗くしない
