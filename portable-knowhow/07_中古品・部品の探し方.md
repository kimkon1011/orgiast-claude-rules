# 中古品・部品の探し方（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: ユーザーから「中古」「安く買いたい」「フリマ」「ヤフオク」「メルカリ」「部品を探して」「最安」等の依頼があった場合の手順です。

## 原則

- 調べ物はAI側で全部完結させる。ユーザーに「見てきて」と頼まない
- 購入・入札（支払い）だけユーザー本人が行う
- ユーザーの手間をAIの効率より優先する

## 検索

### 専用スクリプトがある場合

`node tools/frima-search.mjs` が使える環境ではこれを最優先で使う。

```sh
node tools/frima-search.mjs "{キーワード1}|{キーワード2}|{キーワード3}" --min {下限} --exclude ジャンク,... --qty {必要数}
```

注意:
- **全サイト横断が既定**（`--shops` で絞らない）。ユーザーが「ヤフオクで」と言ってもPayPayフリマ・Yahoo!ショッピング・メルカリ・ラクマ等も出し、指定サイト分は別枠で示す
- 言い換え語を最低3種類（正式型番・略称・規格表記・用途語）使う。1語あたり各サイト約20件しか返らない

### 専用スクリプトがない場合

Web検索で以下のプラットフォームを横断する:
- PayPayフリマ / Yahoo!オークション / Yahoo!ショッピング
- メルカリ / ラクマ / ジモティー
- 各プラットフォームの共通点として、JS描画が必要なページはAPIで直接取得する必要がある場合がある

## 候補の出し方

- **必要数NならN×2以上の具体的出品**を表で出す。各出品のURL・価格・送料・数量/枚数・状態・返品可否を記載する
- セット品（2枚組等）は枚数換算し、必要数を満たす組み合わせと合計金額を最安順に2〜3案提示する
- ユーザーが参考URLを出したら、それより安い同等品がないか必ず比較する

## 互換性確認

- 出品ページの情報を確認してから推奨する。確認できない項目は「未確認」と明記する
- 例: サーバー用メモリは RDIMM / Registered / ECC Reg のみ。UDIMM・SO-DIMM 不可。容量・規格・形状も確認する

## やってはいけないこと

- 出品ページを確認せずに「多分これで合う」と互換性を仮定しない
- 「未確認」の注釈なしに推奨しない
- 価格比較を行うとき、「最安のやつ」だけでなく、送料込みの総額と状態のバランスも考慮する
