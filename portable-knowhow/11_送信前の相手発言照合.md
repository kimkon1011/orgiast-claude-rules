# 送信前の相手発言照合

## 結論

送る前に、相手がすでに済ませたことや変更したことを確かめます。同じ相手がいる別チャットと、本文のない写真も対象です。使い捨てスクリプトからは送信しません。

## 手順

1. 送信先と同じ相手がいる別チャットの直近24時間を読みます。
2. 画像・添付の実物を開き、内容を説明として記録します。読めない添付があれば送信を止めます。
3. 下書きの各指示について、置き場所・日時・部数・宛先・手順を相手の発言と照合します。済んだことの再指示や矛盾する文を直すか削ります。
4. 共通のチェックに通した本文を、承認・整合性チェックのある共通送信入口で扱います。合格マーカーは宛先と本文に結びつき、5分で失効します。

## コマンド

次は読み取りと判定だけを行い、送信しません。画像説明は、実物を読んだ内容をメッセージIDごとにJSONで保存します。

```powershell
node tools/pre-send-reply-check.mjs --channel beeper --chat <チャットID> --text-file <本文ファイル> --image-notes <画像説明JSON> --json --write-pass
```

過去時刻の再現には `--now 2026-11-28T01:25:00Z` を付けます。その時刻より後の発言は判定に使いません。送信は `tools/beeper-send.mjs` 等の共通入口に任せます。

ルールをローカルの指示書へ反映するには、更新を取得した後に次を実行します。2回目は `unchanged` となり、重複しません。

```powershell
node tools/claude-md-block.mjs --all-default
```

## 再発事例

2026年11月28日、東邦ハイツ301で、相手の別チャットに「控えここ入れてます」と写真があり、送信先にも「乙第12号証」記入済みの写真と「投函しておきます」がありました。それを見ずに使い捨てスクリプトから記入と持ち帰りを再指示しました。このため、関連チャット・添付も含む照合と、共通入口以外の送信停止を必須にしました。
