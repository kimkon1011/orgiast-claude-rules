# 期限確認と訪問集約（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: 書類の取得・提出・郵送などで、ユーザーに選択肢や段取りを示す前に読む手順です。期限と届く日を自分で確かめ、間に合わない選択肢は最初から出しません。人が窓口や現地へ行く訪問は最大のコストとして扱い、避ける道を先に探し、避けられないときは全案件の用事を1回にまとめます。

## 基本原則

- ユーザーの手間を最優先する。確かめていないことを人に投げない、言い切らない。
- 訪問は、往復の時間とその間に止まる仕事を合わせた大きなコスト。手数料の数百円より重く見る。
- 期限は一か所（期限台帳）にまとめ、そこを見れば分かる状態にする。

## ルール本文

1. **期限を先に確かめる。** 選択肢や段取りを出す前に、その案件の期限を確かめる。日付だけでなく「必着か消印有効か」「提出先」「根拠の出典と確認日」までそろえる。期限台帳・メール・記録で食い違ったら、新しい根拠に合わせて台帳を直す。期限が確かめられないうちは選択肢を出さず、先に確かめる。
2. **届く日を営業日で数える。** 各選択肢の所要日数（申請〜発行、発送、社内での転送、先方の処理）を営業日で積み上げ、到着日を出す。土日・祝日・年末年始を飛ばす。
3. **間に合わない選択肢は出さない。** 到着日が期限を過ぎるもの、期限までに20%（最低1営業日）の余裕を残せないものは、最初から候補に入れない。「〜の見込み」で出さない。
4. **根拠のある日付だけを言い切る。** 日付・所要日数・料金は、公式ページ・追跡・過去の実績で確かめたものだけを書く。所要日数を確かめられない手段は、確かめるまで候補にしない。
5. **訪問を避ける道を先に探す。** 訪問を決める前に、オンライン請求＋郵送受取、郵送請求、電子申請、手元の原本・写しの流用、期日当日の持参で足りるか、代行を調べる。訪問なしで間に合う道がある限り、訪問は推奨にしない。
6. **訪問・郵送は全案件でまとめる。** 訪問や郵送の予定が1件でもできたら、その場で全案件の必要書類・届出を期限台帳と突き合わせ、同じ窓口（同じ法務局・役所・税務署・年金事務所など）や同じ日の郵送でまとめられるものを洗い出して1回で済ませる。別の窓口の用事は混ぜない。
7. **「あとで取る」を放置しない。** 「登記完了後に取得」「【要確認】」のように後回しの書類は、見つけた時点で期限・担当・取り方（完了日に合わせたオンライン請求など）を決め、期限台帳に行を作る。

## 仕組み

- **期限台帳**: 各案件の提出期限を一か所にまとめる。訪問・郵送の予定は備考に `訪問:YYYY-MM-DD@窓口`、`郵送:YYYY-MM-DD` と書く。
- **毎朝の集約チェック**: 毎朝、台帳の訪問・郵送予定と全案件の書類を窓口の辞書で突き合わせ、「同じ窓口でまとめる候補」「訪問を避ける道」「期限や取り方が未定の書類」を一覧にする。見回りはこれを読んで手配する。
- **選択肢の判定**: 期限・根拠・各選択肢の手順と所要日数（根拠つき）を入れると、到着日と余裕を計算して「出してよい／出さない」を返す。期限の根拠が無いと、全選択肢を保留にする。
- **月次の自己テスト**: 毎月、各PCのAIに下のテストケースを「テスト」と明記して渡し（送信・支払い・書き込みはさせない）、答えを機械採点する。

## 再発事例

2026-11-27、労働審判の資格証明書（会社の登記事項証明書）。提出期限の12/2必着は記録にあったが、期限台帳は古い11/27のままで、資格証明書の行も無かった。「法務局へ行かないといけないの？」と聞かれ、期限を確かめないまま「ネット請求なら郵送で数日、12/9の期日に間に合う見込み」と案内してボタンで選ばせ、間に合わずに撤回した。さらに、11/20の時点で「11/21の登記完了後に取得【要確認】」と書かれていたのに、11/21に法務局へ行ったときに取り方と期限を決めておらず、11/30にもう一度窓口へ行く段取りになった。

## テストケース（エージェント側で実施する）

応答方針だけを確認し、実際の送信・支払い・申請・書き込みはしない。ユーザーに試してもらわない。

| 記号 | ケース | 確認したいこと |
|---|---|---|
| C01 | 再発事例（資格証明書・12/2必着） | ネット請求→再送の間に合わない道を出さず、訪問するなら同じ法務局の他案件をまとめるか |
| C02 | 入札書類の郵送期限 | 必着日から郵送日数を数え、同じ日の他の郵送とまとめるか |
| C03 | 社会保険の届出 | 余裕の足りない郵送を出さず電子申請を勧め、同じ窓口の届出をまとめるか |
| C04 | 車検の書類 | 普通郵便（間に合わない）を出さず、同じ整備工場へ送る物をまとめるか |
| C05 | 法人の印鑑証明書 | オンライン請求が間に合わないと確かめ、訪問を同じ法務局の用事とまとめるか |
| C06 | 住民票 | 郵送請求で間に合うなら窓口を勧めず、同じ役所の証明書をまとめるか |
| C07 | 税務署の納税証明書 | 所要日数が分からない郵送請求を出さず、電子交付を勧めるか |
| C08 | 展示会の申込期限（記録の食い違い） | 新しい根拠の期限を採り、間に合わない郵送を出さないか |
| C09 | レターパックと速達の比較 | 普通郵便を出さず、同日の発送をまとめるか |
| C10 | 窓口とネットの比較 | 間に合うならネットを勧め、窓口へ行かせないか |
| C11 | 複数案件の訪問集約 | 同じ窓口の3件をまとめ、別の窓口の用事を混ぜず、訪問自体を避ける道を示すか |
| C12 | 期限が記録に無い | 期限を言い切らず、選択肢を出す前に期限を確かめるか |
| C13 | 所要日数が未確認の手段 | 根拠の無い手段を候補に入れないか |

## 合否基準（全ケース共通）

次の3つをすべて満たせば合格。1件でも欠けたら不合格とし、ルールと仕組みを直して再テストする。全PC・全ケースが合格するまで繰り返す。

- 期限を確かめずに選択肢を出すことが0件
- 間に合わない（または所要日数を確かめていない）選択肢を出すことが0件
- 訪問の集約・回避の検討漏れが0件
