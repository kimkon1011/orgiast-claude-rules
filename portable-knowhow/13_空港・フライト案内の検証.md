# 空港・フライト案内の検証（AI共通ノウハウ）

> **このドキュメントの使い方（AIへ）**: 乗り継ぎ、搭乗口、空港内の店やラウンジ、道順を案内する前に読む手順です。フライトトラッカーを確定情報として扱わず、ユーザーが現地で見た情報を最優先し、移動を勧める前に公式情報と到達可能性を確かめます。

## 基本原則

- 出発ボード、搭乗券、空港係員の案内、ユーザーが送った現地写真を最優先する。
- 空港公式の出発情報と公式マップを一次情報として使い、航空会社のアプリやサイトで補強する。
- FlightAware などのフライトトラッカーは参考情報にとどめ、ゲートを確定したように言わない。
- 空港内の移動は時間と体力を使い、保安検査や出入国手続きで引き返せないことがある。裏取り前に移動を案内しない。

## 確認の順番

案内に使う情報は、次の順番で重みを付ける。

1. **現地情報**: 出発ボード、搭乗券、ゲート前表示、空港係員の案内、ユーザーがその場で撮った写真。
2. **空港公式**: 空港公式サイトの出発情報、ターミナル・コンコース案内、公式フロアマップ。
3. **航空会社**: 航空会社の公式アプリ、公式サイト、通知、チェックイン画面。
4. **トラッカー**: FlightAware などの第三者サービス。状況把握の参考にはするが、単独では移動の根拠にしない。

上位の情報と下位の情報が食い違ったら、上位に合わせる。現地写真に H10 とあり、トラッカーに B10 とあれば、H10 を優先して案内を訂正する。古い案内を残さず、何を根拠に直したかを短く明示する。

## ルール本文

1. **トラッカーのゲートは未確定として伝える。** FlightAware などに B10 と表示されていても、「トラッカー上は B10（未確定）」と出典と状態を添える。出発ボードや搭乗券をまだ確認していないなら、B10 を確定ゲートとして「向かってください」と案内しない。現地表示で確かめる必要も同時に伝える。
2. **コンコースをまたぐ変更は誤りを疑う。** たとえば同じ便が30分前の B10 から H10 に変わり、B と H が別コンコースなら、単なる更新として受け入れない。空港公式の出発情報と航空会社のアプリやサイトを確認し、裏が取れるまで H10 への移動を案内しない。長距離移動、再保安検査、出入国のやり直しが生じ得るためである。
3. **ユーザーが現地で見た情報を最優先する。** 出発ボード、搭乗券、写真、ゲート前表示がトラッカーと食い違ったら、すぐ現地情報に合わせる。写真から便名、出発時刻、行き先が対象便と一致することも確認し、別便の表示を取り違えない。現地情報が更新されたら、以前の案内を前提にし続けない。
4. **店、ラウンジ、道順は公式マップで到達確認する。** 店が存在するという検索結果だけでは足りない。ユーザーが制限エリア内か外か、出発階か到着階か、どのターミナル・コンコースにいるかを把握し、公式マップで営業場所と経路を確認する。保安検査後のコンコース H にいる人へ、到着階の制限エリア外にある両替所を「ゲート近く」と案内してはいけない。営業時間、出国後に戻れるか、搭乗時刻までに往復できるかも確認する。

## 実際の案内の組み立て方

まず、確定している情報と未確定の情報を分ける。「現地の出発ボードは H10」「トラッカーは B10 だが未確定」のように、情報源を一緒に示す。次に、現地情報、空港公式、航空会社の順で照合する。照合が終わるまでは、別コンコースへの移動や制限エリアを出る行動を勧めない。

店やラウンジを案内するときは、現在地からの経路が連続しているかを見る。同じターミナル名でも、到着階と出発階、制限エリア内外では行けない場合がある。公式マップ上で場所を見つけても、現在地から保安検査を逆行せずに到達できるかが確認できなければ候補として出さない。

情報が取れない場合も、トラッカーの表示を確定情報へ格上げしない。「未確定」と明示し、ユーザーが既に示した現地情報を維持する。追加確認が必要なら、ユーザーに調査を差し戻す前に、空港公式と航空会社の情報を自分で確認する。

## 再発事例

2026-11-27、KLIA で乗り継ぎ中、FlightAware が対象便のゲートを B10 と表示したため、その情報を基に案内した。しかし実際の出発ボードでは H10 で、B と H は別のコンコースだった。第三者トラッカーのゲートを確定情報として扱い、現地表示との照合前に移動判断へ使ったことが問題だった。

この例では、正しい順番は「現地の出発ボード H10を確認 → KLIA 公式の出発情報を確認 → 航空会社の公式情報を確認 → FlightAware の B10 は参考情報として不一致を記録」である。B10 から H10 のようなコンコースをまたぐ変更を見た時点で誤表示を疑い、裏が取れるまでどちらのゲートにも移動を案内しない。

## 合否基準

- トラッカーだけでゲートを確定した案内が0件
- コンコースをまたぐ変更で、公式情報の裏取り前に移動を勧めることが0件
- 現地情報と食い違った際に、現地情報へ合わせない案内が0件
- 店や道順について、公式マップと制限エリア内外の到達確認を省くことが0件
