# AI共通ノウハウ（portable-knowhow）

オージャストの業務ノウハウを、**特定のAI（Claude・Gemini・ChatGPT等）に依存しない形**で記述したドキュメント集です。

## 目的

- Claude Code 専用のスキルファイル（SKILL.md）には `user_time_v0` や `Skill` などClaude専用ツール名が書かれており、他のAIがそのまま使えない
- このディレクトリのドキュメントは、どのAIでも読んで実行できる一般名詞（「カレンダーを読める道具で」「メールの下書きを作れる道具で」等）で手順を書いている

## ファイル一覧

| # | ファイル | 内容 |
|---|---|---|
| 00 | 目次・使い方（まずこれを読む） | Drive上で自動生成（後述） |
| 01 | カレンダー空き日程の出し方 | 2本のカレンダーを合算した空き時間の計算ルール |
| 02 | 日程確定と返信メールの書き方 | 予定登録・招待・返信のセット手順 |
| 03 | 会食先の選び方 | 店探しのリサーチ手順と出力フォーマット |
| 04 | メール送信の作法 | 送信元アカウント・承認プロセス・書き方ルール |
| 05 | 請求から入金確認まで | 請求書発行→入金確認→催促の一連の流れ |
| 06 | 見せる資料の作り方 | ハイブリッド企画書モデルと手順 |
| 07 | 中古品・部品の探し方 | フリマ横断検索と互換性確認の手順 |
| 08 | 名刺発注 | マヒト法人名刺の発注手順 |
| 09 | GoogleのURLの渡し方 | authuser パラメータの付け方 |
| 10 | 社内に頼む・聞くときの書き方 | 受け手が1通で用が済む連絡の書き方 |

## 追加・修正の方法

1. このディレクトリの `.md` ファイルを編集する
2. `main` ブランチにマージする
3. 毎晩の自動更新（`tools/portable-knowhow-push.mjs`）で Google ドキュメントに反映される

注意:
- Claude 専用ツール名（`user_time_v0`、`Skill`、`Agent` 等）を本文に書かない
- 機密情報（APIキー・トークン・パスワード・口座番号・個人電話番号）を書かない
- 各ファイル 1,500〜6,000 字程度に収める
- `README.md` は Drive にアップロードされない（目次は別途自動生成）
