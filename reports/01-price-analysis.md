## 状態: データ未取得（認証待ち）

落札実績データは調達ポータル認証後にのみ取得可能です。
全省庁統一資格を再申請し、ログイン認証を獲得した後に本分析を実行します。

## 認証後の取得手順

```bash
# 1. 調達ポータルにログイン後、落札実績をダウンロード
# URL: https://www.p-portal.go.jp/pps-web-biz/UAB02/OAB0201
# 全年度一括: successful_bid_record_info_all_YYYY.zip（2013〜2026年）

# 2. awards.mjs を更新してデータをパース
node tools/awards.mjs
```

## 分析予定項目（データ取得後）
- 役務関連案件の件数・金額分布（中央値・四分位）
- 1,000万円以上の案件一覧
- 落札者の上位20社（競合分析）
- 発注機関の上位20（重点開拓先）
- 継続案件（毎年同じ案件が出ているもの）の一覧
- オージャストの保有資格で参加可能な案件の割合
