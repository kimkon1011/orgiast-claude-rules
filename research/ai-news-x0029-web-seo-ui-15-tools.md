## 概要

2026年、ウェブサイト制作・SEO・UIデザインの各工程に特化したAIツールが急増している。「全部入り」の単一プラットフォームではなく、**目的別に特化したツールをチェーンする**ことで、初回のアウトプット品質と人間による修正のしやすさの両立が現実になっている。

本提案は15のAIツールを6カテゴリに整理し、株式会社オージャストの展示会サイト改善に**Oxylabs + Firecrawl + Browser Use + Surfer SEO**の4ツールを組み合わせた再現可能ワークフローを提示する。

## カテゴリ別15ツール

### 📐 サイト生成・UIプロトタイピング（4ツール）

#### 1. v0 by Vercel
- **機能**: テキストプロンプトからフルスタックNext.jsアプリを生成。スクリーンショットやFigmaデザインからレイアウトを再現し、デザイントークンを抽出するDesign Modeを持つ。
- **特長**: 出力は実コード（React/Next.js）で、GitHub同期・ワンクリックデプロイが可能。既存コードベースへの追加にも対応。
- **料金**: Free（$5クレジット・7メッセージ/日）〜Business $100/user/月
- **最適な用途**: 既存Next.jsコードベースにUIを追加する開発チーム

#### 2. Figma Make
- **機能**: Figmaのデザインシステム（ライブラリ変数・スタイル）を読み込み、プロンプトからコードベースのプロトタイプを生成。Supabase連携、Payloadバックエンドのスキャフォールディングが可能。
- **特長**: 生成したプレビューをFigma Designに編集可能レイヤーとしてペーストできる「ラウンドトリップ」が特徴。
- **料金**: Starter 150AIクレジット/日〜Full seat $16/月（年払い）
- **最適な用途**: Figmaを既に使っているチームのデザイン→プロトタイプ高速化

#### 3. Claude Design（Anthropic）
- **機能**: プロンプト・ドキュメント・画像・コードベースからプロトタイプ・スライド・ワンページャーを構築。コードベースを読んでデザインシステムを抽出し、将来のプロジェクトで再利用可能にする。
- **特長**: ハンドオフスコア5/5（全AIデザインエージェント中最高）。HTML/PDF/PPTX/Canva/Claude Code用ハンドオフバンドルに出力可能。
- **料金**: 全Claudeプランに含まれる（Free〜Enterprise）
- **最適な用途**: プロトタイプをそのままコード化したいプロダクトチーム

#### 4. Hostinger Horizons
- **機能**: AIによるサイト生成に特化。最短で公開まで持っていける高速サイト構築が強み。
- **特長**: 他のAIサイトビルダーより「公開までの時間」が最短クラス。移植性は低いが、ランディングページを即座に立ち上げたい場合に最適。
- **最適な用途**: 展示会の一時的な特設サイトやキャンペーンページ

### 🔍 SEO・コンテンツ最適化（5ツール）

#### 5. Surfer SEO
- **機能**: コンテンツスコアリング機能で、作成した記事が検索上位ページと比較してどの程度最適化されているかを数値化。Surfer AIによる自動記事作成（約20分）、AI TrackerでChatGPT・Gemini・AI Overviews・Perplexityでの可視性を追跡。
- **料金**: €49/月（Discovery）〜€299/月（Peace of Mind）
- **最適な用途**: 量産型コンテンツチームのSEO最適化

#### 6. NeuronWriter
- **機能**: SERP分析＋NLP用語推薦をトップ10ページと比較。AIエディタでワンクリック記事作成、AI検索モニタリング（Google AI Overviews・AI Mode・ChatGPT・Perplexity）を全プランで提供。
- **料金**: $23/月（Bronze）〜$117/月（Diamond）、7日間無料トライアル
- **最適な用途**: 個人ブロガー〜小規模事業所の低予算SEO

#### 7. Semrush AI
- **機能**: AI Visibility ScoreでブランドのAI検索での言及をベンチマーク。ChatGPT・Google AI・Gemini・Perplexityでの可視性追跡、ブランドパフォーマンスダッシュボード（シェア・オブ・ボイス×センチメント分析）。Content ToolkitでSEOデータを活用したAI記事作成。
- **料金**: SEOプラン$139/月〜、AI Visibility Toolkit $99/月
- **最適な用途**: 多機能オールインワンSEOスイートを求める企業

#### 8. Ahrefs Brand Radar AI
- **機能**: AIコンテンツヘルパーで記事ドラフトを173以上の言語でスコアリング。Brand Radar AIでAIチャットボットにおけるブランド言及を追跡。10年以上のバックリンク・キーワードデータベース。
- **料金**: Starter $29/月〜、Brand Radar AI $199/月（アドオン）
- **最適な用途**: バックリンク分析とAI可視性の両方を必要とするリンクビルダー

#### 9. Google Stitch
- **機能**: Google Labsのクイックスケッチ＆UI探索ツール。複雑なビジネスロジックを伴わない初期UI案の作成に特化。
- **特長**: 2026年の新しいAIウェブデザインツール。Figmaほどの精密さはないが、アイデアのラフスケッチを即座に形にするのに適する。
- **最適な用途**: 初期コンセプトの高速プロトタイピング

### 🖼️ 画像・ビジュアル生成（2ツール）

#### 10. Adobe Firefly
- **機能**: Adobe Stockおよびパブリックドメインのみで学習。IP補償付き（有料プラン）。Photoshop/Illustratorと深く統合され、Generative Fill・Generative Expandを提供。
- **料金**: 約$9.99/月（2,000クレジット）、無料枠あり
- **最適な用途**: 商用利用必須のブランド・代理店業務。法的安全性が最優先の案件

#### 11. Midjourney
- **機能**: 独自の芸術的スタイルで知られる画像生成AI。有料加入者には商用利用権（年間売上$1M超はPro $60/月以上が必要）。IP補償なし。
- **料金**: Basic $10/月〜Mega $120/月
- **最適な用途**: クリエイティブ探索・コンセプトアート・広告ビジュアルの方向性出し

### 🤖 AIエージェント・自動化（3ツール）

#### 12. Browser Use
- **機能**: AIエージェントにブラウザを与え、Webサイトのナビゲーションとタスク実行を自動化するオープンソースライブラリ（MITライセンス）。PythonコードをCDP（Chrome DevTools Protocol）経由で実行し、リアルブラウザを制御。
- **特長**: スティルス性能90.5%（ボット検知回避率No.1）、ショッピングエージェントタスク完了率95.8%、ブラウザ起動386ms。Browser Use Cloudは$0.06/ブラウザ時間、タスク単価$0.006〜。
- **料金**: オープンソース（無料）〜Cloud $0.06/時間
- **最適な用途**: UI自動化テスト・フォーム自動入力・Webデータ収集パイプライン

#### 13. Oxylabs
- **機能**: Web API統合により検索（/search）とスクレイピング（/scrape）を1つのAPIで提供。AI Parsingで自然言語プロンプトから構造化JSONを抽出、OxyCopilotでスクレイパーコードを自然言語で生成。
- **特長**: MCP（Model Context Protocol）対応でAIエージェントと直接統合可能。セルフヒーリングパーサーがHTML変更に自動追従。CAPTCHA・JSレンダリング自動処理。
- **料金**: クレジットベース課金（1APIキー）
- **最適な用途**: 競合サイトの大規模データ収集・価格モニタリング・SEOデータ収集

#### 14. Firecrawl
- **機能**: ウェブサイトをクリーンなAI対応データ（Markdown・構造化JSON）に変換するオープンソースWebデータAPI。Search・Scrape・Crawl・Map・Parse・Interact・Agent・Monitorの8エンドポイント。
- **特長**: P95レイテンシ3,387ms（リアルタイムエージェント対応）。月1,000クレジット無料。ナビゲーション・広告・定型文を自動除去しLLM-readyなMarkdownを出力。MCPサーバー・CLI・ChatGPTプラグイン対応。
- **料金**: 月1,000クレジット無料〜
- **最適な用途**: AIパイプラインへのWebデータ取り込み・コンテンツ最適化・LLMトレーニングデータ作成

### 💻 AIコーディング支援（1ツール）

#### 15. Continue
- **機能**: VS Code拡張・JetBrainsプラグイン・CLIツールとして動作するオープンソースAIコーディングエージェント（Apache 2.0）。Agent Mode（自律型コーディング支援）、Chat Mode、Edit Mode、Autocompleteを提供。
- **特長**: モデルロール設定により、タスクごとに最適なモデルを割り当て可能（Chat/EditはOpus・AutocompleteはQwenCoder等）。カスタムスラッシュコマンド・MCPサーバー統合・YAML設定に対応。GitHub 36,500+ stars。
- **注意**: 2026年現在、最終リリース2.0.0でアクティブメンテナンス終了（read-only）。ただし機能は完成形で、商用利用に支障なし。
- **最適な用途**: オープンソース志向の開発チームのコーディングワークフロー効率化

## オージャスト適用ワークフロー：4ツールチェーン

展示会ブース制作会社のサイト改善において、以下の4ツールを直列にチェーンすることで、競合分析からコンテンツ最適化・UI改善までを自動化する再現可能なワークフローを構築する。

### フェーズ1: 競合データ収集（Oxylabs）

```
Oxylabs /search + /scrape
  → 展示会ブース制作の競合10社のサイトを収集
  → サービス一覧・料金表・実績写真・お問い合わせ導線を構造化JSONで抽出
  → 週次で自動収集（差分検出）
```

**ターゲットサイト**: hakuten.co.jp / partners.eventbank.jp / strarts-event.com / imitsu.jp / sekatsuku.jp など、AI検索で上位に出典となる競合・関連サイト

**収集項目**: サービスカテゴリ / 料金帯 / 問い合わせ導線の配置 / 使用しているSEOキーワード / 掲載実績の形式

### フェーズ2: コンテンツのLLM最適化（Firecrawl）

```
Firecrawl /crawl + /monitor
  → 自社サイト（orgiast.jp / rebooth.co.jp）を全ページクロール
  → 各ページのMarkdown + 構造化データを抽出
  → AI検索（ChatGPT / Gemini / Perplexity）が引用しやすい形式に変換
  → 変更を監視し、更新時にSlack/Webhook通知
```

**最適化ポイント**:
- サービスページのFAQセクションをLLMが引用しやすいQ&A形式に
- 「大阪 展示会 ブース制作」「1小間 費用」の具体的数値・事例をMarkdownの見出し構造で明示
- FAQページをJSON-LDのFAQPageスキーマでマークアップ（LLMが引用しやすい）

### フェーズ3: SEOコンテンツスコアリング（Surfer SEO）

```
Surfer SEO Content Score + AI Tracker
  → フェーズ2で最適化した各ページのコンテンツスコアを測定
  → 検索上位ページとのギャップを特定
  → AI Visibility（ChatGPT/Gemini/AI Overviewsでの露出）を週次追跡
  → スコア低下ページのAuto-Optimize
```

**測定指標**: キーワード密度 / 見出し構造 / 文章量 / 内部リンク / 関連語カバレッジ / AI検索での引用回数

### フェーズ4: UI自動化テスト（Browser Use）

```
Browser Use + Continue
  → Browser Useで問い合わせフォーム・資料請求導線を自動巡回
  → 各画面の表示崩れ・導線の断絶・エラーメッセージを検出
  → Continueで検出されたUI不具合の修正コードを生成
  → 修正後にBrowser Useで再テスト（CIパイプライン化）
```

**テスト項目**: お問い合わせフォーム全項目入力→送信 / スマートフォンレイアウトの崩れ / ページ遷移のデッドリンク / フォームバリデーションエラー時の案内文

## 再現方法

1. `node tools/oxylabs-competitor-collect.mjs`（競合データ収集）
2. `node tools/firecrawl-site-crawl.mjs --url https://orgiast.jp`（自社サイトクロール）
3. `node tools/surfer-content-audit.mjs --dir outputs/`（コンテンツスコアリング）
4. `node tools/browser-use-test.mjs --url https://orgiast.jp/contact`（UI自動テスト）

各スクリプトは独立して実行可能で、cron/GitHub Actionsでスケジュール実行できる。
