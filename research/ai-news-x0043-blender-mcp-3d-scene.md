# AIニュース提案 [X-0043]: Blender MCP — AIプログラムによる3Dシーン構築とブースウォークスルー自動生成

観測日: 2026-11-17
出典: ahujasid/mcp-for-blender (GitHub/MIT) / shefq/blendrelay-mcp (GitHub) / blender.org/lab/mcp-server (Blender Foundation)
ライセンス: MIT / GPL

## 概要

Blender MCP は、AIアシスタント（Claude、Codex CLI、Cursor等）が Blender を直接操作できるようにする MCP（Model Context Protocol）サーバー。Blender アドオン + MCP サーバーの2構成で、AI が自然言語またはプログラムされた手順に従って 3D シーンの構築・編集・レンダリングを自動実行する。

複数の実装が存在し、それぞれ異なる強みを持つ:

| 実装 | 開発元 | 特徴 |
|------|--------|------|
| MCP for Blender | ahujasid | 双方向通信、Poly Haven連携、AI 3D生成（Hyper3D/Hunyuan3D） |
| BlendRelay MCP | shefq | 完全シーン生成・4プロファイル・チェックポイント復元・Blender 4.5+ |
| Blender公式 MCP Server | Blender Foundation/Lab | Blender 5.1以降、軽量、公式サポート |
| Blender Assets MCP | TimotheFCN | Poly Haven/ambientCG/BlenderKit からのCC0アセット検索・ダウンロード特化 |

## アーキテクチャ

```
AIクライアント (Claude/Cursor/Codex CLI)
    ↓ MCPプロトコル（JSON-RPC over stdio/WebSocket）
Blender MCP サーバー（Python）
    ↓ Blender Python API (bpy)
Blender プロセス（3Dシーン）
```

AI が Blender Python API (`bpy`) のコードを動的に生成・実行する。オブジェクト作成・編集・マテリアル設定・カメラ制御・レンダリングまで、全ての操作をプログラムとして指示できる。

## 部位分割プログラム方式（19本の指示）

### コンセプト

1枚の平面図（SVG）と3枚の参考画像をもとに、ブース全体を**部位ごとに19本の独立した指示プログラム**に分割して生成する。各プログラムは単一の責任を持ち、並列または逐次実行可能。

| # | プログラム名 | 生成内容 | 使用アセット |
|---|-------------|---------|-------------|
| 01 | floor.mcp | 床面（仕上げ材・色・サイズ） | Poly Haven 床テクスチャ |
| 02 | walls.mcp | 壁面（3面・高さ・塗装/クロス） | — |
| 03 | structure.mcp | 構造フレーム（アルミ/鉄骨） | — |
| 04 | ceiling.mcp | 天井・吊り下げ構造 | — |
| 05 | lighting-main.mcp | メイン照明（LED/スポット） | Poly Haven HDRI |
| 06 | lighting-accent.mcp | アクセント照明（間接照明） | — |
| 07 | shelves.mcp | 什器棚（形状・配置） | — |
| 08 | display-cases.mcp | ショーケース（ガラス・内部照明） | — |
| 09 | counter.mcp | カウンター（受付・商談スペース） | — |
| 10 | furniture.mcp | 家具（椅子・テーブル・スタンド） | Poly Haven 3Dモデル |
| 11 | signage-main.mcp | メインサイン（会社名・ロゴ） | — |
| 12 | signage-sub.mcp | サブサイン（案内・パネル） | — |
| 13 | screen.mcp | デジタルサイネージ・モニター | — |
| 14 | brochure.mcp | パンフレット・資料配置 | — |
| 15 | flooring-detail.mcp | 床敷物・カーペット | Poly Haven テクスチャ |
| 16 | plants.mcp | 観葉植物・装飾 | Poly Haven CC0モデル |
| 17 | lighting-final.mcp | 最終照明調整・環境光 | Filmic High Contrast |
| 18 | camera-walkthrough.mcp | カメラパス設定（魚眼17.5mm） | — |
| 19 | render-settings.mcp | レンダリング設定（24fps/360コマ） | — |

### 指示プログラムの構造（テンプレート）

各 `.mcp` プログラムは、AI エージェントが解釈可能な以下の構造で記述する:

```markdown
## [program-name]
### 目的
<当該プログラムの責務を1文で>

### 入力参照
- 平面図: floorplan.svg（ゾーン座標: x,y,w,h）
- 参考画像: ref-01.jpg〜ref-03.jpg（各部位の意匠参照）
- 前プログラム出力: <依存する前工程の出力への参照>

### 生成手順
1. <具体的なBlender操作の手順>
2. <各ステップは計測可能なパラメータを含む>
...

### パラメータ
- サイズ: W x D x H (mm)
- マテリアル: <マテリアル名>
- 色: #HEX or RGB
- 配置座標: (x, y, z)

### 使用アセット
- Poly Haven URL: <CC0アセットのURL>
- 解像度: 2K（テクスチャ）

### 出力条件
- シーン内のオブジェクト名: <命名規則>
- レイヤー/コレクション: <所属>
```

### メリット

1. **分割による品質安定**: 1プログラムが複雑になりすぎず、AIの1回の出力が限定された範囲に集中する
2. **再生成が局所的**: 壁の色を変えたい場合、`walls.mcp` だけ再実行すればよい
3. **並列実行可能**: 依存関係の無いプログラムは並列実行できる
4. **再利用性**: 標準ブースサイズ（3x3/3x6/6x6/6x9）のテンプレートとして蓄積可能
5. **可監査性**: 各プログラムの出力を個別に確認・承認できる

## Poly Haven CC0 アセット統合

Poly Haven（polyhaven.com）は CC0 ライセンスの HDRI・テクスチャ・3Dモデルを提供する最大級のライブラリ。Blender MCP の主要実装は標準で Poly Haven との連携をサポートする。

### 連携方法

| アセット種別 | MCP連携 | 解像度 |
|-------------|---------|--------|
| HDRI（環境光） | 自然言語検索→自動適用 | 1K〜24K |
| PBRテクスチャ | サーチ→オブジェクトに貼付 | 1K〜8K |
| 3Dモデル | サーチ→インポート→配置 | — |

### 用途別推奨アセット

| 目的 | 推奨カテゴリ | 具体例 |
|------|-------------|--------|
| ブース内環境光 | HDRI（スタジオ/屋内） | `studio_small_04` / `brown_photostudio_01` |
| 床材テクスチャ | 木目/タイル/カーペット | `wood_floor_01` / `ceramic_tiles_02` |
| 壁材テクスチャ | コンクリート/塗装 | `concrete_rough_01` / `plaster_01` |
| 展示什器 | 家具/装飾品 | `table_01` / `shelf_unit_01` |

### 制約

- ダウンロードにはインターネット接続必須
- 3Dモデルは GLTF/OBJ 形式、マテリアル再調整が必要な場合あり
- HDRI の解像度が高いとレンダリングメモリ消費増加（ブース提案用途では 2K〜4K で十分）

## レンダリング設定

### カラーマネジメント: Filmic High Contrast

Blender の Filmic High Contrast は、標準の sRGB よりも広いダイナミックレンジを扱えるカラースペース変換。

| 設定項目 | 値 | 効果 |
|---------|-----|------|
| View Transform | Filmic High Contrast | ハイライトのディテール保持、シャドウのつぶれ防止 |
| Look | High Contrast | メリハリのある展示会ブース表現に最適 |
| Display Device | sRGB | 一般的なモニター出力 |

### カメラ設定: 魚眼 17.5mm / 24fps / 360フレーム

ウォークスルー動画生成のためのカメラ設定:

| 設定項目 | 値 | 根拠 |
|---------|-----|------|
| 焦点距離 | 17.5mm（フルサイズ換算） | 魚眼に近い広角で空間の広がりを表現。実際のブース見学時の視野角を再現 |
| フレームレート | 24fps | 映画標準。なめらかな動きと十分なコマ数 |
| 総フレーム数 | 360フレーム | 24fps × 15秒 = 360コマ。短尺プロモーションとして適切な長さ |
| カメラパス | ベジェ曲線によるスムーズパス | ブース外周→入り口→内部一周→出口の導線 |

### カメラパス設計（360フレーム分割案）

| 区間 | フレーム範囲 | カメラ動作 | 説明 |
|------|------------|-----------|------|
| アプローチ | 1〜60 | ブース正面へ直線移動 | 全体像を遠景から見せる |
| 入り口 | 61〜90 | 入り口で一時停止＋見回し | ブース名・メインビジュアルを捉える |
| 左壁巡回 | 91〜180 | 左壁に沿ってスライド | 展示什器・パネルを順に確認 |
| 中央展示 | 181〜240 | 中央部をゆっくり旋回 | メイン展示物を多角度から |
| 右壁巡回 | 241〜300 | 右壁に沿ってスライド | カウンター・商談スペース |
| 退出 | 301〜360 | 出口へ移動＋振り返り | 最後に全体を見渡して終了 |

## セットアップ手順（オージャスト標準環境）

### MCP for Blender（推奨）

```bash
# 1. uv のインストール（Pythonパッケージマネージャ）
pip install uv

# 2. MCP for Blender サーバー起動
uvx mcp-for-blender

# 3. Blenderアドオンインストール
uvx mcp-for-blender install-addon

# 4. Blenderを起動 → アドオン有効化（Edit → Preferences → Add-ons → "MCP for Blender"）
# 5. Claude Code の MCP 設定に追加
```

### BlendRelay MCP（複雑シーン向け）

```bash
# 1. uvx でインストール・セットアップ
uvx blendrelay-mcp setup

# 2. Blender 4.5+ でアドオン有効化
# 3. サイドバー(N) → BlendRelay タブ → Connect
# 4. プロファイル選択: Complex Production（19プログラム分割時）
# 5. 生成スコープ: Full Scene
```

### Claude Code 連携設定

```json
{
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": ["mcp-for-blender"]
    }
  }
}
```

## オージャストでの適用シナリオ

### シナリオ1: 展示会ブースのウォークスルー提案（最優先）

顧客にブース提案を行う際、これまでは平面図＋参考画像＋3D静止画レンダリングで提案していた。Blender MCP により:

1. 平面図（SVG）と参考画像3枚を準備
2. 19本の指示プログラムを生成（標準テンプレートから自動生成）
3. Poly Haven CC0アセットを自動適用
4. 魚眼17.5mm 24fps 360コマのウォークスルー動画を自動生成
5. 顧客に共有 → 修正指示は該当プログラムだけ再実行

### シナリオ2: イベント会場レイアウトシミュレーション

複数出展者のブース割り当て・動線計画を3Dで可視化:

1. 会場平面図を読み込み
2. 各出展者のブースを自動配置
3. 動線・導線をカメラパスで確認
4. 混雑予測・視認性分析のための俯瞰レンダリング

### シナリオ3: 過去案件の3Dアーカイブ化

過去に制作したブースの写真＋図面から3Dシーンを復元:

1. 参考写真から主要構造を推定
2. 標準プログラムテンプレートに当てはめ
3. Poly Haven アセットで補完
4. アーカイブとして保存 → 類似案件の参考として再利用
