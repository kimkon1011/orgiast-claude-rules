# AIニュース提案 [X-0065]: Copilotで展示会準備のムダ業務を片づける

## 目的

Microsoft Copilot（Copilot Chat / Copilot for Microsoft 365）の一時的チャット・Work IQ・Excel連携・会議メモ要約機能を組み合わせ、展示会準備に潜む「ムダ業務」を定型化・自動化するパターンを提示する。オージャストのブース制作現場で、Copilot の具体的な使い方（Excel見積の解読・最適化、打ち合わせメモの構造化議事録化）を示す。

観測日: 2026-11-17
出典: 日本能率協会「業務効率化に関する実態調査2025」/ Microsoft Work Trend Index 2025 / Copilot for Microsoft 365 公式ドキュメント / オージャスト実績

## 1. 展示会準備に潜む4つのムダ

### 1.1 ムダ1: 何を決めるか決まっていない会議（結論の出ない会議 64.4%）

展示会出展の準備会議は「とりあえず集まって話す」になりがち。出展目的・ブースサイズ・予算配分など、決めるべきことが曖昧なまま時間だけが過ぎる。

**Copilotでの解決**: 「この会議で決めること」を1行でアジェンダ化する。

```
Copilot Chat への入力例:
「展示会準備の打ち合わせです。以下の議題を『この会議で決めること』を
先頭に書いたアジェンダにまとめてください。
  - 出展する展示会の選定
  - ブースサイズ（小間数）の決定
  - 予算枠の確認
  - チラシ制作のスケジュール
  - 担当者の割り振り」
```

**期待効果**: 会議時間の短縮（31〜60分が52% → 15〜20分目標）。Copilot Chatの一時的チャットは履歴に残らないので、使い捨てのアジェンダ案として気軽に使える。

### 1.2 ムダ2: Excel式の解読に時間がかかる（64.2%）

ブース制作の見積書や出展計画のExcelは、前任者が作った複雑な数式（VLOOKUP・IFのネスト・条件付き書式）が入り組んでいて、修正するたびに解読に時間がかかる。

**Copilotでの解決**: Excel式を貼ってひと言説明とXLOOKUPへの書き直しを依頼する。

```
Copilot Chat への入力例:
「この数式をひと言で説明して、XLOOKUPで書き直してください。
=IF(VLOOKUP(A2,単価表!A:B,2,FALSE)="","要確認",
  IF(VLOOKUP(A2,単価表!A:B,2,FALSE)*B2>100000,
    "要承認",VLOOKUP(A2,単価表!A:B,2,FALSE)*B2))」
```

**期待効果**: 数式の解読時間を 1/5 に短縮。XLOOKUP は VLOOKUP より参照方向の制約が少なく、メンテナンス性が向上する。

### 1.3 ムダ3: 展示会の情報を探すのに1日平均38分

出展計画を立てる際、過去の出展実績・会場案内図・搬入ルール・小間割当などを社内のどこから探せばいいか分からない。

**Copilotでの解決**: Work IQ（Copilot for Microsoft 365の組織内検索）をオンにして自然言語で検索する。

```
Copilot Chat（Work IQオン）への入力例:
「今年の東京ビッグサイト 東ホールでの展示会で、昨年
オージャストが使ったブース場所と小間サイズを教えて」
```

**期待効果**: 情報探しの時間を 38分 → 数秒に短縮。Work IQ は組織の SharePoint・OneDrive・メールを横断検索するため、ファイル名を覚えていなくても自然言語で目的の情報にたどり着ける。

### 1.4 ムダ4: 打ち合わせメモの議事録化作業（31〜60分が52%）

打ち合わせの内容を「決まったこと」「未定」「担当と期日」に整理する作業は、手作業だと30分〜1時間かかる。

**Copilotでの解決**: 打ち合わせメモを Copilot Chat に貼り、構造化された議事録を生成させる。

```
Copilot Chat への入力例:
「以下の打ち合わせメモから『決まったこと』『未定』『担当と期日』
に分けて議事録を作ってください。
---
ブース場所は東ホール2小間で決定。チラシは500部。
ノベルティはまだ決まってない。チラシのデザインは来週までに
白川さんが3案用意。予算は30万円以内。
ノベルティの候補はタオルかボールペン。
次回打ち合わせは11/25 14:00。
---」
```

**出力イメージ**:

| カテゴリ | 内容 | 担当 | 期日 |
|---------|------|------|------|
| **決まったこと** | ブース場所: 東ホール2小間 | — | — |
| | チラシ: 500部印刷 | — | — |
| | 予算: 30万円以内 | — | — |
| | 次回打ち合わせ: 11/25 14:00 | — | — |
| **未定** | ノベルティ（タオル or ボールペン） | — | — |
| **担当と期日** | チラシデザイン3案用意 | 白川 | 来週まで |

**期待効果**: 議事録作成時間を 30〜60分 → 5分に短縮。

## 2. 株式会社オージャストでの応用

### 2.1 ブース制作見積のExcel式をCopilotで解読・最適化

オージャストのブース制作見積書には、以下のような複雑な計算ロジックが含まれている:
- 搬入費 = 会場までの距離 × 重量単価（会場別係数あり）
- 施工費 = 基本工数 + 時間外割増（時間帯別係数）
- 材料費 = 単価 × 数量（過去発注レートの参照）

これらを Copilot Chat に貼り、「この計算式の意味をひと言で説明して」「XLOOKUPを使って書き直して」と依頼する。

**実測計画**:
1. 既存のブース制作見積Excel（実際の案件1件分）を匿名化
2. Copilot Chat で数式1つずつ解読・説明させる
3. 手動解読との時間差を計測（目標: 1/5以下）
4. 書き直した数式を実際の見積に適用し、計算結果の一致を確認

### 2.2 イベント打ち合わせメモの議事録化

オージャストのクライアントとの打ち合わせでは、以下の情報が頻出する:
- ブースのサイズ・レイアウト
- 使用する備品（什器・照明・モニター）
- チラシやノベルティの仕様・部数
- 設置・撤去のスケジュール
- 予算と支払い条件

これらを「決まったこと」「未定」「担当と期日」に構造化することで、次のアクションが明確になり、確認漏れを防げる。

**実測計画**:
1. 実際の打ち合わせメモ5件を Copilot Chat で議事録化
2. 手動議事録作成との時間差を計測（目標: 1/6以下）
3. 抽出精度を確認（目標: 「決まったこと」の再現率90%以上）

### 2.3 Copilot の選択ガイド

| 用途 | 使うCopilot | 必要なライセンス | 備考 |
|------|-----------|----------------|------|
| 会議アジェンダ作成 | Copilot Chat | 無料（Microsoftアカウント） | 一時的チャット、履歴不要 |
| Excel式の解読・最適化 | Copilot Chat | 無料 | 数式だけを貼って使う |
| 社内情報検索（過去の出展実績等） | Copilot Chat + Work IQ | Microsoft 365 Copilot ライセンス | 組織内データにアクセス |
| 打ち合わせメモの議事録化 | Copilot Chat | 無料 | テキストを貼って構造化 |
| Teams会議の自動文字起こし+議事録 | Copilot for Microsoft 365 | Microsoft 365 Copilot ライセンス | リアルタイム要約 |

## 3. 期待効果と費用対効果

### 3.1 1案件あたりの削減時間（試算）

| 業務 | 現状（手作業） | Copilot活用後 | 削減率 |
|------|--------------|-------------|-------|
| 会議アジェンダ作成 | 15分 | 2分 | 87% |
| Excel式解読（5式） | 30分 | 5分 | 83% |
| 情報検索（過去実績） | 38分 | 2分 | 95% |
| 議事録作成 | 45分 | 5分 | 89% |
| **合計（1案件あたり）** | **128分** | **14分** | **89%** |

### 3.2 費用

| ツール | 月額 | 備考 |
|-------|------|------|
| Copilot Chat（無料版） | $0 | Microsoftアカウントのみ |
| Copilot for Microsoft 365 | $30/ユーザー/月 | Work IQ・Teams連携が必要な場合 |

無料の Copilot Chat だけでも、Excel式解読・議事録化・アジェンダ作成の3つは実現可能。Work IQ（社内情報検索）とTeams連携には有料ライセンスが必要だが、1ユーザー $30/月で導入できる。
