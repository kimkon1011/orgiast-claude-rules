# AIニュース提案 [X-0069]: Search Console 3ゾーンバブルチャートでSEO改善を可視化

## 目的
Google Search Consoleのクエリデータを**3ゾーンバブルチャート**で可視化し、CTR改善の優先順位を一目で判断できるツールを提供する。

観測日: 2026-11-16
出典: Google Search Console ヘルプ / Chart.js ドキュメント / SEO業界プラクティス

---

## 1. 提案の核

Search Consoleのクエリレポートには「掲載順位は高いのにCTRが低い（ミスマッチ）」または「順位は中程度だがCTRに伸び代がある（可能性）」といった、**数値だけでは見逃しやすいパターン**が存在する。3ゾーン分類で可視化することで:

| ゾーン | 条件 | 意味 | 次のアクション |
|-------|------|------|--------------|
| 🔴 赤（ミスマッチ） | 掲載順位1〜10 かつ CTR < 5% | タイトル・説明文が検索意図と不一致 | 競合のタイトル＆description調査、リライト |
| 🟡 黄（可能性） | 掲載順位11〜20 または CTR 5〜15% | コンテンツ追加でさらに改善可能 | 検索意図調査、不足情報の追加、タイトル修正 |
| ⚪ 灰（見極め） | 掲載順位21以下 | 記事の要否を判断 | サイトに必要な記事か検討、不要なら統廃合 |

---

## 2. ツール概要

`tools/gsc-bubble-chart.mjs` — 単一HTMLを生成するCLIツール:

- **入力**: Search Console エクスポートCSV（Query/Impressions/Clicks/Position/CTR）
- **描画**: Chart.js（CDN参照）によるインタラクティブバブルチャート
- **X軸**: 掲載順位（1→50、右端=1位）
- **Y軸**: インプレッション数（対数スケール）
- **バブルサイズ**: クリック数
- **色分け**: 上記3ゾーン
- **フィルタ**: 最小インプレッション数で絞り込み
- **デモモード**: `--demo` で展示会・ブース関連クエリ50件のサンプルデータを埋め込み
- **出力**: 自己完結型HTML（JS/CSS内蔵）
- **言語**: 日本語UI

---

## 3. オージャストでの適用

### 対象クエリ
- 「展示会 ブース 制作」「イベント ブース デザイン」「企業 展示会 出展」などの展示会・ブース関連KW
- サイト内の「制作事例」「実績」「料金」ページが狙うクエリ

### 期待効果
1. **ミスマッチゾーンの発見**: 掲載順位1〜10でCTRが5%未満のクエリ → タイトル・descriptionを競合と比較してリライト
2. **可能性ゾーンの優先**: 順位11〜20でCTRが高いクエリ → 内部リンク強化・コンテンツ追加でトップ10を狙う
3. **見極めゾーンの棚卸し**: 順位21以下のクエリ → サイトにとって本当に必要な記事かを判断

### 実測サイクル
1. 月初にSearch ConsoleからCSVエクスポート
2. `tools/gsc-bubble-chart.mjs --input queries.csv --site orgiast.jp` でHTML生成
3. 赤ゾーンから順にタイトル・description改善を実施
4. 改善1ヶ月後に再度可視化して効果を確認

## 4. 技術選定の理由

| 選択肢 | 評価 |
|-------|------|
| Chart.js（採用） | 軽量・CDN即利用・日本語ドキュメント充実・バブルチャート標準対応 |
| 素のCanvas/SVG | 工数が3倍以上・メンテナンス性で劣る |
| Plotly.js | 高機能だが過剰・ファイルサイズ大 |
| D3.js | 自由度高いが学習曲線が急 |
