# AIニュース提案 [X-0082]: 社内AI実例共有で活用を定着 — Copilot実例ライブラリ

## 目的
社員それぞれがCopilot（Copilot Chat / Copilot for Microsoft 365 / Claude Code）を実際の仕事でどう使ったか、**依頼文（プロンプト）と成果物をセットで共有**する仕組みを提案する。同僚の具体例を見て自分の仕事に応用し、実践を社内へ継続発信、現場の声を製品改善へ戻すサイクルを回す。

観測日: 2026-11-18
出典: Microsoft Copilot for Microsoft 365 導入事例 / 日本能率協会「AI活用実態調査2025」/ オージャスト社内実績

---

## 1. 課題: AIツールはあるが「どう使うか」が共有されていない

### 1.1 58%に届いているが、使っている人と使っていない人の差が広がる

社内のAIツール利用率は約58%に到達している。しかし、この数字の内訳は「毎日使うヘビーユーザー」と「試したが定着しなかった層」に二極化している。理由の多くは「同僚がどう使っているかが見えない」ことにある。

| 課題 | 影響 |
|------|------|
| 自分でプロンプトをゼロから考える負担 | 「何をどう依頼すればいいか分からない」で使わなくなる |
| 成功例・失敗例が個人のローカルに留まる | 同じ試行錯誤を全員が繰り返す |
| 「AIに任せた」と言うが何をどう任せたか不明 | 成果の再現性がなく、属人化する |
| 現場の「ここが使いにくい」が製品チームに届かない | 改善が入らず、使う側も諦める |

### 1.2 解決の方向: 「実例を見せ合う」が最も効果的

AI活用の定着には「研修」よりも「同僚の実例を見せる」方が効果が高い（日本能率協会2025調査）。人は抽象的な機能説明より、**「同じ職種の同僚が、こんなふうに使って成果を出した」という具体例**から学ぶ。

## 2. 提案: Copilot実例ライブラリ

### 2.1 構成

1つの実例は3要素で構成する:

| 要素 | 内容 | 例 |
|------|------|-----|
| **依頼文（プロンプト）** | 実際にCopilotに入力した全文 | 「このExcelの数式をXLOOKUPで書き直してください」 |
| **成果物** | AIが返した結果（テキスト・コード・表など） | 書き直されたXLOOKUP数式 |
| **どう使えたか** | 使った人のコメント（所要時間・満足度・応用のヒント） | 「今まで30分かかっていた作業が3分になりました」 |

### 2.2 共有チャネル

| チャネル | 向き | 頻度 |
|---------|------|------|
| **社内チャット（チームチャンネル）** | 即席のTips共有、1〜3行のプロンプト | 随時 |
| **社内Wiki / SharePoint** | 構造化された実例ライブラリ、検索可能 | 週1更新 |
| **月次AI活用共有会** | 実際のデモンストレーション、質疑応答 | 月1回 |
| **製品フィードバックチャネル** | 「こういう使い方ができればもっと良くなる」という声 | 月1回とりまとめ |

## 3. オージャストで試す: ブースデザイン・イベント企画の実例

展示会ブース制作・イベント企画の現場で、Copilotの具体的な使い方を実例として蓄積する。

### 3.1 実例1: ブース企画書のたたき台作成

**依頼文（プロンプト）:**
```
あなたは展示会ブースの企画プロデューサーです。
以下の条件で3m×3m小間のブース企画書のたたき台を
作成してください。

出展企業: 株式会社オージャスト（ブース制作会社）
出展展示会: 東京ビッグサイト イベント総合展
ブースサイズ: 3m×3m（1小間）
予算: 80万円（制作費のみ）
強調したい強み: 短納期（納期2週間）・デザイン力
ターゲット: 中小企業の展示会初出展担当者

含める項目:
1. ブースの基本コンセプト（1行）
2. レイアウト案（ゾーニング）
3. 使用する建材・備品のリスト
4. スケジュール（企画〜撤収）
5. 予算配分（項目別概算）
```

**成果物:**
→ 企画書のたたき台が3分で生成。レイアウト案・予算配分・スケジュールが構造化され、そこから人間が手を加えるだけで完成度の高い企画書になる。

**使った人のコメント:**
「ゼロから書こうとすると1時間以上かかる企画書の骨格が3分でできた。『この案は予算オーバー』『搬入動線の記載がない』などの修正指示を追加で出すだけで完成まで30分。以前は企画書だけで半日かかっていた。」

### 3.2 実例2: イベントスケジュールの調整案作成

**依頼文（プロンプト）:**
```
以下の条件で、展示会出展の準備スケジュール案を
ガントチャート形式（テキスト）で作成してください。

- 展示会日: 2026年3月15日（月）〜17日（水）
- ブースサイズ: 6m×6m（4小間）
- 必要な作業:
  ・ブースデザイン決定（12月末まで）
  ・建材発注（1月末まで）
  ・備品手配（2月中旬まで）
  ・チラシ・ノベルティ制作（2月末まで）
  ・搬入（3月14日）
  ・撤収（3月17日）
  ・レポート作成（3月末まで）
- 各作業のリードタイムと担当を割り当ててください
```

**成果物:**
→ 月単位・週単位のガントチャートがテキストで生成。各作業の依存関係が整理され、クリティカルパスが明示される。

**使った人のコメント:**
「展示会の準備って『何をいつまでにやるか』が曖昧になりがち。このスケジュール案をチームで共有してから、『あれはまだ決まってない』という抜けが激減した。」

### 3.3 実例3: チラシコピーのバリエーション生成

**依頼文（プロンプト）:**
```
展示会ブース制作会社のチラシコピーを5パターン
作成してください。ターゲットは中小企業の展示会
初出展担当者です。

強調したい3つの強み:
1. 短納期（企画〜施工2週間）
2. デザイン力（展示会デザイン賞受賞歴あり）
3. ワンストップ対応（企画〜備品〜撤収まで）

各パターンは以下を含む:
- キャッチコピー（15字以内）
- リード文（50字以内）
- 本文の要旨（3行）
- 想定する掲載媒体
```

**成果物:**
→ 5パターンのコピー案が生成。媒体別（Web/チラシ/ポスター）のバリエーションも同時に提案される。

**使った人のコメント:**
「コピーライターに外注すると1案5,000円〜。AIで5案作って、その中から良さそうな2案を磨き直すだけで、品質は外注と遜色なく、コストはゼロ。」

### 3.4 実例4: 搬入計画のチェックリスト作成

**依頼文（プロンプト）:**
```
展示会ブースの搬入計画チェックリストを作成してください。

会場: 東京ビッグサイト 東ホール
ブースサイズ: 3小間
搬入日: 2026年3月14日（日）
搬入可能時間: 9:00〜17:00

以下の観点を含めてください:
- 搬入前に確認すべき書類
- 持ち込み禁止物品の確認
- 搬入動線の確保
- 駐車場・荷捌き場の予約
- 撤収時の廃棄物処理
```

**成果物:**
→ 搬入〜撤収までのチェックリストが30項目で生成。会場別の注意事項も考慮される。

## 4. 実例の蓄積とフィードバックループ

### 4.1 蓄積フォーマット（1事例あたり）

各実例は以下のテンプレートで蓄積する:

```markdown
## [事例タイトル]

**依頼文:**
```（実際のプロンプト全文）

**成果物:**
```（AIの出力結果）

**使った人のコメント:**
- 所要時間: [X分]
- 満足度: ★★★☆☆
- 応用のヒント: [一言]
```

### 4.2 フィードバックの流れ

```
現場の「こういう使い方ができれば」という声
    ↓
チームチャットで共有（随時）
    ↓
月次とりまとめ → 製品フィードバックとして送信
    ↓
Copilot / Claude 製品改善に反映
    ↓
改善が現場に戻ってくる（好循環）
```

### 4.3 期待効果

| 指標 | 現状 | 目標（3ヶ月後） |
|------|------|-----------------|
| AIツール定着率（週1回以上） | 約58% | 75%以上 |
| プロンプトの使い回し率 | 計測なし | 新規プロンプトの40%以上が既存実例の応用 |
| 「AIの使い方が分からない」という声 | 月3〜5件 | 月0件 |
| 製品改善に届く現場の声 | 不定期 | 月1件以上のルーティン化 |
