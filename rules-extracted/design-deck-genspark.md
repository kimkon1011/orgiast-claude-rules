# 見せる資料はハイブリッド企画書モデルで作る

ONBOARDING.md §1.19.2 の圧縮版。2026-09-19、kim 決定。

提案書・企画書・営業資料・プレゼン・デッキ・スライド・ブースプラン・パース入り資料など、見た目が評価対象になる資料では `/design-deck` を必ず使う。学会1枚資料のような定型量産物・数表主体の実務資料は対象外。

Claude単独版は写真で3回差し戻し、Genspark単独版は数字・テキストで差し戻し、ハイブリッド v4 で承認された。見せる資料はハイブリッド企画書モデル（Claude組版×Gemini写真×Genspark参照）で作る。

- Claude: 構成・原稿・文字・数字・表・図解を HTML/CSS で組版。写真を暗く、小さく配置、スクリーンショット拡大はしない。
- Gemini画像モデル: 実写真2〜4枚から文字なしの大きな写真ビジュアルを合成。文字・数字・表・図解を作らない。
- Genspark AI Slides: 写真の面積比・余白・配置文法の参照だけ。成果物をそのまま採用しない。
- 写真の不満は Gemini で再合成。文字・数字・表・余白の不満は Claude が `pages.json` / CSS を修正。
- Canva は安定した写真投入経路がないため使わない。

制作手順、写真選定、組版制約、目視採点、Drive更新は `skills/design-deck/SKILL.md` に従う。
