# 画面設計

## CLI出力形式

### Markdown形式（デフォルト）

```markdown
# AIニュース提案: <キーワード>

## 関連サジェストキーワード
- キーワード1
- キーワード2
...

## 再検索ワード
1. ワード1
1. ワード2
...

## 読者ペルソナ
### ペルソナ1: <名前>
- **属性**: ...
- **関心**: ...
- **課題**: ...

### ペルソナ2: <名前>
...

## 記事構成案
### 案A: <タイトル>
1. 見出し1
1. 見出し2
...

### 案B: <タイトル>
...

## 記事品質チェックリスト
- [ ] チェック項目1
- [ ] チェック項目2
...
```

### JSON形式（`--json`）

```json
{
  "keyword": "展示会ブース制作",
  "suggestions": ["...", "..."],
  "searchTerms": ["...", "..."],
  "personas": [
    { "name": "...", "attributes": "...", "interests": "...", "challenges": "..." }
  ],
  "outlines": [
    { "title": "...", "headings": ["...", "..."] }
  ],
  "qualityChecklist": ["...", "..."]
}
```

## CLI引数

- `--keyword <text>`: 分析するキーワード（必須）
- `--format md|json`: 出力形式（デフォルト: md）
- `--json`: `--format json` のショートカット
