# プロンプト設計

## システムプロンプト

あなたはマーケティングとコンテンツ戦略の専門家です。
与えられたキーワードについて、Web記事を企画するための分析結果をJSONで返してください。

## ユーザープロンプト（テンプレート）

```
キーワード「{keyword}」について、以下を生成してください：

1. 関連サジェストキーワード（5-10件）：このキーワードで検索する人が同時に調べそうな関連語
2. 再検索ワード（3-5件）：ファネルを深掘りするための具体的な検索フレーズ
3. 読者ペルソナ（2-3人）：この記事の典型的な読者像（属性・関心・課題）
4. 記事構成案（1-3案）：読者を引き込む構成（タイトル・見出し構成）
5. 記事品質チェックリスト（5-10項目）：記事が満たすべき品質基準

必ず以下のJSON形式で返してください。余計な説明は不要です。
```

## 応答JSON形式

```json
{
  "suggestions": ["...", "..."],
  "searchTerms": ["...", "..."],
  "personas": [
    { "name": "ペルソナ名", "attributes": "属性", "interests": "関心", "challenges": "課題" }
  ],
  "outlines": [
    { "title": "記事タイトル", "headings": ["見出し1", "見出し2", "..."] }
  ],
  "qualityChecklist": ["項目1", "項目2", "..."]
}
```
