# 作業フォルダの STATUS.md（必須）

各セッションは終わるときや止まるとき、作業フォルダ（通常は `%USERPROFILE%\gb-reports\<案件名>\`）に `STATUS.md` を書く。途中で長く止まるときも、止まった時点の内容で更新する。

必須項目（1行ずつ）:

- 状態: 進行中 / 停止 / 完了 / 金さん待ち のいずれか
- 理由: なぜその状態か（上限・ログアウト・エラー・金さん待ち・次の手順が未着手 など）
- 次の一手: 再開したら何をするか。金さん待ちのときは、決めてほしいことを1行で書く
- 期限: あれば日付と時刻。なければ「なし」

このファイルは各PCの60分おきの軽い集計が読み、000 が `gb-reports\session-status\SUMMARY.md` にまとめる。本文の下書きや社外送信文は書かない。
