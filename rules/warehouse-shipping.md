# 倉庫への「フリマ売却品の発送依頼」は1回で発送まで完結させる（kim 承認 2026-11-17）

対象: 【埼玉渋井倉庫】作業依頼フォーム（フォームの回答 1）に、メルカリ等で売れた商品の発送依頼を書くとき。

## 依頼文のルール
1. 依頼文は「取り出し → 梱包 → 3辺と重さを J列に記入 → そのまま当日セブン-イレブンへ持ち込み発送 → 控え写真と J列『発送完了』」まで1本で書く。
   「発送前に金へ連絡」「バーコードの出し方を確認」のような、人待ちになる一文は入れない。
2. セブン-イレブン（らくらくメルカリ便）は、スマホ提示ができなくても、バーコード下の27桁の番号を店員に伝えれば受付できる（メルカリ公式ヘルプ articles/128）。
   依頼文には「店員さんに『メルカリの発送です』と伝え、下の27桁の番号を読み上げてください」と書く。
   番号はシート（倉庫と社内だけが見る）にだけ書き、チャット・Discord の公開チャンネルには書かない。
3. コンビニではサイズを測らない。ヤマトが集荷後に測ったサイズで送料が自動で決まる。
   なので「サイズ報告を待ってから発送」にしない。サイズ報告は記録と送料の確認用。
4. J列の返事は 000 の warehouse-reply-watch（毎時）が拾って金へ知らせる。
   2026-11-17 から、B列 kim@orgiast.jp または F列「Claude代筆」で K列（対応完了日）が空の行は自動で監視に入る。
   000 以外で依頼を書いたときも登録は不要。ただし B列・F列は必ずこの形で書く。

## サイズを先に決めたい場合（コードがまだ無いとき）
- 取引画面のサイズは「梱包前の見込み」で選んでコードを出してよい（実サイズで自動補正される）。
- 見込みが外れそうな大物だけ、J列のサイズ報告を見て AI が送料表と照合し、差が大きければ金に「アプリでサイズを変える」1タップの確認を出す。
  番号が変わったときだけ同じ行の H列（備考）に新しい番号を書き足し、倉庫に「新しい番号で発送」と追記する。2回目の依頼にはしない。

## 背景（2026-11-17 作業依頼1100行目 オイルヒーター）
依頼文に「バーコードはアプリでしか使えない。発送前に必ず金へ連絡」と書いたため、倉庫が梱包・サイズ記入で止まり翌日発送になった。
さらにこの行が返事の監視に入っておらず、16:30 の返事を誰も自動で拾えなかった。
