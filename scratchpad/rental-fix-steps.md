# 212coffee レンタル入金集計 — 貼り付け手順（3分）

212coffee のアカウント（212.coffee.212@gmail.com）で行う作業です。

## やること

レンタル予約メールの本文を正しく読み取る修正版コードを、212coffee のスプレッドシートのスクリプトに貼り付けます。修正とテストは完了しているので、貼って1回実行するだけです。

## 手順

1. デスクトップにある `212coffee レンタル取込の修正（ダブルクリック）.cmd` をダブルクリックします。黒い画面に `Exit code: 0` と `OK` が出れば成功で、修正版コードがクリップボードに入り、Chrome で 212coffee のスプレッドシートが開きます。`ERROR` と出たら、その画面に表示されている文字をそのまま貼って Claude に伝えてください。原因は Claude が調べます。
2. 開いたスプレッドシートの上部メニュー「拡張機能」→「Apps Script」をクリックします。
3. 左のファイル一覧にある `コード.gs`（表示が `Code.gs` のこともあります）をクリックします。
4. エディタの文字の上を一度クリックしてから、Ctrl+A（全部を選ぶ）→ Ctrl+V（貼り付け）→ Ctrl+S（保存）の順に押します。
5. キーボードの F5 を押します。保存が確定します。
6. スプレッドシートのタブに戻り、上部メニュー「レンタル売上」→「セットアップ（最初に1回）」をクリックします。400日分を読み直すので1〜2分かかります。実行中の表示が消えたら完了です。
7. 終わったら Claude に「貼った」とだけ返してください。

## 終わったあと（Claude 側で自動）

本文が入ったことを確認し、インスタベース・カシカシ・Yoyappin・スペースマーケット・いこーよの各メールから手数料差引後の入金額を読み取る処理を作り、ダッシュボードにカフェ／レンタル／合計を表示します。

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 黒い画面に `ERROR` が出る | 画面の文字をそのまま Claude に貼る |
| Chrome が別のアカウントで開く | 右上のアイコンから 212.coffee.212@gmail.com に切り替えてから開き直す |
| 「拡張機能」メニューが無い | スプレッドシートではなく別のページが開いている。Claude に伝える |
| 「レンタル売上」メニューが出ない | F5 でページを再読み込みして10秒待つ |
