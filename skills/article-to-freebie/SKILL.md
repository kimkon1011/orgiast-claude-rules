# 既存記事 → 無料特典 変換プロンプト

## 目的
既存のWeb記事・ブログ記事を、読者が10分以内に使える3つの無料特典（チェックリスト・診断・テンプレート）に変換する。生成した特典はXで配布、LINE公式アカウントの登録特典、サイトのリード獲得コンテンツとして使える。

## トリガー
- `/article-to-freebie <URLまたは記事ファイル>` で起動
- または `claude -p "この記事を無料特典に変換: <URL>"`

## プロンプト本体

```
以下の記事から、読者が10分以内に使える無料特典を3案作成してください。
チェックリスト・診断・テンプレートの形式に分け、X配布とLINE登録特典に使える
完成形にして出力してください。

【変換元記事】
<記事のタイトル、本文、またはURL>

【出力形式】

## 特典1: チェックリスト

- 形式: 箇条書きチェックリスト（□ チェックボックス形式）
- 内容: 記事の手順・確認事項を簡潔に箇条書き
- 分量: 15〜25項目
- 完成形: 「このリストを埋めれば、記事の内容を実践できる」状態

## 特典2: 診断

- 形式: 自己診断（5〜10問の質問＋点数評価）
- 内容: 記事のテーマに関する読者の現状を評価
- 分量: 5〜10問、各1〜5点、合計点で3〜4段階の判定
- 完成形: 「点数を出したら次の行動が分かる」状態

## 特典3: テンプレート

- 形式: 空欄埋めテンプレート（表形式）
- 内容: 記事で紹介している計画・整理の枠組み
- 分量: 主要セクション5〜7項目
- 完成形: 「空欄を埋めた状態で社内共有や相談に使える」状態

## 品質条件

1. 各特典は単独で完結し、10分で記入・採点できる
2. 記事を読んでいない読者でも使える（独立したコンテンツ）
3. favicon・OGP対策として、タイトルに記事のテーマが分かるキーワードを含める
4. 特典末尾に問い合わせ先やCTAを含める（ただし過剰な営業トーンにしない）
5. 日本語で出力する

## 適用例

### 例1: 広告改善記事の場合
- 変換元: Google広告改善ガイド
- 特典1: 除外キーワードチェックリスト
- 特典2: 広告予算配分診断
- 特典3: 広告文テンプレート
- 追加: ROAS計算表、改善手順PDF

### 例2: オージャスト ブース制作記事の場合 ✅ 実績あり
- 変換元: ブース構成・寸法・備品 / サービス一覧 / 参考仕様
- 特典1: 展示会ブース準備チェックリスト（5段階・27項目）
- 特典2: ブース準備度診断（10問・50点満点・4段階判定）
- 特典3: 展示会出展計画テンプレート（7セクション・空欄埋め）
- 実績: `apps/expo-apply/freebies/` としてサイト公開済み
```

## 使用方法

### 対話で使う場合（推奨）
```
/article-to-freebie https://example.com/your-article
```
または記事URLを指定せずに起動し、対象記事のURLを入力する。

### バッチ変換で使う場合
変換元の記事を複数用意し、上記プロンプトを各記事に適用する。

### 既存の特典を適用例として参照
オージャストのブース制作記事に適用した実績:
- `apps/expo-apply/freebies/booth-preparation-checklist.md` — 展示会ブース準備チェックリスト
- `apps/expo-apply/freebies/booth-readiness-diagnostic.md` — ブース準備度診断
- `apps/expo-apply/freebies/exhibition-planning-template.md` — 展示会出展計画テンプレート
- `apps/expo-apply/freebies/index.md` — 無料リソース一覧

## 技術的条件
- 変換元の記事を事前に読み込めること（URL、ファイル、または直接テキスト）
- 出力はMarkdown形式（そのままWeb公開・PDF変換・LINE配信に使いやすい）
- 出力ファイルの先頭に `<!-- X-Robots-Tag: noindex,follow -->` を付与してSEO重複を防止

## X配布とLINE登録特典としての使い方
- **X配布**: 各特典のURLを短縮し、記事引用＋「無料DLはこちら」で投稿。画像生成と組み合わせてリーチ拡大
- **LINE登録特典**: 特典PDFをLINE公式アカウントの「友だち追加特典」として設定。ダウンロードURLを自動応答メッセージに組み込む
- **サイト特典**: ブログ記事内で「この記事の内容をチェックリストにしました」と導線を設置
