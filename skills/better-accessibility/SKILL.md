# アクセシビリティ改善（better-accessibility）

展示会ブース制作サイトを WCAG 2.2 AA 準拠に向けて改善する。

## 1. 診断

- **自動チェック**: axe-core（`npx axe <URL>`）または Lighthouse アクセシビリティセクション
- **手動チェック（必須）**:
  - Tab キーだけで全操作できるか（フォーカス順序・フォーカス表示・トラップ）
  - スクリーンリーダー（VoiceOver/NVDA）で読み上げ順序が視覚順序と一致するか
  - コントラスト比（本文 4.5:1、大文字 3:1）を満たすか
  - タッチターゲットが 48x48px 以上か
  - エラーメッセージが具体的で修正方法が分かるか

## 2. 改善項目

| カテゴリ | 代表的な修正 |
|---|---|
| フォーカス | `:focus-visible` で明確な枠表示、Tab 順序の論理化（`tabindex` 不使用） |
| 色・コントラスト | 背景/文字色の比を計算（WCAG 2.2 1.4.3/1.4.11）、低コントラストは修正 |
| 代替テキスト | 装飾画像に空 `alt`、説明画像に説明文、リンク画像にリンク先を記述 |
| 見出し | H1→H6 のスキップ禁止、情報の階層と視覚階層の一致 |
| フォーム | `label` と `input` の紐付け、エラー箇所を示す `aria-describedby` |
| 動的コンテンツ | モーダル開閉のフォーカストラップ、トースト通知の `role="alert"` |
| アニメーション | 自動再生の停止手段、`prefers-reduced-motion` 対応、3 秒以上の点滅禁止 |

## 3. 修正と再検証

- 各修正後、自動チェックと手動 Tab 操作で再検証
- 全ての P0 指摘が解消されるまで繰り返す
- 最終的に axe-core の違反 0 を確認する
