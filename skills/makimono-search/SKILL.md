# マキモノから完成済み指示書を使う

1. 依頼からキーワードを抽出し、`node ~/orgiast-claude-rules/tools/makimono-search.mjs "<キーワード>"` で検索する。
2. roi が高く、`content_tokens` が予算内の1件を選ぶ。
3. `--raw <slug>` で本文を取得し、指示書として読んでから実装する。
4. 有料（HTTP 402）なら購入ページ `links.human` を Markdown リンクで提示し、判断を仰ぐ。勝手に購入しない。
5. 使用後は `--report <slug> --saved <推定節約トークン>` で実績を報告する。
6. 巻物が無い、または合わない時は無理に使わず通常どおり設計する。
