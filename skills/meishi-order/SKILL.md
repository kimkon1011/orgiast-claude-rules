# 名刺発注（マヒトデザイン クラウド法人名刺）

CLI: `node ~/orgiast-claude-rules/tools/meishi-order.mjs <check|apply|order|history> <名前|社員ID|名刺ID>`

ログイン情報は `~/.claude/secrets/mahito-meishi.env`（無ければ CLI が案内を出して exit 1）。
ログインIDはメールではなく社員ID `orgiast`。

## 手順（この順番を守る）

1. **確認**: `check <名前>` を実行し、役職・URL(https か)・裏面・申請状況を user に 3〜5 行で報告する。
   **役職や住所に変更が無いか user に確認する**（社内マニュアル上、OK をもらうまで次に進まない）。
   - 役職が「契約ディレクター/契約クリエーター/プロデューサー」以外だと CLI が「標準3種以外」と情報表示する。エラーではない。
   - 「裏面: 判定不能（画面で確認）」と出たら、裏面デザインは画面で確認してもらう。

2. **申請**: まだ申請中でなければ `apply <名前> --qty <枚数>`（既定 100。user 指定があればそれ）。
   既に申請中なら CLI が「既に申請中（申請ID xxx, 枚数 n）」と出して何もせず終了する（exit 0）。

3. **dry run**: `order <名前>` を実行する。確認画面の内容とスクリーンショットのパスが表示される。
   **この時点では注文は確定していない。**

4. **確定**: user の「OK」を得てから `order <名前> --yes`。
   **OK 前に `--yes` を付けない。** 注文は取り消せない外部システムへの実発注。

5. **報告**: 注文履歴の発送予定日・注文番号を添えて、マニュアルの完了報告テンプレを出す。

   > ご依頼の名刺発注完了いたしました。〇/〇発送メール便となります。
   > ・発送先住所
   > ・問い合わせNO（翌日には反映されます）
   > 宜しくお願い致します。

6. **報酬計上リマインド**: アシスタントタスクリスト
   https://docs.google.com/spreadsheets/d/1BTSkpcOLZ8F869vnNqPulyvbaZ1Ou7InjH5jsJH4grA/edit?gid=431931037
   の「名刺作成」行に、担当者名・回数・金額（1回 300円）を記入するよう user に伝える。

## オプション

- `--to "<配送先の一部文字列>"` … 登録済み配送先を選ぶ。`--to new --new-addr "企業名|宛名|郵便番号|番地|建物名|電話"` で「配送先情報を入力する」に直接入力できる（マスタには保存されない）。
- `--paper`（既定 `マットポスト 180kg`）/ `--corner`（既定 `なし`）/ `--pack`（既定はメール便=`トレイ`／宅配便=`紙箱`。梱包は配送方法ごとに選べる種類が違う）/ `--ship`（既定 `メール便`）/ `--days`（出荷営業日。既定 0）
- **500枚以上は配送方法が自動で「宅配便」に切り替わる**（CLI が表示する）。
- `--headful` でブラウザを表示（画面を user と一緒に見たいとき）。
- `--json` で機械可読出力。

## exit 2 が出たら（未確認画面の構造を学ぶ設計）

配送先・用紙・出荷の各画面の内部フォーム要素名は実測できていないため、CLI は**想定要素が無ければ
そのページの全フォーム要素（tag/name/id/type/options/ラベル）を stderr にダンプして exit 2** する。

1. stderr のダンプと `~/.claude/meishi-order/<日時>-error.png` を読む。
2. `tools/meishi-order.mjs` の該当ステップのセレクタ／テキスト（`chooseByText` に渡す値）を直す。
3. 再実行する。**user に画面操作を頼まない。**

## 注意

- `apply` と `order --yes` は**本番に副作用がある**。user の合意なしに実行しない。
- パスワードは env ファイルからのみ読む。argv に載せない・ログに出さない。
