# SEO 診断（seo-audit）

展示会ブース制作サイトの SEO を診断・改善する。

## 1. 診断項目

- **メタ情報**: 全ページの title・meta description・canonical・meta robots を収集。不足・重複・長すぎ/短すぎをチェック
- **サイト構造**: パンくずリスト・HTML と XML サイトマップ（`/sitemap.xml`・`/robots.txt`）の整合・404 連結状況
- **コアウェブバイタル**: PageSpeed API で LCP・FCP・CLS・TBT を取得
- **構造化データ**: 組織・パンくずリスト・FAQ・イベント（展示会）の Schema.org マークアップの有無とバリデーション（Schema.org バリデーターまたは Google リッチリザルトテスト）
- **インデックス状況**: Google Search Console API 経由のインデックス件数・カバレッジエラー・クロール統計
- **被リンク**: 簡易調査（`site:` 検索・`link:` の傾向）→ 手持ちの被リンクデータがあれば参照
- **地域SEO**: 展示会ブース制作＝地域ビジネス（実績のある会場の地名）のキーワード最適化・Google ビジネスプロフィールとの整合

## 2. 改善提案

各指摘に:
- 優先度（P0〜P2）
- 該当ページ
- 修正コード（メタ情報の編集・構造化データの追加）
- 期待される効果（CTR 改善・インデックス改善）

## 3. 検証

改善後、再度メタ情報・構造化データ・PageSpeed を測定し、効果を確認する。Google Search Console は読み取り専用で経過観察し、急激な変化（インデックス急減など）があれば報告する。
