# Web デザインガイドライン診断

展示会ブース制作サイトの UI/UX を体系的に点検する。

## 1. 点検項目

- **カラー一貫性**: ブランドカラーが全ページで統一されているか。アクセントカラー（CTA・リンク）が一貫しているか
- **タイポグラフィ**: 見出し・本文のフォントサイズ階層（H1〜H6）が適切か。行長（45〜75文字）・行間（1.5〜2.0）の基準を満たすか
- **CTA 導線**: 各ページの目的に対して CTA（問い合わせ・資料請求・ブース見積もり）が1〜2つに絞られているか。ファーストビュー内に主要 CTA があるか
- **モバイルファースト**: タップターゲット（48px 以上）・スワイプ禁止・フォームの autoComplete 設定
- **コンテンツ階層**: 展示会実績→制作事例→サービス→お問い合わせの流れがユーザーの意思決定を妨げていないか

## 2. 診断方法

- 画面上部（ナビ・H1）・中部（コンテンツ・CTA）・下部（フッタ・連絡先）の3層でスクリーンショット確認
- 競合サイト（展示会ブース制作業者の上位3社）と比較した改善余地をリストアップ
- Google PageSpeed の「UX」関連スコア（モバイル）を参照

## 3. 改善案の提示

各指摘に:
- 優先度（P0=至急 / P1=重要 / P2=余裕あれば）
- 該当ページ URL または画面領域
- 修正方針（CSS 変更・レイアウト変更・コンテンツ順序変更）
- 期待される効果（直帰率・CTR・問い合わせ率 の推定変化）

## 4. 検証

適用後、実際のページを目視確認し、改善点が意図通り当たっていることを確認する。
