# WorkBuddy スクショ→Webサイト再現スキル

## 目的

WorkBuddy（Tencent）の Code タブを使用し、スクリーンショットから Web サイトを生成する。展示会ブース提案、イベント詳細ページ、会社概要ページなど、オージャストの Web 制作フローを効率化する。

## 前提条件

- **WorkBuddy アプリ**（Mac: Apple Silicon / Intel, Windows）がインストール済み
- **WorkBuddy アカウント**（無料）でログイン済み
- **Hy4 モデル**が選択可能であること（2026-11-15 までは無料枠）
- **スクショ画像**（PNG/JPG/WebP）がローカルに保存済み

## ワークフロー

### Step 1: WorkBuddy 起動とモデル選択

```
1. WorkBuddy を起動
2. モデルピッカーから [Hy4 Free] を選択
   （他選択肢: Hy3, DeepSeek V4.1 Flash, GPT-6 variants）
3. Code タブを開く
```

### Step 2: テンプレートとエージェント選択

Code タブ内で：
1. **テンプレート**: `Website` を選択（他: App / Dashboard / Portfolio / Blank）
2. **エージェント追加**: `Frontend Developer` + `UI Designer` を追加
3. **思考モード**: `Hy4`（高思考）を選択
4. **資産アップロード**: スクショ（全面 / 主要セクション）+ ロゴ・ブランドアセットをアップロード

### Step 3: プロンプト投入

以下のセクションを含むプロンプトを投入する：

```markdown
## スクリーンショット参照
<アップロードしたスクショの説明>
（例: 「これは展示会ブース提案用LPの完成見本のスクリーンショットです。
ヘッダーにナビゲーション、ヒーローセクションにブース全景写真、
3カラムの特徴紹介、施工実績ギャラリー、CTA、フッターで構成」）

## 構造指定
- ヘッダー: ロゴ（左）+ ナビゲーション4項目（中央）+ CTAボタン（右）
- ヒーロー: フル幅背景画像 + キャッチコピー + サブテキスト
- 特徴: 3カラムグリッド（アイコン + 見出し + 説明文）
- ギャラリー: 3×3グリッド（フィルタータブ付き）
- CTA: 背景画像 + ボタン
- フッター: 会社情報 + リンク + SNS

## ブランド指定
- メインカラー: #1a3a5c（紺）
- アクセント: #e8a838（金）
- ベース: #f8f6f2（白）
- フォント: Noto Sans JP（見出し700 / 本文400）
- トーン: プロフェッショナルで信頼感のある印象

## レイアウトルール
- デスクトップ: 1200px センター固定
- タブレット: 1段組 + マージン調整（ブレークポイント 768px）
- モバイル: 全面1段組 + ハンバーガーメニュー（ブレークポイント 480px）

## インタラクティブ仕様
- ナビゲーション: ホバーで下線アニメーション
- ギャラリー: ホバーで影拡大、クリックでライトボックス
- CTA: ホバーで明るさ変化
- スムーススクロール（全アンカーリンク）

## コンポーネント一覧
1. ヘッダー（ロゴ + ナビ + CTAボタン、固定/スクロール追従）
2. ヒーローセクション（フル幅背景 + キャッチコピー + CTA）
3. 特徴3カラム（アイコン + 見出し + 説明文）
4. ギャラリーグリッド（3×3、カテゴリフィルター）
5. CTAセクション（背景 + アクションボタン）
6. フッター（会社情報 + プライバシーリンク + SNS）

## 技術スタック
- HTML5 + Tailwind CSS v4 + Vanilla JS
- Google Fonts Noto Sans JP
- レスポンシブデザイン（CSS Grid + Flexbox）
- アクセシビリティ対応（ARIAラベル、alt属性、コントラスト比）
- 日本語コンテンツ（プレースホルダー不可）
```

### Step 4: 生成実行

`Run Now` をクリック。生成中は以下が表示される：
- 進捗バー
- エージェント協調状態（Frontend Developer / UI Designer の作業分担）
- 推定残り時間（通常 1〜3分）

### Step 5: レビュー

生成完了後、以下を確認する：

| 確認項目 | 確認内容 |
|---------|---------|
| **最適化テーブル** | Performance / Accessibility / SEO / Best Practices のスコア |
| **デザイン比較** | スクショと生成結果のサイドバイサイド比較 |
| **ファイル構成** | index.html / style.css / script.js など全ファイル一覧 |
| **プレビュー** | ブラウザ実プレビュー（インタラクション動作確認） |
| **レスポンシブ** | デスクトップ/タブレット/モバイルの3ビュー |
| **コード品質** | インデント、命名規則、コメントの妥当性 |

### Step 6: エクスポート

- **ダウンロード**: ZIP で全ファイルをエクスポート
- **GitHub 連携**: リポジトリへ直接プッシュ
- **クリップボード**: コード単位でコピー

## オージャスト向けプロンプトバリエーション

### 展示会ブース提案LP

```markdown
## スクリーンショット参照
ブース全景写真、レイアウト平面図、過去提案書のスクリーンショットをアップロード

## 構造指定
hero（ブース写真）+ about（会社概要）+ gallery（施工実績 3×3グリッド）
+ features（ブース特徴3カラム）+ cta（お問い合わせ導線）

## ブランド指定
メイン #1a3a5c / アクセント #e8a838 / ベース #f8f6f2 / Noto Sans JP
```

### イベント詳細ページ

```markdown
## 構造指定
event-header（タイトル+日時+会場）+ overview + schedule（タイムテーブル）
+ map（アクセスマップ）+ gallery（過去出展写真）+ register（申込フォーム）
```

### 施工実績ギャラリー

```markdown
## 構造指定
gallery-header（タイトル+カテゴリ絞り込み）+ 4列グリッド（カード）
+ detail（カードクリックでモーダル詳細）+ contact（お問い合わせ導線）
```

## 注意事項

1. **ブランド整合性**: 生成後はオージャストのブランドガイドライン（CLAUDE.md）と照合する
2. **アクセシビリティ**: `prefers-reduced-motion` / ARIA ラベル / コントラスト比を確認する
3. **実テキスト置換**: 生成されたサンプルテキストは必ず実コンテンツに置き換える
4. **機密情報**: スクショに顧客名・金額・個人情報が写っていないことを確認する
5. **Hy4 無料枠**: 2026-11-15 以降は API 課金が必要。コスト見積もりを事前に行う
6. **フォールバック**: WorkBuddy が使えない環境では `tools/screenshot-website-builder.mjs` を Claude から直接実行し、同等のプロンプトを生成する
