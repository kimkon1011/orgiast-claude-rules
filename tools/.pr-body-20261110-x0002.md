# X-0002: 動画のGemini渡事前処理でトークン削減

## 概要

動画をそのままGeminiに渡すと1fpsで全フレームが処理され、1時間動画で約931Kトークン消費する。本PRは事前処理パイプラインを導入し、約78-89%のトークンを削減する。

## 変更内容

### 新規ファイル

| ファイル | 説明 |
|---------|------|
| `tools/video-frame-preprocessor.py` | Python メイン処理。ffmpegフレーム抽出→dHash重複間引き→3×3グリッド合成＋タイムスタンプ→字幕対応付け→メタデータJSON出力 |
| `tools/video-preprocess.mjs` | Node.js ラッパー。Python呼び出し＋Gemini CLI統合 |
| `docs/ai-news-x0002-video-preprocess.md` | 設計ドキュメント。アーキテクチャ・トークン削減効果計算・使い方 |
| `tools/video-frame-preprocessor.test.py` | 24テスト（全パス） |

### パイプライン

```
動画 → ffmpeg フレーム抽出 → dHash 重複間引き → 3×3グリッド合成
                                                    ↓
                                             メタデータJSON → Gemini
```

### トークン削減効果（1時間動画・10秒間隔）

- 従来: 360フレーム × 2587 tokens ≈ 931K tokens
- 本方式: 40-80グリッド × 2587 tokens ≈ 103-207K tokens
- 削減率: **78-89%**

### テスト結果

```
24 tests OK (Python unittest)
- dHash: 同一性・異種性・距離計算・64bit範囲
- 重複間引き: 空・単一・同一削除・異種保持
- グリッド合成: 1枚・9枚・空・カスタムサイズ
- 字幕: SRT/VTTパース・時刻変換・フレーム対応付け
- トークン推定: 基本計算・ゼロケース
```

## 使い方

```bash
# 基本
python tools/video-frame-preprocessor.py input.mp4

# 30秒間隔・厳しめ重複間引き
python tools/video-frame-preprocessor.py input.mp4 --interval 30 --threshold 3

# 字幕付き
python tools/video-frame-preprocessor.py input.mp4 --transcript captions.srt

# Node.js ラッパー（Gemini統合）
node tools/video-preprocess.mjs input.mp4 --gemini
```
