# Codex 実装指示

## 作業ディレクトリ
`C:\Users\user\.claude\nightly-repo`

## やること（コマンド1本だけ）
次のコマンドをそのまま1回実行し、標準出力と標準エラーを全文そのまま貼ること。

```
node tools/kim-awaiting.mjs --skip "ap:b6017499f99d" --reason "バックアップは claude-backup リモートで既に自動成功（2026-11-21 04:53:54 complete / claude-019-2026-11-21.zip 2357842328 bytes / rclone-verify=ok）。デスクトップのランチャーを開く操作は不要になったため不要化"
```

## 背景
この待ち項目は元々「デスクトップのバックアップ用ドライブ接続ランチャーを開いて Google で許可してほしい」という人への依頼。
実ログで確認した結果、その許可が無くてもバックアップは自動成功しているため、人に操作してもらう必要が無くなった。待ち行列から外す。

## 失敗時の対処
もし `--skip` オプションが無いと言われたら、`node tools/kim-awaiting.mjs` を実行して使い方を出力に貼ること。その出力にある正しいオプション名で再度試みる。

## 確認
実行後に `node tools/kim-awaiting.mjs` を実行し、`ap:b6017499f99d` が待ち一覧から消えたことを出力に貼ること。
