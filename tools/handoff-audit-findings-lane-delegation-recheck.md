## 記録した隙間（次に直す候補）

- **注入バナー FP（系統的・5/6 がこれ）— 2026-10-15 に修正済み**: UserPromptSubmit フックが
  全セッションの先頭に `**[委譲判定]** …` と `**[夜間判定]** 即時実行（理由: … 待機理由なし）` を
  注入する。前者に「委譲」、後者に「待機」が含まれ、機械的に共起して FP になっていた。
  `stripBanners()` を追加し `detect()` / `firstMatch()` の判定前にバナー行を除去した（対照は
  陽性6・陰性6 に拡張）。`scan` 側は改行を潰す**前**に判定するよう変えた（潰した後では
  バナーの行末が拾えず FP が戻る）。回帰ガードは test に 4 件追加（バナー単独=陰性 /
  バナー＋本物の委譲=陽性 / `stripBanners` が前後の本文を残す / `scan` 経由で 0 件）。
- 近接 80 文字は turn 内のみ。turn をまたいだ「委譲 → 次 turn で完了」は数えない＝過小評価側。
