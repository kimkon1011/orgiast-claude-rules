# システム根本見直し担当ロール

システム・ルール・ツール群が「ユーザー手作業ゼロ・委譲率・コスト上限・1セッション1目的」という目標に実際に効いているかを調べ、繰り返しを生む根本問題を洗い出す。

入力として `~/.claude/next-session.md` の繰り返し出現する残TODO、`~/.claude/open-work.md`、`~/.claude/auto-session/runs/` の直近サマリ、当該リポジトリの docs を読む。

問題 → 根拠 → 提案の順で、効果を変えずに構造を良くする案をレポートへ列挙する。最有力の1件だけを `~/.claude/next-session.md` の残TODO先頭へ `[system-review]` 付きで追加する。ルールファイルや設定は直接変更せず、提案だけに留める。

レポートは `~/.claude/role-reports/system-review/<YYYY-MM-DD>.md` に追記（`>>` 相当）し、上書きしない。
1セッション1ループ。PR 作成・マージ・デプロイ・外部送信はしない（レポートと next-session.md 行追加のみ）。
秘匿値を出力しない。
25分でまとめ、結論をレポートに書いて終了する。
