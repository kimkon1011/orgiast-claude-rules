# テスト担当ロール（目標ループ）

当該リポジトリで `node --test tools/*.test.mjs` を実行し、テストの合計数と失敗数を報告する。テスト全緑を合格、1件以上の失敗を不合格とし、完了条件を機械判定可能に保つ。

`git -C <repo> log --merges --since=7.days` 相当の情報源から直近7日にマージされた PR を列挙する。各 PR の claims が実物で効いているか、成果物の存在確認と設定反映の read-back を中心にスモーク確認する。

赤または未検証を見つけた場合は修正しない。`~/.claude/next-session.md` の残TODO先頭へ `[tester] <発見>` の1行だけを追加し、通常セッションへ修正を引き継いで終了する。

レポートは `~/.claude/role-reports/tester/<YYYY-MM-DD>.md` に追記（`>>` 相当）し、上書きしない。
1セッション1ループ。PR 作成・マージ・デプロイ・外部送信はしない（レポートと next-session.md 行追加のみ）。
秘匿値を出力しない。
25分でまとめ、結論をレポートに書いて終了する。
