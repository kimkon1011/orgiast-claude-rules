# 販管費管理オートパイロット

2026年10月〜2027年9月の正本は [販管費管理台帳](https://docs.google.com/spreadsheets/d/1E-MFGU8MSYiWf8BmXXdgIFdlFQuYLa4P9zmlLKd8o6w/edit)。Node 20 以降で動作し、追加依存はありません。日付の判定は日本時間です。

## 起動

```sh
node tools/sga-autopilot.mjs status --json
node tools/sga-autopilot.mjs init-settings --dry-run
node tools/sga-autopilot.mjs sync --dry-run
node tools/sga-autopilot.mjs approve --item "通信費" --amount 50000 --dry-run
node tools/sga-autopilot.mjs weekly --dry-run
node tools/sga-autopilot.mjs meeting-memo --month 2026/10 --dry-run
node tools/sga-autopilot.mjs watch-dm --dry-run
node tools/sga-autopilot.mjs register --dry-run
node --test tools/sga-autopilot.test.mjs
```

本番適用は監督によるマージ後に行います。`--dry-run` を外すと書き込み・通知を実行します。`--json` は全コマンドで機械可読出力。確認のみでは台帳・状態ファイル・メモ・通知・登録を変更しません。週次確認では CSV をメモリ上で反映したレポートを表示します。

設定は `init-settings`、同期は `sync`、申請は `approve`。申請の `--kind` は `アシスタント報酬` または `その他販管費`、`--month` はゼロ埋めした `YYYY/MM`。`sync --csv <path>` でローカルの仕訳も利用できます。`weekly --force-send` は同日送信防止を解除します。

認証は既存の DWD 部品を利用し、代理ユーザーは kim@orgiast.jp。Sheets は spreadsheets、Drive は既定の drive スコープを使います。必要なら `GOOGLE_SA_KEY` に鍵のパスを指定します。WSL では Windows 側の鍵のパスを指定してください。認証情報を出力しません。

## kim が送るメッセージ

Bot との個別メッセージで送信します。

- `支出 展示会の交通費 50,000`
- `アシスタント報酬に1.2万円`
- `残枠`

ほかに `備品 5万円`、`50000円 備品`、`支出 備品 ¥50000` に対応します。区分は「アシスタント」「報酬」があれば報酬、それ以外はその他です。「強制」「例外」「警戒でも」を添えると警戒モードの制限を解除します。年間上限は解除しません。対象外の会話には返信しません。

## 判定と記録

当月の区分上限から実績と未計上の承認額を引き、残枠を求めます。年間も同様です。「済」の承認は実績と二重計上しません。数値でない金額・0以下の金額・内容が「（記入例）」で始まるログは、件数にも金額にも含めません。

1. 年間残枠を超えたら却下。
2. 消化率が警戒ライン以上なら却下。明示的な例外指示だけ解除できます。
3. 区分の当月残枠を超えたら保留。翌月残枠も確認し、足りる場合だけ「翌月なら可」と案内します。
4. それ以外は承認。

保留・却下も承認ログに追記し、応答された範囲を再読込して確認します。月次は C・E・K・O の2〜13行だけ更新し、O列が「確定」で始まる月と CSV にない月は変更しません。数式・既存ログは変更しません。同期は借方・貸方の戻しを相殺します。給与・役員報酬・家賃などの未計上を考慮し、月中実績を「速報」と表示します。

設定の B2〜B12 は読み取り専用です。初期設定は A15 以降の空き行に、未登録の項目だけ追加します。既存の値は維持します。

| 既定行 | 項目 | 既定値 |
| --- | --- | --- |
| 15 | アシスタント報酬 科目 | 外注費（臼井さんに要確認） |
| 16 | 原価 科目 | 仕入・外注 |
| 17 | 売上 科目 | 売上高 |
| 18 | 販管費から除外する科目 | 空欄 |
| 19 | 週次レポート 通知先 | Discord DM（kim） |

科目は `;` 区切り。通知先の設定は説明用で、送信には既存の kim 通知経路を利用します。貸借科目・営業外科目は自動除外します。

## 定期実行

Windows で `node tools/sga-autopilot.mjs register` を実行すると次のタスクを `-Force` で登録します。実行時間上限15分、同一タスクの重複起動は抑止します。Windows のタイムゾーンは日本時間を前提とします。

| タスク | 時刻 | 処理 |
| --- | --- | --- |
| OrgiastSgaDmWatch | 10分ごと | 本人からの申請と状況照会 |
| OrgiastSgaDailySync | 毎日05:40 | 最新仕訳の同期 |
| OrgiastSgaWeekly | 月曜08:30 | 同期して週次通知 |
| OrgiastSgaMeetingMemo | 毎日07:00に起動、1日だけ実行 | 前月の打合せメモ |

非表示起動と同期リポジトリ解決は既存部品を使います。起動部品の残余引数転送でコマンドを渡します。メモは10月中は10月を対象とします。既存アップロード部品は Google ドキュメント変換に非対応なので Markdown を kim のマイドライブ直下へ保存し、再取得で内容を確認してからリンクを通知します。

## 障害時の確認

- `~/.claude/state/sga-autopilot.json`：最後の週次送信日と内容、処理済み受信番号、処理途中の受信番号。送信失敗は週次送信済みにしません。
- `~/.claude/logs/sga-autopilot/meeting-YYYY-MM.md`：打合せメモ。
- `~/.claude/logs/nightly-bootstrap-YYYY-MM-DD.log` とタスクスケジューラの履歴：起動結果。手動起動のエラーは標準エラーに出ます。
- CSV 鮮度の警告：週1回（日曜05:01 JST）の出力を前提に、CSVの日付から8日超で日付入りの注意を表示します。同期は続け、週次本文では注意を末尾に置きます。仕訳出力元の実行結果を確認してください。
- 再読込不一致：非ゼロ終了します。承認ログへの追記が既に成功している可能性があるため、台帳を確認せず同じ申請を再実行しないでください。同期が途中停止した場合は確定行以外を再同期できます。
- `~/.claude/state/sga-autopilot.json.lock`：異なるコマンド同士の同時書き込みも防ぎます。異常終了で残った場合は、記録されたプロセスが終了済みであることと台帳を確認してから削除します。
- DM は追記前に受信番号を永続化し、返信前に処理済みにします。異常終了や通信応答の喪失では、二重追記・二重返信を避けるため、返信が欠ける場合があります。処理途中の受信があれば次回は再追記せず読み取り失敗を一度案内します。再申請前に台帳を確認してください。
- 未処理のメッセージが取得上限に達した場合は、古い申請を飛ばさず停止します。通知失敗・ロック残留・大量未処理は運用担当者が確認します。

実シートへの同期・追記、通知配信、Windows タスク登録はモック試験と別です。導入時に監督が適用・確認してください。
